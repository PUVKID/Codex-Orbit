# 29차 관측소 기능

관측소와 달력은 같은 GPU 작업자를 공유합니다. 관측소는 실제 삼각형 메시·깊이 가림·금속 조명을 사용하고 모델 종류에 따른 코어와 추론 강도별 입자를 표시합니다. 중립 코어는 미확인 모델이며 솔로 추정하지 않습니다. 품질별 상한은20/30/60fps이고 일시정지·모션축소 시 불필요한 렌더를 멈추며 새 데이터가 오면 정적 화면을 갱신합니다.

작업 위성은 명시 기록의 상태만 사용합니다. 고정된 관심 채팅을 우선하여 최대24개를 배치하며 전체 작업 목록은 별도로 유지합니다. 위성을 누르면 해당 기록을 엽니다. 실제 채팅 이동을 지원한다고 주장하지 않으며 채팅 ID 복사를 사용합니다.

이전·현재 모델과 추론 강도는 동등하게 비교하고 실제 바뀐 필드만 강조합니다. 제목 장식 정리는 표시에서만 적용하며 원문 제목·정확한 모델 ID·기록된 이유를 보존합니다. 기록 재생·관심 채팅·북마크·자리비움 요약은 실제 모델 설정을 변경하지 않습니다.

사용 한도는 서버가 제공한 계정 비율을 사용하며 토큰 수가 아닙니다. 미확인은0과 구분하고 오래된 값은 상태를 표시합니다. 방송 가림은 열린 알림·상세·툴팁에 즉시 적용합니다. 진단 저장은 허용된 상태 항목만 로컬에 담고 원문·대화·경로·인증은 제외합니다. 업데이트는 사용자 요청으로 공식 릴리스를 확인하고 SHA-256·파일 크기 대조 뒤 준비하며 새 실행 확인 실패 시 이전 실행 파일을 복구합니다.
