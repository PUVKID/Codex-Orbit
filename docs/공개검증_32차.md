# 32차 검증 범위

전체 개발 회귀 560개를 두 프로세스에서 실행해 실패 없이 마쳤습니다. Windows 권한이 없는 심볼릭 링크 검사 1개는 건너뛰었습니다. 앞 그룹은 255개·76.555초, 뒤 그룹은 305개·91.977초입니다. 이 수치를 별도 중앙 운영 검증의 실행 결과로 바꾸어 쓰지 않습니다.

| 범위 | 확인한 내용 |
| --- | --- |
| 실제 EXE 화면 조작 | 800×600, 라이트·한국어100%, 다크·영어100%, 라이트·한국어150%, 다크·영어150%의 4조합. 콤보의 마우스·키보드 열기와 닫기, 선택 유지·비활성, 합성 장소 검색과 명시 선택, 이유 펼침·접기, 프라이버시 표시, 실제 글꼴 배율을 확인했습니다. |
| 실제 GPU | 날짜별 대상124개와 특집9개, 총133개의 투명 경계·입체 메시·서로 다른 프레임·정상 자원 회수를 확인했습니다. 27,028일의 일반 대상 연결을 보존하고 국가별 특집을 구분했습니다. |
| 실제 네트워크 | 공개된 경기도 수원시 중심 좌표로 실제 QtNetwork와 WeatherClient를 실행했습니다. 기온·날씨·습도·일출·일몰·시차를 받았으며 IP조회·실계정·사용자 설정 변경은 없었습니다. 응답 기상 격자는 요청 좌표 주변 자료이며 실제 사용자 위치나 현장 센서 검증이 아닙니다. |
| 국가 자료 | 250개 국가·지역의 2026~2099년 자료 파일 해시와 날짜 범위를 검사했습니다. 미래 법 개정·모든 도시 축제의 확정 자료는 아닙니다. 일부 국가의 먼 미래 자료 제한을 표시합니다. |
| 배포 | PyInstaller 단일 EXE와 Inno Setup 설치 파일을 실제로 빌드했습니다. 설치본을 실행하지 않고 읽기 전용으로 추출해 포함 EXE의 SHA-256이 단일 실행본과 같은지 확인했습니다. 기능에 필요 없는 내부 제작 기록 두 파일은 실행 자산에서 제외하고 원본을 보존했습니다. 크기와 SHA-256은 다운로드 표에 기록합니다. 실제 격리 설치 실행은 이번 검증 범위에 포함되지 않습니다. |

첫 전수 시도에는 이전 화면 문구·라벨·기본 크기를 강제하던 기대가 새 요구와 충돌했고, 실제 닫기 버튼이 테마 재적용 후20px로 줄어드는 결함도 있었습니다. 기대 변경은 근거와 함께 구분하고 실제 결함은 클릭 영역30px·150%에서45px를 복원했습니다. 두 테마·한영·100→150→100%·스타일 재적용 뒤의12상태를 확인했습니다. 첫58초/75초 시간 초과 기록과 실패 원문은 성공 결과로 덮지 않고 로컬 차수에 보존합니다.

독립 실행에서는 새 패키징 검사 모듈이 프로젝트 루트의 도구를 찾지 못한 가져오기 오류도 확인했습니다. 검사 네 가지의 기대는 유지하고 검사 파일 기준의 명시적 경로로 도구를 읽도록 수정했습니다. 해당 실패 원문과 이후 독립 재실행 결과를 구분해 보존합니다. 앱 EXE와 설치본 바이트는 이 검사 경로 수정으로 바꾸지 않았습니다.

중앙 운영 검증은 안전 시간 상한을 확대하지 않습니다. 최종 동결 이후 별도 검증자가 전수를 직접 실행하고, 입력·검사 대상·시작과 종료·성공·허용 건너뜀·실행 인자·출력 원문을 결합합니다. 중앙에서는 현재 입력과 그 결과를 다시 대조하고 지역·날씨·국가 행사·알림·이전/현재 값·종료의 핵심 검사를 새로 실행합니다. 실제 중앙 결과와 공개 반영 확인은 별도 영수증으로 판단하며 이 문서가 그 영수증을 대신하지 않습니다.

화면은 실제 배포 EXE에서 합성 기록과 합성 기상 값을 사용했습니다. 개인 채팅·실제 계정 잔량·현재 사용자 위치가 아닙니다. 네트워크 실증은 별도 시험이며 아래22.5℃·55%는 화면 검사용 수치입니다.

날짜 위젯의 고리와 보조 장식은 제거했습니다. ImageGen7개 출력과 종별 표면 타일을 실제 GPU 재질에 사용했으며, 93개 자연물 중 검토한88개에 종별 색상 타일을 적용합니다. 원본 지도는1774×887이며4K 렌더 목표와 구분합니다. 일부 꽃·잎·베리는 절차적 양식화가 남아 사진·식물도감 수준을 보장하지 않습니다. 모든 날짜·각도·기기에서 외관을 직접 확인한 결과로 확대하지 않습니다.

자동 위치는 IP 기반 추정입니다. 상세 주소를 자동으로 알아냈다고 표시하지 않고 도시·주소·장소를 검색해 고른 지점에서 제공된 항목만 표시합니다. 기상은5분 갱신이며 제공 시각과 오래된 값을 구분합니다. 정확한 남은 토큰 개수 대신 Codex가 제공한 계정 사용 한도 비율을 보여 줍니다.
