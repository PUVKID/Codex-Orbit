# 27차 GitHub 전달 재검증 범위

기존 공개본의 기준 커밋은 `7e2821ad78c85f46a131fda6f32bf82a1beee950`입니다. 27차는 26차 앱 2.10.0의 기능을 바꾸지 않고 공개 문서의 첫 화면·검증 범위·차수 설명을 정리합니다.

2026-11-02에 기존 저장소 이름과 기존 저장소 ID 조회는 404, 연결 도구 조회도 404였고 검색 결과에서도 확인되지 않았습니다. 이 관측만으로 저장소가 삭제됐는지·비공개인지·이름이 바뀌었는지는 확정할 수 없습니다. 사용자 승인에 따라 같은 프로젝트 이름으로 공개 전달을 복구합니다. 이전 404 관측과 새 게시 작업을 구분하며 [2.10.0 Release](https://github.com/PUVKID/Codex-Orbit/releases/tag/v2.10.0)의 원격 게시·해시는 별도 확인합니다.

## 보완 내용

README에서 앱의 용도·조작·권리 고지·실제 검증 요약을 바로 찾도록 배치했습니다. 기존 모든 확인 차수의 폴더·설명·직전 소스 전체 diff·파일 해시 명세 연결을 보존하고 별도 앱 소스가 없는 27차 문서 행을 추가했습니다. 20차와 최종에는 확인되지 않은 소스 폴더를 만들지 않습니다.

[26차 검증 요약](공개검증_26차.md)은 공개 87개 회귀와 개발 전체 365개 구성, 중앙 소스 127개 파일을 구분합니다. 중앙 출력 잘림·240fps 미달·계정 한도의 단위도 보존합니다. 비공개 원본 로그와 전체 소스 ZIP은 게시하지 않습니다.

## 확인 순서와 현재 한계

[공개 변경 기록](../변경기록_27차.md)을 먼저 로컬에 저장하고 실제 전체 비교·문서 링크·앱 소스 해시·공개 안전성을 독립 검토합니다. 사용자가 승인한 저장소 재생성과 커밋·푸시·Release 첨부를 진행하며, 원격 커밋·전체 파일·README 차수 연결과 다운로드 파일 해시가 일치해야 공개 반영 완료입니다.

이 문서 작성은 로컬 저장 단계입니다. 독립 검토·원격 게시·Release 파일·공식 공개 완료 검사의 통과 여부는 별도 실제 실행 근거가 필요하며 이 문서만으로 완료 처리하지 않습니다. 원격 반영 영수증은 공개 소스 밖에 보존합니다.
