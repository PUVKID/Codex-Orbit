# 38차 · 한눈에 읽는 변경 알림

**채팅 제목, 바뀐 항목, 이전·현재 값, 짧은 이유 순서로 읽도록 알림을 정리합니다.**
날짜별 픽셀 캐릭터, 관측 기록, 실제 모델 설정은 그대로 유지합니다.

| 영역 | 적용할 표시 | 보존할 정보 |
| --- | --- | --- |
| 제목 | 채팅 제목을 가장 먼저 표시 | 원래 제목과 전체 제목 툴팁 |
| 값 비교 | 모델·추론 강도의 두 행과 이전·현재 열 | 정확한 모델 ID와 강도 원값·이모지 |
| 강조 | 바뀐 현재 값에만 배경 강조 | 이전 값과 바뀌지 않은 값도 읽을 수 있게 표시 |
| 이유 | 짧은 공개 설명과 쉬운 용어 | 별도 스크롤 창의 전체 공개 원문·개인정보 가림 |
| 조작 | 설명 펼치기·고정·보관·닫기 | 순서·독립 알림·자동 닫기·호버 일시정지 |
| 테마 | 기존 사용자 색상·라이트·다크 | 글자 크기와 나눔고딕 Bold |
| 날짜 | **2026/11/25** 형식의 연·월·일 | 지역 날짜 기준·좁은 폭에서 시간 분리 |

## 읽는 순서와 조작

| 순서 | 화면 | 읽는 방법 |
| --- | --- | --- |
| 1 | 큰 채팅 제목 | 어느 채팅의 알림인지 확인합니다. 제목에는 장식 이모지를 추가하지 않습니다. |
| 2 | 변경 종류 | 모델·추론 강도 변경과 작업 재개를 구분합니다. |
| 3 | 이전·현재 비교 | 모델과 추론 강도 각각을 같은 행에서 비교합니다. 바뀐 현재 값만 강조합니다. |
| 4 | 짧은 이유 | 공개된 설명의 핵심 한 문장을 먼저 읽습니다. 없는 이유를 만들지 않습니다. |
| 5 | 설명 더 보기 | 긴 원문을 스크롤 창에서 읽습니다. 읽는 동안 자동 닫기를 멈춥니다. |
| 6 | 고정·보관·닫기 | 기존 독립 알림과 기록 보관 동작을 유지합니다. |

원문 창은 알림을 세로로 늘리지 않으며 화면 안의 크기와 위치로 열립니다.
**작은 화면에서 설명을 펼치면 알림이 넘치던 결함**을 이 방식으로 수정했습니다.
원문 창을 닫으면 자동 닫기를 재개하고, 고정한 알림은 계속 남깁니다.

## 확인 조건

| 확인 | 방법 | 판단 범위 |
| --- | --- | --- |
| 값·원문 보존 | 합성 이벤트를 넣고 이전·현재 값과 원문 펼치기 대조 | 실제 모델 변경을 새로 실행한 결과와 구분 |
| 화면 | 라이트·다크, 한영, 100%·150% 제품 알림 캡처 | 캡처한 조합의 줄바꿈·대비·잘림 확인 |
| 안전 | 비공개 본문 가림·이전값 미기록 검사 재사용 | 없는 이유나 이전 모델을 만들어 표시하지 않음 |

추가 기능 제안은 이번 화면 수정과 구분해 안내하며, 제안만 한 기능을 구현 완료로 표시하지 않습니다.
