# 29차 검증 범위

개발 전체 458개(건너뜀 1개), 공개 185개(건너뜀 0개)를 각각 실행했으며 두 실행의 종료 코드는 0입니다. 서로 다른 검사 범위이며 과거 차수 결과를 새 결과로 집계하지 않습니다.

개발 전체 검사는 개인 대화 fixture·로컬 경계 검사를 포함하므로 공개 검사와 다릅니다. 공개 기존 검사는 동작 단언을 유지하고 Notice 데이터 이름과 시험 스텁만 실제 API에 맞춥니다. 새 관측소·UI·기능·생명주기·안전 업데이트 검사는 합성 이벤트·임시 디렉터리·모의 네트워크를 사용합니다.

실제 계정 사용 한도 조회·EXE·설치·가이드·배포 해시는 별도 배포 검증으로 확인했습니다. 계정 수치·PC 식별 정보·원본 로그는 공개하지 않습니다. 4K 렌더 원본과 실제 생성/GUI/모니터 속도를 구분하며 고정240fps달성을 뜻하지 않습니다. 전체 검사는 의미상 완전 무오류나 모든 환경 지원을 보증하지 않습니다.
