# 33차·자동 지역과 강수량

기본 위치 모드는 네트워크 IP 자동 추정입니다.

사용자가 명시적으로 선택하면 국가·도시·주소 또는 장소를 수동으로 지정할 수 있습니다.

자동·수동을 화면에서 구분하고, 자동 전환 시 이전 수동 위치와 기상 값을 비운 뒤 새로 조회합니다.

수동 검색 또는 취소만으로 저장하지 않습니다.

국가만 선택하면 디자인·행사 기준만 바꾸고 날씨 위치는 별도로 표시합니다.

습도 옆의 현지 시각 안내 대신 강수량을 mm로 표시합니다.

Open-Meteo의 current.precipitation과 current.interval을 함께 검증하여 직전 집계 간격을 표시합니다.

제공 단위가 mm인지 확인하며 값·간격·단위가 없거나 유효하지 않으면 —로 표시합니다.

실제 0 mm와 미확인을 구분합니다.

일출·일몰은 기존처럼 제공 지역 시차를 사용합니다.

오래된 값은 이전 정보로 표시하고 다른 지역 값과 섞지 않습니다.

IP 추정은 GPS나 건물 주소 확인이 아닙니다. 특정 도시로 억지 보정하거나 여러 IP 결과를 평균 내지 않습니다. 검증된 좌표·국가·출처를 사용하고 실패·누락·서비스 한계를 표시합니다. 기존 250개 국가·지역 행사 범위와 법 개정·도시 축제 한계는 유지합니다.

검사 범위: 강수량 0/양수/누락/잘못된 단위·간격/지역 변경/지연, 자동 기본·자동 복귀·수동 검색 취소·국가만 선택·원자 저장과 다른 설정 보존, 한영·작은 창·100/150% 실제 화면. 기존 전체 검사는 생략하지 않습니다.

공식 근거: [Open-Meteo 응답 정의](https://open-meteo.com/en/docs). current.interval은 과거 방향 집계·평균에 사용한 초이며, 900초이면 직전 15분 강수량입니다. IP 기반 위치의 서비스 정확도와 실제 기기 위치를 동일시하지 않습니다.


## 도시 축제·행사 연결

도시 식별자와 국가가 확인되는 수록 자료를 사용합니다. 자동 IP의 도시 추정과 행사 자체의 도시 귀속은 서로 구분합니다. 이름 또는 가까운 좌표만으로 Wikidata 도시를 만들어 붙이지 않으며, Photon 장소에 GeoNames 도시 식별자가 없으면 행사 도시로 강제 매핑 하지 않습니다.

행사 시리즈 목록과 실제 발표된 개별 개최 날짜를 분리합니다.

공식 API의 일치하는 날짜 또는 공식 페이지에서 개별 교차 확인한 날짜만 달력 특집으로 사용합니다.

시각 정보가 충돌하면 공식 페이지에서 날짜를 별도 확인한 행만 날짜를 적용하고, 시간은 미확인으로 표시합니다.

일부 표본의 확인을 전체 자료의 독립 확인으로 확대하지 않습니다.

주요 고정 특집, 발표 도시 행사, 일반 국가 공휴일, 일반 날짜 조형 순으로 적용합니다.

동일 날짜의 여러 도시 행사는 안정된 식별자 순서로 대표 하나를 표시하고 목록에서 나머지 자료를 확인합니다.

종류별 메시 모티프는 음악·영화·눈·빛·카니발·꽃·문화·열 기구의 8 종입니다. 모든 개별 축제마다 독립 수작업 모델을 만들었다는 뜻은 아닙니다. 날짜 기본 대상·월별 주제·고리 없는 표현은 유지합니다.

지역 설정에서 전체 목록 항목 수와 시리즈·개최 회 차·미분류 항목, 선택 연도의 발표 개최 회차와 날짜 수, 원문 출처·라이선스를 구분해 확인합니다.

미발표 연도나 미수록 도시를 실제 행사가 없는 것으로 단정하지 않습니다. 2099년까지의 검색 범위는 미발표 미래 개최 일이 확정됐다는 뜻이 아닙니다.

최종 수록 수는 실제 생성 자료를 검증한 뒤 기록합니다.

일정 갱신은 사용자가 버튼을 누를 때만 수행합니다. 검증된 자료를 국가별 캐시에 원자적으로 적용하고, 바뀐 자료의 revision을 날짜·도시 캐시와 렌더 갱신에 연결합니다. 갱신 실패 시 기존 검증 자료를 유지하고 상태를 표시합니다. 서로 다른 라이선스 자료는 원문 고지를 보존합니다.

기온·강수량 표시는 소수 둘째 자리 아래를 버립니다.

습도와 계정 사용 한도 백분율은 소수 첫째 자리까지 ROUND_HALF_UP 방식으로 반올림하며 원값·비율·표시 방법은 툴팁에서 확인합니다. 99.99%가 반올림된 경우의 ‘약 100.0%’와 실제 100.0%를 구분합니다.

실제 집계초·저장·비교·막대 폭·원본 관측값 자체를 표시값으로 덮어쓰지 않습니다.

기본 화면의 지역 줄에는 지명만 표시하고 지역 선택 모드는 자동·수동으로 간결하게 표시합니다. 위치 확인 방식과 정확도 메타데이터는 유지하되 기본 제목·요약에 반복 안내를 붙이지 않습니다. 도움 문서의 기술적 한계는 유지하며 확인하지 않은 정확도를 보장하지 않습니다.
