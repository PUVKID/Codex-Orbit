## Revision 34 · Pixel 3D sculptures

The daily fruit, flower, calendar and announced city-event subjects are preserved in pixel rendering of actual 3D meshes. The sculpture rotates through a full turn around its vertical axis. Labels, weather and account usage remain sharp. Location controls use Automatic and Manual; the widget shows the place name without repeated source warnings. Percentage summaries round to one decimal place while original values remain available in tooltips.

Revision 33 remains an unfinished historical working revision; its separate build and publication were not completed. Revision 34 continues these location and weather features with the new pixel sculpture work.

## Revision 33 · Automatic location and precipitation

Automatic network estimation is the default. The location dialog explicitly separates Automatic and Manual. Searching or cancelling does not save a manual selection. Switching to Automatic clears the manual override and requests a new estimate. Choosing only a country changes calendar events while keeping the weather location separate. IP location is neither GPS nor a verified building address.

The humidity row shows precipitation in mm and the response’s actual backward-looking aggregation interval. Zero differs from unavailable (—); stale observations are marked as earlier information. Sunrise and sunset retain the provider’s local offset.

Appearance, language and text size are grouped at the top. Choose System, Light or Dark; the choice is saved and System follows the operating system. Overview shows recorded activity. Display settings explains reduced motion, edge docking, sound and performance options. Privacy mode hides chat titles and task descriptions on screen; stored records are unchanged.

The original daily calendar sculpture is the default desktop view. Model notifications keep its date-based title and artwork. The 3D observatory remains available as an explicit display-mode choice.

Run the portable `CodexOrbit.exe` or install `CodexOrbit-Setup.exe` for the current Windows user. Do not run both against the same data directory. Click the transparent widget for history and account usage; drag to move and use the right/bottom edges to resize.

## City festivals and announced schedules

Open Festivals and sources in location settings to separate catalog items from announced schedules for the selected or estimated city. Items include verified series, editions and unclassified records; the total is not presented as a verified series count. City identity requires supported identifiers and matching country, not merely a name or nearby coordinates. A place without a validated city identifier may have unavailable event coverage.

Only announced exact dates can activate one of eight 3D motifs: music, film, snow, lights, carnival, flowers, culture or balloon. Major fixed specials remain. These are category motifs, not individually handcrafted models for every festival. Dates, source and license remain accessible. Refresh schedules explicitly downloads validated country data and refreshes the same city/date when data changes; a failed update keeps previous verified data. The catalog is not a complete list of every city event worldwide and unannounced future dates are not invented.

## Notifications

Notifications show the chat title, previous model and reasoning effort, current model and reasoning effort, and a short explanation. Decorative emoji are removed from the displayed title without renaming the original chat. ☀️ Sol, ✨ Astra, 🌍 Terra and 🌙 Luna retain exact model IDs. Effort levels use distinct emoji. Unknown values and unpublished reasons are never invented.

Each change is presented independently. Hover pauses dismissal; pin keeps a card open; bookmark saves it in history. Changes beyond the visible-card limit remain in history. Assignment and resumed work are distinguished from setting changes.

## Live 3D observatory

Three thick metallic rings rotate on independent axes with actual depth and lighting. Model cores use a sun, crystal, globe or crescent; an unknown model uses a neutral core. Observed workers appear as satellites. Click a satellite or list entry to open its history. Pinned chats take priority, with up to 24 satellites and all workers available in the list.

Only explicit local records supply running, completed, waiting, error or aborted states. Selected settings and observed execution settings are shown separately. Previous and current values have equal emphasis; only changed fields are highlighted.

The history slider replays saved events without changing Codex settings. Since-last-visit summaries and bookmarks help find changes. Direct chat navigation is not claimed; copying a chat ID is available instead.

## Display controls

Choose English or Korean, observatory or calendar mode, rotation speed, pause, reduced motion, and Eco/Balanced/High quality. Text scale is independent of widget size. Use the left navigation to view the observatory, activity or usage separately, including in smaller windows. Edge docking folds the widget into a handle near a screen edge and expands it on hover. Monitor changes correct off-screen positions.

High-quality source frames are 3840×2160 and are delivered at the required display size. A fixed 240 fps is not promised or newly targeted. Pausing motion keeps monitoring, notifications and the clock active.

Privacy mode immediately masks titles and work descriptions in existing notifications and the open detail view, while preserving stored originals. Optional short notification sounds are off by default.

## Usage, temperature and time

Remaining usage is the actual account-limit percentage provided through the signed-in Codex installation, **not an exact remaining-token count**. Numbers, bars and the 3D container distinguish unavailable data from 0%. Stale data retain an explicit status.

Click the location label to search and explicitly select a city, address/place, or country. A selected city/place supplies coordinates for temperature, weather, humidity, sunrise and sunset. Country-only selection changes the calendar country while keeping the weather location explicit. Automatic IP location is an estimate; VPNs and routing can select another city. Windows Location Services are not required. Detailed addresses are shown only when returned by the search provider. The app does not claim automatic building-level accuracy. Failed or outdated responses retain an explicit status.

Calendar mode retains 888 monthly themes for 2026–2099 and procedural daily subjects. See the monthly-theme Markdown and CSV. The desktop calendar displays one subject without rings or side decorations. Supported country holidays and observances override ordinary daily artwork. Data cover 250 countries/territories for 2026–2099, with source limitations preserved; future legislation and every local festival are not guaranteed. Verified city time offsets apply to the matching calendar country; otherwise the Korean-date basis is explicit. This does not mean that every date has a separately hand-built model file.

## MD, diagnostics and updates

`기본_지침.md` is a shareable starter. Remove personal conversations, contact information and secrets before sharing your own Markdown. To apply instructions in Codex, use a supported instruction file in the intended project; this widget does not force instructions into all chats or expose private reasoning.

Save diagnostic file writes only whitelisted, non-sensitive diagnostics locally. It excludes conversation/event originals, credentials and personal paths, and never sends the archive automatically.

Check for update uses only official `PUVKID/Codex-Orbit` HTTPS releases. Downloads are SHA-256 verified before the user installs and restarts. A failed restart check restores the previous executable. Personal settings and Markdown are preserved. Source runs do not install themselves as a distributed EXE.

## Requirements and limits

Windows 10/11 x64 with an OpenGL 3.3 graphics driver. Monitoring uses locally available Codex records and settings, not server identity proof or private reasoning. Unrecorded reasons, previous values and activity states remain unknown. Monitor interruption/recovery notifications are emitted only when the state changes. Personal data stay in the user's AppData/CodexOrbit folder; uninstall does not silently erase them. Bundled license notices cover redistribution.
