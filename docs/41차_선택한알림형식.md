# 41차 · 선택한 알림 형식

| 표시 | 읽는 방법 |
| --- | --- |
| 채팅 제목 | 어느 채팅인지 맨 위에서 확인합니다. |
| 이전 / 현재 | 모델과 추론 강도를 같은 줄에서 비교합니다. 바뀐 현재 값만 강조합니다. |
| 모델 그림 | 태양 Sol, 별 Astra, 지구 Terra, 달 Luna입니다. 정확한 이름은 옆의 모델 ID입니다. |
| 추론 막대 | 막대 수로 강도를 구분하고 보통(medium)·높음(high)처럼 쉬운 이름과 원래 값을 함께 표시합니다. |
| 이유 | 비교표 아래에 짧은 설명을 표시합니다. 문장 속 ✅·⚠️ 같은 이모지는 유지합니다. |
| 설명 더 보기 | 기록된 전체 공개 설명을 엽니다. |
| 자세히 보기 | 이 알림에 해당하는 상세 기록을 엽니다. |
| 고정 / 기록 보관 | 자동 닫기를 멈추거나 해당 기록을 보관합니다. |

| 조건 | 처리 |
| --- | --- |
| 알림 종류 | 선택 설정은 ✅, 실행 관측 변경은 🔄, 작업 배정은 📋, 작업 재개는 ▶️로 구분합니다. |
| 이전 기록 없음 | 이전 값을 추측하지 않고 기록이 없다고 표시합니다. |
| 확대·테마·언어 | 글자 배율과 라이트/다크·한영 지원을 유지합니다. |
| 이유의 한계 | 기록된 공개 설명만 표시하며 확인하지 못한 원인이나 비공개 추론은 만들지 않습니다. |

별도 이유 상자와 세 번째 큰 버튼을 없애고, 선택한 화면처럼 설명 링크 두 개와 하단 버튼 두 개로 구성했습니다. 모델·강도 장식은 직접 그리는 그림으로 표시하며 글꼴의 이모지 지원은 유지합니다.

날짜별 과일·꽃·기념일 모션과 감시·날씨·사용 한도·설정은 바꾸지 않습니다. 운영체제에 없는 미래 이모지나 모든 환경의 무결함까지 보장하는 것은 아닙니다.
