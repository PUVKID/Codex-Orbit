# 역사 자료 공통 보관

1~28차와 최종 폴더에서 확인한 문서·제작 도구·배포 자산·디자인 시안을 원래 차수의 상대경로와 SHA-256으로 연결합니다. 내용 주소 방식으로 같은 바이트를 한 번만 보관하며 기존 불변 소스 스냅샷과 동일하면 해당 파일을 참조합니다. 현행 문서·도구·자산처럼 후속 편집 가능한 파일은 같은 SHA여도 별도의 내용 주소 사본으로 고정하여 과거 원문 참조가 바뀌지 않게 합니다. 서로 다른 원문 버전을 최신판으로 대체하지 않습니다.

이 보관 자료는 **역사 시점의 내용**입니다. 과거 계획·다운로드 주소·검증 서술은 현재 지원·배포 상태를 보증하지 않습니다. 원문 Markdown을 `.md.txt`로 보존한 경우 내용은 그대로 읽을 수 있지만 그 안의 상대 링크는 원래 폴더 기준입니다. 탐색에는 아래 차수별 목록을 사용하십시오.

공개 편집은 실제 채팅 식별자·계정 조회값·사용자 홈/프로젝트 절대경로 등의 제외/일반화로 제한합니다. 원본 SHA와 공개 SHA·크기·정제 이유를 각각 기록합니다. 개인 운영 기억·연결 상태·실관측 최종 검증 원문은 로컬 보존하고 공개에서 제외합니다. 범용 배포 안내 템플릿은 개인 원본 지침과 구분합니다.

과거 원소 영상 ZIP과 GLB는 자체 제작 고지와 제작 도구에 대응하는 자산입니다. ZIP의 이미지 항목·CRC와 GLB 메타데이터를 확인했으며 파일 크기만으로 제외하지 않았습니다. 프레임 이미지와 GLB는 조명·모션 표현이 다를 수 있고 과학적으로 정확한 원자 모델을 뜻하지 않습니다. 기존 저작권·글꼴·의존성 고지를 각 차수 명세에 함께 보존하며 새 라이선스를 부여하지 않습니다.

## 이번 보완의 실제 범위

29개 차수 상태에 원본 2,281개 항목을 대응했습니다. 원문 보존 2,111개, 정제 보존 120개, 비공개 제외 50개입니다. 공유 객체는 508개·706,764,385바이트이며 각 객체는 100 MB보다 작습니다. 항목 수는 동일 원본의 여러 차수별 대응을 포함하며 고유 파일 수와 다릅니다. 20차의 38개·21차의 110개 시안을 정적 디자인 자료로 보존합니다.
