-## 입체 관측소
-
-- Sol은 태양, Astra는 결정, Terra는 구체, Luna는 초승달 코어입니다. 모델이 미확인이면 중립 코어를 사용합니다.
-- 실제 로컬 기록에서 확인한 작업자는 위성으로 표시합니다. 위성이나 작업 목록을 누르면 해당 채팅 기록을 엽니다. ★ 관심 채팅은 우선 궤도에 표시합니다. 위성은 최대 24개이며 나머지도 목록에서 확인합니다.
-- 진행·완료·응답 대기·오류·중단은 명시된 기록이 있을 때만 표시합니다. 확인되지 않은 작업을 진행 중이나 완료로 추정하지 않습니다.
-- 이전/현재 값은 같은 비중으로 표시하고 실제 바뀐 값만 강조합니다. 선택한 설정과 실행 중 관측한 설정은 구분합니다.
-- 슬라이더는 저장된 기록을 재생합니다. 실제 Codex 모델이나 추론 강도를 되돌리는 기능이 아닙니다.
-- 자리비움 이후 기록 수와 보관한 기록을 확인할 수 있습니다. 채팅 직접 이동은 지원이 확인되지 않아 ID 복사를 제공합니다.

-## 화면 조작
-
-기록창의 조작줄과 위젯 우클릭에서 언어·회전 속도·관측소/달력 모드·일시정지·모션 축소·자원 사용을 조절합니다. **글자 크기는 위젯 크기와 별도로** 바꿉니다. 좌측에서 입체 관측소·변경 기록·사용 한도를 선택해 작은 창에서도 각 화면을 넓게 볼 수 있습니다.
-
-절전·균형·고화질은 자원 사용 상한을 조절합니다. 고품질 원본 렌더는 3840×2160이며 실제 표시 크기에 맞게 전달합니다. 초당 240프레임 달성을 보장하거나 새로 실험하지 않습니다. 모션을 정지해도 감시·알림·시계는 계속 동작합니다.
-
-가장자리 도킹을 켜고 화면 좌우 끝에 두면 작은 손잡이로 접히며, 마우스를 올리면 펼쳐집니다. 화면 연결이 달라지면 보이는 영역으로 위치를 보정합니다.
-
-프라이버시 모드는 제목·작업 설명을 이미 열린 알림과 상세창까지 즉시 가립니다. 저장 원문을 삭제하지 않습니다. 알림음은 기본 꺼짐이며 종류별 운영체제의 짧은 소리를 선택적으로 사용합니다.

-## 실제 사용 한도·날씨·시계
-
-잔량은 설치된 Codex의 로그인 상태에서 조회한 **계정 사용 한도 비율**입니다. 정확한 남은 토큰 개수가 아닙니다. 숫자와 막대, 관측소의 입체 용기로 표시합니다. 미확인은 0%와 다르며, 오래된 값은 조회 상태와 함께 구분합니다.
-
-위젯의 지역 표시를 눌러 도시·지역, 주소·장소 또는 국가를 검색하고 결과에서 직접 선택합니다. 도시·장소를 고르면 해당 지점의 현재 기온·날씨·습도·일출·일몰을 네트워크로 받습니다. 국가만 고르면 디자인 국가만 바꾸고 날씨 기준 지역은 별도로 표시합니다. 자동 위치는 IP 기반 추정이므로 VPN·통신망에 따라 다른 도시가 나올 수 있습니다. Windows 위치 서비스를 켤 필요가 없습니다. 상세 주소는 검색 결과에 있는 정보만 표시하며 실제 건물 위치를 자동으로 보장하지 않습니다. 날씨는 선택 좌표 주변의 기상 자료이며 건물마다 별도의 실측 기온을 제공하는 것은 아닙니다. 연결 실패와 오래된 값은 갱신 상태로 구분합니다.
-
-## 날짜별 조형
-
-달력 모드는 2026~2099년의 888개 연월 주제와 날짜별 대상 조형을 사용합니다. [전체 월 테마](../docs/연도별_월별_테마_전체.md)와 CSV를 확인하십시오. 날짜별 조형은 규칙에 따라 생성되며 27,028개의 개별 수작업 모델 파일이 있다는 뜻이 아닙니다. 선택 도시와 디자인 국가가 일치하고 날씨 응답에서 시차가 확인되면 해당 현지 날짜를 사용합니다. 국가만 선택해 시간대가 정해지지 않으면 한국 날짜 기준을 안내합니다. 250개 국가·지역의 공휴일과 지원 기념일에는 실제 행사명과 특집 조형을 우선합니다. 미래 법 개정이나 모든 도시 축제까지 확정한 자료는 아닙니다.
-
-## MD·진단·업데이트
-
-배포 폴더의 `기본_지침.md`는 공유 가능한 시작 자료입니다. 개인 MD를 다른 사람에게 줄 때 대화·연락처·인증값을 먼저 제외하십시오. 위젯이 Codex의 모든 채팅에 MD를 강제로 주입하거나 비공개 추론을 읽는 것은 아닙니다. Codex에 적용하려면 해당 프로젝트가 지원하는 지침 파일로 사용해야 합니다.
-
-‘문제 확인용 파일 저장’은 대화·이벤트 원문·인증값·개인 경로를 제외한 허용 항목만 **로컬 파일**로 저장합니다. 자동 전송하지 않습니다.
-
-‘새 버전 확인’은 공식 `PUVKID/Codex-Orbit` HTTPS 릴리스만 확인합니다. 새 버전을 내려받아 SHA-256을 검증한 뒤 직접 설치·재시작할 수 있습니다. 재시작 검사 실패 시 이전 실행 파일을 복구하며 개인 설정과 MD는 보존합니다. 소스 실행에서는 배포 EXE의 설치 동작을 대신 수행하지 않습니다.
-
-## 한계와 문제 확인
-
-Codex에서 로컬로 공개하는 기록·설정만 관측합니다. 서버 모델 신원이나 비공개 추론을 증명하지 않습니다. 기록이 없는 이유·이전 값·작업 상태는 확인 불가로 표시합니다. 감시가 중단되거나 복구되면 상태가 바뀔 때 한 번 알립니다.
-
-필요 환경: Windows 10/11 x64, OpenGL 3.3 지원 그래픽 드라이버. 개인 데이터는 사용자 AppData의 CodexOrbit 폴더에 유지하며 제거 프로그램은 개인 기록을 임의로 지우지 않습니다. 출처·라이선스는 배포의 라이선스 폴더를 확인하십시오.
-
-주소·장소 검색 자료는 © OpenStreetMap contributors입니다. [저작권·ODbL 안내](https://www.openstreetmap.org/copyright)를 확인할 수 있습니다. 공개 검색 서버에 검색어를 보내며 모든 장소의 수록이나 건물 단위 정확도를 보장하지 않습니다.

+## 34차 · 픽셀 입체 조형
+
+날짜별 과일·꽃·기념일과 도시 행사 주제를 유지하면서 실제 입체 모형의 픽셀 표현을 표시합니다. 모형은 세로축을 중심으로 한 바퀴 회전하며, 지명·기온·강수량·잔량과 알림 글자는 또렷하게 표시합니다. 위치는 자동·수동을 고르고 기본 화면에는 지명을 간결하게 표시합니다. 백분율 요약은 소수 첫째 자리 반올림이며 원값은 툴팁에서 확인합니다.
+
+## 지역·날씨와 도시 행사
+
+위치는 자동 네트워크 추정이 기본입니다. 지역 선택 창에서 자동·수동을 명확히 고릅니다. 수동 검색이나 취소만으로 저장하지 않으며, 자동 모드로 돌아가면 이전 수동 위치를 해제하고 다시 조회합니다. 국가만 고르면 행사 기준만 바뀌고 날씨 지역은 유지됩니다. 네트워크 추정은 GPS나 건물 주소가 아닙니다.
+
+습도 옆에는 강수량(mm)과 제공 자료의 실제 직전 집계 간격을 표시합니다. 실제 0과 미확인(—)을 구분하고, 오래된 값은 이전 정보로 표시합니다. 일출·일몰은 제공 지역의 시간대를 유지합니다.
+
+화면 위의 선택 영역에서 언어·화면 테마(시스템/라이트/다크)·글자 크기를 바꿀 수 있습니다. 테마는 즉시 적용되고 저장되며, 시스템은 운영체제의 테마 변화를 따릅니다. 왼쪽 작업 현황에서 기록된 작업과 선택 설정·최근 실행에서 확인한 값을 구분해 봅니다. 화면 설정에는 움직임 줄이기·화면 가장자리에 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인이 있습니다. 프라이버시 모드는 화면에서 채팅 제목과 작업 설명을 가리며 저장된 기록은 그대로 유지합니다. 기존 월별 주제와 날짜별 대상은 유지하고, 날짜 위젯의 고리와 좌우 보조 장식은 제거했습니다. 당일 대상 하나를 입체로 표시합니다.
+
+투명한 바탕화면에서 당일의 3D 대상 하나가 움직이며, 로컬 Codex의 모델·추론 강도 변경과 작업 배정·재개를 알려 줍니다. 개인 기록은 이 컴퓨터에 저장합니다.

+## 도시 축제와 발표 일정
+
+지역 설정의 ‘축제 목록·출처’에서 선택 도시 또는 추정 도시의 수록 항목과 발표 일정을 구분해 봅니다. 전체 항목에는 검증된 행사 시리즈, 개최 회차, 아직 분류되지 않은 항목이 함께 있으며 시리즈 수로 부풀리지 않습니다. 이름이나 가까운 좌표만으로 도시를 만들어 연결하지 않습니다. 주소·장소에 검증된 도시 식별자가 없으면 목록 지원 범위가 미확인으로 표시될 수 있습니다.
+
+실제 발표된 정확한 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열기구의 8가지 입체 모티프를 적용합니다. 주요 고정 특집은 유지합니다. 모든 개별 축제의 독립 수작업 모델이나 미발표 미래 개최일을 보장하지 않습니다. 발표 일정의 날짜·출처·라이선스를 확인할 수 있고 ‘일정 새로고침’은 검증된 국가 자료를 받아 같은 도시·날짜에도 새 자료를 반영합니다. 연결·검증 실패 시 기존 자료를 유지하고 상태를 표시합니다. 목록은 전 세계 모든 도시 행사의 완전한 사전이 아닙니다.

+투명한 바탕화면에서 당일의 3D 대상 하나가 움직이며, 로컬 Codex의 모델·추론 강도 변경과 작업 배정·재개를 알려 줍니다. 개인 기록은 이 컴퓨터에 저장합니다.
+
+## 시작
+
+1. 단일 `CodexOrbit.exe`를 실행하거나 `CodexOrbit-Setup.exe`로 현재 사용자에게 설치합니다. 둘을 동시에 같은 데이터 폴더에서 실행하지 않습니다.
+2. 위젯을 클릭하면 기록과 실제 계정 사용 한도가 열립니다. 드래그로 이동하고 오른쪽·아래 가장자리로 크기를 조절합니다.
+3. 첫 감시는 이전 기록을 기준선으로 읽습니다. 이후 새 변경을 알립니다. 선택 설정과 실행 관측은 서로 구분합니다.

+## 알림 읽기
+

+- 채팅 제목
+- ⬅️ 이전 모델 / 이전 추론 강도
+- ➡️ 현재 모델 / 현재 추론 강도

+## 입체 관측소
+
+- Sol은 태양, Astra는 결정, Terra는 구체, Luna는 초승달 코어입니다. 모델이 미확인이면 중립 코어를 사용합니다.

+- 슬라이더는 저장된 기록을 재생합니다. 실제 Codex 모델이나 추론 강도를 되돌리는 기능이 아닙니다.
+- 자리비움 이후 기록 수와 보관한 기록을 확인할 수 있습니다. 채팅 직접 이동은 지원이 확인되지 않아 ID 복사를 제공합니다.

+## 화면 조작
+
+기록창의 조작줄과 위젯 우클릭에서 언어·회전 속도·관측소/달력 모드·일시정지·모션 축소·자원 사용을 조절합니다. **글자 크기는 위젯 크기와 별도로** 바꿉니다. 좌측에서 입체 관측소·변경 기록·사용 한도를 선택해 작은 창에서도 각 화면을 넓게 볼 수 있습니다.
+
+절전·균형·고화질은 자원 사용 상한을 조절합니다. 고품질 원본 렌더는 3840×2160이며 실제 표시 크기에 맞게 전달합니다. 초당 240프레임 달성을 보장하거나 새로 실험하지 않습니다. 모션을 정지해도 감시·알림·시계는 계속 동작합니다.
+
+가장자리 도킹을 켜고 화면 좌우 끝에 두면 작은 손잡이로 접히며, 마우스를 올리면 펼쳐집니다. 화면 연결이 달라지면 보이는 영역으로 위치를 보정합니다.
+
+프라이버시 모드는 제목·작업 설명을 이미 열린 알림과 상세창까지 즉시 가립니다. 저장 원문을 삭제하지 않습니다. 알림음은 기본 꺼짐이며 종류별 운영체제의 짧은 소리를 선택적으로 사용합니다.

+## 실제 사용 한도·날씨·시계
+
+잔량은 설치된 Codex의 로그인 상태에서 조회한 **계정 사용 한도 비율**입니다. 정확한 남은 토큰 개수가 아닙니다. 숫자와 막대, 관측소의 입체 용기로 표시합니다. 미확인은 0%와 다르며, 오래된 값은 조회 상태와 함께 구분합니다.

+위젯의 지역 표시를 눌러 도시·지역, 주소·장소 또는 국가를 검색하고 결과에서 직접 선택합니다. 도시·장소를 고르면 해당 지점의 현재 기온·날씨·습도·일출·일몰을 네트워크로 받습니다. 국가만 고르면 디자인 국가만 바꾸고 날씨 기준 지역은 별도로 표시합니다. 자동 위치는 IP 기반 추정이므로 VPN·통신망에 따라 다른 도시가 나올 수 있습니다. Windows 위치 서비스를 켤 필요가 없습니다. 상세 주소는 검색 결과에 있는 정보만 표시하며 실제 건물 위치를 자동으로 보장하지 않습니다. 날씨는 선택 좌표 주변의 기상 자료이며 건물마다 별도의 실측 기온을 제공하는 것은 아닙니다. 연결 실패와 오래된 값은 갱신 상태로 구분합니다.

+## MD·진단·업데이트

+# 33차 · 자동 지역과 강수량
+
+기본 위치 모드는 네트워크 IP 자동 추정입니다. 사용자가 명시적으로 선택하면 국가·도시·주소 또는 장소를 수동으로 지정할 수 있습니다. 자동·수동을 화면에서 구분하고, 자동 전환 시 이전 수동 위치와 기상 값을 비운 뒤 새로 조회합니다. 수동 검색 또는 취소만으로 저장하지 않습니다. 국가만 선택하면 디자인·행사 기준만 바꾸고 날씨 위치는 별도로 표시합니다.
+
+습도 옆의 현지 시각 안내 대신 강수량을 mm로 표시합니다. Open-Meteo의 current.precipitation과 current.interval을 함께 검증하여 직전 집계 간격을 표시합니다. 제공 단위가 mm인지 확인하며 값·간격·단위가 없거나 유효하지 않으면 —로 표시합니다. 실제 0 mm와 미확인을 구분합니다. 일출·일몰은 기존처럼 제공 지역 시차를 사용합니다. 오래된 값은 이전 정보로 표시하고 다른 지역 값과 섞지 않습니다.
+
+IP 추정은 GPS나 건물 주소 확인이 아닙니다. 특정 도시로 억지 보정하거나 여러 IP 결과를 평균 내지 않습니다. 검증된 좌표·국가·출처를 사용하고 실패·누락·서비스 한계를 표시합니다. 기존 250개 국가·지역 행사 범위와 법 개정·도시 축제 한계는 유지합니다.
+
+검사 범위: 강수량 0/양수/누락/잘못된 단위·간격/지역 변경/지연, 자동 기본·자동 복귀·수동 검색 취소·국가만 선택·원자 저장과 다른 설정 보존, 한영·작은 창·100/150% 실제 화면. 기존 전체 검사는 생략하지 않습니다.
+
+공식 근거: [Open-Meteo 응답 정의](https://open-meteo.com/en/docs). current.interval은 과거 방향 집계·평균에 사용한 초이며, 900초이면 직전 15분 강수량입니다. IP 기반 위치의 서비스 정확도와 실제 기기 위치를 동일시하지 않습니다.
+
+
+## 도시 축제·행사 연결
+
+도시 식별자와 국가가 확인되는 수록 자료를 사용합니다. 자동 IP의 도시 추정과 행사 자체의 도시 귀속은 서로 구분합니다. 이름 또는 가까운 좌표만으로 Wikidata 도시를 만들어 붙이지 않으며, Photon 장소에 GeoNames 도시 식별자가 없으면 행사 도시로 강제 매핑하지 않습니다.
+
+행사 시리즈 목록과 실제 발표된 개별 개최 날짜를 분리합니다. 공식 API의 일치하는 날짜 또는 공식 페이지에서 개별 교차 확인한 날짜만 달력 특집으로 사용합니다. 시각 정보가 충돌하면 공식 페이지에서 날짜를 별도 확인한 행만 날짜를 적용하고, 시간은 미확인으로 표시합니다. 일부 표본의 확인을 전체 자료의 독립 확인으로 확대하지 않습니다. 주요 고정 특집, 발표 도시 행사, 일반 국가 공휴일, 일반 날짜 조형 순으로 적용합니다. 동일 날짜의 여러 도시 행사는 안정된 식별자 순서로 대표 하나를 표시하고 목록에서 나머지 자료를 확인합니다.
+

+# 도시별 축제와 발표 일정
+
+도시를 선택하면 해당 도시로 귀속이 확인된 축제 목록과 발표 일정을 조회합니다. 국가 공휴일, 축제 시리즈, 실제 개최분과 날짜는 따로 구분합니다. 국가만 선택하면 다른 도시의 축제를 임의로 적용하지 않습니다.
+
+현재 생성 중 확인한 Wikidata 축제 분류의 ID는 36,019개입니다. 동일 분류의 COUNT 결과와 ID 목록 수가 일치했으나 개별 항목의 시리즈·개최분 분류 및 도시 연결은 후속 메타데이터 검토 대상입니다. 이 수를 동봉 완료한 축제 시리즈 수나 전세계 모든 축제 수로 부르지 않습니다. 실제 동봉 집계는 생성이 끝난 index.json을 기준으로 이 문서에 반영합니다.
+
+공식 주최자·관광기관의 발표 날짜 사실표에는 2027년의 9개 개최분·9개 도시·8개 국가·114개 도시 개최일을 준비했습니다. 이 값은 해당 사실표의 범위이며 시리즈 카탈로그나 파리 전체 행사 수와 합쳐 부풀리지 않습니다. 도시 식별자 정합 검증과 최종 동봉 검증이 끝나기 전에는 전체 기능이 완료됐다고 안내하지 않습니다.
+
+일정이 발표되지 않은 연도에는 ‘일정 미발표’로 표시합니다. 매년 열린다는 정보나 보통 열리는 달만으로 2099년까지 날짜를 생성하지 않습니다. 공식 발표한 날짜만 행사 테마의 대상이 됩니다. 베네치아 거리 공연처럼 날짜가 떨어진 행사는 실제 날짜 집합만 수록하고 중간 날짜를 채우지 않습니다.
+
+도시 연결은 GeoNames 식별자 또는 검증된 Wikidata 도시 식별자와 국가를 함께 대조합니다. 장소가 공연장·공원이면 행정 소속을 확인하며 가까운 좌표만으로 어느 도시의 행사인지 확정하지 않습니다. IP 추정으로 연결된 도시에는 추정임을 유지하고 실제 사용자 위치를 확인한 것으로 표시하지 않습니다.
+
+자료 갱신은 지역 설정의 새로고침 요청으로 시작합니다. 한 국가에 하루 한 번 확인하며 앱 소유자의 공개 저장소에서 안전한 JSON 자료만 내려받습니다. 스키마·국가·해시·크기를 검증한 새 세대를 로컬 데이터 폴더에 저장한 뒤 활성 포인터를 교체합니다. 실패하거나 자료가 없으면 마지막 검증본과 기본 날짜 조형을 유지하며 실패를 표시합니다. 실행 코드·설정 업데이트와는 별개입니다. 현재 최초 게시 전의 원격 경로를 검증했다고 주장하지 않습니다.
+
+Wikidata는 CC0, 파리 시의 일정 데이터는 ODbL, 주최자 발표 날짜 사실표는 factual-schedule 분류로 파일과 출처를 구분합니다. 파리 자료의 시간대 필드가 충돌하면 정확한 UTC 시각을 표시하지 않고 확인 가능한 날짜만 사용합니다. 원천의 설명문·사진·로고·연락처는 복제하지 않습니다. 자세한 조건은 [자료 이용 고지](../assets/City-Festivals-NOTICE.txt)에 있습니다.

+# 34차 GPU 프로세스 격리
+
+날짜별 조형의 실제 GPU 작업은 전용 자식 프로세스가 실행합니다. 부모의 CalendarMotion과 감독 QThread는 기존 날짜·국가·도시·모션 시계·정지·가시성·최신 프레임 통지를 유지합니다. 96×96 픽셀 타깃, 최근접 확대, 3840×2160 원본 렌더 설정과 기존 메시·재질은 바꾸지 않았습니다.
+
+## 실행과 소유권
+
+단일 실행 파일의 orbit_entry가 일반 앱과 내부 GPU 요청을 무거운 GUI import 전에 분기합니다. 소스 실행은 현재 Python과 같은 폴더에 있는 pythonw.exe를 명시 선택하고 절대 경로의 entry를 사용합니다. 같은 실행 환경의 pythonw.exe가 없으면 명시 오류로 중단하며 콘솔 Python으로 돌아가지 않습니다. frozen 실행은 기존과 같이 동일한 windowed EXE와 내부 역할 인자를 그대로 재사용합니다. 자식은 QApplication·위젯·계정 조회·날씨 네트워크·개인 설정 저장을 시작하지 않습니다. 손상된 내부 요청은 일반 GUI로 떨어지지 않습니다.
+
+Windows CreateProcessW로 초기 스레드를 정지 상태로 만든 뒤, 부모만 소유하는 kill-on-close Job에 할당하고 재개합니다. breakaway와 핸들 상속은 허용하지 않습니다. 전역 프로세스 이름 검색이나 다른 앱 종료를 사용하지 않습니다. 이전 콘솔 소스 실행에서는 venv Python·base Python·conhost 세 프로세스를 관측했습니다. 현재 pythonw 소스 실행 한 번에서는 같은 venv의 GUI 실행기와 base GUI 실행기 두 프로세스의 실제 경로를 확인했으며, 정확한 Job 구성원 핸들을 계속 수집합니다. 종료 성공은 Job ActiveProcesses=0, 누적 구성원 수와 확보 핸들 수 일치, 각 핸들의 실제 signaled, 감독 QThread 완료, 공유 자원 회수를 함께 확인합니다.
+
+## 유한 IPC와 자료 갱신
+
+현재 사용자 SID만 허용하는 DACL과 임의 세대 nonce를 가진 Local 매핑·이벤트·뮤텍스를 사용합니다. 요청 슬롯은 65,536바이트, 응답 JSON은 16,384바이트, RGBA8888 영상 슬롯은 최대2160×2160×4바이트입니다. 헤더를 포함한 공유 매핑은 18,744,448바이트 한 개입니다. 실제 전달 크기만 복사하며, 세대·요청/응답 ID·JSON 길이·영상 폭/높이·stride·픽셀 형식·날짜/지역 문맥을 검증합니다. pickle과 무제한 Queue/Pipe를 쓰지 않습니다.
+
+GPU native 호출 동안 mutex를 보유하지 않습니다. stop 이벤트는 mutex와 독립적입니다. 부모의 짧은 수명 잠금은 stop 신호와 최종 IPC 핸들 회수만 직렬화하며, GPU 호출과 프로세스 종료 대기는 이 잠금 밖에서 수행합니다. abandoned mutex, 잘린 헤더, 이전 세대, 잘못된 크기·상태는 정상 프레임으로 받지 않습니다. 초기화는 ready 응답, 달력·관측소 렌더는 frame 응답만 허용하며 busy 응답도 기존5초 응답 기한을 넘어 대기하지 않습니다.
+
+부모 최신 QImage 한 개와 정적 fallback 한 개의 기존 계약을 유지하고, 공유 영상 슬롯 및 전송 중 유한 바이트 복사본은 별도 메모리로 구분합니다. 부모 QImage는 매핑을 외부 저장소로 계속 참조하지 않습니다. 자식의 렌더 결과를 복사한 뒤에만 최신 프레임을 교체합니다.
+
+도시 자료는 부모가 선택한 기존 읽기 전용 캐시 경로와 revision을 전달합니다. 자식은 기존 configure_city_cache와 자료 검증 경로를 사용하고, 실제 revision을 부모 값과 대조합니다. 경로 또는 revision 변경 시 날짜·국가 자료 캐시를 비웁니다. 자식이 사용자 자료를 다운로드하거나 새 설정을 저장하지 않습니다.
+
+## 종료와 한계
+
+기존2초 종료 예산 하나를 유지합니다. 정상 종료 요청 후 최대0.75초를 기다리며 필요한 경우 소유 Job만 강제 종료하고 남은 같은 예산 안에서 실제 회수를 확인합니다. 0.75초는 소스 Python 후손의 정상 정리 약0.5초 관측을 반영한 내부 배분이며 추가2초를 더하지 않습니다. native 생성·렌더·close 영구 대기는 별도 실행권을 가진 부모가 종료할 수 있습니다. OS·커널의 모든 정지를2초 안에 없앤다는 절대 보장은 아닙니다.
+
+실제 회수를 기한 안에 확인하지 못하면 False와 retiring 참조·OS 핸들을 보존하고 새 GPU 서비스 생성을 거부합니다. 다음 close에서 회수 여부를 다시 확인할 수 있습니다. 자식 crash는 실제 종료 코드와 단계, 자식 예외는 제한된 원문으로 표시하며 자동 재시작하지 않습니다. 종료 요청 전에 이미 확정된 오류 응답은 정상 취소보다 우선 보존합니다. 현재 세대·요청 ID가 일치하는 오류 JSON만 한 번 확인하고, mutex가 즉시 확보되지 않으면 기다리지 않습니다. 이 확인은 같은 종료 기한과 최대10ms의 짧은 읽기 예산 안에서 수행하며 새 요청이나 프레임 바이트 복사를 시작하지 않습니다. 강제 종료로 실제 잔존0을 확인한 결과는 자식 renderer.close가 정상 완료됐다는 뜻이 아닙니다.
+
