+### LEVEL 1 · 31차의 구체적인 기능과 확인
+
+**무엇이 달라졌나요:** 화면을 시스템 설정에 맞추거나 밝게·어둡게 고를 수 있고, 고른 화면이 바로 적용되고 저장됩니다. 같은 설정 영역에서 언어·글자 크기·회전 속도도 바꿉니다. 작업 화면은 사용자가 고른 설정과 최근 실행 기록에서 확인한 값을 따로 보여 줍니다.
+
+**어떻게 쓰나요:** 움직임 줄이기, 화면 끝에 붙이기, 알림 소리, 성능과 화질, 문제 확인용 파일 저장, 새 버전 확인은 화면 설정 메뉴에서 확인합니다. 프라이버시 모드는 화면의 제목과 작업 설명을 가리지만 기록 원문은 지우지 않습니다.

+    """Qt 예약 호출을 포함한 미처리 전달 수를 스레드 사이에서 제한합니다."""
+    def __init__(self):
+        self.lock = threading.Lock()
+        self.tickets = set()
+        self.closed = False
+
+    def acquire(self):
+        with self.lock:
+            if self.closed or len(self.tickets) >= MAX_PENDING:
+                raise RuntimeError('알림 전달 대기 한도 또는 종료 상태: 다음 감시 주기에 재시도합니다.')
+            ticket = NoticeTicket(self)
+            self.tickets.add(ticket)
+            return ticket
+
+    def available(self):
+        with self.lock:
+            return MAX_PENDING - len(self.tickets)
+
+    def close(self):
+        with self.lock:
+            self.closed = True
+            self.tickets.clear()
