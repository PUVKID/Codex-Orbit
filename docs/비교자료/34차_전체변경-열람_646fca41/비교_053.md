-
-위젯의 지역 표시를 눌러 도시·지역, 주소·장소 또는 국가를 검색하고 결과에서 직접 선택합니다. 도시·장소를 고르면 해당 지점의 현재 기온·날씨·습도·일출·일몰을 네트워크로 받습니다. 국가만 고르면 디자인 국가만 바꾸고 날씨 기준 지역은 별도로 표시합니다. 자동 위치는 IP 기반 추정이므로 VPN·통신망에 따라 다른 도시가 나올 수 있습니다. Windows 위치 서비스를 켤 필요가 없습니다. 상세 주소는 검색 결과에 있는 정보만 표시하며 실제 건물 위치를 자동으로 보장하지 않습니다. 날씨는 선택 좌표 주변의 기상 자료이며 건물마다 별도의 실측 기온을 제공하는 것은 아닙니다. 연결 실패와 오래된 값은 갱신 상태로 구분합니다.
-
-## 날짜별 조형
-
-달력 모드는 2026~2099년의 888개 연월 주제와 날짜별 대상 조형을 사용합니다. [전체 월 테마](연도별_월별_테마_전체.md)와 CSV를 확인하십시오. 날짜별 조형은 규칙에 따라 생성되며 27,028개의 개별 수작업 모델 파일이 있다는 뜻이 아닙니다. 선택 도시와 디자인 국가가 일치하고 날씨 응답에서 시차가 확인되면 해당 현지 날짜를 사용합니다. 국가만 선택해 시간대가 정해지지 않으면 한국 날짜 기준을 안내합니다. 250개 국가·지역의 공휴일과 지원 기념일에는 실제 행사명과 특집 조형을 우선합니다. 미래 법 개정이나 모든 도시 축제까지 확정한 자료는 아닙니다.
-
-## MD·진단·업데이트
-
-배포 폴더의 `기본_지침.md`는 공유 가능한 시작 자료입니다. 개인 MD를 다른 사람에게 줄 때 대화·연락처·인증값을 먼저 제외하십시오. 위젯이 Codex의 모든 채팅에 MD를 강제로 주입하거나 비공개 추론을 읽는 것은 아닙니다. Codex에 적용하려면 해당 프로젝트가 지원하는 지침 파일로 사용해야 합니다.
-
-‘문제 확인용 파일 저장’은 대화·이벤트 원문·인증값·개인 경로를 제외한 허용 항목만 **로컬 파일**로 저장합니다. 자동 전송하지 않습니다.
-
-‘새 버전 확인’은 공식 `PUVKID/Codex-Orbit` HTTPS 릴리스만 확인합니다. 새 버전을 내려받아 SHA-256을 검증한 뒤 직접 설치·재시작할 수 있습니다. 재시작 검사 실패 시 이전 실행 파일을 복구하며 개인 설정과 MD는 보존합니다. 소스 실행에서는 배포 EXE의 설치 동작을 대신 수행하지 않습니다.
-
-## 한계와 문제 확인
-
-Codex에서 로컬로 공개하는 기록·설정만 관측합니다. 서버 모델 신원이나 비공개 추론을 증명하지 않습니다. 기록이 없는 이유·이전 값·작업 상태는 확인 불가로 표시합니다. 감시가 중단되거나 복구되면 상태가 바뀔 때 한 번 알립니다.

+## 34차 · 픽셀 입체 조형
+
+날짜별 과일·꽃·기념일과 도시 행사 주제를 유지하면서 실제 입체 모형의 픽셀 표현을 표시합니다. 모형은 세로축을 중심으로 한 바퀴 회전하며, 지명·기온·강수량·잔량과 알림 글자는 또렷하게 표시합니다. 위치는 자동·수동을 고르고 기본 화면에는 지명을 간결하게 표시합니다. 백분율 요약은 소수 첫째 자리 반올림이며 원값은 툴팁에서 확인합니다.
+
+## 지역·날씨와 도시 행사
+
+위치는 자동 네트워크 추정이 기본입니다. 지역 선택 창에서 자동·수동을 명확히 고릅니다. 수동 검색이나 취소만으로 저장하지 않으며, 자동 모드로 돌아가면 이전 수동 위치를 해제하고 다시 조회합니다. 국가만 고르면 행사 기준만 바뀌고 날씨 지역은 유지됩니다. 네트워크 추정은 GPS나 건물 주소가 아닙니다.
+
+습도 옆에는 강수량(mm)과 제공 자료의 실제 직전 집계 간격을 표시합니다. 실제 0과 미확인(—)을 구분하고, 오래된 값은 이전 정보로 표시합니다. 일출·일몰은 제공 지역의 시간대를 유지합니다.
+
+화면 위의 선택 영역에서 언어·화면 테마(시스템/라이트/다크)·글자 크기를 바꿀 수 있습니다. 테마는 즉시 적용되고 저장되며, 시스템은 운영체제의 테마 변화를 따릅니다. 왼쪽 작업 현황에서 기록된 작업과 선택 설정·최근 실행에서 확인한 값을 구분해 봅니다. 화면 설정에는 움직임 줄이기·화면 가장자리에 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인이 있습니다. 프라이버시 모드는 화면에서 채팅 제목과 작업 설명을 가리며 저장된 기록은 그대로 유지합니다. 기존 월별 주제와 날짜별 대상은 유지하고, 날짜 위젯의 고리와 좌우 보조 장식은 제거했습니다. 당일 대상 하나를 입체로 표시합니다.
+
+투명한 바탕화면에서 당일의 3D 대상 하나가 움직이며, 로컬 Codex의 모델·추론 강도 변경과 작업 배정·재개를 알려 줍니다. 개인 기록은 이 컴퓨터에 저장합니다.

+## 도시 축제와 발표 일정
+
+지역 설정의 ‘축제 목록·출처’에서 선택 도시 또는 추정 도시의 수록 항목과 발표 일정을 구분해 봅니다. 전체 항목에는 검증된 행사 시리즈, 개최 회차, 아직 분류되지 않은 항목이 함께 있으며 시리즈 수로 부풀리지 않습니다. 이름이나 가까운 좌표만으로 도시를 만들어 연결하지 않습니다. 주소·장소에 검증된 도시 식별자가 없으면 목록 지원 범위가 미확인으로 표시될 수 있습니다.
+
+실제 발표된 정확한 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열기구의 8가지 입체 모티프를 적용합니다. 주요 고정 특집은 유지합니다. 모든 개별 축제의 독립 수작업 모델이나 미발표 미래 개최일을 보장하지 않습니다. 발표 일정의 날짜·출처·라이선스를 확인할 수 있고 ‘일정 새로고침’은 검증된 국가 자료를 받아 같은 도시·날짜에도 새 자료를 반영합니다. 연결·검증 실패 시 기존 자료를 유지하고 상태를 표시합니다. 목록은 전 세계 모든 도시 행사의 완전한 사전이 아닙니다.

+## 시작
+
+1. 단일 `CodexOrbit.exe`를 실행하거나 `CodexOrbit-Setup.exe`로 현재 사용자에게 설치합니다. 둘을 동시에 같은 데이터 폴더에서 실행하지 않습니다.
+2. 위젯을 클릭하면 기록과 실제 계정 사용 한도가 열립니다. 드래그로 이동하고 오른쪽·아래 가장자리로 크기를 조절합니다.
+3. 첫 감시는 이전 기록을 기준선으로 읽습니다. 이후 새 변경을 알립니다. 선택 설정과 실행 관측은 서로 구분합니다.

+- ➡️ 현재 모델 / 현재 추론 강도

+## 입체 관측소
+
+- Sol은 태양, Astra는 결정, Terra는 구체, Luna는 초승달 코어입니다. 모델이 미확인이면 중립 코어를 사용합니다.
+- 실제 로컬 기록에서 확인한 작업자는 위성으로 표시합니다. 위성이나 작업 목록을 누르면 해당 채팅 기록을 엽니다. ★ 관심 채팅은 우선 궤도에 표시합니다. 위성은 최대 24개이며 나머지도 목록에서 확인합니다.
+- 진행·완료·응답 대기·오류·중단은 명시된 기록이 있을 때만 표시합니다. 확인되지 않은 작업을 진행 중이나 완료로 추정하지 않습니다.
+- 이전/현재 값은 같은 비중으로 표시하고 실제 바뀐 값만 강조합니다. 선택한 설정과 실행 중 관측한 설정은 구분합니다.
+- 슬라이더는 저장된 기록을 재생합니다. 실제 Codex 모델이나 추론 강도를 되돌리는 기능이 아닙니다.
+- 자리비움 이후 기록 수와 보관한 기록을 확인할 수 있습니다. 채팅 직접 이동은 지원이 확인되지 않아 ID 복사를 제공합니다.

+## 화면 조작
+
+기록창의 조작줄과 위젯 우클릭에서 언어·회전 속도·관측소/달력 모드·일시정지·모션 축소·자원 사용을 조절합니다. **글자 크기는 위젯 크기와 별도로** 바꿉니다. 좌측에서 입체 관측소·변경 기록·사용 한도를 선택해 작은 창에서도 각 화면을 넓게 볼 수 있습니다.
+
+절전·균형·고화질은 자원 사용 상한을 조절합니다. 고품질 원본 렌더는 3840×2160이며 실제 표시 크기에 맞게 전달합니다. 초당 240프레임 달성을 보장하거나 새로 실험하지 않습니다. 모션을 정지해도 감시·알림·시계는 계속 동작합니다.
+
+가장자리 도킹을 켜고 화면 좌우 끝에 두면 작은 손잡이로 접히며, 마우스를 올리면 펼쳐집니다. 화면 연결이 달라지면 보이는 영역으로 위치를 보정합니다.
+
+프라이버시 모드는 제목·작업 설명을 이미 열린 알림과 상세창까지 즉시 가립니다. 저장 원문을 삭제하지 않습니다. 알림음은 기본 꺼짐이며 종류별 운영체제의 짧은 소리를 선택적으로 사용합니다.
+
+## 실제 사용 한도·날씨·시계
+
+잔량은 설치된 Codex의 로그인 상태에서 조회한 **계정 사용 한도 비율**입니다. 정확한 남은 토큰 개수가 아닙니다. 숫자와 막대, 관측소의 입체 용기로 표시합니다. 미확인은 0%와 다르며, 오래된 값은 조회 상태와 함께 구분합니다.
+
+위젯의 지역 표시를 눌러 도시·지역, 주소·장소 또는 국가를 검색하고 결과에서 직접 선택합니다. 도시·장소를 고르면 해당 지점의 현재 기온·날씨·습도·일출·일몰을 네트워크로 받습니다. 국가만 고르면 디자인 국가만 바꾸고 날씨 기준 지역은 별도로 표시합니다. 자동 위치는 IP 기반 추정이므로 VPN·통신망에 따라 다른 도시가 나올 수 있습니다. Windows 위치 서비스를 켤 필요가 없습니다. 상세 주소는 검색 결과에 있는 정보만 표시하며 실제 건물 위치를 자동으로 보장하지 않습니다. 날씨는 선택 좌표 주변의 기상 자료이며 건물마다 별도의 실측 기온을 제공하는 것은 아닙니다. 연결 실패와 오래된 값은 갱신 상태로 구분합니다.

+## 날짜별 조형

+## MD·진단·업데이트
+
+배포 폴더의 `기본_지침.md`는 공유 가능한 시작 자료입니다. 개인 MD를 다른 사람에게 줄 때 대화·연락처·인증값을 먼저 제외하십시오. 위젯이 Codex의 모든 채팅에 MD를 강제로 주입하거나 비공개 추론을 읽는 것은 아닙니다. Codex에 적용하려면 해당 프로젝트가 지원하는 지침 파일로 사용해야 합니다.
+
+‘문제 확인용 파일 저장’은 대화·이벤트 원문·인증값·개인 경로를 제외한 허용 항목만 **로컬 파일**로 저장합니다. 자동 전송하지 않습니다.
+
+‘새 버전 확인’은 공식 `PUVKID/Codex-Orbit` HTTPS 릴리스만 확인합니다. 새 버전을 내려받아 SHA-256을 검증한 뒤 직접 설치·재시작할 수 있습니다. 재시작 검사 실패 시 이전 실행 파일을 복구하며 개인 설정과 MD는 보존합니다. 소스 실행에서는 배포 EXE의 설치 동작을 대신 수행하지 않습니다.

+### LEVEL 1 추가 해설 · 앱의 목적과 사용

+Codex Orbit은 Windows 바탕화면에서 날짜에 맞는 입체 모형과 시계·날씨·사용 한도 등을 보여 주고, 컴퓨터에 남은 Codex 작업 기록을 읽어 변화가 있을 때 알려 주는 앱입니다. **입체 모형**은 평면 그림이 아니라 깊이가 있는 형상입니다. 관측소는 사용자가 선택할 때 열리는 별도 화면입니다.

+위젯을 누르면 기록과 사용 한도 화면을 열 수 있습니다. 드래그하여 위치를 바꾸고 가장자리에서 크기를 조절합니다. 지역을 직접 검색할 수 있으며 자동 위치는 인터넷 기반의 대략적인 추정입니다. 날씨의 미확인 값은 0과 다릅니다. 잔량은 **계정 사용 한도 비율**이며 남은 토큰 개수가 아닙니다.

+### LEVEL 1 추가 해설 · 처음 시작하고 화면 읽기

+1. Windows 10 또는 11의 64비트 컴퓨터와 OpenGL 3.3을 지원하는 그래픽 드라이버를 준비합니다. 단일 `CodexOrbit.exe`를 열거나 설치본을 사용할 수 있습니다. 두 실행본을 같은 데이터 폴더에서 동시에 열지 않습니다.

+### LEVEL 1 추가 해설 · 알림과 관측소

+
+도시·장소를 선택하면 그 좌표 주변의 날씨를 읽습니다. 예를 들어 국가만 선택한 경우에는 행사 디자인의 국가만 달라지고, 날씨는 기존 지역을 기준으로 유지됩니다. 선택 도시와 디자인 국가가 같고 날씨 자료에 시차가 있으면 현지 날짜를 쓰며, 국가만 선택해 시간대를 알 수 없으면 한국 날짜 기준을 알립니다.

+발표된 정확한 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열기구의 여덟 모형 주제를 적용합니다. 각 축제를 별도 수작업 모형으로 만든 것은 아니며 주요 고정 특집은 유지합니다. ‘일정 새로고침’은 검증된 국가 자료를 받아 같은 도시·날짜에도 새 일정을 반영합니다. 연결이나 자료 검증에 실패하면 이전 자료를 유지하고 실패 상태를 표시합니다. 출처·날짜·라이선스와 수록 범위를 함께 확인합니다.

+### LEVEL 1 추가 해설 · 화면을 조절하고 기록을 해석하는 예

+언어·시스템/라이트/다크 테마·글자 크기는 선택 즉시 반영하고 저장합니다. 시스템 테마는 운영체제의 테마 변화를 따릅니다. 작은 창에서는 왼쪽에서 관측소·변경 기록·사용 한도를 골라 넓게 볼 수 있고, 모니터 연결이 달라지면 위젯 위치를 보이는 영역으로 옮깁니다. 알림음은 기본 꺼짐이며 종류별 짧은 운영체제 소리를 선택할 수 있습니다.

+### LEVEL 1 추가 해설 · 처리 과정과 실패를 읽는 방법
+
+앱은 파일 읽기 → 새 변화 분류 → 알림·이력 표시 순서로 동작합니다. 감시가 중단되거나 복구되면 상태가 바뀔 때 한 번 알립니다. 오래된 설정 자료가 잘못됐다고 자동으로 빈 자료로 덮어쓰지 않습니다. 계정 한도와 날씨는 로컬 기록 읽기와 별도의 조회입니다. 30차 소스 설명의 한도 조회는 30초마다 갱신하고 12초 응답 제한, 65초 뒤 오래된 자료 표시를 사용합니다. 연결 실패 시 3·6·9초 간격으로 최대 세 번 재연결하며 실패를 0%로 바꾸지 않습니다.
+
+34차의 입체 계산은 앱이 소유한 별도 프로세스, 곧 따로 실행되는 계산 프로그램에서 합니다. 첫 그림 준비는 최대 5초이고, 준비 뒤 화면에 그림이 도착하는 기존 2초 검사는 별개입니다. 닫을 때 정상 종료를 먼저 요청하고 필요하면 앱이 소유한 작업 묶음만 종료합니다. Windows의 모든 멈춤을 이 시간 안에 해결한다는 보장은 없습니다.
+
+### LEVEL 1 추가 해설 · 소스·권리와 논문 여부
+
+단일 EXE는 Python 설치 없이 실행하며 설치본은 현재 사용자용 바로가기와 제거 기능을 제공합니다. 제거할 때 사용자 AppData의 개인 기록을 임의로 지우지 않습니다. 공개 소스는 저장소나 GitHub의 Source code ZIP에서 받습니다. 소스를 직접 다시 만들려면 해당 버전의 도구·자산·라이선스를 먼저 준비한 뒤 `python -B -X utf8 tools/build_distribution.py`를 사용합니다. 이 명령이 있다는 것과 현재 컴퓨터에서 빌드가 성공한 것은 별개입니다.
+
+배포의 `기본_지침.md`는 시작 자료이며 개인 문서는 대화·연락처·인증값을 확인하고 공유합니다. 프로젝트가 지원하는 지침 파일로 적용해야 하며 모든 열린 채팅에 강제로 넣거나 비공개 추론을 읽지 않습니다. 개인 대화·지침·인증 자료와 비공개 전체 개발 ZIP은 배포하지 않습니다. 기존 라이선스를 보존하며 새 라이선스를 임의 부여하지 않습니다. **이 앱 작업에는 논문·원고가 없어 논문 PDF를 만들지 않았습니다.**

+### LEVEL 1 추가 해설 · 34차의 변화와 검증
+
+**목적과 변화:** 날짜에 어울리는 과일·꽃·기념일이나 도시 행사 모양을 바탕화면에 보여 줍니다. 입체 모형을 작은 점처럼 표현하는 픽셀 방식으로 그리며, 모형이 세로축을 중심으로 한 바퀴 돕니다. 위치·날씨와 남은 사용 한도 글자는 알아보기 쉽게 따로 표시합니다.
+
+**준비와 사용:** Windows 10 또는 11의 64비트 환경과 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. 단일 실행 파일을 열거나 설치본을 사용할 수 있습니다. 위젯을 누르면 기록과 한도 화면을 볼 수 있고, 지역 표시를 눌러 자동 추정이나 직접 검색한 지역을 선택할 수 있습니다. 자동 위치는 인터넷 주소에 따른 추정이어서 실제 건물 위치와 다를 수 있습니다.
+
+**무엇을 확인하나요:** 강수량은 제공된 집계 간격을 함께 읽고 실제 0과 확인되지 않은 값을 구분합니다. 백분율은 소수 첫째 자리로 반올림해 보여 주며 원값은 툴팁에서 확인합니다. 도시 행사는 발표된 정확한 날짜에만 해당 모티프를 적용합니다.
+
+**주의:** 모든 도시 행사나 발표되지 않은 미래 날짜가 수록된 것은 아닙니다. 33차는 별도 출시 없이 진행한 기록이고, 34차 검증 결과와 구분해 읽어야 합니다. 한도 비율은 남은 토큰 개수가 아닙니다.
+
+
+**검증 범위:** 검사에서는 총 653개 중 실패가 없었고 1개는 건너뛰었습니다. 실제 프로그램의 네 화면 조합에는 예시 날씨와 도시 자료를 사용했습니다. 설치 파일은 실행 설치가 아니라 내용만 꺼내 확인했습니다. 날씨 조회에는 8초 제한이 있으며 처음 조회가 시간 초과된 뒤 다시 한 번 성공했지만, 첫 실패 이유는 확인되지 않았습니다. 다른 방식의 보조 GPU 진단에서는 첫 화면을 제시간에 받지 못했고 종료 뒤 남은 작업이 없음을 확인했습니다.

+지역 설정은 자동 네트워크 추정과 수동 선택 상태를 분리합니다. 검색하거나 취소하는 동작은 저장 선택과 같지 않습니다. 자동으로 돌아가면 수동 위치를 해제하고 다시 조회합니다. IP 추정은 GPS나 건물 주소가 아니고 Windows 위치 서비스를 요구하지 않습니다. 주소·장소 검색은 공개 서버에 검색어를 보내며 OpenStreetMap 자료를 사용하므로 모든 장소와 건물 단위 정확도를 보장하지 않습니다.
+
+날씨 좌표와 디자인 국가는 서로 다른 설정입니다. 국가만 고르면 행사 국가만 바뀌고 날씨는 기존 좌표를 유지합니다. 선택 도시와 국가가 일치하고 날씨 응답의 시차가 확인될 때 현지 날짜를 사용합니다. 시간대를 특정하지 못하는 국가 선택에는 한국 날짜 기준을 안내합니다. 강수량도 수치와 제공 집계 간격이 한 묶음이며 일출·일몰은 제공 지역 시간대를 유지합니다.
+
+도시 식별자는 이름·거리로 임의 추정하지 않습니다. 주소에 검증된 도시 ID가 없으면 목록 지원이 미확인일 수 있습니다. ‘축제 목록·출처’는 행사 시리즈·특정 개최분·미분류 항목 및 발표 일정을 분리하므로 전체 목록 행 수가 시리즈 수는 아닙니다. 정확하게 발표된 날짜에 음악·영화·눈·빛·카니발·꽃·문화·열기구의 8종 모티프를 적용하고 주요 고정 특집은 유지합니다. 독립 수작업 축제 모델이나 미발표 미래 날짜를 보장하지 않습니다. 일정 새로고침은 검증된 국가 자료를 받아 같은 도시·날짜의 새 자료도 반영하되 실패 때 기존 자료와 오류 상태를 보존합니다.
+
+### LEVEL 2 추가 해설 · 표시 설정과 기록 보존의 관계
+
+시스템·라이트·다크 테마는 즉시 적용·저장되며 시스템 선택은 운영체제 변화를 따릅니다. 글자 크기는 창 크기와 독립적입니다. 작은 창은 왼쪽 탐색으로 관측소·이력·한도 중 하나를 넓게 보여 줍니다. 모니터 구성이 바뀌면 보이는 영역으로 위치를 보정합니다. 알림음은 기본 꺼짐이며 종류별 운영체제 소리를 선택합니다. 모션 일시정지는 실제 시계와 감시를 멈추지 않고 품질 선택은 자원 상한을 조정합니다.
+
+Sol/태양·Astra/결정·Terra/구체·Luna/초승달과 중립 코어는 시각 식별 수단입니다. 관심 채팅의 우선 궤도와 24개 위성 상한, 나머지 기록 목록을 구분합니다. 위성·목록은 앱 내부 기록을 열며 직접 Codex 채팅 이동은 확인되지 않아 ID 복사를 제공합니다. 이모지 제거는 제목 표시만 정리합니다. 정확한 모델 ID와 기록된 강도 없음·최소·낮음·보통·높음·매우 높음·최고를 유지하고 기록 없는 값은 만들지 않습니다.
+
+### LEVEL 2 추가 해설 · 감시와 외부 조회·종료의 관계
+
+로컬 JSONL은 줄마다 기록을 담는 파일이며 최초 읽기는 기준선, 이후 변화는 새 이벤트로 분류합니다. 감시 중단·복구는 상태 전환 때 한 번 알립니다. 30차 기록 읽기의 상한은 묶음 512KiB·기록 하나 2MiB·파일 4096개·주기 전체 8MiB·대기 256개·주기 0.2초입니다. 이는 자원 제한이며 실제 처리율 성과가 아닙니다.
+
+계정 조회는 별도 파이프로 Codex app-server에 읽기 요청합니다. 30차 소스의 30초 갱신·12초 응답 제한·65초 후 오래된 값 표시와 최대 세 번 3/6/9초 재연결을 구분합니다. 종료에서는 요청을 정리하고 500ms 기다린 뒤 필요하면 강제 종료 후 다시 500ms 기다립니다. 날씨는 네트워크, 감시는 로컬 읽기이므로 한쪽 실패가 다른 기능의 성공을 뜻하지 않습니다.
+
+34차는 입체 계산을 소유한 별도 프로세스에 둡니다. 최대 5초 준비와 준비 뒤 기존 2초 표시 검사는 다른 단계입니다. 정상 회수를 먼저 요청하고 필요한 경우 소유 Job, 곧 앱이 만든 프로세스 묶음만 강제 회수합니다. 운영체제의 모든 정지를 기한 안에 해결한다는 보장은 없습니다.
+
+### LEVEL 2 추가 해설 · 공개 소스와 문서·권리
+
+배포 EXE는 Python 없이 실행하고 현재 사용자용 설치·제거를 제공합니다. 제거 프로그램은 AppData 개인 기록을 임의 삭제하지 않습니다. 저장소와 Source code ZIP의 공개 소스는 비공개 전체 개발 ZIP과 구분합니다. 버전별 의존성·자산·라이선스를 준비한 소스 재빌드 명령은 `python -B -X utf8 tools/build_distribution.py`이며 실제 재현 여부는 검증 근거를 읽습니다.
+
+공유 가능한 기본 MD와 개인 MD를 구분하고 개인 대화·연락처·인증값은 제외합니다. 지침 파일은 해당 프로젝트가 지원하는 방식으로 적용하며 모든 채팅 자동 주입이나 비공개 추론 열람을 제공하지 않습니다. 진단은 허용 항목의 로컬 저장, 업데이트는 공식 릴리스 확인·SHA-256 지문 대조·실행 검사·실패 복구의 연결입니다. 개인 설정과 MD는 보존하며 소스 실행이 설치 EXE 교체를 대신하지 않습니다. 기존 라이선스를 유지하고 임의로 새 라이선스를 붙이지 않습니다. **원고 없는 소프트웨어 작업이므로 논문 PDF는 없습니다.**
