+Windows에 해당 의존성·원소 프레임·글꼴과 라이선스를 준비하고 날짜별 원소와 사용 한도 표시를 각각 확인합니다. 원자번호와 계정 비율의 라벨을 구별하고 실제 한도 비율은 별도 App Server 응답과 대조합니다. 캐시 제한과 활성 원소만 여는 동작은 element_frames.py의 선언을 확인합니다. 자산 오류를 이전 형상으로 대신한 성공 화면으로 읽지 않습니다.
