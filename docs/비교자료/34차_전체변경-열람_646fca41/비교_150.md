+def normalize_paris(source, checked_at, rejections=None):
+    def reject(reason):
+        if rejections is not None:rejections[reason]=rejections.get(reason,0)+1

+    try:

+    except (KeyError,TypeError,ValueError):return reject('missing_or_invalid_bounds')
+    if raw_start.tzinfo is None or raw_end.tzinfo is None or raw_end<raw_start:return reject('missing_or_invalid_bounds')

+날짜별 과일·꽃·기념일과 도시 행사 주제를 실제 입체 메시의 픽셀 렌더로 표시하고 세로축으로 한 바퀴 회전합니다. 글자·날씨·잔량은 또렷하게 유지합니다. 자동·수동 위치와 강수량 집계 간격, 소수 첫째 자리 반올림·원값 확인을 이어받습니다. 도시 축제 목록 항목과 발표 일정, 근거 있는 시리즈·개최분·미분류를 구분합니다. 공식 날짜만8종 행사 모티프로 연결하고 출처·라이선스·갱신과 수록 한계를 표시합니다. 전 세계 모든 행사나 미발표 미래 날짜를 보장하지 않습니다. 33차는 별도 릴리스 없이 진행한 원문을 이번 공개에 보존하고34차에 통합했으며, 당시 진행 상태와34차의 실제 검증 결과를 구분합니다. GPU 작업은 별도 소유 프로세스에 격리하고 일반 앱과 내부 GPU 진입을 분리합니다. 최대5초 준비와 준비 뒤 표시 프레임의 기존2초 검사는 별개이며, 종료는 정상 회수를 먼저 요청하고 필요한 경우 소유 Job만 한정해 강제 회수합니다. OS의 모든 정지를 기한 안에 해결한다는 보장은 아닙니다. 실제 최종 결과는 검증 문서에서 구분해 확인합니다.
+
+[전체 비교](docs/34차_전체변경.diff)는 주석·공백과 바이너리 차이를 포함합니다.
+
+## 다섯 읽기 수준 설명
+
+실제 1~34차와 최종본을 다섯 읽기 수준으로 연결했습니다. 기존 전체 원문과 코드·관측값·실패 이력을 보존하며, 각 차수의 기능·조건·결과·한계와 같은 수준의 차수 연결을 제공합니다. 초급도 단순 축약본으로 대체하지 않았습니다.
+
+## 최신 문서와 34차 변경의 연결
+
+기준은 기존 문서의 모바일 목차와 다섯 읽기 수준 정리를 포함하는 공개 커밋 `6744103c62dc2c911d97261bbe735a770f9b5808`입니다. 기존 원문·수치·코드·차수 주소와 문서 정리 기록을 보존하면서 각 수준에 구체적인 기능·조건·확인 설명을 보강했습니다. 33·34차 자료와 현재 사용법·다운로드를 함께 연결했으며, 문장과 링크 목차는 전체 폭을 사용합니다. 기존 문서 정리의 전체 비교는 원래 문서에 보존하고 이번 실제 전체 비교는 위 기준 커밋 이후의 변경을 기록합니다.
+
+## 이전 후 독립 검사 기록
+
+첫 중앙 시간 초과와 같은 소스·명세의 후속 독립 통과를 구분해 [추가 검증](docs/34차_이전후_추가검증.md)에 기록했습니다. 최초 원인은 미확정이며 제한을 완화하거나 실패를 삭제하지 않았습니다.
+
+## 배포 사용법의 다섯 수준 안내
+
+개발 원본과 동봉 사용법 5경로의 첫 제목 뒤에 다섯 설명으로 이동하는 작은 웹 링크를 추가했습니다. 원래 본문과 상대 주소를 유지했고 [가이드 수리 범위](docs/34차_배포사용법_수준안내.md), [현재 원문 목록](history/34차/변경원문.json), [실제 가이드 비교](history/34차/배포사용법_변경.diff)를 연결합니다. 가이드 보강 후 재빌드와 새 배포 검사를 확인했으며 이전 바이트·실패 관측은 별도 역사로 보존합니다.
+
+## 표 구성과 새 배포 가이드
+
+기존 원격의 본문·모든 표 필드와 값을 보존하고, 최신 표 구성으로 비교와 탐색을 복원했습니다. 차수 목차는 차수·핵심 변경·자료 3열이며 같은 행에서 폴더·상세·직전 비교를 연결합니다. 수준별 설명·모든 원문·코드·수치·앵커를 보존합니다. [표 변환의 실제 비교](docs/34차_표구성_변경.diff)와 [현재 가이드·배포 확인](docs/34차_배포사용법_수준안내.md)을 연결합니다. 새 배포의 실제 크기·SHA는 다운로드 문서에 따로 갱신하고 이전 바이트와 실패 관측은 역사로 유지했습니다.
