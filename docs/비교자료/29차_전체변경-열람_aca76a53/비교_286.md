+def run(argv, name, timeout):
+    """실제 인자와 종료 결과를 별도 파일에 보존합니다."""
+    started = time.time()
+    build_env = os.environ.copy()
+    base_python = Path(sys.base_prefix)
+    windows = Path(os.environ.get('SystemRoot', r'C:\Windows'))
+    # 외부 PDF 도구 등의 동명 ICU DLL이 Qt 의존성으로 들어오지 않게 합니다.
+    build_env['PATH'] = os.pathsep.join(map(str, [Path(sys.executable).parent, base_python,
+                                                windows / 'System32', windows]))
+    process = subprocess.Popen(argv, cwd=ROOT, stdout=subprocess.PIPE,
+                               stderr=subprocess.STDOUT, shell=False, env=build_env)
+    captured = bytearray()
+    total_bytes = 0
+    def collect():
+        nonlocal total_bytes
+        while True:
+            chunk = process.stdout.read(65536)
+            if not chunk:
+                break
+            total_bytes += len(chunk)
+            captured.extend(chunk[:max(0, 524288 - len(captured))])
+    reader = threading.Thread(target=collect, daemon=True)
+    reader.start()
+    timed_out = False
+    try:
+        exit_code = process.wait(timeout=timeout)
+    except subprocess.TimeoutExpired:
+        timed_out = True
+        subprocess.run(['taskkill', '/PID', str(process.pid), '/T', '/F'],
+                       stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL, timeout=15)
+        exit_code = process.wait(timeout=15)
+    reader.join(timeout=5)
+    process.stdout.close()
+    raw = bytes(captured)
+    (ROOT / 'work' / (name + '.raw')).write_bytes(raw)
+    try:
+        decoded = raw.decode('utf-8')
+        valid_utf8 = True
+    except UnicodeDecodeError:
+        decoded = raw.decode('utf-8', errors='replace')
+        valid_utf8 = False
+    output = decoded.encode('utf-8')
+    (ROOT / 'work' / (name + '.log')).write_bytes(output)
+    record = {'argv': argv, 'cwd': str(ROOT), 'exit_code': exit_code, 'timed_out': timed_out,
+              'started_at': started, 'elapsed_seconds': time.time() - started,
+              'output_bytes': total_bytes, 'captured_bytes': len(raw),
+              'valid_utf8': valid_utf8, 'output_truncated': total_bytes > len(raw)}
+    (ROOT / 'work' / (name + '.json')).write_text(
+        json.dumps(record, ensure_ascii=False, indent=2), encoding='utf-8')

+## 회전 속도 조절
+
+상세창 위쪽의 **회전 속도** 슬라이더를 움직이면0.25~3배로 바뀝니다. **1배 복원**으로 기본 속도로 돌아갑니다. 바탕화면 위젯을 우클릭하고 **회전 속도**에서도0.25·0.5·1·1.5·2·3배를 선택할 수 있습니다. 선택은 저장되어 재실행 뒤에도 적용됩니다.
+
+배율은 링과 조형의 재생 속도에만 적용되며 실제 시각·날짜·날씨·잔량의 갱신 주기는 그대로입니다. 변경 순간의 각도를 이어서 재생하며 프레임 목표240과 회전 배율은 별도로 처리합니다. 실제 생성률·GUI 그리기와 물리 모니터 표시율은 각각 확인해야 합니다.

+## 매일 바뀌는 조형
+
+한국 날짜 기준 2026-01-01부터 2099-12-31까지 27,028일을 지원합니다. 37개 주제 모티프와24개 동반 모티프의 서로 다른 쌍으로888개 연월 컬렉션을 구성하며 두 모티프와 날짜별 주연 대상을 실제 형상 규칙에 연결합니다. 같은12개 월 테마를 매년 반복하지 않습니다. 위젯에는 실제 대상 이름을 표시하며 월 테마는 카탈로그에 별도로 기록합니다. 공통 형상 생성기를 재사용하는 장식용 조형이며888개 수작업 모델이나 과학 도감 수준의 정확한 복제품이라는 뜻은 아닙니다. 전체 연월 목록은 함께 제공하는 `연도별_월_테마.md`와CSV, 원본은 [테마 설명](assets/calendar-art/themes.md) 및 [CSV](assets/calendar-art/themes.csv)에서 확인합니다.
+
+자정 이후 다음 프레임에 한국 날짜를 다시 확인하고 조형과 도크를 바꿉니다. 절전에서 복귀하거나 시계를 되돌려도 날짜를 재확인합니다. 수만 개 영상을 넣지 않고 그날의 실제 삼각형 메시만 렌더합니다. 굵은 금속 링 세 개가 서로 다른 축에서 각각12초·6초·4초에 한 바퀴씩 연속 회전합니다. 바탕화면과 내부 모션은 한 GPU 작업자·한 컨텍스트·최신 이미지와 정적 준비 이미지 두 장을 공유하며 3840×2160 원본을 GPU에서 렌더하고 작은 위젯에 맞춰 축소 전달하며 초당 240프레임을 목표로 합니다. 실제 생성·전달 속도는 PC 부하와 그래픽 장치에 따라 달라지며 모니터의 실제 표시 주사율과는 구분합니다. 표시 대상이 없으면 렌더를 쉽니다. 날짜 카탈로그는 [assets/calendar-art/catalog.json](assets/calendar-art/catalog.json)에 있습니다.

+## 변경 기록과 실제 한도
+
+위젯에는 PC의 현지 시각을 초 단위로 표시하며, 인터넷 접속 IP의 대략적인 지역에서 현재 기온을 조회합니다. Windows 위치 서비스는 필요하지 않습니다. 지역 조회는 ipwho.is, 기온은 Open-Meteo의 최신 현재 기온 자료를 사용하며5분마다 자동 갱신합니다. 정확한 GPS 위치나 초 단위 현장 온도 센서 측정은 아니며 VPN·통신사망에서는 실제 지역과 다를 수 있습니다. IP로 추정한 전 세계 지역명을 선택한 한국어·영어로 표시하고, 번역이 없으면 실제 원래 지명을 표시합니다. 기온과 지역은 별도 줄로 표시하며 지명을 임의로 창작하지 않습니다. 긴 지역명은 말줄임하고 전체 지역명·출처·조회 시각은 툴팁에 표시하며, 조회 실패나 오래된 값은 정상 최신 기온으로 표시하지 않습니다. 앱은 IP·좌표·이동 이력을 저장하지 않습니다.
+
+알림과 상세에서 모델 및 추론 강도를 각각 **이전 → 변경 후** 두 칸으로 표시합니다. 실제로 달라진 행만 강조합니다. 작업 배정·재개는 별도 종류이며 현재 설정을 표시합니다. 이전 기록이 없거나 필드가 미기록이면 사실대로 표시하고 과거 값을 추정하지 않습니다. 정확한 채팅 제목·맡긴 일·공개된 이유를 보존하며, 비공개 추론이나 확인되지 않은 선택 이유를 만들어 쓰지 않습니다.
+
+잔량은 Codex App Server의 읽기 전용 `account/rateLimits/read`에서 조회한 계정 사용 한도 비율입니다. 남은 토큰 개수는 아닙니다. 30초마다 갱신하고 숫자·막대는 같은 실제 비율을 사용합니다. 0%는 빈 막대, 100%는 가득 찬 막대이며 최소 채움을 임의로 보태지 않습니다. 지연·미확인은 정상 잔량으로 채우지 않습니다. 사용 한도 화면은 큰 숫자, 비례 막대, 초기화·최종 조회 시각과 날짜별 입체 모션을 분리합니다.

+위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 오른쪽 가장자리를 끌면 폭, 아래쪽을 끌면 높이, 우하단 모서리를 끌면 두 크기를 함께 조절합니다. 크기와 위치는 저장되며 화면 밖에 있으면 복구합니다. 기본220×332·최소180×250이고, 조형과 이름·날짜·현재 시각·기온·실제 잔량은 독립 영역입니다. 기존에 저장한 크기는 보존합니다. 이름은 최소16픽셀로 유지하고 긴 이름은 줄을 바꿉니다. 로컬 선택 설정을 200ms 주기로 관측하며 알림은 각각 표시됩니다. 최대 8장 이후에는 오래된 창을 숨기고 기록은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 파일 수 4096개, 레코드 2MiB, 주기별 읽기 예산과 화면 이력 500건의 상한을 유지합니다. 원격·클라우드·서버 모델 신원·비공개 추론 또는 모든 부하에서 무지연을 보장하지 않습니다.
+
+기본 데이터는 현재 사용자의 `%LOCALAPPDATA%/CodexOrbit`입니다. 기존 설정·사용자 MD·백업과 이력을 보존합니다. 설정·내 지침·도움말 탭은 사용자 요청에 따라 노출하지 않으며, 내장 MD를 몰래 적용하지 않습니다. 문서 저장은 계정 전역 메모리나 다른 채팅의 지침 재주입을 의미하지 않습니다. 인증·신뢰·보안 설정을 바꾸지 않습니다. 개인 대화·인증 파일은 배포본에 포함하지 않습니다.

+## 재빌드
+
+`requirements.txt`의 고정 의존성을 준비하고 `tools/build_distribution.py`를 실행합니다. `CODEX_ORBIT_ISCC`에 Inno Setup 컴파일러 경로를 지정합니다. 배포 파일의 SHA256.json과 라이선스를 보존하십시오. ModernGL·glcontext·NumPy·Pillow·PySide6는 EXE에 포함되며 별도 사용자 설치가 필요하지 않습니다. 공개 제작·검사 도구는 `tools/`에 있습니다. 공개본의 검사 범위는 [검증 안내](docs/공개검증_26차.md)를 확인하십시오. Windows 바로가기·트레이·실행파일 아이콘은 운영체제 형식상 정적이며, 실행 위젯과 내부 조형은 움직입니다.

+- 변경마다 별도 말풍선이 즉시 나타납니다. 앞 알림을 닫을 필요가 없습니다. 화면 안에 세로로 쌓고 공간이 부족하면 어긋나게 겹칩니다. 새 알림을 가장 위에 표시하며 각 창의 닫기·클릭·자동 만료는 다른 창에 영향을 주지 않습니다. 같은 ID의 갱신은 기존 창을 보강하고 표시 시간을 초기화하지 않습니다. 이력 다시 보기는 같은 창이 있으면 갱신하고 없으면 즉시 새 창으로 엽니다.
+- 동시에 최대 8장을 표시합니다. 초과하면 가장 오래된 창만 숨기고 새 알림은 바로 표시합니다. 숨긴 누적 건수는 말풍선과 이력 상단에 안내합니다. 이력에서 다시 볼 수 있으며 화면 이력은 최근 500건, 파일 보존에는 아래 순환 상한이 적용됩니다.
+- 채팅 제목을 맨 위에 크게 표시하고 모델 변경·추론 강도 변경·모델·추론 변경을 구별합니다. 이전 값과 새 설정을 위아래로 비교하며 새 설정을 강조합니다. 강도는 없음 (none), 최소 (minimal), 낮음 (low), 보통 (medium), 높음 (high), 매우 높음 (xhigh), 최고 (ultra)처럼 원문과 함께 표시합니다. 한글은 앱의 표시 편의이며 공식 품질 보증이 아닙니다. 모델 ID·공개 이유 원문은 상세에 보존하고 확인되지 않은 이유는 만들어 넣지 않습니다.
+- 같은 감시 묶음은 유효한 원본 시각 순으로 전달하고 시각이 같으면 감지 순서를 유지합니다. 시각이 없거나 잘못되면 감지 위치를 유지하고 이미 표시한 알림은 뒤늦게 읽은 파일로 재정렬하지 않습니다.
+- 밝은 화면에서는 ‘밝은 배경’, 어두운 화면에서는 ‘어두운 배경’ 대비를 선택할 수 있습니다.

+## 실시간 Codex 잔량

+외곽 눈금·진행 링·빛 이동은 장식 모션입니다. 중간 애니메이션 값을 계정 수치로 표시하지 않습니다. 확인된 숫자는 반올림 애니메이션 없이 즉시 표시합니다.

+## 모델 변경 감시와 근거
+
+기본은 CODEX_HOME 환경변수 또는 사용자 홈의 .codex/sessions 폴더입니다. 설정에서 실제 sessions 폴더를 선택할 수 있습니다. 최초 실행은 기존 기록을 기준선으로 읽으므로 과거 알림을 쏟아내지 않습니다. 폴더별 상태가 별도로 보존됩니다.
+
+Codex가 채팅 ID와 함께 남긴 선택 설정 기록을 읽어 모델·추론 강도 변경을 다음 메시지 실행 전에 감지합니다. ‘채팅 선택 설정 변경’은 설정 관측이며 사용자가 바꿨다는 사실이나 서버 실행 모델을 인증하지 않습니다. 일반·계획 모드의 활성 모델과 추론 강도를 비교하고, 같은 설정 반복이나 뒤따르는 동일 turn_context는 중복 알림을 만들지 않습니다. 실제 로컬 실행 관측이 선택값과 다르면 별도로 남깁니다. 부모에서 상속한 다른 채팅의 설정·턴은 자식의 변경으로 처리하지 않습니다.
+
+감시 주기 대기는 200ms입니다. Codex가 기록하기 전의 화면 선택이나 서버 내부 변경을 알 수 없으며, 큰 파일을 나누어 읽는 시간과 화면 처리 시간 때문에 전체 알림 지연이 200ms 이하라고 보장하지 않습니다. 같은 sessions 루트 아래 날짜·프로젝트·자식 채팅을 감시하지만 탐색은 기존처럼 최대 4096개 파일로 제한됩니다.
+
+이전 감시 상태를 처음 열면 원본 state를 별도 백업하고 이미 읽은 위치까지만 선택 설정 기준선을 재생합니다. 과거 이력·중복 방지 기록을 초기화하지 않습니다. 재생 시작 뒤 추가된 설정은 새 변경으로 처리하며 중간 종료 후에는 저장된 위치에서 이어갑니다. 남은 기존 기록이 있으면 ‘기준선 준비 중’과 잔여 바이트를 진단에 표시합니다.
+
+감지 시각은 앱이 변경을 발견한 시각이며, 원본 turn_context의 시각은 별도 보존해 상세에서 표시합니다. 파일 읽기 예산 때문에 뒤늦게 발견한 항목과 이미 전송한 알림 사이의 전체 시간순까지 보장하지 않습니다. 비교할 수 없는 시각을 현재 시각으로 만들어 정렬하지 않습니다.
+
+채팅 제목은 sessions와 같은 상위 폴더의 session_index.jsonl에서 읽습니다. 앱 데이터 폴더의 title-cache.json에 공식 앱에서 확인한 제목을 저장하면 그 확인 캐시를 우선합니다. 출처와 확인 시각은 상세에 남으며 현재 실시간 조회로 표현하지 않습니다. 자식 작업에는 부모 채팅의 정확한 제목과 별도 작업 이름을 표시합니다. 확인할 수 없으면 ‘채팅 제목 확인 불가’로 표시하며 첫 프롬프트나 폴더명을 제목으로 만들지 않습니다.
+
+공개 이유는 부모의 공개 설명과 spawn 호출 ID·호출 결과·자식 작업 경로가 정확히 연결된 첫 배정에서만 보강합니다. 명시 요청에 모델·강도가 있으면 관측값과 대조합니다. 부모가 늦게 읽히면 기존 이력을 보강하며 과거 알림을 다시 만들지 않습니다. 최근 부모 기록은 파일당 최대 4 MiB, 주기당 추가 8 MiB 안에서 우선 조회합니다. 범위 밖의 호출은 순차 감시를 기다리므로 즉시 이유를 찾지 못할 수 있습니다. 기록에 공개 이유가 없거나 연결 근거가 부족하면 ‘확인 불가’입니다. 다른 도구가 공개 설명과 배정 사이에 있으면 자동으로 이유를 추정하지 않습니다. 로컬 기록이나 명시 배정 요청은 서버 모델 신원 인증이 아닙니다. 비공개 추론을 추출하지 않습니다.
+
+기본 카드에는 채팅 제목·작업·전후 모델과 추론 강도·한국 시각·짧은 공개 이유가 나옵니다. 짧은 이유는 명시된 ‘이유:’ 문장과 배정·선택의 목적 또는 원인이 적힌 원문 문장을 우선 발췌합니다. 이런 문장이 없으면 첫 문장을 표시합니다. 첫 문장이 짧은 ‘맡기겠습니다/배정하겠습니다’ 예고이면 다음 원문 문장을 발췌하며 자동으로 원인을 만들어 요약하지 않습니다. ‘원문 · ID · 근거 펼치기’에서 전체 이유와 ID·출처를 볼 수 있습니다. 자식 첫 배정은 같은 자식 내부의 모델 변경과 구분됩니다. 앱 표시 요청과 사용자가 실제 화면을 읽었다는 확인은 다릅니다. 모바일 ChatGPT 푸시나 Windows 알림 센터 보관을 제공하지 않습니다.
+
+이력은 화면에 최근 500개를 표시하며 파일 읽기도 최대 2 MiB로 제한합니다. 감시기는 파일당 읽기 예산과 전체 읽기 예산을 두고 큰 파일을 나누어 읽으므로 새 변경 감지가 지연될 수 있습니다. 이력·진단은 2 MiB 초과 시 이전 파일 하나를 보존하며 순환합니다. 전체 영구 보관이 아닙니다. 설정·진단 탭에서 최근 오류를 확인할 수 있습니다.
+
+감시 작업자가 20초 이상 진행 상태를 보내지 않으면 상세 창에 ‘감시 지연’과 가로선이 있는 상태점을 표시합니다. 종료가 확인된 작업자는 간격을 늘려 세 차례까지 다시 시작합니다. 실행 중인 정체 작업자는 강제 종료하지 않습니다. 상태가 오래 멈춰 있으면 설정을 확인하고 앱을 정상 종료 후 다시 실행하세요. 모든 모델 변경이 로컬 기록에 즉시 남는다는 보장은 없으며 최초 정체의 모든 원인을 자동 수리하는 기능은 아닙니다.
+
+상태 저장은 호출별로 다른 임시 파일을 쓰며, Windows 공유 오류일 때 최대 다섯 번까지 교체를 시도합니다. 재시도 사이 대기는 합계 0.26초이고 실제 파일 입출력 시간은 별도입니다. 끝까지 실패하면 기존 상태 파일을 보존하고 오류를 표시합니다. 진단 파일도 저장할 수 없으면 원래 오류와 진단 저장 오류를 메모리에 최근 다섯 건까지 함께 보존해 화면에 보여 주며 다음 주기 감시를 계속합니다. 잠금이나 접근 문제가 해소돼야 저장이 회복될 수 있습니다. 전원 차단이나 표시 요청 직후 이력 저장 실패 시 재알림 가능성은 남습니다.
+
+필수 감시 준비가 실패하면 회전 위젯을 남기지 않고 시작 오류를 안내합니다. 준비 완료 뒤에도 첫 정상 진행 상태를 받기 전에는 정상 감시 점을 표시하지 않습니다. 앱 데이터 폴더의 `startup.jsonl`에는 시작·감시 단계, 실제 PID, 시각, 실행·데이터·세션 경로와 오류를 남깁니다. 기록 자체의 저장 실패도 진단에 표시하며, 손상된 캐시나 상태를 자동 초기화해 숨기지 않습니다. 과거 17:32 정지의 최초 원인은 당시 증거가 없어 여전히 미확정입니다.
+
+`notice-presentations.jsonl`에는 말풍선 표시 요청 시각과 이벤트 ID·대상·모델·강도·원본 시각·동시 표시 수를 기록합니다. 대화 본문·제목·공개 이유는 포함하지 않습니다. `display_requested`는 앱의 표시 요청이며 `user_confirmed`는 항상 false입니다. 사용자가 실제로 읽거나 클릭했다고 인증하는 기록은 아닙니다. 기록 쓰기에 실패해도 독립 말풍선 표시는 계속 진행하고 진단에 실패를 표시합니다. 이 기록과 시작 기록도 2 MiB를 넘으면 이전 파일 하나만 보존하며 순환합니다.
+
+‘종료’를 누르면 잔량 연결을 정리하고 감시 작업자에 중단을 요청합니다. 진행 중인 읽기가 끝날 때까지 화면 응답을 유지하며, 실제 작업자 종료 신호를 받은 뒤 앱을 종료합니다. 종료 중에는 감시기를 다시 시작하지 않습니다. 작업자가 운영체제 입출력에서 계속 정체되면 정상 종료 완료가 늦어질 수 있습니다.
