+# Codex Orbit 배포 안내
+
+21차 / 버전2.5.0. 투명148정사각형 위쪽에는 날짜별로 다른 실제3D 금속 조형물이 움직이며 세 링의 축·방향·속도는 독립적입니다. 하단 도크에는 번호·큰 원소기호·한국어 이름을, 그 아래에는 실제 조회 잔량 숫자와 비례 채움 막대를 분리합니다. 화면은 변경 기록과 사용 한도 두 탭만 두며 설정·내 지침·도움말 UI는 노출하지 않습니다. 이전19차와20차는 보존합니다.
+
+## 전달 파일
+
+- CodexOrbit.exe: Windows10/11 x64 단일 실행 파일.
+- CodexOrbit-Setup.exe: 현재 사용자 설치형. 설치 위치·시작 메뉴·선택 바탕화면 바로가기·제거 기능.
+- 사용법.md/배포안내.md: 앱 밖 한국어 문서.
+- 라이선스 및 소스와_재빌드.zip: 포함 구성 요소 라이선스와 재빌드 자료.
+- 기본_지침.md: 개인 정보 없는 참고 지침. 앱 안 MD 적용 화면은 없으며 자동으로 적용하지 않습니다.
+
+위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 로컬 Codex의 모델·추론 강도 선택 변경 기록을200ms 주기로 감지하며 각 알림을 독립 표시합니다. 최대8장 초과 시 오래된 창을 숨기고 최신을 즉시 표시하며 기록은 보존합니다. 정확한 제목·원문 모델ID·강도·공개 이유를 확인할 수 있습니다.
+
+계정 잔량은 설치된 Codex App Server의 읽기 전용 account/rateLimits/read를30초마다 조회한 사용 한도 비율입니다. 토큰 개수가 아니며 없는 수치·이유를 만들지 않습니다. 실제 로그인은 설치된 Codex가 관리하고 이 앱은 인증 파일 직접 읽기·로그인·리셋·구매·모델 실행을 하지 않습니다.
+
+기존 사용자 설정·MD·백업은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 감지 파일 수4096·레코드2MiB·주기별 읽기 예산, 화면 이력500건과 로그 순환 상한이 있습니다. 원격PC·클라우드·서버 모델 신원·비공개 추론·모든 부하에서의 무지연을 보장하지 않습니다. 상세한 동작과 진단 옵션은 사용법.md를 참고하십시오.
+
+프로젝트 docs/운영_기억.md에 최신 운영 원칙을 보존합니다. 문서 저장이 계정 전역 AI 메모리 저장 또는 이미 열린 모든 대화의 지침 재주입을 뜻하지 않습니다. 앱은 사용자 설정·Codex 권한·인증·신뢰를 바꾸지 않습니다.
+
+## 재빌드
+
+requirements.txt의 의존성을 준비한 Python 환경에서 tools/build_distribution.py를 실행합니다. Inno Setup 컴파일러 경로는 CODEX_ORBIT_ISCC로 지정합니다. 배포 라이선스를 유지하고 SHA256.json을 확인하십시오. Python·PySide6·PyInstaller·Inno Setup이 필요하며 배포 EXE 실행에는 Python 설치가 필요하지 않습니다.
+
+3D 원본과 제작 도구는 assets/atom3d 및 tools/render_atom3d.py에 포함합니다. 제작에만 필요한 의존성은 tools/requirements-3d.txt를 참고하십시오. 앱 실행에는 ModernGL·NumPy·Pillow 설치가 필요하지 않습니다. 중앙의 번호·기호·이름은 한국 날짜에 대응하는 원소이며, 실제 조회한 사용 한도 잔량은 아래 별도 표지에 표시합니다.
+
+16차 수정: 모델·추론 변경의 이전값과 새값을 각각 구분해 표시합니다. 이전 기록이 없는 첫 관측은 실제 변경과 구분하며 과거값을 임의로 채우지 않습니다. 금속 원자 모션과 감시·계정 조회 및 보존 자료는 유지합니다.
+
+17차 디자인: 실제3D 금속 원자 모델의 세 링이 서로 다른 축으로 움직이며 앱 상단과 알림도 같은 모션을 공유합니다. 기능 아이콘은 무채색 입체 표식으로 통일했습니다. 실행 위젯과 앱 안 로고는 움직이고 Windows 바로가기·실행파일·트레이 아이콘은 같은 모델의 정적 렌더입니다. 이전/새 모델과 추론 강도 및 실제 조회 수치의 의미는 유지합니다.
+
+18차: 모델/추론 변경과 별도로 새 작업 배정·기존 작업 재개를 알립니다. 정확한 채팅·맡긴 일·확인된 공개 이유를 표시하고 없는 이유는 만들지 않습니다. 부드러운 색상과 카드로 내부 화면을 개선했습니다. 바탕화면은 기존3D형상을 유지하면서 한국 날짜1~31일에 맞춘 원소번호·기호·이름·디자인색을 표시하고 자정에 바뀝니다. 실제 잔량은 별도표시하며 원자번호와 혼동하지 않습니다. 26일은Fe철,27일은Co코발트,31일은Ga갈륨입니다. 색은 디자인 팔레트이며 실제 불꽃색/전자배치 시뮬레이션이 아닙니다.
+
+19차(2026-10-26):원소와잔량을비겹침영역으로분리하고중앙원소가독성을높였습니다.기존투명정사각형/3D금속모션을유지하면서차가운은색·청색계열과SUIT글꼴로정돈합니다.실제사용한도와날짜별원소의의미및알림감지는유지합니다.사용자가글꼴변경을요청해이프로젝트19차는SUIT를사용하며실제글꼴파일과SUNN의SIL Open Font License1.1을함께포함합니다.공식출처:https://github.com/sun-typeface/SUIT/blob/main/LICENSE .이전18차는보존합니다.
+
+
+21차(2026-10-26): 선택한 하단 도크 디자인을 적용했습니다. 위쪽 금속 조형물에는 숫자를 겹치지 않으며, 아래 도크의 번호·큰 기호·한국어 이름과 그 아래 잔량 막대를 분리합니다. 한국 날짜1~31에 대응하는31개 원소는 서로 다른 실제3D 메시·색의 모션을 사용합니다. 조형물은 원소의 성질·쓰임에서 얻은 디자인이며 실제 원자 모습·전자배치·물리적 고유색을 재현하지 않습니다.
+
+잔량 막대는 실제 조회한 남은 비율에 비례합니다. 3%도3% 폭으로 표시하며 최소 폭을 임의로 더하지 않습니다. 0%는 빈 트랙,100%는 꽉 찬 트랙입니다. 숫자와 막대는 같은 실제 비율을 사용합니다. 지연·미확인은 정상 값으로 채우지 않으며, 사용 한도 상세의 이전 조회 숫자는 ‘이전 조회’로 구분합니다. 시안이나 검토 이미지에 쓰인3%·97% 등 제어 예시는 현재 계정 값이라는 뜻이 아닙니다. 실행 앱은 읽기 전용 조회 결과를 사용합니다. SUIT500/600,투명148정사각형과 드래그·클릭·기존 알림 및 데이터 보존을 유지합니다.

+## 요구 사항과 성공 조건
+
+- 배경·테두리가 투명한 약 140px 상시 표시 창에 굵은 궤도 3개와 중심 심볼을 그립니다. 시간에 따라 모양이 변하는 연속 회전이며 첨부 그림 자체를 편집하거나 정지 이미지로 대체하지 않습니다.

+            corners=[(radius*math.cos(a),y,radius*math.sin(a)),(radius*math.cos(b),y,radius*math.sin(b)),
+                     (next_radius*math.cos(b),next_y,next_radius*math.sin(b)),(next_radius*math.cos(a),next_y,next_radius*math.sin(a))]
+            start=len(vertices)
+            for k,p in enumerate(corners):
+                t=(a if k in (0,3) else b) if smooth else (a+b)/2
+                n=np.array([(next_y-y)*math.cos(t),radius-next_radius,(next_y-y)*math.sin(t)])
+                n/=np.linalg.norm(n)
+                vertices.append((*p,*n))
+            indices.extend((start,start+1,start+2,start,start+2,start+3))
+    return finish(vertices,indices)

+def tube(points,radius=3,closed=False,sides=14):
+    """3D 경로를 따라 원형 단면을 운반합니다. 코일은 실제 깊이를 가집니다."""
+    points=np.asarray(points,dtype=float);vertices=[];indices=[];count=len(points)
+    for i,p in enumerate(points):
+        before=points[(i-1)%count] if closed or i else points[0]
+        after=points[(i+1)%count] if closed or i<count-1 else points[-1]
+        tangent=after-before;tangent/=np.linalg.norm(tangent)
+        up=np.array([0.,1.,0.]) if abs(tangent[1])<.95 else np.array([1.,0.,0.])
+        side=np.cross(tangent,up);side/=np.linalg.norm(side);vertical=np.cross(tangent,side)
+        for j in range(sides):
+            n=side*math.cos(math.tau*j/sides)+vertical*math.sin(math.tau*j/sides)
+            vertices.append((*list(p+radius*n),*list(n)))
+    for i in range(count if closed else count-1):
+        for j in range(sides):
+            a=i*sides+j;b=((i+1)%count)*sides+j;c=((i+1)%count)*sides+(j+1)%sides;d=i*sides+(j+1)%sides
+            indices.extend((a,b,c,a,c,d))
+    # 끝점은 작은 구면으로 가려지는 조립부이며 열린 단면의 용도를 기록합니다.
+    return finish(vertices,indices)

+def rgb_shader():
+    """기존 검증된 스튜디오 조명을 RGB 금속 반사율로 확장합니다."""
+    s=atom.FRAGMENT.replace('uniform float base_color;','uniform vec3 base_color;')
+    for name in ('f0','fresnel','reflected','f','specular','diffuse','radiance'):
+        s=s.replace('float '+name+' =','vec3 '+name+' =')
+    s=s.replace('mix(.04,base_color,metallic)','mix(vec3(.04),base_color,metallic)')
+    s=s.replace('float display = pow(aces(radiance),1.0/2.2);','vec3 display = pow(vec3(aces(radiance.r),aces(radiance.g),aces(radiance.b)),vec3(1.0/2.2));')
+    return s.replace('vec4(display,display,display,1.0)','vec4(display,1.0)')

+def orbit_mesh(number,index):
+    """원소별 단면 폭과 완만한 가장자리 장식을 실제 메시로 변주합니다."""
+    radius=atom.RADII[index];width=2.0+(number%5)*.22;depth=1.35+(number%3)*.15
+    vertices=[];indices=[];segments=160;sections=24
+    waves=3+number%5;amplitude=.0 if number%3==0 else .45 if number%3==1 else .8
+    for i in range(segments):
+        t=math.tau*i/segments;c,s=math.cos(t),math.sin(t)
+        center=radius+amplitude*math.cos(waves*t+index)
+        derivative=-amplitude*waves*math.sin(waves*t+index)
+        for j in range(sections):
+            a=math.tau*j/sections
+            # 표면 편미분의 외적으로 파형의 실제 월드 법선을 구합니다.
+            radial=center+width*math.cos(a)
+            dt=np.array([derivative*c-radial*s,derivative*s+radial*c,0.])
+            da=np.array([-width*math.sin(a)*c,-width*math.sin(a)*s,depth*math.cos(a)])
+            n=np.cross(dt,da);n/=np.linalg.norm(n)
+            vertices.append((radial*c,radial*s,depth*math.sin(a),*n))
+    for i in range(segments):
+        for j in range(sections):
+            a=i*sections+j;b=((i+1)%segments)*sections+j;c=((i+1)%segments)*sections+(j+1)%sections;d=i*sections+(j+1)%sections
+            indices.extend((a,b,c,a,c,d))
+    return finish(vertices,indices)

+# Codex Orbit · 23차 / 2.7.0
+
+크기를 조절할 수 있는 투명 바탕화면 위젯에서 날짜별 3D 조형이 움직이고, 클릭하면 모델·추론 강도 변경과 작업 배정·재개 기록을 확인합니다. SUIT 글꼴과 잉크 네이비 화면을 사용합니다. 이전 차수는 보존했습니다.
+
+## 전달 파일
+
+- `CodexOrbit.exe`: Windows 10/11 x64용 단일 실행 파일.
+- `CodexOrbit-Setup.exe`: 현재 사용자 설치·시작 메뉴·선택 바탕화면 바로가기·제거 프로그램.
+- `사용법.md`, `기본_지침.md`, 라이선스, `소스와_재빌드.zip`.
+
+Python을 별도로 설치하지 않아도 실행합니다. 날짜별 실제 3D 모션에는 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. GPU 준비 중에는 해당 월의 정적 표식을 보여 주며, 실패하면 사유를 표시합니다. 이때 정적 표식을 3D 성공으로 기록하지 않습니다. 감시·계정 조회는 3D 렌더와 분리됩니다.
+
+## 매일 바뀌는 조형
+
+한국 날짜 기준 2026-01-01부터 2099-12-31까지 27,028일을 지원합니다. 37개 주제 모티프와24개 동반 모티프의 서로 다른 쌍으로888개 연월 컬렉션을 구성하며 두 모티프와 날짜별 주연 대상을 실제 형상 규칙에 연결합니다. 같은12개 월 테마를 매년 반복하지 않습니다. 위젯에는 실제 대상 이름을 표시하며 월 테마는 카탈로그에 별도로 기록합니다. 공통 형상 생성기를 재사용하는 장식용 조형이며888개 수작업 모델이나 과학 도감 수준의 정확한 복제품이라는 뜻은 아닙니다. 전체 연월 목록은 함께 제공하는 `연도별_월_테마.md`와CSV, 원본은 `assets/calendar-art/themes.md` 및 `themes.csv`에서 확인합니다.
+
+자정 이후 다음 프레임에 한국 날짜를 다시 확인하고 조형과 도크를 바꿉니다. 절전에서 복귀하거나 시계를 되돌려도 날짜를 재확인합니다. 수만 개 영상을 넣지 않고 그날의 실제 삼각형 메시만 렌더합니다. 두 궤도는 서로 다른 축과 속도로 움직입니다. 바탕화면과 내부 모션은 한 GPU 작업자·한 컨텍스트·최신 이미지와 정적 준비 이미지 두 장을 공유하며 초당 최대 30프레임입니다. 표시 대상이 없으면 렌더를 쉽니다. 날짜 카탈로그는 소스 ZIP의 `assets/calendar-art/catalog.json`에 있습니다.
+
+## 변경 기록과 실제 한도
+
+위젯에는 PC의 현지 시각을 초 단위로 표시하며, 인터넷 접속 IP의 대략적인 지역에서 현재 기온을 조회합니다. Windows 위치 서비스는 필요하지 않습니다. 지역 조회는 ipwho.is, 기온은 Open-Meteo의 최신 현재 기온 자료를 사용하며5분마다 자동 갱신합니다. 정확한 GPS 위치나 초 단위 현장 온도 센서 측정은 아니며 VPN·통신사망에서는 실제 지역과 다를 수 있습니다. 출처·조회 시각·네트워크 기반 지역은 툴팁에 표시하고, 조회 실패나 오래된 값은 정상 최신 기온으로 표시하지 않습니다. 앱은 IP·좌표·이동 이력을 저장하지 않습니다.
+
+알림과 상세에서 모델 및 추론 강도를 각각 **이전 → 변경 후** 두 칸으로 표시합니다. 실제로 달라진 행만 강조합니다. 작업 배정·재개는 별도 종류이며 현재 설정을 표시합니다. 이전 기록이 없거나 필드가 미기록이면 사실대로 표시하고 과거 값을 추정하지 않습니다. 정확한 채팅 제목·맡긴 일·공개된 이유를 보존하며, 비공개 추론이나 확인되지 않은 선택 이유를 만들어 쓰지 않습니다.
+
+잔량은 Codex App Server의 읽기 전용 `account/rateLimits/read`에서 조회한 계정 사용 한도 비율입니다. 남은 토큰 개수는 아닙니다. 30초마다 갱신하고 숫자·막대는 같은 실제 비율을 사용합니다. 0%는 빈 막대, 100%는 가득 찬 막대이며 최소 채움을 임의로 보태지 않습니다. 지연·미확인은 정상 잔량으로 채우지 않습니다. 사용 한도 화면은 큰 숫자, 비례 막대, 초기화·최종 조회 시각과 날짜별 입체 모션을 분리합니다.
