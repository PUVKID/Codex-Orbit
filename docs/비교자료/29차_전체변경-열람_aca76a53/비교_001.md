-## 회전 속도 조절
-
-상세창 위쪽의 **회전 속도** 슬라이더를 움직이면0.25~3배로 바뀝니다. **1배 복원**으로 기본 속도로 돌아갑니다. 바탕화면 위젯을 우클릭하고 **회전 속도**에서도0.25·0.5·1·1.5·2·3배를 선택할 수 있습니다. 선택은 저장되어 재실행 뒤에도 적용됩니다.

-배율은 링과 조형의 재생 속도에만 적용되며 실제 시각·날짜·날씨·잔량의 갱신 주기는 그대로입니다. 변경 순간의 각도를 이어서 재생하며 프레임 목표240과 회전 배율은 별도로 처리합니다. 실제 생성률·GUI 그리기와 물리 모니터 표시율은 각각 확인해야 합니다.

+# Codex Orbit 2.10.0 · Quick guide
+
+Run CodexOrbit.exe directly, or use CodexOrbit-Setup.exe to install it for the current Windows user. The installer supports Korean and English.
+
+Choose 한국어 or English in the detail window's top language selector, or in the desktop widget's right-click menu. The selection is saved. Drag the widget to move it; drag its right or bottom edge to resize it. Click it to open change history.
+
+Worldwide location and current temperature use the internet connection's approximate IP location. Windows Location Services are not required. Place names use Open-Meteo/GeoNames translations. If a translation or reliable match is unavailable, the original place name is shown. VPNs and mobile networks may point to a different region.
+
+The GPU renders an actual 3840×2160 source and downsamples it to the widget size before transfer. Pacing targets 240 fps; measured development-window generation was approximately 233–235 fps, so fixed 240 fps has not been achieved. Rendered frames, GUI paint counts and physical monitor refresh rate are different measurements.
+
+Usage bars show the account's remaining rate-limit percentage, not an exact token count. Chat titles, model IDs, role IDs and recorded public reasons remain unchanged when the interface language changes. Reasons not present in the source are not invented.
+
+The uninstaller preserves user instructions, backups and history. Included default instructions are not applied silently. Do not share your account credentials, local chat data or personal instruction files with the application package.
+
+Sources: https://open-meteo.com/ · https://www.geonames.org/ · https://ipwhois.io/
+
+
+## Rotation speed
+
+Use the Rotation speed slider near the top of the details window to select0.25×–3×. Reset to1× restores the default. You can also right-click the desktop widget and choose a speed preset. The choice is saved and restored on restart.
+
+Speed changes preserve the current animation phase. They affect the rings and sculpture only; clock, date, weather and usage updates retain their real-time schedules. Rotation speed and the240fps pacing target are separate controls of the animation.
+
+
+## Version 26 rotation speed
+
+Use the detail window slider or widget context menu to select 0.25–3× speed. The setting persists across restarts. Korean and English are supported. Further work toward fixed 240fps was withdrawn by the user. Recent measurements were approximately 227–230 generated frames/s and 214–229 unique Qt paints/s; these are separate from physical display refresh.

+# Codex Orbit 배포 안내
+
+17차 / 버전2.3.0. 투명한 정사각형 위젯에 금속 곡면의 세 링·흑연 원자핵·전자 입자가 움직입니다. 실제 3D 메시·법선·깊이·반사 조명으로 제작한 18초 모션을 재생하며 각 링의 축·방향·속도는 독립적입니다. 화면은 변경 기록과 사용 한도만 남겼으며 설정·내 지침·도움말 UI는 제거했습니다. 이전16차는 보존합니다.
+
+## 전달 파일
+
+- CodexOrbit.exe: Windows10/11 x64 단일 실행 파일.
+- CodexOrbit-Setup.exe: 현재 사용자 설치형. 설치 위치·시작 메뉴·선택 바탕화면 바로가기·제거 기능.
+- 사용법.md/배포안내.md: 앱 밖 한국어 문서.
+- 라이선스 및 소스와_재빌드.zip: 포함 구성 요소 라이선스와 재빌드 자료.
+- 기본_지침.md: 개인 정보 없는 참고 지침. 앱 안 MD 적용 화면은 없으며 자동으로 적용하지 않습니다.
+
+위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 로컬 Codex의 모델·추론 강도 선택 변경 기록을200ms 주기로 감지하며 각 알림을 독립 표시합니다. 최대8장 초과 시 오래된 창을 숨기고 최신을 즉시 표시하며 기록은 보존합니다. 정확한 제목·원문 모델ID·강도·공개 이유를 확인할 수 있습니다.
+
+계정 잔량은 설치된 Codex App Server의 읽기 전용 account/rateLimits/read를30초마다 조회한 사용 한도 비율입니다. 토큰 개수가 아니며 없는 수치·이유를 만들지 않습니다. 실제 로그인은 설치된 Codex가 관리하고 이 앱은 인증 파일 직접 읽기·로그인·리셋·구매·모델 실행을 하지 않습니다.
+
+기존 사용자 설정·MD·백업은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 감지 파일 수4096·레코드2MiB·주기별 읽기 예산, 화면 이력500건과 로그 순환 상한이 있습니다. 원격PC·클라우드·서버 모델 신원·비공개 추론·모든 부하에서의 무지연을 보장하지 않습니다. 상세한 동작과 진단 옵션은 사용법.md를 참고하십시오.
+
+프로젝트 docs/운영_기억.md에 최신 운영 원칙을 보존합니다. 문서 저장이 계정 전역 AI 메모리 저장 또는 이미 열린 모든 대화의 지침 재주입을 뜻하지 않습니다. 앱은 사용자 설정·Codex 권한·인증·신뢰를 바꾸지 않습니다.
+
+## 재빌드
+
+requirements.txt의 의존성을 준비한 Python 환경에서 tools/build_distribution.py를 실행합니다. Inno Setup 컴파일러 경로는 CODEX_ORBIT_ISCC로 지정합니다. 배포 라이선스를 유지하고 SHA256.json을 확인하십시오. Python·PySide6·PyInstaller·Inno Setup이 필요하며 배포 EXE 실행에는 Python 설치가 필요하지 않습니다.
+
+3D 원본과 제작 도구는 assets/atom3d 및 tools/render_atom3d.py에 포함합니다. 제작에만 필요한 의존성은 tools/requirements-3d.txt를 참고하십시오. 앱 실행에는 ModernGL·NumPy·Pillow 설치가 필요하지 않습니다. 중앙 숫자는 영상에 포함한 시연값이 아니라 Qt가 현재 조회 결과를 별도로 표시합니다.
+
+16차 수정: 모델·추론 변경의 이전값과 새값을 각각 구분해 표시합니다. 이전 기록이 없는 첫 관측은 실제 변경과 구분하며 과거값을 임의로 채우지 않습니다. 금속 원자 모션과 감시·계정 조회 및 보존 자료는 유지합니다.
+
+17차 디자인: 실제3D 금속 원자 모델의 세 링이 서로 다른 축으로 움직이며 앱 상단과 알림도 같은 모션을 공유합니다. 기능 아이콘은 무채색 입체 표식으로 통일했습니다. 실행 위젯과 앱 안 로고는 움직이고 Windows 바로가기·실행파일·트레이 아이콘은 같은 모델의 정적 렌더입니다. 이전/새 모델과 추론 강도 및 실제 조회 수치의 의미는 유지합니다.

+Bootloader and Related Files
+----------------------------
+
+Bootloader and related files are files which are embedded within the
+final executable. This includes files in directories:
+
+./bootloader/
+./PyInstaller/loader
+
+
+Run-time Hooks
+----------------------------
+
+Run-time Hooks are a different kind of files embedded within the final
+executable. To ease moving them into a separate repository, or into the
+respective project, these files are now licensed under the Apache License,
+Version 2.0.
+
+Run-time Hooks are in the directory
+./PyInstaller/hooks/rthooks
+
+
+Additional Run-time Modules
+----------------------------------
+
+In addition to run-time hooks, PyInstaller may embed additional run-time
+modules in the final executable. At the time of writing, these include
+the splash-screen module (``pyi_splash``) and modules from utility package
+for run-time hooks (``_pyi_rth_utils``). All these files are licensed under
+the Apache License, Version 2.0, and are located in the following directory:
+
+./PyInstaller/fake-modules
+
+
