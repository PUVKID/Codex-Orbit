+# Codex 잔량 표시 구현 계획
+
+확인일: 2026-10-24. 3차 결과는 보존하고 4차에서 구현합니다. 사용자 요청은 기존 EXE에 실시간 Codex 토큰 잔량 표시를 추가하는 것입니다. 실제 제공 데이터는 남은 토큰 개수가 아닌 계정 사용 한도 비율입니다.
+
+## 설계와 선택 근거
+
+공식 `account/rateLimits/read`를 현재 PC에 설치된 `codex app-server`의 표준 입력·출력 연결로 조회합니다. [실제 계정 응답 수치 제외.] 남은 비율은 100-usedPercent입니다. 공개 문서: https://learn.chatgpt.com/docs/app-server . 이 read 요청만 허용하며 새 작업·모델 추론·로그인·리셋·구매·사용자 설정 변경 요청을 보내지 않습니다.
+
+검토한 대안은 로컬 세션의 과거 사용량을 읽는 방식과 채팅 도구 결과를 정기 파일로 전달하는 방식입니다. 전자는 사용 중이지 않으면 갱신되지 않고, 후자는 채팅 실행에 종속되어 독립 EXE 배포에 부적합합니다. 현재 확인된 공식 조회를 Qt 비동기로 연결하는 방식을 부모가 선택합니다. 앞서 설명에 머물지 말고 직접 구현하라는 사용자 지시에 따라 추가 설계 승인 질문은 생략합니다.
+
+## 구현 범위
+
+- 새 `src/usage.py`: 설치된 Codex EXE 탐색, 숨김 QProcess 연결, initialize/initialized/read 순서, 물리적 LF JSON 파싱·응답 크기 상한·응답 시간 제한, 30초 자동 갱신·업데이트 수신·수동 조회, 제한된 재연결, 정상 종료와 본인이 시작한 프로세스 정리.
+- `src/app.py`: 투명 회전 위젯의 작은 잔량 표시와 상세 창의 계정 사용 한도 패널·초기화 시각·조회시각·새로고침 버튼. 기존 다크테크·나눔고딕 Bold700 유지. API 키·로그인·복잡한 서버 설정을 제품 흐름에 노출하지 않습니다. 자동 탐색 실패 시 Codex EXE 선택 안내를 제공합니다.
+- `tests/test_usage.py` 및 기존 앱 검사: 실제 응답 형태, 5시간/주간/다중 버킷, null/누락/비정상 값, JSON 부분 조각·과다 응답, 인증/실행실패/연결 종료·타임아웃·중복조회·종료, UI 표시·낡은 수치 구분. 테스트를 먼저 실패시키고 구현 후 통과를 확인합니다.
+- `assets/사용법.md`, `README.md`: 잔량 단위·30초 주기·수동 갱신·실패 표시·설치된 Codex 로그인 필요를 안내합니다. 인증 파일과 사용자 대화·사용량을 배포에 넣지 않습니다.
+
+## 성공 조건과 검증 순서
+
+1. 실제 설치된 Codex에서 새 잔량을 조회하고 위젯 및 상세 창에 표시합니다. 기간은 duration으로 판별하며 없는 5시간 한도를 만들어 넣지 않습니다. null을 0% 또는 100%로 만들지 않습니다. 초기화 시간이 지났다고 서버 재조회 전 잔량을 임의 복구하지 않습니다.
+2. UI는 조회 중에도 회전·드래그·MD·모델 알림을 유지합니다. 실패 시 과거 값은 지연/이전 조회로 명시하거나 미확인으로 표시하며 현재 값으로 가장하지 않습니다. 다른 계정의 값이 디스크 캐시에서 섞이지 않도록 사용량을 영구 복원하지 않습니다.
+3. 테스트·엄격 UTF-8·구문 검사 후 단일 EXE와 설치본 재빌드, 격리 경로에서 실행/설치/실행/제거 및 MD 보존을 확인합니다.
+4. 구현자와 다른 verifier Sol/high가 실제 로그·사용량 조회·UI·실패 경로·배포를 직접 대조합니다. 소스 동결과 실제 로컬 child 실행 근거를 부모가 등록하고 독립 verifier만 검증 영수증을 발급합니다.
+
+기술 스택은 기존 Python3.12/PySide6/Qt/QProcess/PyInstaller/Inno를 사용합니다. parent는 빌드·설치 도구와 증거·라우팅·계획을, 구현자는 usage/app/tests/사용 안내를 소유합니다. 상호 변경을 되돌리지 않습니다. 동시 설치 검사는 하지 않습니다.
+
+## 추가 사용자 요구와 알림 진단
+
+사용자가 같은 작업 중 모델 변경마다 알림이 나오지 않는다고 보고했습니다. 실제 기존 앱 프로세스가 떠 있어도 C 앱 데이터 heartbeat/state/history는 17:32에 멈췄습니다. state 복사본에서 4회 poll0.625초로 실제 새 배정 3건을 읽었으며, 이전 앱을 정상 종료하고 같은 데이터 경로를 명시해 재실행하자 18:48에 heartbeat와 이력이 다시 갱신됐습니다. 이전 프로세스 정지의 최초 원인은 미확정이며 재실행 성공을 원인 수리로 가장하지 않습니다.
+

+# Codex Orbit 배포 안내
+
+10차 / 버전 1.5.2: 로컬 Codex 채팅에 선택한 모델·추론 강도 설정이 기록되면 다음 메시지 실행을 기다리지 않고 변경 알림을 표시합니다. 변경마다 독립 알림을 즉시 표시하며 무채색 입체 궤도·잔량·MD 기능은 유지합니다. 이전9차를 보존합니다.
+
+투명한 회전 궤도 위젯으로 Codex 계정 잔량과 로컬 모델·추론 강도 변경을 확인하는 Windows 10/11 x64 앱입니다.
+
+중심에는 확인된 기간 중 가장 적게 남은 사용 한도 비율을 표시합니다. 남은 토큰 개수가 아닙니다. 상세 창 상단에는 버킷·기간별 잔량 막대, 초기화 한국 시각, 최종 조회 시각과 수동 새로고침이 있습니다. 공식 `account/rateLimits/read`를 설치된 `codex app-server`에서 읽기 전용으로 30초마다 조회하며 서버의 갱신 알림도 반영합니다. 없는 기간·null 수치는 만들어 표시하지 않습니다.
+
+설치된 Codex의 ChatGPT 로그인이 필요합니다. EXE를 자동 탐색하고 실패하면 설정에서 설치된 `codex.exe`를 선택할 수 있습니다. 앱은 인증 파일을 직접 읽거나 복사하지 않고 로그인·리셋·구매·모델 실행·Codex 설정 변경을 하지 않습니다. 연결 실패·지연이면 이전 값임을 명시하며 재실행할 때 잔량을 디스크에서 복원하지 않습니다. 서버 반영과 연결 상황에 따라 조회가 늦어질 수 있습니다.
+
+연속 변경은 앞 알림을 닫지 않아도 각각 즉시 표시합니다. 화면 안에 세로로 쌓고 공간이 부족하면 어긋나게 겹칩니다. 창은 최대 8장이며 초과 시 가장 오래된 창을 숨기고 새 알림을 바로 표시합니다. 숨긴 누적 건수는 화면에 안내하고 기존 이력에서 다시 볼 수 있습니다. 각 창의 닫기·클릭·자동 만료는 다른 창을 닫거나 표시 시간을 초기화하지 않습니다. 감시 진행이 20초 이상 없으면 지연을 표시하고, 종료된 작업자만 세 차례까지 재시작합니다. 실행 중인 정체 작업자를 강제 종료하지 않으며 이전 정체의 최초 원인은 확인되지 않았습니다.
+

+# Codex Orbit · 22차 / 2.6.0
+
+투명한 148×148 바탕화면 위젯에서 날짜별 3D 조형이 움직이고, 클릭하면 모델·추론 강도 변경과 작업 배정·재개 기록을 확인합니다. SUIT 글꼴과 잉크 네이비 화면을 사용합니다. 이전 차수는 보존했습니다.
+
+## 전달 파일
+
+- `CodexOrbit.exe`: Windows 10/11 x64용 단일 실행 파일.
+- `CodexOrbit-Setup.exe`: 현재 사용자 설치·시작 메뉴·선택 바탕화면 바로가기·제거 프로그램.
+- `사용법.md`, `기본_지침.md`, 라이선스, `소스와_재빌드.zip`.
+
+Python을 별도로 설치하지 않아도 실행합니다. 날짜별 실제 3D 모션에는 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. GPU 준비 중에는 해당 월의 정적 표식을 보여 주며, 실패하면 사유를 표시합니다. 이때 정적 표식을 3D 성공으로 기록하지 않습니다. 감시·계정 조회는 3D 렌더와 분리됩니다.

+## 매일 바뀌는 조형

+크기를 조절할 수 있는 투명 바탕화면 위젯에서 날짜별 3D 조형이 움직이고, 클릭하면 모델·추론 강도 변경과 작업 배정·재개 기록을 확인합니다. SUIT 글꼴과 잉크 네이비 화면을 사용합니다. 이전 차수는 보존했습니다.
+
+## 전달 파일
+
+- `CodexOrbit.exe`: Windows 10/11 x64용 단일 실행 파일.
+- `CodexOrbit-Setup.exe`: 현재 사용자 설치·시작 메뉴·선택 바탕화면 바로가기·제거 프로그램.
+- `사용법.md`, `기본_지침.md`, 라이선스, `소스와_재빌드.zip`.
+
+Python을 별도로 설치하지 않아도 실행합니다. 날짜별 실제 3D 모션에는 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. GPU 준비 중에는 해당 월의 정적 표식을 보여 주며, 실패하면 사유를 표시합니다. 이때 정적 표식을 3D 성공으로 기록하지 않습니다. 감시·계정 조회는 3D 렌더와 분리됩니다.
+
+## 매일 바뀌는 조형
+
+한국 날짜 기준 2026-01-01부터 2099-12-31까지 27,028일을 지원합니다. 37개 주제 모티프와24개 동반 모티프의 서로 다른 쌍으로888개 연월 컬렉션을 구성하며 두 모티프와 날짜별 주연 대상을 실제 형상 규칙에 연결합니다. 같은12개 월 테마를 매년 반복하지 않습니다. 위젯에는 실제 대상 이름을 표시하며 월 테마는 카탈로그에 별도로 기록합니다. 공통 형상 생성기를 재사용하는 장식용 조형이며888개 수작업 모델이나 과학 도감 수준의 정확한 복제품이라는 뜻은 아닙니다. 전체 연월 목록은 함께 제공하는 `연도별_월_테마.md`와CSV, 원본은 `assets/calendar-art/themes.md` 및 `themes.csv`에서 확인합니다.
+
+자정 이후 다음 프레임에 한국 날짜를 다시 확인하고 조형과 도크를 바꿉니다. 절전에서 복귀하거나 시계를 되돌려도 날짜를 재확인합니다. 수만 개 영상을 넣지 않고 그날의 실제 삼각형 메시만 렌더합니다. 굵은 금속 링 세 개가 서로 다른 축에서 각각12초·6초·4초에 한 바퀴씩 연속 회전합니다. 바탕화면과 내부 모션은 한 GPU 작업자·한 컨텍스트·최신 이미지와 정적 준비 이미지 두 장을 공유하며 초당 최대 30프레임입니다. 표시 대상이 없으면 렌더를 쉽니다. 날짜 카탈로그는 소스 ZIP의 `assets/calendar-art/catalog.json`에 있습니다.
+
+## 변경 기록과 실제 한도
+
+위젯에는 PC의 현지 시각을 초 단위로 표시하며, 인터넷 접속 IP의 대략적인 지역에서 현재 기온을 조회합니다. Windows 위치 서비스는 필요하지 않습니다. 지역 조회는 ipwho.is, 기온은 Open-Meteo의 최신 현재 기온 자료를 사용하며5분마다 자동 갱신합니다. 정확한 GPS 위치나 초 단위 현장 온도 센서 측정은 아니며 VPN·통신사망에서는 실제 지역과 다를 수 있습니다. IP로 추정한 지역명과 현재 기온은 위젯의 별도 줄에 표시합니다. 긴 지역명은 말줄임하고 전체 지역명·출처·조회 시각은 툴팁에 표시하며, 조회 실패나 오래된 값은 정상 최신 기온으로 표시하지 않습니다. 앱은 IP·좌표·이동 이력을 저장하지 않습니다.
+
+알림과 상세에서 모델 및 추론 강도를 각각 **이전 → 변경 후** 두 칸으로 표시합니다. 실제로 달라진 행만 강조합니다. 작업 배정·재개는 별도 종류이며 현재 설정을 표시합니다. 이전 기록이 없거나 필드가 미기록이면 사실대로 표시하고 과거 값을 추정하지 않습니다. 정확한 채팅 제목·맡긴 일·공개된 이유를 보존하며, 비공개 추론이나 확인되지 않은 선택 이유를 만들어 쓰지 않습니다.
+
+잔량은 Codex App Server의 읽기 전용 `account/rateLimits/read`에서 조회한 계정 사용 한도 비율입니다. 남은 토큰 개수는 아닙니다. 30초마다 갱신하고 숫자·막대는 같은 실제 비율을 사용합니다. 0%는 빈 막대, 100%는 가득 찬 막대이며 최소 채움을 임의로 보태지 않습니다. 지연·미확인은 정상 잔량으로 채우지 않습니다. 사용 한도 화면은 큰 숫자, 비례 막대, 초기화·최종 조회 시각과 날짜별 입체 모션을 분리합니다.
+
+## 사용 및 보존
+
+위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 오른쪽 가장자리를 끌면 폭, 아래쪽을 끌면 높이, 우하단 모서리를 끌면 두 크기를 함께 조절합니다. 크기와 위치는 저장되며 화면 밖에 있으면 복구합니다. 기본220×332·최소180×250이고, 조형과 이름·날짜·현재 시각·기온·실제 잔량은 독립 영역입니다. 기존에 저장한 크기는 보존합니다. 이름은 최소16픽셀로 유지하고 긴 이름은 줄을 바꿉니다. 로컬 선택 설정을 200ms 주기로 관측하며 알림은 각각 표시됩니다. 최대 8장 이후에는 오래된 창을 숨기고 기록은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 파일 수 4096개, 레코드 2MiB, 주기별 읽기 예산과 화면 이력 500건의 상한을 유지합니다. 원격·클라우드·서버 모델 신원·비공개 추론 또는 모든 부하에서 무지연을 보장하지 않습니다.
+
+기본 데이터는 현재 사용자의 `%LOCALAPPDATA%/CodexOrbit`입니다. 기존 설정·사용자 MD·백업과 이력을 보존합니다. 설정·내 지침·도움말 탭은 사용자 요청에 따라 노출하지 않으며, 내장 MD를 몰래 적용하지 않습니다. 문서 저장은 계정 전역 메모리나 다른 채팅의 지침 재주입을 의미하지 않습니다. 인증·신뢰·보안 설정을 바꾸지 않습니다. 개인 대화·인증 파일은 배포본에 포함하지 않습니다.
+
+## 재빌드
+
+`requirements.txt`의 고정 의존성을 준비하고 `tools/build_distribution.py`를 실행합니다. `CODEX_ORBIT_ISCC`에 Inno Setup 컴파일러 경로를 지정합니다. 배포 파일의 SHA256.json과 라이선스를 보존하십시오. ModernGL·glcontext·NumPy·Pillow·PySide6는 EXE에 포함되며 별도 사용자 설치가 필요하지 않습니다. 제작 및 검증 도구는 소스 ZIP에 있습니다. Windows 바로가기·트레이·실행파일 아이콘은 운영체제 형식상 정적이며, 실행 위젯과 내부 조형은 움직입니다.
+
+## 데이터와 진단 상세
+
+
+설정·MD·도움말 UI를 노출하지 않습니다. 기존 설정과 사용자 MD·백업은 삭제하거나 초기화하지 않습니다. 지침을 몰래 적용하지 않습니다. 앱 밖 운영 기록은 프로젝트 docs/운영_기억.md에 보존하며 계정 전역 메모리 저장이나 모든 대화의 지침 재주입을 뜻하지 않습니다.
+
+기본 앱 데이터는 현재 사용자의 LocalAppData/CodexOrbit입니다. 감시 경로와 Codex 실행 파일은 기존 설정 및 자동 탐색을 사용합니다. 별도 감시 경로가 필요한 실행에는 --sessions 경로, 독립 데이터에는 --data-dir 경로를 지정할 수 있습니다. 공유할 때 개인 대화·계정·원본 사용자 데이터는 배포 파일에 포함하지 않습니다.
+
+감시는 현재 설정된 sessions 디렉터리와 대응 session_index.jsonl의 로컬 기록 범위입니다. 다른 PC·원격·클라우드, 로컬에 기록되기 전 UI 선택, 서버 내부 모델 신원과 비공개 추론은 보장하지 않습니다. 파일 수4096개·레코드2MiB·주기별 읽기 예산이 있으며 상한/잘못된 기록은 진단에 남깁니다. 화면 이력은 최근500건입니다. startup.jsonl과 notice-presentations.jsonl은2MiB 순환 상한의 운영 기록이며 표시 요청은 사용자 실제 열람 인증이 아닙니다.
+
+## 배포와 진단
+

+
+투명한 148×148 바탕화면 위젯에서 날짜별 3D 조형이 움직이고, 클릭하면 모델·추론 강도 변경과 작업 배정·재개 기록을 확인합니다. SUIT 글꼴과 잉크 네이비 화면을 사용합니다. 이전 차수는 보존했습니다.

+## 매일 바뀌는 조형
+
+한국 날짜 기준 2026-01-01부터 2099-12-31까지 27,028일을 지원합니다. 1월 꽃, 2월 보석, 3월 나비, 4월 물과 비, 5월 숲, 6월 바다, 7월 우주, 8월 과일, 9월 음악, 10월 가을, 11월 빛과 건축, 12월 겨울입니다. 1월은 햇살꽃·봉오리·겹연꽃·종꽃·나팔꽃·동백빛·백합빛 구조를 사용하며 일자별 부품·비율과 연도 인자를 달리합니다. 다른 달도 그 주제의 메시와 일자별 부품 수·비율·곡률을 달리합니다. 실제 생물종이나 물성을 정확히 재현한다는 뜻은 아닙니다.
+
+자정 이후 다음 프레임에 한국 날짜를 다시 확인하고 조형과 도크를 바꿉니다. 절전에서 복귀하거나 시계를 되돌려도 날짜를 재확인합니다. 수만 개 영상을 넣지 않고 그날의 실제 삼각형 메시만 렌더합니다. 두 궤도는 서로 다른 축과 속도로 움직입니다. 바탕화면과 내부 모션은 한 GPU 작업자·한 컨텍스트·최신 이미지와 정적 준비 이미지 두 장을 공유하며 초당 최대 30프레임입니다. 표시 대상이 없으면 렌더를 쉽니다. 날짜 카탈로그는 소스 ZIP의 `assets/calendar-art/catalog.json`에 있습니다.

+## 변경 기록과 실제 한도
+
+알림과 상세에서 모델 및 추론 강도를 각각 **이전 → 변경 후** 두 칸으로 표시합니다. 실제로 달라진 행만 강조합니다. 작업 배정·재개는 별도 종류이며 현재 설정을 표시합니다. 이전 기록이 없거나 필드가 미기록이면 사실대로 표시하고 과거 값을 추정하지 않습니다. 정확한 채팅 제목·맡긴 일·공개된 이유를 보존하며, 비공개 추론이나 확인되지 않은 선택 이유를 만들어 쓰지 않습니다.
+
+잔량은 Codex App Server의 읽기 전용 `account/rateLimits/read`에서 조회한 계정 사용 한도 비율입니다. 남은 토큰 개수는 아닙니다. 30초마다 갱신하고 숫자·막대는 같은 실제 비율을 사용합니다. 0%는 빈 막대, 100%는 가득 찬 막대이며 최소 채움을 임의로 보태지 않습니다. 지연·미확인은 정상 잔량으로 채우지 않습니다. 사용 한도 화면은 큰 숫자, 비례 막대, 초기화·최종 조회 시각과 날짜별 입체 모션을 분리합니다.
+
+## 사용 및 보존
+
+위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 로컬 선택 설정을 200ms 주기로 관측하며 알림은 각각 표시됩니다. 최대 8장 이후에는 오래된 창을 숨기고 기록은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 파일 수 4096개, 레코드 2MiB, 주기별 읽기 예산과 화면 이력 500건의 상한을 유지합니다. 원격·클라우드·서버 모델 신원·비공개 추론 또는 모든 부하에서 무지연을 보장하지 않습니다.
+
+기본 데이터는 현재 사용자의 `%LOCALAPPDATA%/CodexOrbit`입니다. 기존 설정·사용자 MD·백업과 이력을 보존합니다. 설정·내 지침·도움말 탭은 사용자 요청에 따라 노출하지 않으며, 내장 MD를 몰래 적용하지 않습니다. 문서 저장은 계정 전역 메모리나 다른 채팅의 지침 재주입을 의미하지 않습니다. 인증·신뢰·보안 설정을 바꾸지 않습니다. 개인 대화·인증 파일은 배포본에 포함하지 않습니다.
+
+## 재빌드
+
+`requirements.txt`의 고정 의존성을 준비하고 `tools/build_distribution.py`를 실행합니다. `CODEX_ORBIT_ISCC`에 Inno Setup 컴파일러 경로를 지정합니다. 배포 파일의 SHA256.json과 라이선스를 보존하십시오. ModernGL·glcontext·NumPy·Pillow·PySide6는 EXE에 포함되며 별도 사용자 설치가 필요하지 않습니다. 제작 및 검증 도구는 소스 ZIP에 있습니다. Windows 바로가기·트레이·실행파일 아이콘은 운영체제 형식상 정적이며, 실행 위젯과 내부 조형은 움직입니다.
+
+## 데이터와 진단 상세
+
+
+설정·MD·도움말 UI를 노출하지 않습니다. 기존 설정과 사용자 MD·백업은 삭제하거나 초기화하지 않습니다. 지침을 몰래 적용하지 않습니다. 앱 밖 운영 기록은 프로젝트 docs/운영_기억.md에 보존하며 계정 전역 메모리 저장이나 모든 대화의 지침 재주입을 뜻하지 않습니다.
+
+기본 앱 데이터는 현재 사용자의 LocalAppData/CodexOrbit입니다. 감시 경로와 Codex 실행 파일은 기존 설정 및 자동 탐색을 사용합니다. 별도 감시 경로가 필요한 실행에는 --sessions 경로, 독립 데이터에는 --data-dir 경로를 지정할 수 있습니다. 공유할 때 개인 대화·계정·원본 사용자 데이터는 배포 파일에 포함하지 않습니다.
+
+감시는 현재 설정된 sessions 디렉터리와 대응 session_index.jsonl의 로컬 기록 범위입니다. 다른 PC·원격·클라우드, 로컬에 기록되기 전 UI 선택, 서버 내부 모델 신원과 비공개 추론은 보장하지 않습니다. 파일 수4096개·레코드2MiB·주기별 읽기 예산이 있으며 상한/잘못된 기록은 진단에 남깁니다. 화면 이력은 최근500건입니다. startup.jsonl과 notice-presentations.jsonl은2MiB 순환 상한의 운영 기록이며 표시 요청은 사용자 실제 열람 인증이 아닙니다.
+
+## 배포와 진단
+
+CodexOrbit.exe는 Python 설치 없이 실행합니다. CodexOrbit-Setup.exe는 현재 사용자용 설치·시작 메뉴·선택 바탕화면 바로가기를 제공합니다. 제거 프로그램은 사용자 MD·백업·이력을 삭제하지 않습니다. 소스ZIP과 라이선스도 함께 제공합니다. 이 사용법은 배포 문서이며 앱 내부 도움말 탭은 없습니다.
+
+--smoke-test --smoke-report 경로는 실제 EXE의 프레임 변화·투명 모서리·내장 글꼴을 검사하고 종료합니다. --usage-smoke-test는 실제 계정 조회·화면 표시를 저장하는 별도 진단이며 실제 사용자 알림 수신 증거는 아닙니다. --show-event 이벤트ID 또는 대상ID는 기존 이력을 다시 표시하며 새 관측이나 실행 중 앱에 명령 전달을 만들지 않습니다.

+## 위젯 조작
+
+위젯을 끌어 이동하고, 오른쪽·아래쪽 가장자리나 우하단을 끌어 크기를 조절합니다. 클릭하면 상세창을 엽니다. 위치·크기는 저장됩니다. 상세창 위쪽 또는 우클릭 메뉴에서 한국어·영어를 선택합니다.
+
+상세창의 회전 속도 슬라이더로 0.25~3배를 선택합니다. 1배 복원 버튼과 우클릭 속도 메뉴도 있습니다. 속도는 저장되며 시계·날씨·사용 한도 갱신 주기에는 영향을 주지 않습니다.
+
+## 📨 간결해진 알림
+
+알림에는 💬 채팅 제목, ⬅️ 이전 모델, 🧠 이전 추론 강도, ➡️ 현재 모델, 🧠 현재 추론 강도, 💡 이유를 표시합니다. 모델은 ☀️ 솔·✨ 아스트라·🌍 테라·🌙 루나로 구분하고 정확한 모델 ID도 유지합니다. 다른 모델은 🤖로 표시합니다.
+
+이유는 기록으로 확인한 내용을 쉬운 말로 설명합니다. 선택 이유가 기록되지 않았으면 그 사실을 알려 드리며, 실제로 없는 동기나 비공개 추론을 만들지 않습니다. 작업 배정·재개는 설정 변경과 구분합니다. 자세한 원문과 근거는 상세 기록에서 확인합니다.
+
+## 알림 읽기
+
+모델과 추론 강도는 각각 **이전 → 변경 후**로 표시합니다. 작업자 배정·재개는 별도 종류로 표시하며, 기록된 채팅 제목·맡긴 일·공개된 이유를 보여 줍니다. 기록이 없는 이전값이나 이유는 확인 불가로 표시합니다. 비공개 추론을 복원하지 않습니다.
+
+로컬 선택 상태를 관측해 메시지 전송 전 변경도 감지하며, 로컬 기록에 반영되기 전 선택·원격/클라우드 채팅·서버 내부 모델 신원까지 보장하지 않습니다. 감시 파일 4,096개, 레코드 2MiB, 주기별 읽기 예산이 있습니다. 알림은 여러 창으로 표시하며 최대 8장 이후 오래된 창을 숨기고 최근 기록 500건을 보존합니다. 최초 실행은 과거 기록을 기준선으로 읽습니다.
+
+## 시각·기온·남은 한도
+
+PC 현지 시각을 표시합니다. Windows 위치 서비스 대신 인터넷 IP의 대략적인 지역을 사용하고 현재 기온을 5분마다 갱신합니다. VPN·통신사망에서는 실제 위치와 다를 수 있습니다. IP 지역은 ipwho.is, 날씨는 Open-Meteo 자료를 사용합니다. 조회 실패·오래된 값은 구분해서 표시합니다.
+
+잔량 막대는 Codex 계정의 실제 **남은 사용 한도 비율**이며 남은 토큰 개수는 아닙니다. 읽기 전용 계정 조회를 30초마다 수행하며, 조회되지 않은 값을 임의로 채우지 않습니다.

+## 날짜별 모션과 화질
+
+한국 날짜 기준 2026~2099년의 27,028일을 지원합니다. 888개 연월 조합과 날짜별 형상 규칙을 사용합니다. 모든 날짜가 별도의 수작업 3D 모델이라는 뜻은 아닙니다. 날짜는 한국 자정 기준으로 바뀌며 시계는 PC 현지 시각을 표시합니다.

+금속 곡면의 세 링과 흑연 원자핵, 전자 입자가 움직이는 투명한 무채색 위젯입니다. 실제 3D로 제작한 18초 모션을 재생하며 링은 각기 다른 축·방향·속도로 회전합니다. 중심의 숫자는 고정하며 실제 조회한 Codex 계정의 남은 사용 한도 비율만 표시합니다. 글꼴은 내장 나눔고딕 Bold700입니다.
+
+## 화면과 조작
+
+- 위젯을 끌면 위치가 바뀌고 다음 실행에서도 기억합니다. 화면 밖으로 이동한 위치는 보이는 모니터 안으로 복구합니다.
+- 위젯을 누르면 변경 기록이 열립니다. 우클릭 메뉴에는 기록 열기와 종료처럼 필요한 조작만 둡니다.
+- 화면은 ‘변경 기록’과 ‘사용 한도’ 두 탭만 사용합니다. 설정·내 지침·도움말 화면은 제거했습니다.
+- 변경 기록에서 정확한 채팅 제목, 이전/새 모델 ID, 이전/새 추론 강도, 공개 이유를 확인합니다. 원문·ID·근거는 펼쳐 읽을 수 있습니다. 공개 이유가 없으면 임의로 만들지 않습니다.
+- 긴 제목은 가능한 영역에 표시하고 화면을 넘으면 명시적으로 줄입니다. 상세와 원문은 보존합니다.
+- ‘감시 중’, ‘새 변경’, ‘확인 필요’는 실제 감시/읽지 않은 기록 상태에 따른 문구입니다. 연결·기준선 준비·지연·실패를 정상으로 표시하지 않습니다. 오류 진단은 변경 기록 화면에서 확인합니다.
+
+## 모델·추론 변경 알림
+
+현재 사용자의 로컬 Codex 기록에서 선택 설정의 변경이 기록되면 다음 메시지 실행을 기다리지 않고 알립니다. 200ms 감시 주기와 실제 파일 쓰기·부하·UI 표시 지연이 있으므로 0ms 즉시 전달을 보장하지는 않습니다. 일반 채팅과 자식 작업의 모델만·강도만·동시 변경을 구분하며 후속 실행에서 같은 선택을 중복 알리지 않습니다. 앱은 모델을 바꾸는 도구가 아닙니다.
+
+처음에는 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 기존 감시 상태·이력과 읽은 위치를 보존하며 큰 기록의 준비에는 시간이 걸릴 수 있습니다. 같은 감지 묶음은 유효한 원본 기록 시각 순으로 안정 정렬하고, 시각이 없거나 잘못되면 감지 위치를 유지합니다. 늦게 읽은 파일 때문에 이미 표시한 알림을 재정렬하지 않습니다.
+
+변경마다 별도 알림이 나타나 앞 알림을 닫을 필요가 없습니다. 공간 안에 쌓고 부족하면 어긋나게 겹칩니다. 동시 최대8장, 초과 시 오래된 창을 숨기고 최신 알림을 바로 표시합니다. 숨긴 건수와 이력을 유지합니다. 각 알림의 닫기·클릭·만료는 다른 알림에 영향을 주지 않습니다. 기본 표시 시간은30초이며 기존 사용자 설정은 보존합니다. 알림을 누르면 그 항목의 정확한 기록이 열립니다.
+
+감시 진행이20초 이상 없으면 지연을 표시하며 실제 종료된 작업자만 최대3차례 재시도합니다. 정체된 실행 작업자를 임의 강제 종료하지 않습니다. 이전 정체의 역사적 최초 원인은 확정되지 않았으며 진단과 실제 관측을 구분합니다.
+
+## 실제 잔량
+
+현재 로그인된 Codex 계정의 사용 한도 비율입니다. 남은 토큰 개수가 아닙니다. 여러 버킷·기간이 있으면 확인된 값 중 가장 낮은 남은 비율을 중심에 표시합니다. ‘사용 한도’에서 기간·버킷별 막대, 초기화 한국 시각, 최종 조회 시각과 수동 새로고침을 확인합니다. 서버가 주간만 주면 주간만 표시합니다.
+
+설치된 Codex의 공식 App Server에 숨김 연결해 읽기 전용 account/rateLimits/read만 조회합니다. 최초 실행 후30초마다 자동 조회하고 서버 갱신 알림도 반영합니다. 설치된 Codex의 ChatGPT 로그인이 필요합니다. 앱은 인증 파일을 직접 읽거나 복사하지 않으며 로그인·리셋·구매·모델 실행·Codex 설정 변경을 하지 않습니다.
+
+미확인은 ‘—’, 지연된 이전 수치는 ‘?’와 이전 조회 표시를 사용합니다. 초기화 시각이 지나도 임의로100%를 만들지 않습니다. 잔량을 디스크에서 복원하는 캐시는 사용하지 않습니다. 모션 장식의 중간값을 실제 잔량으로 표시하지 않습니다. 미리보기의53%·81% 등은 예시라고 표시한 경우 시연 숫자입니다.
+
+## 지침·설정과 데이터
+
+설정·MD·도움말 UI를 노출하지 않습니다. 기존 설정과 사용자 MD·백업은 삭제하거나 초기화하지 않습니다. 지침을 몰래 적용하지 않습니다. 앱 밖 운영 기록은 프로젝트 docs/운영_기억.md에 보존하며 계정 전역 메모리 저장이나 모든 대화의 지침 재주입을 뜻하지 않습니다.
+
+기본 앱 데이터는 현재 사용자의 LocalAppData/CodexOrbit입니다. 감시 경로와 Codex 실행 파일은 기존 설정 및 자동 탐색을 사용합니다. 별도 감시 경로가 필요한 실행에는 --sessions 경로, 독립 데이터에는 --data-dir 경로를 지정할 수 있습니다. 공유할 때 개인 대화·계정·원본 사용자 데이터는 배포 파일에 포함하지 않습니다.
+
+감시는 현재 설정된 sessions 디렉터리와 대응 session_index.jsonl의 로컬 기록 범위입니다. 다른 PC·원격·클라우드, 로컬에 기록되기 전 UI 선택, 서버 내부 모델 신원과 비공개 추론은 보장하지 않습니다. 파일 수4096개·레코드2MiB·주기별 읽기 예산이 있으며 상한/잘못된 기록은 진단에 남깁니다. 화면 이력은 최근500건입니다. startup.jsonl과 notice-presentations.jsonl은2MiB 순환 상한의 운영 기록이며 표시 요청은 사용자 실제 열람 인증이 아닙니다.
+
+## 배포와 진단
+
+CodexOrbit.exe는 Python 설치 없이 실행합니다. CodexOrbit-Setup.exe는 현재 사용자용 설치·시작 메뉴·선택 바탕화면 바로가기를 제공합니다. 제거 프로그램은 사용자 MD·백업·이력을 삭제하지 않습니다. 소스ZIP과 라이선스도 함께 제공합니다. 이 사용법은 배포 문서이며 앱 내부 도움말 탭은 없습니다.
+
+--smoke-test --smoke-report 경로는 실제 EXE의 프레임 변화·투명 모서리·내장 글꼴을 검사하고 종료합니다. --usage-smoke-test는 실제 계정 조회·화면 표시를 저장하는 별도 진단이며 실제 사용자 알림 수신 증거는 아닙니다. --show-event 이벤트ID 또는 대상ID는 기존 이력을 다시 표시하며 새 관측이나 실행 중 앱에 명령 전달을 만들지 않습니다.
+
+16차 수정: 모델·추론 변경의 이전값과 새값을 각각 구분해 표시합니다. 이전 기록이 없는 첫 관측은 실제 변경과 구분하며 과거값을 임의로 채우지 않습니다. 금속 원자 모션과 감시·계정 조회 및 보존 자료는 유지합니다.
+
+17차 디자인: 실제3D 금속 원자 모델의 세 링이 서로 다른 축으로 움직이며 앱 상단과 알림도 같은 모션을 공유합니다. 기능 아이콘은 무채색 입체 표식으로 통일했습니다. 실행 위젯과 앱 안 로고는 움직이고 Windows 바로가기·실행파일·트레이 아이콘은 같은 모델의 정적 렌더입니다. 이전/새 모델과 추론 강도 및 실제 조회 수치의 의미는 유지합니다.

+def orbit_image(size, moment=0, badge='81%', fraction=.81):
+    image = QImage(size, size, QImage.Format.Format_RGBA8888)
+    image.fill(Qt.GlobalColor.transparent)
+    painter = QPainter(image)
+    painter.setRenderHint(QPainter.RenderHint.Antialiasing)
+    painter.translate(size / 2, size / 2)
+    painter.scale(size / 148, size / 148)
+    draw_orbit(painter, moment, badge, fraction, 'fresh', True)
+    painter.end()
+    return image
+
+
+def png_bytes(image):
+    data = QByteArray()
+    buffer = QBuffer(data)
+    buffer.open(QIODevice.OpenModeFlag.WriteOnly)
+    image.save(buffer, 'PNG')
+    return bytes(data)
+
+
+def chunk(kind, value):
+    return struct.pack('>I', len(value)) + kind + value + struct.pack('>I', binascii.crc32(kind + value) & 0xffffffff)
+
+
+def write_motion(path):
+    size, frames = 360, 48
+    output = bytearray(b'\x89PNG\r\n\x1a\n')
+    output += chunk(b'IHDR', struct.pack('>IIBBBBB', size, size, 8, 6, 0, 0, 0))
+    output += chunk(b'acTL', struct.pack('>II', frames, 0))
+    sequence = 0
+    for index in range(frames):
+        image = orbit_image(size, index / 12)
+        if index in (0, 12, 24, 36):
+            image.save(str(path.parent / f'orbit-frame-{index:02}.png'))
+        raw = bytes(image.constBits())
+        packed = zlib.compress(b''.join(b'\0' + raw[y * size * 4:(y + 1) * size * 4] for y in range(size)), 6)
+        output += chunk(b'fcTL', struct.pack('>IIIIIHHBB', sequence, size, size, 0, 0, 1, 12, 0, 0))
+        sequence += 1
+        if index == 0:
+            output += chunk(b'IDAT', packed)
+        else:
+            output += chunk(b'fdAT', struct.pack('>I', sequence) + packed)
+            sequence += 1
+    output += chunk(b'IEND', b'')
+    path.write_bytes(output)
