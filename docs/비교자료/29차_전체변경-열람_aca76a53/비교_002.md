+# Codex Orbit 사용 설명 · 5차 / 버전 1.3
+
+실행하면 투명 배경의 작은 원자 궤도가 화면 위에 나타납니다. 나눔고딕 Bold 글꼴을 내장하며 인터넷으로 대화 내용을 전송하지 않습니다.
+
+## 궤도 조작
+
+- 마우스로 드래그하면 위치를 옮깁니다. 다음 실행에서도 위치를 기억하고, 모니터가 바뀌어 화면 밖에 놓이면 보이는 화면으로 복구합니다.
+- 궤도를 클릭하면 변경 이력이 열립니다. 우클릭하면 설정과 종료 메뉴가 나옵니다.
+- 중심의 작은 점은 정상 감시일 때 초록, 새 변경이 있을 때 분홍, 감시 오류일 때 주황입니다.
+- 새 변경의 말풍선을 클릭하면 그 알림의 정확한 이력을 엽니다. 새 항목이 추가돼도 다른 항목으로 바뀌지 않습니다. 기본 표시 시간은 30초이며, 설정의 ‘알림을 직접 닫을 때까지 유지’를 켜면 ×를 누를 때까지 유지합니다.
+- 같은 감시 주기에 대기한 변경은 유효한 원본 기록 시각 순서로 정렬한 뒤 말풍선을 차례로 표시합니다. 원본 시각이 같으면 감지 순서를 유지하고, 시각이 없거나 잘못된 항목은 감지 위치를 유지합니다. 이미 표시한 알림은 뒤늦게 읽은 파일 때문에 재정렬하지 않습니다. 닫기·클릭·자동 만료 뒤 다음 알림이 나타나며 대기 건수도 표시합니다. 직접 닫기 설정에서도 닫거나 클릭하면 다음으로 넘어갑니다. 이력 다시 보기는 현재 알림을 덮어쓰지 않고 대기하며, 이미 대기 중인 같은 항목은 중복하지 않습니다.
+- 말풍선 대기는 최대 100건입니다. 초과 건수는 말풍선과 이력 상단에 명시하므로 최근 변경 이력에서 확인하세요. 화면 이력은 최근 500건이며 파일 보존에도 아래의 순환 상한이 있습니다.
+- 밝은 화면에서는 ‘밝은 배경’, 어두운 화면에서는 ‘어두운 배경’ 대비를 선택할 수 있습니다.

+## 실시간 Codex 잔량
+
+중심 숫자는 현재 로그인된 Codex 계정의 남은 **사용 한도 비율**입니다. 남은 토큰 개수를 뜻하지 않습니다. 여러 버킷·기간이 있으면 확인된 값 중 가장 적게 남은 비율을 중심에 표시합니다. 상세 창 상단에서 각 버킷의 기간별 잔량 막대·초기화 한국 시각·최종 조회 시각을 확인할 수 있습니다. 서버가 주간 한도만 주면 주간만 표시하며 없는 5시간 한도를 만들지 않습니다.
+
+앱은 PC에 설치된 Codex의 공식 App Server를 별도 숨김 프로세스로 연결하여 읽기 전용 `account/rateLimits/read`만 조회합니다. 최초 실행 후 30초마다 자동 조회하며 ‘새로고침’을 눌러 수동 조회할 수 있습니다. 서버가 사용 한도 변경을 알리면 반영합니다. 실제 조회 지연과 서버 반영 시차가 있으며 매 순간의 확정값은 아닙니다. 연결 중에도 궤도 회전·드래그와 기존 알림 기능을 사용할 수 있습니다.
+
+아직 한도를 받지 못했거나 수치가 없으면 중심은 ‘—’입니다. 조회 실패·지연 또는 초기화 시각 경과 후 재조회 전에는 과거 수치를 현재값으로 표시하지 않으며, 이전 수치가 있으면 중심에 ‘?’와 상세에 ‘이전 조회 값’을 표시합니다. 초기화 시각이 지났다고 임의로 100%로 바꾸지 않습니다. 잔량을 디스크에 캐시해 다음 실행에 복원하지 않습니다.
+
+설치된 Codex에서 ChatGPT 로그인이 되어 있어야 합니다. 앱은 로그인·계정 선택·리셋·크레딧 구매·모델 실행·Codex 설정 변경을 하지 않으며 인증 파일을 직접 읽거나 복사하지 않습니다. 연결 실패 시 세 차례까지만 자동 재연결하며 수동 새로고침으로 다시 시도할 수 있습니다. Codex EXE 자동 탐색이 실패하면 ‘설정 · 진단’의 ‘Codex EXE 선택’에서 설치된 `codex.exe`를 선택하고 저장하세요. 비워 저장하면 자동 탐색으로 돌아갑니다. API 키를 입력하는 기능은 없습니다.
+
+## 모델 변경 감시와 근거
+
+기본은 CODEX_HOME 환경변수 또는 사용자 홈의 .codex/sessions 폴더입니다. 설정에서 실제 sessions 폴더를 선택할 수 있습니다. 최초 실행은 기존 기록을 기준선으로 읽으므로 과거 알림을 쏟아내지 않습니다. 폴더별 상태가 별도로 보존됩니다.
+
+실제 turn_context의 모델과 추론 강도 변화, 새 세션의 첫 배정을 로컬 기록에서 감지합니다. 로그에 남기 전의 화면 설정 변경과 서버 내부 변경을 즉시 알 수는 없습니다. 부모에서 상속한 기록은 자식의 실제 턴으로 중복 처리하지 않습니다.
+
+감지 시각은 앱이 변경을 발견한 시각이며, 원본 turn_context의 시각은 별도 보존해 상세에서 표시합니다. 파일 읽기 예산 때문에 뒤늦게 발견한 항목과 이미 전송한 알림 사이의 전체 시간순까지 보장하지 않습니다. 비교할 수 없는 시각을 현재 시각으로 만들어 정렬하지 않습니다.
+
+채팅 제목은 sessions와 같은 상위 폴더의 session_index.jsonl에서 읽습니다. 앱 데이터 폴더의 title-cache.json에 공식 앱에서 확인한 제목을 저장하면 그 확인 캐시를 우선합니다. 출처와 확인 시각은 상세에 남으며 현재 실시간 조회로 표현하지 않습니다. 자식 작업에는 부모 채팅의 정확한 제목과 별도 작업 이름을 표시합니다. 확인할 수 없으면 ‘채팅 제목 확인 불가’로 표시하며 첫 프롬프트나 폴더명을 제목으로 만들지 않습니다.
+

+# Codex Orbit 배포 안내
+
+13차 / 버전 2.0.2: 로컬 Codex 채팅에 선택한 모델·추론 강도 설정이 기록되면 다음 메시지 실행을 기다리지 않고 변경 알림을 표시합니다. 변경마다 독립 알림을 즉시 표시하며 무채색 입체 궤도·잔량·MD 기능은 유지합니다. 이전12차를 보존합니다.
+
+투명한 회전 궤도 위젯으로 Codex 계정 잔량과 로컬 모델·추론 강도 변경을 확인하는 Windows 10/11 x64 앱입니다.
+
+중심에는 확인된 기간 중 가장 적게 남은 사용 한도 비율을 표시합니다. 남은 토큰 개수가 아닙니다. 사용 한도 탭에는 버킷·기간별 잔량 막대, 초기화 한국 시각, 최종 조회 시각과 수동 새로고침이 있습니다. 공식 `account/rateLimits/read`를 설치된 `codex app-server`에서 읽기 전용으로 30초마다 조회하며 서버의 갱신 알림도 반영합니다. 없는 기간·null 수치는 만들어 표시하지 않습니다.
+
+설치된 Codex의 ChatGPT 로그인이 필요합니다. EXE를 자동 탐색하고 실패하면 설정에서 설치된 `codex.exe`를 선택할 수 있습니다. 앱은 인증 파일을 직접 읽거나 복사하지 않고 로그인·리셋·구매·모델 실행·Codex 설정 변경을 하지 않습니다. 연결 실패·지연이면 이전 값임을 명시하며 재실행할 때 잔량을 디스크에서 복원하지 않습니다. 서버 반영과 연결 상황에 따라 조회가 늦어질 수 있습니다.

+## 시작과 MD 적용
+
+앱을 켜면 작은 회전 위젯이 나타납니다. 끌어서 옮기고 클릭해서 상세 창을 여십시오. 처음에는 기존 기록을 기준선으로 읽으며 과거 알림을 쏟아내지 않습니다. 이전 버전의 감시 상태는 원본을 백업하고 이미 읽은 위치까지만 선택 설정 기준선을 복원합니다. 기존 이력을 지우지 않으며 복원 중 추가된 변경은 이후 새 알림으로 처리합니다. 큰 기록은 ‘기준선 준비 중’으로 표시하며 처리 시간이 걸릴 수 있습니다.
+
+MD 탭에서 지침을 가져오거나 편집하고 적용 대상 AGENTS.md를 선택합니다. 미리보기를 확인하고 적용 버튼을 누릅니다. 기존 내용은 백업하고 관리구역만 갱신합니다. 다른 프로그램이 파일을 변경하면 적용·원복을 거부하여 그 변경을 보호합니다. 다른 사람에게 윤석님의 원본 MD를 줄 때는 개인 이름·절대 경로·프로젝트·민감 정보부터 확인하십시오.
+
+MD 파일 적용은 Codex의 설정·권한·인증을 바꾸거나 이미 열린 모든 채팅에 지침을 재주입하는 기능이 아닙니다. 새 채팅이나 해당 프로젝트를 다시 여는 시점의 지침 읽기를 통해 적용 여부를 확인하십시오. 앱은 모델 자체를 변경하지 않습니다.

+## 기록과 한계

+## 라이선스와 재빌드

+def run(argv, name, timeout):
+    """실제 인자와 종료 결과를 별도 파일에 보존합니다."""
+    started = time.time()
+    build_env = os.environ.copy()
+    base_python = Path(sys.base_prefix)
+    windows = Path(os.environ.get('SystemRoot', r'C:\Windows'))

+기본은 CODEX_HOME 환경변수 또는 사용자 홈의 .codex/sessions 폴더입니다. 설정에서 실제 sessions 폴더를 선택할 수 있습니다. 최초 실행은 기존 기록을 기준선으로 읽으므로 과거 알림을 쏟아내지 않습니다. 폴더별 상태가 별도로 보존됩니다.
+
+실제 turn_context의 모델과 추론 강도 변화, 새 세션의 첫 배정을 로컬 기록에서 감지합니다. 로그에 남기 전의 화면 설정 변경과 서버 내부 변경을 즉시 알 수는 없습니다. 부모에서 상속한 기록은 자식의 실제 턴으로 중복 처리하지 않습니다.
+
+감지 시각은 앱이 변경을 발견한 시각이며, 원본 turn_context의 시각은 별도 보존해 상세에서 표시합니다. 파일 읽기 예산 때문에 뒤늦게 발견한 항목과 이미 전송한 알림 사이의 전체 시간순까지 보장하지 않습니다. 비교할 수 없는 시각을 현재 시각으로 만들어 정렬하지 않습니다.

+def chunk(kind, value):
+    return struct.pack('>I', len(value)) + kind + value + struct.pack('>I', binascii.crc32(kind + value) & 0xffffffff)

+def write_motion(path):
+    size, frames = 360, 144
+    output = bytearray(b'\x89PNG\r\n\x1a\n')
+    output += chunk(b'IHDR', struct.pack('>IIBBBBB', size, size, 8, 6, 0, 0, 0))
