## 목표와 범위

**35차 소스와 36차 설치 기반**을 이어 버전 3.7.0을 준비합니다. 기존 PySide6 앱을 확장하며 별도 앱이나 새 의존성은 추가하지 않습니다. 감시 상태와 복구, 알림 묶음, 중요한 변경의 강조, 실제 기록을 만들지 않는 미리보기, 안전한 업데이트를 개선합니다. [50개 기능과 선택 근거](37차_50개개선.md)를 기준으로 구현합니다.

| 영역 | 계획 | 보존할 조건 |
|---|---|---|
| 알림 센터 | 검색·필터·묶음·요약·복사·내보내기 | 프라이버시 가림과 CSV 수식 방어 |
| 업데이트 | 공식 출처·공간·검증·단계·결과 안내 | 기존 복구와 설정 보존을 유지·보완 |
| 감시와 알림 | 상태·지연·재연결·집중·음소거·표시 설정 | 실제 관측과 미확인 구분, 미리보기 이력 미생성 |
| 화면과 설치 | 시스템·라이트·다크, 날짜별 과일·꽃 픽셀 3D 유지 | 고리·모델 위젯 복원 없음; 바로가기 체크박스 없는 기존 설치 방식 유지 |

## 확인된 문서 관계와 한계

이전 차수의 고리·모델 중심 위젯 계획은 당시의 기록이며 이후 날짜별 조형과 34차 픽셀 3D 요구로 대체된 부분이 있습니다. 이전 문서에 후속 결과를 덧씌우지 않습니다. 원소와 연월·날짜별 테마는 기존 카탈로그 원문과 표준 열을 유지합니다. 조형과 정보의 분리 및 자동 복구는 기존 기능을 보완하거나 유지합니다.

요청값·관측값·실행 근거를 구분합니다. 사용 한도와 갱신 시각, 예상 크기와 시간은 확인되지 않으면 미확인으로 표시합니다. IP 기반 위치는 GPS나 검증된 주소가 아닙니다. 개인 운영 기록은 공개 문서에 복제하지 않습니다.

## 순서와 검증 상태

1. 기존 소스와 설치 기반에 50개 항목을 연결하고 설정과 개인정보 경계를 보존합니다.
2. 변경된 기능과 실패 경로를 필요한 범위에서 확인하고 결과를 기록합니다.
3. 빌드·설치 및 결과를 확인한 뒤 실제 결과에 맞게 이 문서를 갱신합니다.

**현재 상태:** 구현과 관련 합성 검사 21개를 완료했습니다. 새 센터의 검색·프라이버시 복사·가상 알림과 라이트·다크 화면을 격리한 Qt 화면에서 확인했습니다. 최초 통합 검사의 업데이트 창 닫기 오류는 수정 후 해당 닫기 경로만 다시 확인했습니다. 별개의 기존 3D 초기 응답 시간 초과 기록은 보존하며 전체 회귀 성공으로 간주하지 않습니다. 최종 패키징 결과는 배포 기록에서 구분합니다.

현재 배포 파일과 GUI 연결 관측은 [37차 최소 검사](37차_최소검사.md)에 기록합니다. 각 모듈의 확인 결과를 전체 회귀·실제 업데이트 통과로 확대하지 않습니다.
