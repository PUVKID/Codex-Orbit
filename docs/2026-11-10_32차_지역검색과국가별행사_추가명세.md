# 지역 검색과 국가별 행사

## 사용 흐름

- 위젯의 지역 표시를 눌러 `도시·지역`, `주소·장소`, `국가` 중 하나를 검색합니다. 결과 목록에서 직접 선택한 뒤 적용합니다. 검색 첫 결과를 자동으로 선택하지 않습니다.
- 도시·주소·장소를 선택하면 해당 좌표의 날씨와 해당 국가의 달력 디자인을 적용합니다. 이름이 같은 다른 도시를 구분할 수 있도록 국가와 상위 지역을 표시합니다.
- 국가만 선택하면 국가별 디자인을 바꿉니다. 국가 전체에 하나의 기온을 붙이지 않습니다. 날씨의 기준 지역은 그대로 표시하고 다른 국가라면 도시를 추가로 선택하도록 안내합니다.
- 자동 위치로 돌아가면 네트워크 IP 기반으로 다시 찾습니다. IP 위치는 추정 지역이며 실제 동·건물 위치를 보장하지 않습니다. 사용자가 선택하지 않은 상세 주소를 만들어 표시하지 않습니다.
- 직접 선택한 장소와 국가 설정은 로컬에 저장합니다. 주소·좌표·설정 원문은 공개 저장소에 포함하지 않습니다.

## 날씨와 시각

Open-Meteo의 동일 좌표 요청으로 현재 기온·날씨·상대습도와 당일 일출·일몰을 받습니다. 일출·일몰은 제공자의 해당 지역 UTC 시차로 표시합니다. 극지방이나 누락된 값은 `—`로 표시하며 임의 시각을 만들지 않습니다. 시간대가 달라도 컴퓨터의 한국 시각을 일출 시각으로 오해하지 않게 합니다.

날씨는 선택 좌표 주변의 기상 모델 격자 자료이며, 집 앞 기온계의 직접 측정값이 아닙니다. 지점을 상세하게 선택해도 거리·건물마다 별도 실측값이 생기는 것은 아닙니다.

지역을 바꾸면 이전 지역의 기온과 부가 정보를 비우고 새 응답을 기다립니다. 변경 전 요청이 늦게 도착해도 새 지역을 덮지 않습니다. 연결 실패 시 새 값인 것처럼 표시하지 않으며 조회 상태·마지막 확인 시각을 구분합니다. 갱신 간격은 5분이며 초 단위 관측을 보장하지 않습니다.

도시 검색은 Open-Meteo/GeoNames, 주소·장소 검색은 Photon/OpenStreetMap을 사용합니다. 장소 검색은 명시적 검색으로만 실행하고 전체 클라이언트에서 최소 1초 간격과 작은 캐시를 유지합니다. 공개 검색 서버의 서비스 수준이나 모든 주소 수록 여부를 보장하지 않습니다. 검색어는 선택한 검색 서비스로 전송됩니다.

## 달력과 디자인

기존 2026~2099년의 날짜별 대상·월별 주제는 일반일의 기본값으로 보존합니다. 날짜 위젯의 금속 고리와 좌우의 별도 장식은 모든 날짜에서 제거합니다. 당일 대상 하나를 실제 입체 기하와 재질로 렌더링하고 회전·정지·속도·모션 축소를 유지합니다.

국가 행사 자료는 `holidays 0.108` 및 Babel 2.18.0의 국가 이름을 바탕으로 생성해 앱에 동봉합니다. 250개 국가·지역의 2026~2099년 자료이며 국가 공휴일과 자료가 지원하는 기념일 범위입니다. 모든 도시의 지역 축제나 향후 법 개정까지 미리 확정했다는 뜻이 아닙니다. 자료의 제한 경고를 보존합니다. 인도 등 일부 미래 연도의 제한은 숨기지 않습니다.

실제 행사명을 유지하고 해당 행사에 맞는 특집 디자인을 우선합니다. 행사 자료가 없는 날에는 기존 날짜별 디자인으로 돌아갑니다. 다른 나라에 한국 공휴일을 그대로 적용하지 않습니다. 국가만 선택해 시간대가 정해지지 않은 경우에는 한국 날짜 기준을 안내하고 도시 선택으로 현지 시차를 연결합니다.

## 검증 기준

선택 좌표와 요청 좌표의 일치, 잘못된 좌표·과도한 응답·늦은 응답 거부, 언어 전환, 저장 실패 되돌리기, 장소 검색 제한, 시간대·극지방 예외를 검사합니다. 동봉 국가 자료 250파일의 크기·SHA-256과 전체 행사 날짜·연도 범위를 대조합니다. 공개 수원 도시·장소 검색과 실제 날씨 응답을 확인하되 사용자 실제 위치를 확인한 것으로 표현하지 않습니다.

화면은 한영·라이트/다크·확대·좁은 위젯·팝업·키보드·버튼 상태를 실제 조작으로 점검합니다. 테스트 성공만으로 사진 수준의 사실감이나 미래의 완전 무오류를 주장하지 않습니다.
