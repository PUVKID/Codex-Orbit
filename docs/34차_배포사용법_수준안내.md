# 34차·배포 사용 법의 수준 안내

**개발 원본과 동 봉 사용법의 5 경로에 다섯 설명으로 이동하는 링크를 추가했습니다.** 저장소 공개 문서에는 이미 수준 선택이 있었지만, 개발 원본 README 두 언어와 assets·docs의 사용법에는 해당 안내가 빠져 있었습니다.

첫 제목 바로 뒤에 작은 링크 묶음을 넣고 원래 본문·코드·상대 주소와 개 행을 유지했습니다.

실행 모듈과 검사 논리를 바꾼 수리는 아닙니다.

## 링크와 사용 범위

배포 사용 법에서 LEVEL 1 - Beginner부터 LEVEL 5 - Expert까지 선택하면 같은 프로젝트의 전체 설명으로 이동합니다.

저장소의 공개 사용법과 모바일 목차는 그대로 유지합니다.

배포 폴더에 저장 소 전체가 없어도 주소 기준이 바뀌지 않도록 절대 웹 주소를 사용했습니다.

페이지를 여는 데 필요한 인터넷 연결과 원격 서비스 접근은 별도 조건입니다.

## 이전 배포본과 새 빌드의 구분

**가이드 추가 후 재빌드와 새 배포 검사를 확인했습니다.** 전체 653개 검사에서 실패 0·건너뜀 1, 빌드 입력 843 파일 불변을 확인했습니다.

새 EXE의 한국어 가이드와 별도 한국어·영어 사용법에는 다섯 링크가 있으며, 영어 가이드까지 모두 EXE 안에 내장된 구조는 아닙니다.

새 실행 본의 네 합성 화면 조합·정적 227 검사·설치 본 47 파일 추출 대조를 확인했지만 실제 설치와 새 EXE의 행사 8 종 순회는 이 결과에 포함하지 않습니다.

가이드 보강 후 2026년 11월 14일 재빌드는 414.282초에 종료 코드 0으로 끝났습니다.

앞 325개 검사는 119.095초, 뒤 328개는 130.054초이며 이는 각 unittest 기록 시간입니다.

실행 프로세스 시간은 각각 128.217초와 133.141초로 구분합니다.

기존 입력 843 파일은 빌드 전후 같았습니다.

EXE는 assets의 한국어 사용법을 포함합니다.

영어는 별도 Usage.en.md로 제공합니다.

비공개 전체 개발 ZIP의 Markdown 선택은 기존 빌더의 7 경로이며, 세 가이드 경로에서 다섯 링크를 확인했습니다.

개발 원본의 docs 가이드 두 경로까지 ZIP 또는 EXE에 각각 들어간다고 가정하지 않습니다.

이 비공개 ZIP은 공개 릴리스 첨부에서 제외합니다.

2026년 11월 20일 새 EXE의 실제 GPU 프레임 변화, 합성 자료를 쓴 한국어·영어/라이트·다크/100%·150% 네 화면 조합과 종료 상태, 정적 227개 확인, 설치 본을 실행하지 않은 47 파일 추출 대조를 별도로 확인했습니다.

새 EXE에서 행사 8 종을 순회하는 시험은 실행하지 않았고 이전 배포의 해당 관측을 새 결과로 바꾸지 않았습니다.
