# 35차·색상과 조명

34차의 공개 배포와 설치·최종 납품 교체를 마친 뒤 새 35차에 적용합니다. 이 문서는 준비 명세이며 현재 EXE의 구현·검증 완료를 뜻하지 않습니다.

## 사용 방법

화면 위쪽 **화면 테마**에서 시스템·라이트·다크를 선택합니다.  
바로 옆 **색상 꾸미기**에서 색 조합을 고르거나 포인트색·다크 배경·라이트 배경의 색상 코드를 입력합니다.  
색 선택 버튼으로 고를 수도 있습니다.

조명 강도는 0부터 100까지 조절합니다.  
0은 발광 효과를 끕니다.  
미리 보기의 다크·라이트 선택은 미리 보기만 바꾸며 앱 전체 테마를 바로 바꾸지 않습니다.  
**적용**하면 저장하고, **취소**하면 저장하지 않습니다.  
**기본값 복원**도 마지막으로 적용을 눌러야 저장됩니다.

잘못된 색상 코드는 해당 입력 칸에 설명하고 적용을 막습니다.  
저장에 실패하면 기존 설정과 화면을 복원하고 창을 유지합니다.  
입력한 원색은 보존하며, 글자와 선택 상태의 색은 읽기 좋게 보정합니다.  
조명으로 섞인 최종 배경도 글자 대비를 확인합니다.

## 구현과 보존 범위

- 검정·차콜에 선명한 초록을 기본 조합으로 제공합니다.  
  밝은 테마와 시안·바이올렛·앰버·무채색 등 여섯 조합을 제공합니다.  
  기존 사용자가 고른 테마 모드는 임의 초기화하지 않습니다.
- 필요한 패널과 선택 테두리에 정적인 조명을 적용합니다. 새 애니메이션 타이머나 화면 전체 블러를 추가하지 않습니다.
- 바탕화면 정보창도 테마와 사용자 색상을 따릅니다. 팔레트가 바뀌면 정보창 캐시를 갱신합니다. 잔량 막대의 실제 비율과 원값은 바꾸지 않습니다.
- 날짜별 과일·꽃·기념일·도시 행사, 픽셀 3D 회전과 자연색은 유지합니다. 링이나 모델 아이콘으로 날짜 주제를 바꾸지 않습니다.
- 기존 모델·추론 변경, 작업 배정·재개 알림, 이전값·이유·MD 적용, 자동·수동 위치·날씨 기능은 유지합니다.  
  지역 정보나 사용 한도의 정확성을 색상 기능의 추가만으로 확대 주장하지 않습니다.
- 글꼴은 나눔고딕 Bold 700을 유지합니다. 글자 100·150%, 한국어·영어, 작은 창에서 새 대화 상자와 버튼·메뉴·입력 상태를 확인합니다.

## 완료 조건

독립 준비 검사와 실제 제품 검사는 구분합니다.

준비 본의 16개 검사·메서드 Stub·오프 스크린 대비 결과만으로 EXE가 완성됐다고 보고하지 않습니다.

새 차수에서 실제 앱 버튼으로 창을 열고 입력 오류·프리셋·미리 보기·취소·저장 실패·설정 다시 읽기·팔레트 캐시를 검사합니다.

설정 다시 읽기를 전체 앱 프로세스 재시작 시험으로 표현하지 않습니다.

실제 새 EXE·설치 본, 현재 소스의 독립 검증, 공개 가능 파일의 차수별 설명과 전체 비교, 정상 GitHub 반영 및 원격 첨부 해시 확인을 마친 뒤 설치 본과 최종 납품을 교체합니다.  
34차의 검사 수치·실패·성공을 35차의 새 실측으로 복사하지 않습니다.
