Watcher/core/activity/notice_format과 calendar_renderer/observatory_scene,UsageClient/safe_update의 생명주기·실패·저장을 검토합니다. 고정 자산 재생과 실시간 메시 생성의 차수 차이를 보존합니다.

## LEVEL 4 · 용어와 실수하기 쉬운 구분

위젯은 바탕화면에 작게 띄우는 화면입니다. JSONL은 기록 한 건을 한 줄씩 저장하는 형식이고 감시는 그 파일의 새 기록을 읽는 일입니다. 모델·추론 강도는 기록에 담긴 설정·실행 관측 값이며 로컬 표시가 서버 신원을 증명하지는 않습니다. 렌더는 입체 모형을 화면 그림으로 만드는 계산이고 GPU는 그 그림 계산 장치입니다. 합성 화면은 검사용 예시 자료를 넣어 만든 화면입니다.

**설정 관측·실행 관측·기록된 공개 이유를 구분합니다.** 기록되지 않은 과거값·동기·작업 상태를 만들지 않습니다. 실제 계정 한도는 남은 비율이며 토큰 개수가 아닙니다. 합성 예시·목표 프레임·과거 렌더를 실제 계정 상태·서버 모델 신원·실측 성능으로 읽지 않습니다.

### LEVEL 4 · 감시·표시·저장·업데이트의 연결

기록 읽기 — 30차 notifier는 읽기 묶음512KiB·레코드2MiB·파일4096개·poll 총8MiB·대기256개·주기0.2초 상한을 둡니다. 최초 기준선과 새 기록 알림을 구분합니다.

## Codex Orbit 3.2.0

연도·월·일에 맞춘 3D 테마를 기본으로 보여 주는 Windows 바탕화면 앱입니다. 관측소는 명시적으로 선택해 사용할 수 있습니다.

로컬 기록에서 확인한 모델·추론 강도 변화와 작업 상태를 보여 주며, 실제 계정 사용 한도 비율·시계·기온을 함께 확인할 수 있습니다.

## 32차 · 지역 검색과 당일 입체 조형

날짜 위젯은 고리와 좌우 장식 없이 당일 대상 하나를 표시합니다. 기존 888개 월별 주제와 일반일 대상을 보존하고, 250개 국가·지역의 공휴일·지원 기념일에는 실제 행사명과 특집 조형을 적용합니다. 미래 법 개정과 모든 도시 축제까지 확정한 자료는 아닙니다.

지역 표시를 눌러 도시·주소·장소·국가를 직접 검색합니다. 선택 지점의 기온·날씨·습도·일출·일몰을 받아오며, 자동 IP 위치는 추정임을 표시합니다.

알림은 이전·현재 모델과 추론 강도를 나란히 비교하고 짧은 설명과 접을 수 있는 원문으로 정리했습니다. 화면은 흰색·슬레이트 블루와 다크 테마를 제공합니다.

## 31차 · 화면 마감과 테마 선택

시스템·라이트·다크 화면 테마를 즉시 적용하고 선택을 저장합니다. 언어·글자 크기·회전 속도는 같은 설정 영역에서 조절하고, 작업 현황에서 선택 설정과 최근 실행 관측을 구분합니다. 화면 설정 메뉴는 움직임 줄이기·가장자리 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인을 설명합니다. 프라이버시 모드는 화면의 제목과 작업 설명을 가리며 저장 원문을 유지합니다. 날짜별 과일·세 금속 링·날짜 규칙과 모델·추론 변경 알림은 유지합니다.

## 감시·표시·저장·업데이트의 연결

30차 소스에서 `notifier.Watcher`는 로컬 JSONL을 읽어 설정 관측·실행 관측·공개 이유를 구분하고 `app.py`가 알림·위젯·상세 이력을 표시합니다. `core.py`는 JSONL 꼬리 읽기·채팅 제목·화면 위치와 Markdown 적용/복구를 담당합니다. `activity.py`의 작업 상태와 `notice_format.py`의 표현을 렌더러의 장식 상태와 구분합니다.

**경계:** 기록 읽기

**실제 처리:** 30차 notifier는 읽기 묶음512KiB·레코드2MiB·파일4096개·poll 총8MiB·대기256개·주기0.2초 상한을 둡니다. 최초 기준선과 새 기록 알림을 구분합니다.

**경계:** 표시

**실제 처리:** calendar가 기본이며 명시 선택한 관측소는 유지합니다. calendar_renderer·observatory_scene의 GPU 그림과 실제 모델/추론 기록은 별개입니다.

**경계:** 계정 한도

**실제 처리:** UsageClient가 codex.exe app-server를 QProcess 분리 파이프로 열고 읽기 요청합니다. 30초 갱신·12초 응답 제한·65초 이후 오래된 값 표시를 적용합니다.

**경계:** 연결 실패

**실제 처리:** 한도 조회 실패 때 이전값을 stale로 표시하고 최대3회,3/6/9초 지연으로 다시 연결합니다. 미확인을0%로 바꾸지 않습니다.

**경계:** 종료

**실제 처리:** UsageClient.close는 타이머와 pending을 정리하고 종료 요청 뒤500ms 대기, 필요하면 kill 후500ms 대기합니다.

**경계:** 배포 교체

**실제 처리:** safe_update의 check→stage→apply 단계로 공식 릴리스·자산·SHA·로컬 경계를 검사하고 실행 확인 실패 시 이전 EXE를 복구합니다. MAX_DOWNLOAD는512MiB입니다.


사용자는 감시 경로·언어·표시 모드·모션/자원 품질을 고르고 새 알림의 이전/이후 값과 근거를 읽습니다.

날씨·사용 한도·업데이트는 네트워크 또는 App Server 기능이며 로컬 감시기의 기능 범위와 나눠 봅니다. 방송 모드와 진단 ZIP의 공개 제외 조건을 유지합니다. 실제 사용법·릴리스·빌드 안내와 차수별 함수/설정 참조는 아래에 연결되어 있습니다.

## 30차 · 원래 날짜별 테마 기본 복원

설정에 표시 모드가 없는 경우에도 원래 날짜별 달력 조형을 표시합니다. 모델 변경 이벤트를 받아도 날짜 제목과 조형은 유지합니다. 888개 월 테마·일별 디자인·색·재질·날짜 규칙은 바꾸지 않았습니다. 이전/현재 모델·추론 강도·알림 기능도 유지합니다.

## 선택 가능한 29차 관측소 기능

- 은색 금속 링 세 개가 서로 다른 축에서 움직입니다. 솔의 태양·아스트라의 결정·테라의 구체·루나의 초승달 코어와 추론 강도별 입자 밀도를 구분합니다. 확인되지 않은 모델은 중립 조형으로 표시합니다.
- 위성은 기록에서 명시적으로 관측한 작업 상태를 표시합니다. 관심 채팅 고정·기록 북마크·자리비움 요약·시간 슬라이더 재생을 제공하며 재생은 실제 모델 설정을 바꾸지 않습니다.
- 알림은 채팅 제목·이전 모델과 추론 강도·현재 모델과 추론 강도·기록된 이유를 비교합니다. 정확한 모델 ID와 원문 기록은 보존하고 표시 제목의 장식 이모지를 정리합니다. 마우스를 올리면 자동 닫힘을 멈추고 알림을 고정할 수 있습니다.
- 방송 모드는 열린 알림·제목·작업·툴팁을 가립니다. 진단 ZIP은 대화·인증·경로·이벤트 원문을 제외한 항목만 로컬에 저장합니다. 업데이트는 사용자가 확인을 눌러 공식 릴리스를 조회하고 SHA-256 대조 후 준비하며, 교체 후 실행 확인 실패 시 이전 실행 파일로 복구합니다.
- 민트와 화이트 화면·나눔고딕 Bold를 사용합니다. 글자 크기·가장자리 도킹·펼침·재생/일시정지·모션 축소·자원 품질을 조절할 수 있으며 일시정지 중에도 알림 감시는 계속됩니다.

실제 한도는 **남은 사용 한도 비율**이며 남은 토큰 개수가 아닙니다. 미확인은 0%와 구분합니다. 선택 설정 관측과 실제 실행 기록 관측을 구분하며 로컬 기록이 서버 모델 신원을 보증하지 않습니다. 기록되지 않은 이유와 작업 상태를 만들어 내지 않습니다.

## 달력 모드와 기존 기능

2026~2099년의 [888개 월 테마](../%EC%97%B0%EB%8F%84%EB%B3%84_%EC%9B%94%EB%B3%84_%ED%85%8C%EB%A7%88_%EC%A0%84%EC%B2%B4.md)와 [CSV](../%EC%97%B0%EB%8F%84%EB%B3%84_%EC%9B%94%EB%B3%84_%ED%85%8C%EB%A7%88_%EC%A0%84%EC%B2%B4.csv), 날짜별 실제 메시 조형을 달력 모드로 보존합니다. 공통 생성 규칙을 재사용하므로 888개 수작업 모델을 뜻하지 않습니다. 한영 선택·날씨·IP 기반 지역·시계·속도 조절을 유지합니다. 하나의 GPU 작업자가 3840×2160 원본을 렌더하며 관측소 품질은 20/30/60fps 상한을 사용합니다. 실제 생성률과 모니터 표시율은 별개이고 고정 240fps 달성을 주장하지 않습니다.

## 실행·소스와 권리

Windows 10/11 x64와 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. 단일 EXE는 Python 설치 없이 실행하고 설치본은 현재 사용자용 바로가기·제거를 제공합니다. GPU 준비/실패는 정적 표식 또는 오류 설명으로 구분합니다.

## LEVEL 4 · 34차까지의 자세한 사용과 검토

### LEVEL 4 추가 해설 · 앱의 목적과 사용

구현은 로컬 기록 감시, 설정과 저장, 정보 계층, 날짜·관측소 렌더 및 외부 조회 경계를 나눕니다. 계정 한도는 Codex app-server에 조회하고 날씨와 위치는 네트워크에 의존합니다. GPU 작업은 별도 소유 프로세스에서 처리합니다.

기록 파서는 기준선과 새 이벤트를 구분하고 화면은 원문에서 확인한 값만 사용합니다. 사용 한도 클라이언트는 별도 파이프로 조회하며 실패 시 이전값과 재연결 상태를 표시합니다. 업데이트는 공식 릴리스와 SHA를 확인해 준비하고 실행 확인 실패 시 이전 실행 파일을 복구합니다.

### LEVEL 4 추가 해설 · 구성 경계와 상태 전이

로컬 기록 감시기는 JSONL을 읽어 기준선과 신규 변경을 구분하며, 앱은 명시적으로 기록된 모델·추론 강도·이유를 화면에 전달합니다. 계정 한도는 `UsageClient`가 Codex app-server를 별도 파이프로 열어 읽기 요청합니다. 30초 갱신·12초 응답 제한·65초 이후 오래된 값 표시, 최대 세 번 3/6/9초 재연결은 30차 소스 설명의 범위입니다. 실패를 0%로 바꾸지 않습니다.

날짜 및 관측소의 GPU 그림은 실제 기록 관측과 분리됩니다. 34차는 GPU 소유 프로세스와 일반 앱 진입을 분리하며 최대 5초 준비와 준비 후 기존 2초 표시 프레임 검사를 구별합니다. 종료는 정상 회수 우선 후 필요할 때 소유 Job에 한정해 강제 회수합니다. OS 전체 정지 해결에 대한 절대 보장은 아닙니다.

위치 자동 추정, 수동 검색, 국가별 디자인, 날씨 좌표와 현지 날짜 적용은 별도 조건입니다. 강수량의 제공 집계 간격·미확인·이전값과 행사 시리즈·개최 회차·미분류를 보존합니다. 8종 모티프는 실제 발표된 정확한 날짜에 연결하며 자료가 모든 행사를 포괄하지 않습니다.

설정의 테마·배율·모션, 프라이버시 표시, 진단 파일의 제외 규칙, 공식 릴리스 SHA 검증과 실패 시 복구는 별개 경계입니다. 실제 과거 차수의 함수·설정·전체 비교는 해당 차수의 같은 수준 설명과 원문을 함께 확인합니다.

### LEVEL 4 추가 해설 · 기능별 상태와 입력 경계 상세

지역 상태는 자동 네트워크 추정·수동 선택·디자인 국가를 분리합니다. 검색·취소는 저장 전이가 아니고 자동 복귀는 수동 좌표 해제와 재조회입니다. 국가 선택만으로 날씨 좌표를 변경하지 않습니다. 도시와 디자인 국가 일치 및 날씨 응답의 시차 확인 뒤 현지 날짜를 적용하고, 국가만 선택해 시간대가 없으면 한국 날짜 기준을 안내합니다. IP 추정은 GPS·건물 주소가 아니며 Windows 위치 서비스와 무관합니다. 공개 주소 검색 서버에 검색어를 보내고 OpenStreetMap 출처·ODbL을 고지하며 모든 장소·건물 단위 정확도를 보장하지 않습니다.

도시 ID는 이름·거리만으로 생성하지 않습니다. 식별자 없는 주소의 목록 지원은 미확인일 수 있습니다. 행사 목록의 검증된 시리즈·개최 회차·미분류와 발표 일정은 별도 엔터티입니다. 발표된 정확한 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열기구 8종 모티프를 연결하고 주요 고정 특집을 유지합니다. 일정 새로고침은 검증된 국가 자료로 같은 도시·날짜도 갱신하고 연결·검증 실패 시 기존 자료와 오류 상태를 보존합니다. 독립 수작업 축제 모델·미발표 미래 일정·전 세계 전수 수록은 보장하지 않습니다.

알림 표시의 제목 이모지 정리는 원제목 변경과 분리됩니다. 정확한 모델 ID, 기록된 없음·최소·낮음·보통·높음·매우 높음·최고 강도, 전후 값의 동등한 표시와 실제 변경 강조를 유지합니다. 알림 오버·고정·보관·닫기와 지속 이력은 다른 상태입니다. 관측소 Sol/태양·Astra/결정·Terra/구체·Luna/초승달·미확인 중립 코어, 관심 채팅 우선 표시, 위성 24개 상한과 전체 목록을 구분합니다. 앱 내부 기록 클릭과 Codex 직접 이동 미지원·ID 복사를 혼동하지 않습니다. 시간 재생은 설정 변경이 아닙니다.

### LEVEL 4 추가 해설 · 자원·수명·실패 분기의 구체 값

30차 감시 선언은 READ_BYTES 512KiB, MAX_RECORD 2MiB, MAX_FILES 4096, POLL_READ_BYTES 8MiB, MAX_PENDING 256, 주기 0.2초입니다. 물리 LF를 기준으로 완성 기록만 읽고 기준선·신규 이벤트·명시 배정·실행 관측을 구분합니다. 중단·복구는 상태 전이당 한 번 알립니다. 이 제한은 처리량 성과의 측정값이 아닙니다.

한도 클라이언트의 종료는 타이머·pending 정리, 종료 요청, 500ms 대기와 필요 시 kill·500ms 추가 대기입니다. GPU 그림 생성률과 모니터 표시율은 별도이며 3840×2160 원본, 관측소 20/30/60fps 품질 상한·240fps 목표 선언은 고정 달성 주장이 아닙니다. 34차 GPU는 일반 앱 진입과 내부 소유 프로세스 진입을 분리하고 정상 회수 우선·필요 시 소유 Job에 한정한 강제 회수를 사용합니다. 5초 첫 준비와 준비 후 2초 표시 검사를 별개로 검토합니다.

언어·테마·배율·회전 선택은 즉시 적용·저장하며 시스템 테마는 OS 전환을 따릅니다. 작은 창의 좌측 탐색·화면 연결 변경 시 가시 영역 보정·가장자리 접힘/펼침·기본 꺼짐 알림음과 종류별 OS 소리를 확인합니다. 모션 정지와 감시/알림/실시간 시계는 분리되고 프라이버시는 열린 알림·상세까지 가리되 저장 원문을 삭제하지 않습니다.

### LEVEL 4 추가 해설 · 배포·지침·공개 범위와 논문 부재

Windows 10/11 x64·OpenGL 3.3이 필요하고 단일 EXE는 Python 없는 실행, 설치본은 현재 사용자용 설치·제거를 지원합니다. 제거는 AppData 개인 이력을 임의 삭제하지 않습니다. Source code ZIP 또는 저장소의 공개 소스에 차수별 의존성·자산·라이선스를 맞춘 재빌드는 `python -B -X utf8 tools/build_distribution.py`입니다. 비공개 전체 개발 ZIP·개인 대화·지침·인증은 배포하지 않고 기존 라이선스를 보존하며 임의 신설하지 않습니다.

기본 MD는 공유 가능한 시작 자료이며 개인 MD는 민감 정보 제거 후 해당 프로젝트가 지원하는 파일로 사용합니다. 전 채팅 강제 주입·비공개 추론 열람 기능을 뜻하지 않습니다. 진단은 허용 항목 로컬 저장이며 자동 전송하지 않습니다. 업데이트는 공식 PUVKID/Codex-Orbit HTTPS 릴리스만 check→stage→apply하며 SHA·자산·경로·실행 확인과 실패 복구, 개인 설정/MD 보존을 분리합니다. 소스 실행은 설치 EXE 교체를 대신하지 않습니다. **원고 없는 소프트웨어 개발 작업으로 논문 PDF는 없습니다.**

### LEVEL 4 추가 해설 · 34차의 변화와 검증

**목적과 변화:** 픽셀 입체 조형은 실제 메시를 렌더하고 정보 텍스트는 별도로 유지합니다. GPU 작업은 일반 앱과 내부 GPU 진입을 분리한 소유 프로세스에서 처리합니다. 날짜별 테마와 선택 지역·날씨·행사 정보는 각자의 조건에 따라 연결됩니다.

**조건과 절차:** GPU 준비의 최대 5초와 준비 뒤 표시 프레임에 대한 기존 2초 검사는 서로 다른 단계입니다. 종료 시 정상 회수를 먼저 요청하고 필요할 때 소유 Job에 한해 강제 회수합니다. 행사 일정은 검증된 국가 자료로 갱신하며 연결 또는 검증 실패 때 기존 자료를 유지합니다.

**확인과 주의:** 공개 32차 이후 전체 비교와 33차 진행 원문 비교는 서로 다른 기준입니다. 행사 시리즈와 개최 회차를 동일한 수로 합치지 않고, 주소의 도시 식별자가 확인되지 않으면 목록 지원이 미확인일 수 있습니다. 운영체제의 모든 정지가 시간 내 해결된다는 보장은 없습니다.


**검증 범위:** 검증은 325개/84.370초와 328개/117.643초의 두 실행으로 총 653개·실패 0·건너뜀 1을 기록했습니다. 정상 frozen 네 조합의 종료 조건과 외부 Python 부모가 onefile EXE의 GPU 분기를 시작한 보조 경로를 구분합니다. 후자는 5초 응답에 실패했으나 Job 회수 후 잔존 0이었고 첫 프레임 성공은 확인하지 못했습니다. 날씨 조회의 8초 제한과 최초 시간 초과 후 새 클라이언트 한 회의 1.157초 성공은 원인 확정이 아닙니다.

## LEVEL 4 · 배포 사용법의 수준 안내 추가

**가이드 추가 후 재빌드와 새 배포 검사를 확인했습니다.** 전체 653개 검사에서 실패 0·건너뜀 1, 빌드 입력 843파일 불변을 확인했습니다. 새 EXE의 한국어 가이드와 별도 한국어·영어 사용법에는 다섯 링크가 있으며, 영어 가이드까지 모두 EXE 안에 내장된 구조는 아닙니다. 새 실행본의 네 합성 화면 조합·정적 227검사·설치본 47파일 추출 대조를 확인했지만 실제 설치와 새 EXE의 행사 8종 순회는 이 결과에 포함하지 않습니다.

## LEVEL 4 · 35차 색상과 조명 준비

현재 35차는 **3.5.0 미리보기 배포본**으로 안내합니다. 아래 준비 해설의 기능을 새 차수에 반영했으며 실제 EXE·설치본 메타와 최소 실행 결과는 [최소 검사 상태](../35차_최소검사.md)에 기록합니다. 전체 회귀와 독립 검증을 새로 통과한 것으로 표시하지 않습니다.

구현 준비본은 색상 정규화·대비 계산과 팔레트 산출을 `appearance35.py`, 테마와 캐시 및 조명 배경을 `theme.py`, 설정 연결과 표시를 앱·관측소에서 담당합니다. 사용자 입력색과 읽기용 의미색을 구분하고, 텍스트 및 선택 상태뿐 아니라 정적 조명이 섞인 최종 배경의 대비도 고려합니다. 팔레트 변경은 정보창 캐시를 갱신합니다.

설정 창은 여섯 프리셋, 각 6자리 HEX, 조명 0~100과 미리보기를 다룹니다. 취소는 저장하지 않으며 기본값 복원도 적용이 필요합니다. 검증 오류는 적용을 막고 저장 예외는 이전 설정·화면을 복구한 채 창을 유지하도록 준비했습니다. 새 타이머나 전체 화면 블러는 도입하지 않습니다. 실제 제품 검증에서 작은 창, 언어·배율, 조작 상태와 저장 실패 경로를 확인해야 합니다.

날짜별 과일·꽃·기념일·도시 행사와 자연색·픽셀 3D 회전은 유지 대상입니다. 자동 위치는 IP 기반의 대략적 추정이고 수동 위치는 선택한 지역을 사용하며, 정확한 실제 위치를 보장하지 않습니다. 사용 한도는 남은 토큰 수가 아니며 실제 비율과 원값을 보존합니다. 자원 설정은 초당 240장 달성을 보장하지 않습니다. **35차의 최소 실행 관측과 미해결 오류는 아래에 구분하며, 전체 검증을 마친 안정판으로 표시하지 않습니다.** 앞의 34차 측정은 34차의 결과입니다.
