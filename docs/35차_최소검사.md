**정식 배포본의 최소 관측 범위**

사용자는 150% 배율의 실 사용이 정상이라고 직접 확인했습니다. 이는 자동 검사 전체 통과와 구분합니다. 자동 검사 미완료를 실제 150% 제품 고장으로 확정하지 않습니다.

| 항목 | 실제 결과 | 한계 |
| --- | --- | --- |
| EXE·Setup 생성 | 두 빌 드 종료 코드 0 | 설치·전체 동작 통과와 구분 |
| 설정 검사 | 다섯 항목 통과 | 첫 대화 상자 검사에서 180초 제한.<br>전체 16개 미완료 |
| 실제 EXE 합성 UI | 라이트·한국어 100%, 다크·영어 100%, 라이트·한국어 150% 완료 | 다크·영어 150% 완료 기록 없이 AssertionError로 종료.<br>정확한 원인 미확정 |
| 기본 실행 | 같은 EXE의 기본 실행 한 번은 종료 코드 0으로 끝났고 시작 준비·프레임 변화·투명 위젯을 확인했습니다. | 전체 UI·회귀·설치의 통과와 구분 |
| 공개 문서·코드 정적 독립 대조 | 최초 35차 변경 34 파일의 연결·공개 안전 최소 검토 통과 | 제품 전체·원격 화면을 새로 검증한 결과와 구분 |

합성 UI는 격리된 자료와 QTest 조작으로 실행했습니다.

완료한 각 조합에서 색상 창 버튼 열기, 취소 유지, HEX 검증, 프리 셋 선택, 미리 보기 격리, 적용·설정 재읽기, 저장 실패 복원, 조명 0, 마우스·포커스·키보드, 정보 창 캐시 갱신의 열 항목이 참이었습니다.

설정 재읽기는 전체 프로세스 재시작 검사가 아닙니다.

합성 지역·날씨·잔 량 값을 실제 사용자 관측으로 해석하지 않습니다.

UI 실행은 33.344초 뒤 종료 코드 1로 끝났습니다. 오류 원문은 `AssertionError: `이며 구체 위치와 원인은 확정되지 않았습니다. 전체 UI 재실행으로 이 실패를 덮어쓰지 않았습니다. GPU 준비와 종료 뒤 자원 정리는 보고됐지만 네 번째 조합의 성공을 뜻하지 않습니다.
