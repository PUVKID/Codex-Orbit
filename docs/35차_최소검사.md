34차의 검사653개와 이전 실행 결과를35차의 새 실측으로 복사하지 않습니다. 합성 조작·설정 재읽기와 직접 화면 제어·전체 프로세스 재시작을 구분합니다. 아래는 같은3.5.0 바이너리의 실제 최소 관측이며 전체 통과 판정이 아닙니다.

합성 UI는 격리된 자료와 QTest 조작으로 실행했습니다. 완료한 각 조합에서 색상 창 버튼 열기, 취소 유지, HEX 검증, 프리셋 선택, 미리보기 격리, 적용·설정 재읽기, 저장 실패 복원, 조명0, 마우스·포커스·키보드, 정보창 캐시 갱신의 열 항목이 참이었습니다. 설정 재읽기는 전체 프로세스 재시작 검사가 아닙니다. 합성 지역·날씨·잔량 값을 실제 사용자 관측으로 해석하지 않습니다.

UI 실행은33.344초 뒤 종료 코드1로 끝났습니다. 오류 원문은 `AssertionError: `이며 구체 위치와 원인은 확정되지 않았습니다. 전체 UI 재실행으로 이 실패를 덮어쓰지 않았습니다. GPU 준비와 종료 뒤 자원 정리는 보고됐지만 네 번째 조합의 성공을 뜻하지 않습니다.
