# 44차 · 알림과 내부 화면 통일

| 영역 | 변경 방향 | 보존하는 내용 |
| --- | --- | --- |
| 변경 기록 | 위젯 알림과 같은 이전·현재 비교표, 모델 그림과 추론 강도 막대 | 정확한 모델 ID·강도·채팅 제목 |
| 이유 | 짧은 설명을 먼저 표시하고 원문은 펼쳐 읽기 | 공개된 작업 설명과 기록 근거 |
| 내부 화면 | 공통 간격·조작 상태·탐색 스크롤과 나눔고딕700 | 언어·테마·배율·설정·사용 한도 기능 |

| 배포 | 단일 EXE와 설치형을 같은 소스로 생성 | 이전 차수와 사용자 설정·기록 |

## 디자인 기준

사용자가 선택한 작은 알림의 비교표를 내부에서도 사용합니다. 긴 설명이 모델과 강도보다 먼저 화면을 차지하지 않도록 정보 순서를 바꿉니다. 누락된 이전 값은 추정해 채우지 않습니다.

라이트·다크와 직접 지정한 색을 유지합니다. Rust 테마 엔진은 실행 파일 안에 포함해 현재 팔레트의 버튼·입력·메뉴·표 스타일을 실제로 생성합니다. E 드라이브의 개발 도구가 없는 배포 환경에서도 내장 엔진으로 실행하도록 연결합니다. 기존 날씨 응답 검증 Rust DLL도 유지합니다. 성능 개선은 측정하지 않았습니다.

## 확인 범위

| 실제 검사 | 결과 |
| --- | --- |
| 2026~2099 날짜 | 27,028일·888개월·윤일18개, 누락 없음 |
| 동봉 국가 행사 | 250개 국가·지역, 246,906개 행사 날짜 연결 정상 |
| 고유 모형 | 141종·실제 GPU282프레임, 생성·투명 배경·프레임 차이 확인 |
| 날짜 전환 | 자정·월말·연말·윤년·시차7개 경계와 감독 스레드 전환 검사 통과 |

매일의 데이터 연결과 고유 모형의 렌더 경로를 나누어 검사했습니다. 모든141종을 사람이 개별 미적 평가했다는 의미는 아닙니다. 날짜 누락이나 등록 모형의 렌더·회전 실패는 이번 검사에서 발견되지 않았으며 제품의 날짜 배정 코드는 변경하지 않았습니다.

날짜 생성과 실제 그림 생성 검사를 구분해 기록합니다. 미래 모든 날에 컴퓨터가 켜져 있거나 외부 날씨·행사 제공처가 정상이라는 보장은 아닙니다. 모든 도시의 모든 축제가 포함되었다고 확대하지 않습니다. 지원 자료의 범위는 기존 지역·행사 문서를 따릅니다.

기존 유효한 감시·날씨·모션·알림 검사는 재사용하고 변경한 비교표·작은 창·테마·배율·원문 펼치기와 포장된 실행 경로를 확인합니다. 확인 결과와 미해결 사항은 배포 전 근거 문서에 연결합니다.

스크롤 콘텐츠는 실제 크기 정책과 레이아웃 최소 크기를 함께 적용합니다. 구현 기준: [Qt 공식 QScrollArea 문서](https://doc.qt.io/qt-6/qscrollarea.html).
