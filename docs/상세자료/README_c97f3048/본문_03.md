- 입력과 오류의 관계: 자동 교체 대상은 예상 경로의 현재 사용자 AppData 안에 설치된 일반 실행 파일이어야 하는 구조입니다. 소스나 휴대용 실행본에서는 공식 릴리스를 직접 설치해야 하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L163)

- 입력과 오류의 관계: 이 소유 프로세스 검사·설치 실행 파일 교체는 Windows에서만 지원하는 구조입니다. 다른 운영 체제에서는 실행하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L274)

- 입력과 오류의 관계: 현재 사용자 전용 업데이트 준비 폴더 안의 plan.json이라는 일반 파일만 허용하며 65,536바이트 이 하여야하는 구조입니다. 다른 경로·다른 이름·폴더·큰 파일은 받지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L328)

- 입력과 오류의 관계: 업데이트 계획은 이름과 값의 사전이며 schema_version 값이 1이어야하는 구조입니다. 형식이나 버전이 다르면 적용하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L331)

- 입력과 오류의 관계: 계획과 준비 EXE의 폴더가 같고 설치 EXE의 현재 지문도 계획 당시 값과 같아야하는 구조입니다. 준비 뒤 경로나 설치 파일이 바뀌면 멈춥니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L335)

- 입력과 오류의 관계: 프로세스 번호는 참/거짓이 아닌 양의 정수여야 하는 구조입니다. 교체 작업 자신과 같은 번호도 거부하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L338)

- 입력과 오류의 관계: 이전 교체의 백업 파일이나 후보 파일이 하나라도 남아 있으면 자동 덮어쓰기를 하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L342)

- 입력과 오류의 관계: 공식 릴리스 API 요청에서 예상하지 못한 다른 주소로의 이동 응답이 오면 따라가지 않고 거부하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L84)

- 입력과 오류의 관계: 다시 이동할 주소도 github.com의 허용된 공식 릴리스 경로로 시작해야하며 추가 질의가 없어야하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L94)

- 입력과 오류의 관계: 릴리스 자료는 항목 이름과 값으로 구성되어야 하며 초안 여부와 사전 공개 여부가 둘 다 명시적으로 거짓이어야 하는 구조입니다. 둘 중 하나가 빠지거나 참이면 사용하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L204)

- 입력과 오류의 관계: 응답의 공식 릴리스 페이지 주소가 예상한 릴리스 URL과 정확히 같아야하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L210)

- 입력과 오류의 관계: 해당 이름의 CodexOrbit.exe 자산이 정확히 하나이고 업로드 완료 상태여야 하는 구조입니다. 없거나 중복되거나 업로드 미완료면 받지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L214)

- 입력과 오류의 관계: 새 정식 릴리스가 명시적으로 사용 가능해야하고 태그는 버전 문자열 자체 또는 앞에 v를 붙인 값이어야하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L228)

- 입력과 오류의 관계: 내려받은 전체 바이트 수가 발표 크기와 같고, SHA-256 파일 지문도 같아야하는 구조입니다. Windows 실행 파일 시작 표식 MZ도 확인하며 어느 하나라도 다르면 사용하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L232)

- 입력과 오류의 관계: 프로세스 번호는 참/거짓이 아닌 양의 정수여야 하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L250)

- 입력과 오류의 관계: 기존 앱의 종료를 30초 동안 기다려 정상 종료가 확인되어야하는 구조입니다. 확인되지 않으면 실행 파일을 교체하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L288)

- 입력과 오류의 관계: 교체 직전 후보 파일과 현재 설치 파일의 지문을 각각 계획 값과 다시 대조하는 구조입니다. 한쪽이라도 달라졌으면 교체하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L350)

- 입력과 오류의 관계: 새 실행 파일의 시작 검사 결과가 명시적인 성공이 아니면 교체를 성공으로 처리하지 않고 이전 실행 파일을 복원하는 경로로 갑니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L355)

- 입력과 오류의 관계: 새 실행 파일의 재시작이 명시적으로 성공하지 않으면 이전 실행 파일을 복원하는 경로로 갑니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L357)

- 입력과 오류의 관계: 프로그램 이름 뒤에 업데이트 계획 파일 인자가 하나 있어야 하는 구조입니다. 인자 수가 다르면 실행하지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L377)

- 입력과 오류의 관계: 릴리스 응답 크기가 그 요청에 허용한 최대 크기보다 크면 읽기를 거부하는 구조입니다. [해당 검사](../../../history/30%EC%B0%A8/src/safe_update.py#L107)

### LEVEL 2·30차 추가 해설·LEVEL 2·[src/theme.py](../../../history/30%EC%B0%A8/src/theme.py)

파일 선택창·버튼·기본 기호의 색과 문구·배치를 맞춥니다. 긴 한글 버튼이나 파일 이름이 들어갈 공간도 다룹니다.

**맡은 일과 결과**

- 이 부분의 역할: 별도 Qt 번역 패키지가 없는 배포에서도 기본 파일 선택 문구를 번역하는 구조입니다. [구현 이름 KoreanDialogs](../../../history/30%EC%B0%A8/src/theme.py#L81)

- 이 부분의 역할: 앱 파일 선택창의 이름 열과 한글 버튼에 충분한 공간을 확보하는 구조입니다. [구현 이름 DialogLayout](../../../history/30%EC%B0%A8/src/theme.py#L97)

### LEVEL 2·30차 추가 해설·LEVEL 2·[src/update_widgets.py](../../../history/30%EC%B0%A8/src/update_widgets.py)

새 버전 확인 화면에 쓰는 버전 정보를 둡니다. 이 값이 있다는 사실과 실제 내려받기·교체 성공은 별도입니다.

**선택값과 제한값**

- 구성에 쓰는 값: 이 화면이 사용하는 앱 버전 표시는 **'3.0.1'**입니다. 이 값의 단위와 역할을 다른 모듈의 같은 이름과 혼동하지 않습니다. [VERSION](../../../history/30%EC%B0%A8/src/update_widgets.py#L9) 원래 선언을 함께 대조합니다: `정의='3.0.1'`

### LEVEL 2·30차 추가 해설·LEVEL 2·[src/usage.py](../../../history/30%EC%B0%A8/src/usage.py)

Codex의 읽기 전용 계정 조회로 사용 한도 응답을 읽습니다. 예를 들어 자료가 없다는 상태를 잔량 0으로 바꾸지 않습니다.

**맡은 일과 결과**

- 이 부분의 역할: 불리언·문자열·비유한 숫자를 한도 수치로 해석하지 않습니다. [구현 이름 number](../../../history/30%EC%B0%A8/src/usage.py#L16)

- 이 부분의 역할: 계정에서 여러 사용 한도 구간을 보내 주면 그 공식 구간을 먼저 사용하는 구조입니다. 버킷은 서로 다른 기간의 한도 묶음이라는 뜻입니다. 기간이나 수치가 응답에 없으면 임의로 채우지 않습니다. [구현 이름 normalize_limits](../../../history/30%EC%B0%A8/src/usage.py#L35)

- 이 부분의 역할: 사용자 선택, PATH, 공식 데스크 톱 번들 위치 순으로 EXE만 찾습니다. [구현 이름 discover_codex](../../../history/30%EC%B0%A8/src/usage.py#L69)

**선택값과 제한값**

- 구성에 쓰는 값: 응답을 읽는 최대 바이트 수는 **1024 * 1024**입니다. 바이트는 파일·메모리 크기를 세는 단위이고, 곱셈 표기는 그 크기를 계산하는 식입니다. [MAX_BYTES](../../../history/30%EC%B0%A8/src/usage.py#L12) 원래 선언을 함께 대조합니다: `정의=1024 * 1024`

- 구성에 쓰는 값: 한국 표준시인 UTC보다 9시간 빠른 시간대입니다. [KST](../../../history/30%EC%B0%A8/src/usage.py#L13) 원래 선언을 함께 대조합니다: `정의=timezone(timedelta(hours=9))`

**받지 않는 입력과 실패 처리**

- 입력과 오류의 관계: 객체가 아닌 응답 자료는 항목 이름과 값의 쌍으로 구성되어야 하는 구조입니다. 순서 있는 목록·단순 문장·숫자를 같은 자료로 받아들이지 않습니다. [해당 검사](../../../history/30%EC%B0%A8/src/usage.py#L226)

### LEVEL 3 · 이 차수를 준비하는 범위

3.0.1은 표시 모드 기본값 네 곳을 calendar로 복원합니다. 새 설정과 표시 모드가 없는 기존 설정은 원래 날짜별 조형을 표시하고 모델 이벤트 이후에도 날짜 제목과 조형을 유지합니다. 명시 선택한 관측소 기능은 보존합니다. 기존 월·일 테마 코드와 자산을 바꾸지 않습니다.

Windows와 해당 폴더의 requirements.txt를 기준으로 Python 의존성을 준비합니다. history는 공개 소스 보존 본이며 현재 루트 assets가 과거 모든 차수의 자산과 호환된다는 뜻은 아닙니다.

날짜별 실제 메시 렌더에는 ModernGL과 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다.

자산과 의존성을 준비한 이 차수 폴더에서 `python src/app.py`를 실행합니다. history 소스만으로 과거 배포 EXE와 동일한 화면·자산이 모두 복원되지는 않습니다.
