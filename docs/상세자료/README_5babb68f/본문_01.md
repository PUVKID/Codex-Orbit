## LEVEL 1 - Beginner

### LEVEL 1 · 이 자료가 하는 일과 달라진 점

앱과 투명 렌더의 SUIT 글꼴 등록을 공통화하고 원소·궤도·상태 화면의 글자와 구성을 조정합니다. 글꼴 등록과 실제 자산 로딩을 함께 확인합니다.

### LEVEL 1 · 실제 동작을 따라 읽기

앱과 투명 렌더의 SUIT 글꼴 등록을 공통화하고 원소·궤도·상태 화면의 글자와 구성을 조정합니다. 글꼴 등록과 실제 자산 로딩을 함께 확인합니다.

로컬 세션 기록에서 모델·추론 강도의 변경과 명시된 배정을 구분합니다. 감시기는 외부 통신 없이 로컬 자료를 읽습니다.

공개 협업 호출과 소유자가 확인된 native 활동을 연결합니다.

검증된 금속 원자 프레임을 추출 없이 읽는 제한 메모리 재생기입니다.

같은 실제 3D 자산을 공유하는 정적 마크와 가시성 기반 내부 모션입니다.

한국 날짜의 1~31일에 대응하는 원소와 디자인 영감 팔레트입니다.

원본 3D 자산을 변경하지 않는 제한 메모리 Qt 색 합성입니다.

앱이 소유하는 화면과 대화상자의 부드러운 청록 테마입니다.

번들 SUIT 글꼴을 앱과 투명 렌더에서 동일하게 사용합니다.

Codex App Server의 계정 사용 한도를 읽기 전용으로 조회합니다.

제작된 실제 3D 금속 프레임과 고정된 실제 잔량·상태를 합성합니다.

Codex App Server의 `account/rateLimits/read`를 읽기 전용으로 조회합니다. 표시값은 남은 토큰 개수가 아니라 계정 사용 한도 비율입니다.

JSONL은 한 줄마다 하나의 JSON 기록을 담은 파일입니다. CLI는 명령어와 옵션을 입력해 프로그램을 실행하는 방식입니다.

입력 — 현재 사용자 Codex의 로컬 JSONL과 이 차수의 앱 설정

처리 — 변경 감시 → 공개 이유·전후 모델 정리 → 알림·상세창 표시

출력 — 알림·변경 이력·로컬 진단 기록

### LEVEL 1 · 준비하고 확인할 것

Windows와 해당 폴더의 requirements.txt를 기준으로 Python 의존성을 준비합니다. history는 공개 소스 보존 본이며 현재 루트 assets가 과거 모든 차수의 자산과 호환된다는 뜻은 아닙니다.

자산과 의존성을 준비한 이 차수 폴더에서 `python src/app.py`를 실행합니다. history 소스만으로 과거 배포 EXE와 동일한 화면·자산이 모두 복원되지는 않습니다.

### LEVEL 1·19차의 구체적인 기능과 확인

앱 화면과 투명하게 보이는 모형 화면에서 같은 SUIT 글꼴을 쓰도록 글꼴 등록을 공통화했습니다. 원소·궤도·상태를 보여 주는 글자와 배치도 조정합니다. 이때 글꼴을 등록했다는 사실과 실제 글꼴 파일을 읽었는지는 각각 확인해야 합니다.

이 앱은 내 컴퓨터에 있는 Codex 기록을 읽어 모델과 추론 강도의 변화를 알립니다.

컴퓨터에 기록된 값과 이유만 보여 주므로 기록이 없으면 모른다고 남겨야합니다.

계정 사용 한도는 별도 읽기 요청으로 받아 비율로 보여 주며 남은 토큰 개수가 아닙니다.

원소는 한국 날짜의 1일부터 31일까지에 대응하고, 금속 모양 프레임과 현재 잔량·상태를 함께 표시합니다.

실행하려면 이 차수 소스·의존성과 해당 자산을 준비한 Windows 환경에서 `python src/app.py`를 사용합니다.

현재의 자산이 과거 차수에 모두 맞는 것은 아니고 큰 프레임 자산이 공개 이력에 없을 수 있습니다.

처음 기존 기록을 읽는 것과 그 뒤 새 변화를 감지하는 것은 다릅니다.

18차와 비교한 파일 추가·수정·삭제와 글자 한 칸 차이까지 원래 비교에서 살필 수 있습니다. 당시 실행 결과는 보존돼 있지 않아 실행 성공을 주장할 수 없습니다. 현재 개인 설정이나 대화 기록을 공유하기 전에는 내용을 확인해야 합니다.

## LEVEL 3 - Practitioner

### LEVEL 3 · 이 차수를 준비하는 범위
