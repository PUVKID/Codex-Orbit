- [src/calendar_catalog.py](../../../history/25/src/calendar_catalog.py): 원문이 명시한 모듈 책임은 실제 대상 이름과 조형 특징을 연결하는 편집 사전입니다.

- [src/calendar_motion.py](../../../history/25/src/calendar_motion.py): 원문이 명시한 모듈 책임은 한 GPU 작업 스레드와 최대 네 이미지로 날짜별 모션을 공유합니다.

- [src/calendar_renderer.py](../../../history/25/src/calendar_renderer.py): 원문이 명시한 모듈 책임은 현재 날짜의 실제 메시를 소유 스레드의 오프 스크린 GPU에서 렌더합니다.

## 설치 환경과 실행·사용법

Windows와 해당 폴더의 requirements.txt를 기준으로 Python 의존성을 준비합니다. history는 공개 소스 보존 본이며 현재 루트 assets가 과거 모든 차수의 자산과 호환된다는 뜻은 아닙니다.

<a name="️-제약과-문제-해결"></a>
## 제약과 문제 해결

**상황:** 알림이 나타나지 않음

**확인할 내용:** 감시하는 sessions 경로·새 JSONL 기록·중복 실행 잠금·알림 설정을 확인합니다. 최초 기준선 읽기와 새 변경 감지는 다릅니다.

**상황:** 자산 또는 글꼴 오류

**확인할 내용:** 이 차수에서 참조하는 assets와 라이선스를 준비합니다. 소스 이력에는 과거 대용량 프레임 자산이 없을 수 있습니다.

**상황:** 이유 또는 이전값이 없음

**확인할 내용:** 원문 기록에 해당 필드가 있는지 확인합니다. 누락된 동기를 추정해서 채우지 않습니다.
