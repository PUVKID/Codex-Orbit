# 32차 날짜별 입체 조형

바탕화면에는 그날의 주요 대상 하나를 크게 표시합니다. 날짜별 장식 고리와 좌우 보조물은 제거했으며, 별도로 선택하는 작업현황 화면의 고리와 브랜드 표식은 유지합니다.

## 날짜와 대상

기존 124개 대상의 이름·카탈로그와 일반 날짜의 연결은 보존했습니다. 2026년부터 2099년까지 27,028일을 검사하며, 선택 국가의 공휴일과 계절 특집은 별도 대상으로 연결합니다.

행사 이름은 국가별 자료의 이름을 사용하고, 전용 모티프가 없는 행사는 공통 축하 조형으로 표시합니다.

국가별 미래 공휴일은 법령 변경이나 자료 지원 범위에 따라 달라질 수 있습니다.

도시의 국가와 선택한 테마 국가가 일치하고 시차가 확인된 경우 현지 날짜를 사용합니다. 확인되지 않은 경우 기본 한국 날짜를 유지합니다. 정지 상태에서도 날짜·국가·시차가 바뀌면 새 장면을 갱신합니다.

## 실제 기하와 재질

꽃·열매·잎·악기 각 31개의 공통 표면과 종별 구조를 보강했습니다. 코코넛은 섬유질 껍질과 세 눈, 과일은 골·능선·비늘·껍질 무늬, 잎은 곡면·잎맥·갈래와 실제 천공, 악기는 건반·곡관·밸브·북면 등을 삼각형 메시로 구성합니다. 자연물은 비금속 재질을, 악기는 부품에 맞는 목재·금속·북 면 재질을 사용합니다.

ImageGen으로 생성한 코코넛 껍질 색상 지도와 과 피·식물의 높이 지도, 종별 표면 지도 3개와 베리 보강 지도 1개까지 총 7개 이미지를 실제 GPU 표면 재질에 연결했습니다. 93개 자연물 가운데 검토한 88개 대상에 종별 색상 타일을 적용하며, 큰 형상 명암이 섞인 파인애플·멜론·용과·고사리는 기존 절차 재질을, 코코넛은 별도 섬유 재질을 유지합니다.

베리 보강 지도에서는 지정한 세 칸만 사용합니다.

삼면 투영과 높이 변화에 따른 법 선 보정에 사용하며, 완성된 정지 그림을 움직이는 3D처럼 표시하지 않습니다.

형상은 절차적으로 생성되므로 꽃의 반복 배열 등 양식화가 남습니다. 124개 대상을 사진 수준으로 재현하거나 27,028일을 각각 수작업으로 모델링했다는 뜻은 아닙니다.

## 모션과 자원 수명

투명 배경, 날짜 교체, 출력 크기 변경, 재생·정지·모션 축소를 유지합니다. 렌더 작업자는 하나를 공유하며 240Hz는 예약 목표입니다. 실제 프레임률은 GPU·출력 크기·장면·시스템 부하에 따라 달라지며 항상 240fps를 보장하지 않습니다.

종료 요청을 가져 오기·컨 텍스트 생성·렌더 시작 경계에서 확인합니다.

생성된 GPU 자원은 소유 작업자의 종료 경로에서 해제합니다.

종료 대기는 기존 2초를 유지하며, 미완료 작업자는 참조를 보존하고 새 컨 텍스트를 시작하지 않습니다.

이후 종료 또는 재시작 시 완료 여부와 남은 이미지·객체 정리를 다시 확인합니다.

진행 중인 드라이버 호출을 강제로 중단하거나 모든 환경의 종료 시간을 보장하지 않습니다.

## 확인 범위

- 기존 대상 124개와 특집 9개, 총 133개를 실제 GPU로 렌더했습니다. 서로 다른 프레임, 투명 경계, 유효한 법 선·인덱스와 자원 해제를 확인했습니다.
- 27,028일의 일반 날짜 연결·특집 연결과 단일 대상 경로를 검사했으며 날짜별 고리 호출은 없었습니다.
- 실제 GPU 검사에서 재질 파일, 코코넛 구조, 입체 깊이, 모션·크기·날짜·국가 변경과 종료를 확인했습니다. 모션 제어 7개와 속도 검사 6개도 통과했습니다.
- 종료 시점 주입과 재시작은 별도 제어 검사로 확인합니다. 접촉시트는 대표 날짜와 시점의 시각 점검이며 모든 날짜·각도·기기에서의 외관을 직접 확인한 것으로 확대하지 않습니다.

전체 제품·설치본 검증 결과는 해당 배포의 검증 문서를 따릅니다. 이 문서의 국소 검사만으로 전체 배포 완료를 뜻하지 않습니다.
