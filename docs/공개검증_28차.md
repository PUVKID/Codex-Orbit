기존 큐 검사 단언은 그대로 유지했습니다. 고정 80ms 비동기 검사는 최소 프레임·도착·전달 조건을 유지하고 준비 완료를 최대1초 기다리도록 보완했습니다. 새 검사에 잘못 적은 영어 대소문자1곳도 정정했으며 실패 원문을 보존했습니다. 이후 사용자 추가 요구의 강도별 이모지 검사4개를 더했습니다. 미구현 TDD와 영문 NativeToast의 필드 예산42로 인한 이모지 잘림은 구분해 보존했고 두 강도 필드만52로 보완하며 전체255 UTF-16 상한은 유지했습니다. 제품 렌더·페이싱이나 감지 부분을 변경한 작업이 아닙니다.

새 사본의 재빌드 도구는 work 폴더를 자동 준비합니다. 이 빌드 도구 보완 당시에는 비공개 소스ZIP만 재포장했으며, 이후 독립 공개 검토에서 한영 사용법의 검사 수87개가 남아 있어104개로 정정한 뒤, 추가 강도 이모지 검사4개를 포함한108개로 안내를 갱신하고 단일EXE·설치본·소스ZIP을 다시 빌드했습니다. 실행 소스24개와 공개 사본의 대응 바이트도 대조했습니다.

모델·추론·배정·재개 알림은 로컬 관측 범위입니다. 서버 모델 신원·기록되지 않은 선택 동기·비공개 추론을 증명하지 않습니다. 별도 NativeToast는 XML 합성 검사만 수행했으며 실제 레거시 CLI 전달은 미검증입니다.

4K는 3840×2160 GPU 원본입니다. 고정240fps는 달성하지 못했고 추가 달성 작업을 재개하지 않았습니다. 27,028일은 카탈로그/형상 규칙의 지원 범위이며 모든 날짜 실렌더나 수작업 고유 모델을 뜻하지 않습니다.
