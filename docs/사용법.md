# 🪐 Codex Orbit 2.10.0 사용법

Windows 10/11 x64에서 실행하는 투명 바탕화면 위젯입니다. 날짜별 입체 조형과 세 링이 움직이며, 클릭하면 로컬 Codex 채팅의 변경 기록을 엽니다.

## 실행하기

- 설치 없이 사용: `CodexOrbit.exe`를 실행합니다.
- 설치해서 사용: `CodexOrbit-Setup.exe`를 실행합니다. 현재 사용자용 설치이며 시작 메뉴와 선택 바탕화면 바로가기를 제공합니다.
- Python을 별도로 설치할 필요가 없습니다. 3D 모션에는 OpenGL 3.3 지원 그래픽 드라이버가 필요합니다. 준비·실패 상태는 화면에 구분해 표시합니다.

## 위젯 조작

위젯을 끌어 이동하고, 오른쪽·아래쪽 가장자리나 우하단을 끌어 크기를 조절합니다. 클릭하면 상세창을 엽니다. 위치·크기는 저장됩니다. 상세창 위쪽 또는 우클릭 메뉴에서 한국어·영어를 선택합니다.

상세창의 회전 속도 슬라이더로 0.25~3배를 선택합니다. 1배 복원 버튼과 우클릭 속도 메뉴도 있습니다. 속도는 저장되며 시계·날씨·사용 한도 갱신 주기에는 영향을 주지 않습니다.

## 알림 읽기

모델과 추론 강도는 각각 **이전 → 변경 후**로 표시합니다. 작업자 배정·재개는 별도 종류로 표시하며, 기록된 채팅 제목·맡긴 일·공개된 이유를 보여 줍니다. 기록이 없는 이전값이나 이유는 확인 불가로 표시합니다. 비공개 추론을 복원하지 않습니다.

로컬 선택 상태를 관측해 메시지 전송 전 변경도 감지하며, 로컬 기록에 반영되기 전 선택·원격/클라우드 채팅·서버 내부 모델 신원까지 보장하지 않습니다. 감시 파일 4,096개, 레코드 2MiB, 주기별 읽기 예산이 있습니다. 알림은 여러 창으로 표시하며 최대 8장 이후 오래된 창을 숨기고 최근 기록 500건을 보존합니다. 최초 실행은 과거 기록을 기준선으로 읽습니다.

## 시각·기온·남은 한도

PC 현지 시각을 표시합니다. Windows 위치 서비스 대신 인터넷 IP의 대략적인 지역을 사용하고 현재 기온을 5분마다 갱신합니다. VPN·통신사망에서는 실제 위치와 다를 수 있습니다. IP 지역은 ipwho.is, 날씨는 Open-Meteo 자료를 사용합니다. 조회 실패·오래된 값은 구분해서 표시합니다.

잔량 막대는 Codex 계정의 실제 **남은 사용 한도 비율**이며 남은 토큰 개수는 아닙니다. 읽기 전용 계정 조회를 30초마다 수행하며, 조회되지 않은 값을 임의로 채우지 않습니다.

## 날짜별 모션과 화질

한국 날짜 기준 2026~2099년의 27,028일을 지원합니다. 888개 연월 조합과 날짜별 형상 규칙을 사용합니다. 모든 날짜가 별도의 수작업 3D 모델이라는 뜻은 아닙니다. 날짜는 한국 자정 기준으로 바뀌며 시계는 PC 현지 시각을 표시합니다.

GPU 원본은 3840×2160이며 위젯 크기로 축소합니다. 초당 240프레임 고정은 달성하지 못했고 추가 달성 작업은 중단했습니다. 생성 프레임·화면 그리기·물리 모니터 주사율은 서로 다릅니다. Windows 바로가기와 EXE 아이콘은 정적이며 실행 위젯에서 모션을 봅니다.

## 사용자 자료와 MD

설정·사용자 MD·백업·이력은 `%LOCALAPPDATA%/CodexOrbit`에 보존합니다. 설정·내 지침·도움말 탭은 제공하지 않습니다. 포함된 지침을 몰래 적용하지 않으며, 앱 파일 공유가 다른 채팅이나 계정 전체에 MD를 자동 적용하지 않습니다. 제거 프로그램은 사용자 지침·백업·이력을 보존합니다.

계정 인증값·로컬 채팅·개인 지침은 다른 사람에게 전달하지 마십시오. 이 릴리스는 공개 실행 소스와 일반 사용법을 제공합니다. 개인정보 테스트 자료가 있는 로컬 전체 소스 ZIP은 공개하지 않습니다.

## 다운로드 무결성과 소스

`SHA256SUMS.txt`로 파일 SHA-256을 대조할 수 있습니다. `Licenses.zip`에는 포함 구성요소의 라이선스가 있습니다. 실행 코드와 공개용 검사 87개는 [프로젝트 저장소](https://github.com/PUVKID/Codex-Orbit), 빌드 방법은 저장소 README에서 확인합니다. GitHub 자동 Source code ZIP은 공개 저장소만 포함합니다.
