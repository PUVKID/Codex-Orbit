# 29차 관측소 정적 자산 출처와 재현

관측소의 실제 삼각형 메시·깊이 버퍼·금속 반사 셰이더를 기존 ModernGL 렌더 경로에서 직접 렌더해 만들었습니다. 외부 생성 이미지나 다운로드한 로고를 사용하지 않았으며 기존 원자 자산과 폰트 라이선스는 변경하지 않았습니다. 새 라이선스를 임의로 부여하지 않습니다.

- 원본 렌더: 3840×2160 GPU 타깃, 중앙 정사각형을 1024픽셀로 GPU 축소한 투명 이미지입니다.
- 대표 장면: 모델이 확인되지 않은 중립 은색 구체·세 금속 링, 실제 재생 시각 0.65초입니다. 특정 모델을 기본 모델로 주장하지 않습니다.
- 설치 이미지는 민트·화이트 배경과 나눔고딕 Bold 700을 사용합니다. 배포 아이콘·설치 배너는 정적 대표 장면이며 실행 중 3D 모션과 구분합니다.
- 제작용 빈 용기와 0 설정은 로고 구성을 위한 합성 입력입니다. 실계정 잔량이나 실제 사용자 작업을 나타내지 않습니다.
- ICO는 16·24·32·48·64·128·256의 일곱 해상도 PNG를 포함합니다. 설치 배너는 328×628, 작은 이미지는 110×110입니다.

재현 코드는 [생성 도구](../tools/generate_observatory29_assets.py), 메시·재질 코드는 [렌더러](../src/calendar_renderer.py), 공유 배치와 클릭 투영은 [장면 모듈](../src/observatory_scene.py)에 있습니다. 기존 프로젝트의 고정 의존성을 준비한 환경에서 프로젝트 루트 기준으로 `python -B -X utf8 tools/generate_observatory29_assets.py`를 실행합니다. GPU 드라이버 차이로 출력 바이트가 달라질 수 있으므로 아래 값은 이번 검증 산출물의 식별값입니다.
