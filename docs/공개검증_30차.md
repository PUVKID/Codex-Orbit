# 30차 검증 범위

개발 전체462개(건너뜀1개)는46.169초, 공개189개(건너뜀0개)는19.032초에 통과했습니다. 두 프로세스 종료 코드는0이며 서로 다른 검사 범위입니다. 공개189개는 기존185개와 신규 날짜 기본값 회귀4개입니다. 신규·기존 설정, 모델 이벤트 후 날짜 조형 보존, 명시 관측소 선택을 확인합니다.

기존 날짜 테마4개 모듈과 관련 자산을 포함한177개 파일642,252,410바이트를29차 원문과 SHA-256으로 전수 대조했습니다. 원래 테마 디자인·색·재질·날짜 규칙은 바꾸지 않았습니다. 실제 단일EXE는 calendar 모드·프레임 변화·날짜별 과일 화면을 확인했습니다. 설치본 생성과 실제 설치 동작 검증은 구분합니다.

개발 검사에는 공개하지 않는 로컬 경계 fixture가 포함됩니다. 개인정보·대화·설정·운영 로그와 비공개 전체 개발 ZIP은 제외합니다. 원고가 없는 앱 수정입니다. 모든 환경 지원이나 의미상 완전 무오류를 보증하지 않습니다.
