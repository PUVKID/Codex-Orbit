# 39차 · 선명한 변경 알림

| 표시 | 의미 |
| --- | --- |
| 큰 제목 | 변경된 채팅의 제목입니다. |
| 이전·현재 | 같은 행에서 모델과 추론 강도를 비교합니다. |
| 현재 값 강조 | 실제로 바뀐 값만 강조합니다. |
| 태양·별·지구·달 | Sol·Astra·Terra·Luna 모델 계열 그림입니다. 정확한 ID도 표시합니다. |
