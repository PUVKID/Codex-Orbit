**이 차수에서 확인할 내용:** 최종 폴더에 별도 검증 기록이 확인되었으나 이 공개 소스 이력과 구분되는 최종 `src/` 스냅샷은 확인되지 않았습니다. 확인되지 않은 최종 제품 버전·공개 소스·직전 diff를 만들지 않았습니다. 이 폴더는 상태 설명만 담으며 비공개 검증 원문은 게시하지 않습니다.

**항목:** 2

**이 차수에서 확인할 내용:** 당시의 [문서·제작 도구·자산·시안 목록](보존자료.md)과 [원본/공개 해시·정제·제외 대응](부가자료_보존.json)을 제공합니다. 같은 SHA의 파일은 공통 보관 파일을 참조하며 실제 원본 경로와 버전을 보존합니다. 운영 기억·실제 계정/채팅 원문·비공개 검증은 제외하고 이유를 명시합니다. 보존 문서는 당시 내용이며 현재 안내는 저장소 첫 화면을 사용하십시오.
