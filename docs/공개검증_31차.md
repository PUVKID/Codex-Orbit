# 31차 검증 범위

현재 소스로 공개 전체 회귀 202개와 세 번째 배포 빌드의 개발 전체 475개 검사를 완료했습니다. 개발 전체는 1개를 건너뛰었고 실패는 없습니다. 최종 단일 EXE와 설치본의 크기·해시는 [다운로드](DOWNLOADS.md)에 기록했습니다.

최초 중앙 운영 검증은 개별 검사 상한 75초에 90초 명세를 전달해 명세 검증에서 실패했습니다. 이 시도에서는 기능 검사가 실행되지 않았고 소스 정확성 154파일 검사만 통과했습니다. 위 475개 결과는 별도 배포 빌드에서 실제 실행한 결과이며 중앙 운영 검증의 성공 결과가 아닙니다. 같은 검사 항목을 중복 없이 나누는 운영 명세 보완과 별도 재검증 대상이며, 게시 완료 여부는 중앙 재검증·독립 공개 검토·원격 확인 결과로 따로 판단합니다.

독립 재현에서는 상세 영역이 표시 영역의 폭 안에 들어가고 가로 스크롤이 없으며, 작은 창의 위아래 배치와 넓은 창의 좌우 배치가 복원됐습니다. 긴 제목·상태·이유·선택 이유와 이전/현재 모델·추론의 네 값, 선택한 기록, 언어 왕복, 원문 끝 접근도 확인했습니다. 동결320파일의 SHA가 모두 일치했습니다.

저장150% 설정의 한영 초기 생성·재생성과100% 대조, 기존 테마·배율 전환의 동적 강조 검사를 다시 통과했습니다. 이는 임시 합성 설정을 사용한 Qt offscreen Controller 검사입니다. 새 배포 EXE의 별도 프로세스 재시작 검증과 구분하며 화면 캡처는 상단·목록·상세 시작 부분, 원문 끝 접근은 실제 기하·스크롤·커서 단언으로 확인했습니다.

달력4모듈과 기존자산173개 중 사용법Markdown1개만 현재 버전 안내로 갱신했습니다. 나머지176개는30차 원문과 SHA-256이 같습니다. 과일·세 금속 링·날짜 규칙·그래픽과 글꼴 자산을 보존합니다.

합성 Qt 화면에서 라이트·다크, 한영,800×600의150% 화면과 끝 스크롤, 선택칸·설정 메뉴, 이전/현재 값과 프라이버시 가림을 확인했습니다. 합성 사용 한도0%·43.25%·100%는 시험 데이터이며 실계정 수치가 아닙니다. 개인 화면과 실제 경로가 보이는 파일창은 공개하지 않습니다. 최종 배포 화면과 소스 실행 화면은 구분합니다.

초기 공개 준비의 신규 모듈 복사 누락, 테마·배율 전환의 강조 소실, 저장150% 시작의 중복 확대, 좁은 상세 영역의 가로 잘림을 각각 재현하고 수정했습니다. 이전 소스의 공개199개·201개 및 개발472개·474개 결과와 첫째·둘째 실패 배포본은 별도로 보존하며 현재 소스의 결과로 재사용하지 않습니다.

최종 EXE의 독립 프로세스 스모크는 종료 코드 0으로 8.641초에 끝났으며 달력 모드, NanumGothic, 투명 모서리와 프레임 변화를 확인했습니다. 합성 설정으로 초기 시작·재시작 8회를 실행하고 8회 모두 설정 보존을 확인했습니다. 공개한 라이트·다크 두 화면은 실제 배포본의 합성 자료입니다. 작은 창에서 모든 상세 내용이 한 화면에 동시에 보인다는 뜻은 아니며, 끝 접근은 별도의 소스 스크롤 검사 근거입니다.

설치 파일은 Inno 빌드와 정적 버전·포함 파일을 확인했습니다. 이 문서의 빌드 검증 범위에는 실제 격리 설치 실행이 포함되지 않습니다.
