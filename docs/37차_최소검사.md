이번 변경에 관련된 기존 검사 근거를 재사용했습니다. 구현된 기능과 실제 실행으로 확인한 범위를 구분합니다.

| 항목 | 실제 확인 범위 |
| --- | --- |
| 관련 순수 기능 | 기존 17개와 지역 정합성 4개, 합계 21개 통과 근거 재사용. 변경 후 재분석 지점 1개 재검사 근거는 별도로 구분 |
| 배포 파일 | 실제 EXE·Setup 크기·SHA-256은 [다운로드](DOWNLOADS.md)에 기록. 최종 EXE·Setup 생성 결과와 변경된 12개 모듈의 실제 납품 코드 일치를 확인했습니다. 실제 납품 EXE의 첫 프레임·회전 변화·투명 배경을 별도 실행으로 확인했습니다. |
| GUI 연결 | 격리한 Qt 합성 화면에서 알림 센터 검색·빈 결과·초기화·프라이버시 복사·기록 없는 미리보기와 라이트·다크 화면을 확인했습니다. 수정 후 업데이트 창 닫기·취소·처리 중 닫기 차단만 별도로 확인해 종료 코드 0, 10.797초였습니다. 색상 편집창의 외부 그림자 효과로 인한 정지를 수리했고 대화상자 8개 검사가 통과했습니다. 날짜별 대상 133종과 도시 행사 형상 8종의 실제 픽셀 렌더에서 두 시점의 회전 변화가 확인됐습니다. 소스 기본 화면 연결에서도 실제 GPU 회전·투명 배경이 확인됐습니다. |
| 미실시·한계 | 과거 시간 초과·닫기 오류 원문은 보존합니다. 전체 27,028일을 각각 화면으로 확인하거나 모든 환경의 무결함을 보장한 결과가 아닙니다. 자동 위치는 연결망 제공 정보에 따라 실제 도시와 다를 수 있습니다. 실제 사용자 채팅·MD·계정 정보는 검사와 공개 자료에 복제하지 않습니다. 사용자 기기의 설치 결과는 별도 확인 범위로 기록합니다. |

합성 자료와 실제 관측, 코드 연결과 실제 모델 변경, 빌드와 실제 설치·업데이트는 서로 다른 근거입니다. 미실시·미완료를 통과로 바꾸지 않습니다.

## 픽셀 모션과 최종 화면·설치 확인

날짜별 대상 **133종**과 도시 행사 형상 **8종**의 실제 픽셀 렌더에서 두 시점의 회전 변화를 확인했습니다. 납품 EXE에서도 첫 프레임·회전·투명 배경을 확인했습니다. 라이트·한국어 100%/150%, 다크·영어 100%/150%의 네 합성 화면 조합이 통과했고, 설치본 적용 후 실행 파일 일치·기존 설정 보존·바탕화면 바로가기 생성을 확인했습니다. 모든 날짜나 모든 기기에서의 무결함을 보장한다는 뜻은 아닙니다.
