# 34차·이전 후 독립 검증

**첫 중앙 검사에서는 두 항목이 시간 제한을 넘겼습니다.** 픽셀 입체·초기화·종료 검사는 40초 제한에서 출력 없이, 지역·알림 검사는 60초 제한에서 일부 검사를 실행한 뒤 끝나지 않았습니다. 소스 문법 검사는 통과했습니다. 이 실패는 이후 성공과 별도로 보존했습니다.

두 번째 중앙 검사에서도 첫 항목이 40초 제한을 넘겼습니다. 지역·알림 33개와 소스 문법 219개는 통과했습니다. 추가 E17 Python 호스트 진단은 20.719초에 실제 GPU 픽셀 검사 경로의 접근 위반으로 실패했습니다. 이 충돌이 기존 시간 초과와 같은 원인인지는 확인하지 못했습니다.

C 기본 Python 호스트를 사용한 보조 진단에서는 29개가 14.531초에 완료됐습니다.

기록된 leaf 명령·작업 위치·관련 Python/Qt 환경 값은 같았으나 전체 상속 환경해 시는 달랐고 미기록 차이를 복원할 수 없습니다.

**호스트 하나만 다른 완전한 대조 실험이나 원인 해결로 표현하지 않습니다.** 최초 시간 초과와 접근 위반의 원인은 미확정입니다.

추가 진단을 종료한 뒤 새 독립 검증자가 C 기본 Python 호스트에서 아래 명세를 실행했습니다.

실제 검사는 E17 Python의 원래 명령으로 실행됐으며 제품 소스와 검사 명세, 개별 제한 40·60·20초와 전체 검사 제한 120초를 유지했습니다.

호스트와 환경의 차이는 위 한계와 함께 보존합니다.

소스 해 시를 읽는 시간과 실제 검사 제한은 구분합니다.

| 검사 | 제한(초) | 실제 검사 시간(초) | 결과 |
| --- | ---: | ---: | --- |
| 픽셀 3D 와초기화종료 | 40 | 22.437 | 통과 |
| 지역과알림회귀 | 60 | 18.375 | 통과 |
| 소스검사 | 20 | 0.453 | 통과 |

첫 실패의 소스 변경 없음과 후속 검증의 소스 변경 없음을 각각 대조했습니다.

이 결과는 이번 실행에 대한 확인이며, 모든 실행 환경에서 같은 시간이 걸리거나 향후 시간 초과가 없다는 보장은 아닙니다.

앞서 기록한 전체 개발 검사 653개·건너뜀 1개, 실제 EXE의 네 가지 합성 화면 조합, 별도의 혼합 GPU 진단 실패와 자동 날씨 최초 시간 초과도 그대로 보존합니다.
