# 36차 · 설치 선택 항목 정리

제품 버전은 **3.5.0**이며36차는 설치 파일 수정 이력입니다. [현재 다운로드](../../docs/DOWNLOADS.md) · [직전 전체 비교](직전차수.diff)

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner · 36차

설치 중 바로가기 선택 화면을 없애고 **바탕화면 바로가기를 자동으로 생성**하도록 바꿨습니다. 설치 완료 뒤 앱 실행 선택 체크박스도 제거했습니다. 앱의 제품 버전은 **3.5.0**이며 설치 파일만 교체합니다. 이미 제공한 단일 EXE와150% 설정을 바꾸는 앱 수정은 포함하지 않습니다.

확인 범위는 최종 설치 명세와 Setup 빌드 결과입니다. 글꼴이 그려지는 문제의 원인은 확정하지 않았으며, 선택 요소를 제거한 변경과 구분합니다. 기존35차 검사·실사용 확인과 실패 이력은35차 기록에 유지합니다.

## LEVEL 2 - Explorer · 36차

36차는 설치 명세에서 선택 작업과 완료 화면의 선택 항목을 제거한 차수입니다. 바탕화면 바로가기용 Tasks 조건을 없애고 Icons의 바탕화면 바로가기는 자동 생성하도록 지정했습니다. postinstall 표시를 제거하고 새 명세의 nowait·skipifsilent 실행 규칙을 따르며 제품 기능과 앱 버전은35차와 같습니다.

확인 범위는 최종 설치 명세와 Setup 빌드 결과입니다. 글꼴이 그려지는 문제의 원인은 확정하지 않았으며, 선택 요소를 제거한 변경과 구분합니다. 기존35차 검사·실사용 확인과 실패 이력은35차 기록에 유지합니다.

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner · 36차

현재 v3.5.0의 단일 EXE는35차와 같고 Setup만36차 명세로 다시 만들었습니다. 다운로드에서 현재Setup의 크기·SHA-256과 교체 전35차 값을 구분합니다. 기존 실행 파일이나150% 앱 코드를 재빌드하지 않았습니다. 설치 파일의 체크박스 제거와 앱의 화면 배율 동작은 다른 변경 범위입니다.

확인 범위는 최종 설치 명세와 Setup 빌드 결과입니다. 글꼴이 그려지는 문제의 원인은 확정하지 않았으며, 선택 요소를 제거한 변경과 구분합니다. 기존35차 검사·실사용 확인과 실패 이력은35차 기록에 유지합니다.

## LEVEL 5 - Expert · 36차

36차의 공개 소스 변경은 설치 명세와 그에 대응하는 문서·탐색 연결입니다. 실제35차 자산을 재사용해 Setup을 만들었으며 기존 EXE의 SHA-256은 유지합니다. 선택 요소 제거를 글꼴 paint 문제의 원인 규명으로 해석하지 않습니다. 전면 회귀·설치 화면 전체 조작 검사를 새로 완료했다고 표시하지 않습니다.

확인 범위는 최종 설치 명세와 Setup 빌드 결과입니다. 글꼴이 그려지는 문제의 원인은 확정하지 않았으며, 선택 요소를 제거한 변경과 구분합니다. 기존35차 검사·실사용 확인과 실패 이력은35차 기록에 유지합니다.
