# 41차 · 선택한 당시 알림 디자인

3.11.0은 사용자가 선택한 당시 알림 디자인을 복원합니다. 모델 그림과 추론 막대, 짧은 이유, 설명·상세 링크, 고정·기록 보관 두 버튼으로 구성합니다.

[전체 비교](직전차수.diff) · [웹 비교](비교.md) · [사용 방법](../../docs/41차_선택한알림형식.md)

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

### 기능과 표시

| 항목 | 동작·의미 |
| --- | --- |
| 어느 채팅인가요 | 맨 위 제목으로 채팅을 확인합니다. 제목에는 장식 이모지를 붙이지 않습니다. |
| 무엇이 바뀌었나요 | 왼쪽 이전 값과 오른쪽 현재 값을 같은 줄에서 비교합니다. 바뀐 현재 값만 강조합니다. |
| 그림과 막대 | 태양은 Sol, 별은 Astra, 지구는 Terra, 달은 Luna입니다. 막대는 추론 강도를 구분하며 정확한 이름과 원래 강도도 같이 읽습니다. |
| 이유와 조작 | 짧은 이유를 읽고 설명 더 보기로 원문, 자세히 보기로 해당 상세 기록을 엽니다. 고정·기록 보관은 맨 아래에 있습니다. |

### 설정과 보존

| 조건 | 처리 |
| --- | --- |
| 이전 기록 없음 | 이전 값을 추측하지 않고 기록 부재를 표시합니다. |
| 테마·언어 | 한영·라이트/다크·사용자 색상·글자 배율을 유지합니다. |
| 공개 이유 | 기록된 설명만 표시하며 비공개 추론이나 원인을 만들지 않습니다. |
| 기존 기능 | 날짜별 과일·꽃 픽셀 모션, 감시·날씨·한도 기능은 유지합니다. |

### 확인과 한계

| 근거 | 범위·주의 |
| --- | --- |
| 화면 | 실제 Qt 알림을 합성 이벤트로 촬영해 전후 값과 이유 영역을 확인합니다. |
| 독립 확인 | 모델·강도 그림, 원래 값·문장 이모지, 작은 화면과 설명·상세 버튼을 확인했습니다. 이모지 글꼴은 40차 근거를 재사용합니다. |
| 기존 근거 | 변경하지 않은 기능은 기존 유효한 검사 결과를 재사용합니다. |
| 지원 한계 | 운영체제에 없는 미래 이모지나 모든 환경의 무결함을 보장하지 않습니다. |
| 모델 정보 | 로컬 관측이며 서버 모델 신원·비공개 추론의 증명이 아닙니다. |

## LEVEL 5 - Expert

### 기능과 표시

| 항목 | 동작·의미 |
| --- | --- |
| 계열·원값 | 정해진 gpt-정수[.정수]- 뒤에 sol·astra·terra·luna 중 하나가 붙는 형식 계열은 대응 그림을 사용합니다. 모델 ID는 원값이며 알 수 없는 값도 보존합니다. |
| 강도 매핑 | none=0, minimal=1, low=2, medium=3, high=4, xhigh=5, ultra=6칸입니다. 미확인은 사선과 원래 값으로 구분합니다. |

| 검증 범위 | 100% 실제 합성 카드 500×311, EN150/700×400 카드 625×373, 자식 13개와 그림 경계·원값·버튼을 확인했습니다. 원문 창의 31px 넘침은 실제 frame 기준으로 수리했습니다. |
