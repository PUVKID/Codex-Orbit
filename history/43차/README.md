# 43차 · 1분 날씨와 위치 보정

3.12.0은 날씨를 1분마다 조회하고, 사용자가 확인한 도시를 현재 연결에 한해 보정합니다. 기존 41차 알림 디자인은 유지하며 42차 디자인 작업은 포함하지 않습니다.

[전체 비교](직전차수.diff) · [웹 비교](비교.md) · [사용 방법](../../docs/43차_날씨와위치.md)

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

### 기능과 흐름

| 항목 | 동작·의미 |
| --- | --- |
| 자동 갱신 | 기온·습도·날씨·강수량·일출·일몰을 같은 도시 좌표로 60초마다 재조회합니다. |
| 위치 재확인 | 시작 시와 5분마다 인터넷 접속 위치를 확인합니다. 날씨와 주기를 분리해 무료 위치 API 한도를 고려합니다. |
| 확인 도시 | 사용자가 확인한 도시의 국가·행정구역·도시 ID·좌표를 함께 사용합니다. 보정 설정은 해당 사용자 컴퓨터에만 있습니다. |
| 보정 적용 | 현재 연결 식별값과 국가가 같을 때만 보정하며, 연결이 다르면 사용하지 않습니다. 수동 도시 선택이 우선합니다. |
| 서울 등 다른 도시가 보일 때 | 접속 위치는 통신사 접속 지점일 수 있습니다. 실제 도시를 확인해 보정하거나 직접 도시를 선택할 수 있습니다. |
| 1분의 의미 | 매분 새로 확인하지만 제공업체가 매분 새 관측을 만드는 것은 아닙니다. 오래된 자료는 이전 값으로 표시합니다. |

### 설정과 주의

| 조건 | 처리·한계 |
| --- | --- |
| 정확도 | IP만으로 동·건물 단위 위치를 보장하지 않습니다. 확인 도시는 GPS 측정이 아닙니다. |
| 같은 연결 | 같은 공인 IP 안의 이동은 자동으로 구별할 수 없습니다. 새 연결 감지는 다음 위치 조회 때 반영됩니다. |
| 기상 격자 | 응답에 격자 좌표가 있을 때 25km 거리를 비교하고, 없으면 요청 좌표의 유효성만 검사합니다. 이 조건은 실제 위치 정확도를 보증하지 않습니다. |
| 기존 기능 | 알림 디자인·감시·이전/현재 모델과 강도·한도·달력 모션·테마·언어는 보존합니다. |
| 공개 제외 | 실제 사용자 위치·연결 식별값·개인 설정·대화·운영 기록은 게시하지 않습니다. |

### 검사와 재현

| 근거 | 범위 |
| --- | --- |
| Python | 관련 39건 통과, 초기화 수리·기존 번역 기대 정정 근거를 보존했습니다. |
| Rust | 거리·범위·날짜변경선 4건과 별도 경계 검사를 통과했습니다. 실제 수락 경로에 연결했습니다. |
| 독립 확인 | 초기 국가 코드 null 오류를 수리한 뒤 null·dict·int·list 4종을 통과했습니다. 기존 FAIL은 보존합니다. |
| 실제 통신 | 실제 API의 확인 도시·온습도와 다음 자동 갱신을 확인했습니다. |
| 재사용 | 수정 없는 기능의 기존 41차·37차 유효 근거를 재사용하고 변경 범위만 검사합니다. |
| 성능 | 전후 성능 미측정이며 속도 향상을 주장하지 않습니다. 모든 환경의 무결함을 보장하지 않습니다. |
