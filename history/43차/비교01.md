+# 43차 · 1분 날씨 갱신과 위치 보정
+
+**3.12.0**은 정식 배포 41차의 날씨 처리만 수정합니다. 42차 디자인 작업과 별개이며 기존 알림·날짜별 모션·테마·언어·기록을 유지합니다.
+
+| 항목 | 동작 | 확인할 점 |
+| --- | --- | --- |
+| 날씨 갱신 | 기온·습도·날씨·강수량·일출·일몰을 **60초마다** 같은 좌표로 조회 | 네트워크 응답 시간은 추가됩니다. |
+| 위치 조회 | 시작 시와 5분 간격으로 연결 위치 재확인 | 무료 위치 API 일일 한도를 고려해 날씨와 주기를 분리합니다. |
+| 위치 보정 | 사용자가 확인한 도시를 해당 연결에만 적용 | 자동 IP 위치가 실제 거주지라는 뜻은 아닙니다. |
+| 이동·다른 연결 | 연결 식별값·국가가 다르면 보정 사용 중지 | 같은 공인 IP 안에서 이동하면 자동 구분할 수 없습니다. |
+| 직접 선택 | 기존 자동·수동 도시 선택 유지 | 새 설치에는 특정 도시를 기본 지정하지 않습니다. |
+| 자료 지연 | 실제 자료 시각과 조회 시각 구분·오래된 자료 표시 | 1분 재조회가 관측소의 1분 새 관측을 뜻하지는 않습니다. |
+
+인터넷 접속 위치는 통신사·VPN 등의 접속 지점을 가리킬 수 있어 실제 도시와 다를 수 있습니다. 동·건물 단위 위치를 IP만으로 보장하지 않습니다. 보정은 사용자가 알려 준 도시 중심 좌표이며 GPS 측정값이 아닙니다. 실제 사용자 위치·연결 식별값·운영 기록은 공개하지 않습니다.
+
+## 처리와 오류
+
+| 단계 | 처리 |
+| --- | --- |
+| 확인 도시 | 도시 이름뿐 아니라 국가·행정구역·GeoNames ID·좌표를 함께 보존합니다. |
+| 표시 연결 | 표시 도시와 날씨 요청 좌표를 같이 변경하고, 이전 도시의 날씨를 지웁니다. |
+| 번역 | 확인 도시가 언어 변경·추가 지명 검색으로 다른 도시로 덮이지 않게 합니다. |
+| Rust 검증 | 기상 응답에 격자 좌표가 있으면 DLL이 요청 좌표와의 대권 거리를 계산합니다. 격자 좌표가 없으면 요청 좌표의 유효성만 검사합니다. |
+| 잘못된 응답 | 비유한·범위 밖 좌표 또는 25km 초과 격자를 거부하고 오류 상태로 표시합니다. |
+| DLL 누락 | 검증을 생략하지 않고 날씨 위치 검증 오류를 표시합니다. |
+| 요청 겹침 | 진행 중 요청을 중복 실행하지 않으며, 취소·종료 뒤 콜백을 무시합니다. |
+
+응답에 격자 좌표가 있을 때만 25km 거리 비교가 가능합니다. 격자 좌표가 누락된 자료에서는 요청 좌표 유효성만 확인하므로, 다른 지역 응답 여부까지 입증하지 않습니다.
+
+25km는 기상 모델의 격자 차이를 허용하기 위한 응답 정합 조건입니다. 실제 위치 오차를 25km 이하로 보증하는 수치가 아니며, 자료 제공 격자가 이 범위를 넘으면 해당 응답을 사용하지 않습니다.
+
+## 빌드와 실행
+
+| 대상 | 방법 |
+| --- | --- |
+| Rust | Windows x64 MSVC 개발 환경에서 `cargo test --manifest-path native/weather_guard/Cargo.toml`, `cargo build --release --manifest-path native/weather_guard/Cargo.toml` |
+| DLL | `native/weather_guard/target/release/orbit_weather_guard.dll`을 `assets/orbit_weather_guard.dll`로 복사 |
+| 표준 배포 | 기존 Python 의존 환경에서 `python tools/build43.py --compiler <ISCC.exe 경로>` 실행. Rust 빌드와 DLL 복사를 포함합니다. |
+| 단일 EXE | `CodexOrbit.exe` 실행. DLL은 내부에 포함됩니다. |
+| 설치 | `CodexOrbit-Setup.exe` 실행. 기존 설정·기록을 보존합니다. |
+
+Rust는 실제 날씨 응답의 좌표 검증에 연결했습니다. 같은 환경의 전후 성능 측정은 수행하지 않았으며 속도 개선을 주장하지 않습니다. Graphify의 로컬 코드 그래프와 직접 소스로 호출 관계를 대조했고, 그래프는 비공개로 유지합니다.
