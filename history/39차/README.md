# 39차 · 선명한 변경 알림

**3.9.0**은 알림의 장식을 직접 그린 그림으로 표시합니다. 채팅 제목, 이전·현재 모델과 추론 강도, 짧은 이유 순서로 읽으며 **바뀐 현재 값만 강조**합니다.

[전체 비교](직전차수.diff) · [비교 웹 보기](비교.md) · [사용 방법](../../docs/39차_알림아이콘.md)

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

### 기능과 읽는 순서

| 항목 | 동작·의미 |
| --- | --- |
| 제목과 값 | 맨 위 제목으로 채팅을 확인하고 왼쪽 이전 값과 오른쪽 현재 값을 읽습니다. |
| 모델 그림 | 태양은 Sol, 별은 Astra, 지구는 Terra, 달은 Luna입니다. 옆의 모델 ID가 정확한 이름입니다. |
| 추론 강도 | 막대가 많을수록 더 높은 강도입니다. 쉬운 이름과 원래 값도 같이 표시합니다. |
| 이유 | 공개된 짧은 한 문장을 먼저 읽고 설명 더 보기로 전체 설명을 엽니다. |

### 설정과 조건

| 조건 | 표시·처리 |
| --- | --- |
| 테마·언어 | 라이트·다크, 한국어·영어, 사용자 색상과 글자 배율을 유지합니다. |
| 이전 기록 없음 | 이전 값이 없음을 표시하며 모델이나 강도를 추측하지 않습니다. |
| 실제 변경 | 바뀐 현재 값만 강조합니다. 작업 재개와 설정 변경 구분은 유지합니다. |
| 원문·개인정보 | 공개 원문 창과 가림 기능을 유지하며 비공개 추론을 만들어 내지 않습니다. |

### 확인과 한계

| 근거 | 범위·주의 |
| --- | --- |
| 그림 | 18종 그림의 투명 영역과 실제 표시 픽셀을 확인했습니다. |
| 값 | 정확한 전후 ID·강도 원값·미확인 값 보존을 확인했습니다. |
| 수리 | 150% 그림 아래 잘림과 영어 버튼 번역 누락을 수리하고 해당 부분을 독립 확인했습니다. |
| 화면 | 합성 알림의 라이트/다크·한영·100/150% 네 조합과 공개 원문 창을 확인했습니다. |
| 기존 기능 | 변경하지 않은 감시·날씨·한도·모션은 기존 유효한 검사 근거를 재사용합니다. |
| 한계 | 실제 서버 모델 신원·비공개 추론·모든 환경의 무결함을 증명하는 검사는 아닙니다. |

**이유는 기록된 공개 설명에 근거합니다.** 확인하지 못한 변경 원인을 새로 지어내지 않습니다.

## LEVEL 5 - Expert

| 항목 | 동작·의미 |

| 모델 식별 | gpt-정수[.정수]- 뒤에 sol·astra·terra·luna 중 하나가 붙는 형식과 일치할 때 계열 그림을 사용합니다. 그 외 모델은 일반 그림과 원래 ID를 표시합니다. |
