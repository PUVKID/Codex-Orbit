# 31차 · 화면 마감과 테마 선택

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

3.1.0은 시스템 설정·밝은 화면·어두운 화면 중 고른 테마를 바로 적용하고 기억합니다. 언어·글자 크기·회전 속도도 같은 영역에서 조정합니다. 프라이버시 모드는 제목과 작업 설명을 화면에서 가릴 뿐 저장 원문을 지우지 않습니다. 177개 구성 중 사용법 Markdown 1개를 갱신하고 나머지 176개는 30차와 같은 SHA였습니다. 과일·금속 링·글꼴·날짜 규칙을 새로 만든 차수로 보지 않습니다. 공개 검사 202개와 개발 전체 475개(1개 건너뜀)는 검사 범위이며 합성 화면을 개인 계정의 실측으로 읽지 않습니다.

### LEVEL 1 · 이 자료의 세부 조건을 함께 읽기

3.1.0에서는 시스템·라이트·다크 화면 테마를 즉시 적용하고 선택을 저장합니다. 언어·글자 크기·회전 속도는 같은 설정 영역에서 조절하고, 작업 현황에서 선택 설정과 최근 실행 관측을 구분합니다. 화면 설정 메뉴는 움직임 줄이기·가장자리 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인을 설명합니다. 프라이버시 모드는 화면의 제목과 작업 설명을 가리며 저장 원문을 유지합니다.

달력4모듈과 기존자산173개를 합친177개 중 사용법Markdown1개를 현재 버전 안내로 갱신했습니다. 나머지176개는30차 원문 SHA와 동일하며 과일·세 금속 링·글꼴 자산·날짜 규칙은 바꾸지 않았습니다.

실제 전체 비교는 추가·수정·삭제와 주석·공백·개행을 포함하며 바이너리는 크기와 SHA로 기록합니다. 개인 화면·설정·운영 원문은 공개하지 않습니다.

테마·배율 전환의 강조 보존, 저장된 150% 설정의 초기 시작·재시작, 좁은 창의 위아래 상세 배치와 넓은 창의 좌우 복귀를 수정했습니다. 공개 202개 검사와 개발 전체 475개 검사(1개 건너뜀)를 완료했습니다. 실제 배포본의 합성 라이트·다크 화면은 첫 화면에서 확인할 수 있습니다.

## LEVEL 2 - Explorer

### LEVEL 2 · 구성과 조건의 관계

선택 테마의 즉시 반영·저장과 선택 설정/최근 실행 관측의 구분을 연결합니다. 움직임·가장자리 붙이기·소리·화질·진단·업데이트의 설명을 같은 설정 영역에서 읽고, 프라이버시 가림과 원문 저장을 별개로 봅니다. 보존 범위는 달력 4모듈+자산 173개=177개이며 안내 1개 외 176개의 30차 SHA 동일성을 유지했습니다. 150% 시작/재시작과 창 폭에 따른 상세 배치 수정, 202/475 검사와 합성 화면을 각각 다른 근거로 읽습니다.

## LEVEL 3 - Practitioner
