### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

3.1.0은 시스템 설정·밝은 화면·어두운 화면 중 고른 테마를 바로 적용하고 기억합니다.

과일·금속 링·글꼴·날짜 규칙을 새로 만든 차수로 보지 않습니다.

화면 설정 메뉴는 움직임 줄이기·가장자리 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인을 설명합니다.

프라이버시 모드는 화면의 제목과 작업 설명을 가리며 저장 원문을 유지합니다.

달력 4 모듈과 기존 자산 173개를 합친 177개 중 사용법 Markdown1개를 현재 버전 안내로 갱신했습니다. 나머지 176개는 30차 원문 SHA와 동일하며 과일·세 금속 링·글꼴 자산·날짜 규칙은 바꾸지 않았습니다.

### LEVEL 1·31차의 구체적인 기능과 확인

**무엇이 달라졌나요:** 화면을 시스템 설정에 맞추거나 밝게·어둡게 고를 수 있고, 고른 화면이 바로 적용되고 저장됩니다. 같은 설정 영역에서 언어·글자 크기·회전 속도도 바꿉니다. 작업 화면은 사용자가 고른 설정과 최근 실행 기록에서 확인한 값을 따로 보여 줍니다.

**어떻게 쓰나요:** 움직임 줄이기, 화면 끝에 붙이기, 알림 소리, 성능과 화질, 문제 확인용 파일 저장, 새 버전 확인은 화면 설정 메뉴에서 확인합니다. 프라이버시 모드는 화면의 제목과 작업 설명을 가리지만 기록 원문은 지우지 않습니다.

**확인과 주의:** 글자를 150%로 저장한 뒤 시작·재시작, 작은 창의 위아래 배치와 큰 창의 좌우 배치를 수정했습니다.

공개 검사 202개와 개발 검사 475개 중 건너뜀 1개가 기록됐습니다.

라이트·다크 화면은 합성 예시입니다.

자료 177개 중 안내 문서 1개만 갱신했고 나머지 176개는 이전 차수와 SHA가 같습니다.

SHA는 파일 일치를 확인하는 지문입니다.

### LEVEL 5·31차의 구체적인 기능과 확인

3.1.0은 시스템·라이트·다크의 즉시 적용·저장, 언어·배율·회전 속도 설정, 선택 값과 최근 실행 관측의 구분을 기록합니다. 모션·도킹·소리·성능·진단·업데이트 메뉴와 프라이버시 모드의 표시/저장 경계를 포함합니다. 강조 보존, 저장 150%의 최초·재시작, 좁은 창 세로·넓은 창 가로 복귀가 변경 내용입니다.

달력 4 모듈과 기존 173 자산의 총 177개 중 사용법 Markdown 1개를 갱신했고 나머지 176개가 30차 SHA와 같습니다.

과일·세 금속 링·글꼴·날짜 규칙은 유지됩니다.

파일별 크기·SHA 및 직전 소스·공개 전체 비교는 주석·공백·개행을 포함합니다.

공개 202개와 개발 475개 검사 중 1개 건너뜀 및 합성 화면 조건을 원문대로 보존하고 개인 화면·설정·운영 원문을 공개 근거로 만들지 않습니다.

### LEVEL 5·31차 추가 해설·LEVEL 5·31차·화면 마감과 테마 선택

3.1.0에서는 시스템·라이트·다크 화면 테마를 즉시 적용하고 선택을 저장합니다.

언어·글자 크기·회전 속도는 같은 설정 영역에서 조절하고, 작업 현황에서 선택 설정과 최근 실행 관측을 구분합니다.

화면 설정 메뉴는 움직임 줄이기·가장자리 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인을 설명합니다.

프라이버시 모드는 화면의 제목과 작업 설명을 가리며 저장 원문을 유지합니다.

달력 4 모듈과 기존 자산 173개를 합친 177개 중 사용법 Markdown1개를 현재 버전 안내로 갱신했습니다. 나머지 176개는 30차 원문 SHA와 동일하며 과일·세 금속 링·글꼴 자산·날짜 규칙은 바꾸지 않았습니다.
