# 🎨 31차 · 화면 마감과 테마 선택

3.1.0에서는 시스템·라이트·다크 화면 테마를 즉시 적용하고 선택을 저장합니다. 언어·글자 크기·회전 속도는 같은 설정 영역에서 조절하고, 작업 현황에서 선택 설정과 최근 실행 관측을 구분합니다. 화면 설정 메뉴는 움직임 줄이기·가장자리 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인을 설명합니다. 프라이버시 모드는 화면의 제목과 작업 설명을 가리며 저장 원문을 유지합니다.

달력4모듈과 기존자산173개를 합친177개 중 사용법Markdown1개를 현재 버전 안내로 갱신했습니다. 나머지176개는30차 원문 SHA와 동일하며 과일·세 금속 링·글꼴 자산·날짜 규칙은 바꾸지 않았습니다.

실제 전체 비교는 추가·수정·삭제와 주석·공백·개행을 포함하며 바이너리는 크기와 SHA로 기록합니다. 개인 화면·설정·운영 원문은 공개하지 않습니다.

테마·배율 전환의 강조 보존, 저장된 150% 설정의 초기 시작·재시작, 좁은 창의 위아래 상세 배치와 넓은 창의 좌우 복귀를 수정했습니다. 공개 202개 검사와 개발 전체 475개 검사(1개 건너뜀)를 완료했습니다. 실제 배포본의 합성 라이트·다크 화면은 첫 화면에서 확인할 수 있습니다.
