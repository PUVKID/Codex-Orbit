# 35차·개발자용 색상과 조명

현재 35차는 **3.5.0 정식 배포본**으로 안내합니다. 아래 준비 해설의 기능을 새 차수에 반영했으며 실제 EXE·설치본 메타와 최소 실행 결과는 [최소 검사 상태](../../docs/35차_최소검사.md)에 기록합니다. 전체 회귀와 독립 검증을 새로 통과한 것으로 표시하지 않습니다.

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner·35차

검정과 초록을 기본으로 하는 화면에서 **화면 테마**를 시스템·라이트·다크로 선택하고, **색상 꾸미기**에서 여섯 색 조합을 고르거나 포인트·다크 배경·라이트 배경의 6 자리 HEX 색상 코드를 입력할 수 있도록 준비했습니다.

색 선택 버튼도 사용할 수 있습니다.

조명은 0~100으로 조절하며 0이면 꺼집니다.

미리 보기의 밝기 선택은 앱 전체를 즉시 바꾸지 않습니다.

적용하면 저장하고 취소하면 저장하지 않으며, 기본값 복원도 적용해야 저장됩니다.

**HEX는 색을 정하는 여섯 글자 코드**입니다.

앞의 `#`은 색 코드 표시이고, 그 뒤에 숫자와 영문자를 여섯 개 적습니다.

기본 예시는 초록 포인트 `#73F936`, 어두운 배경 `#0B0D0C`, 밝은 배경 `#F7F8F7`입니다.

코드를 직접 입력하기 어렵다면 먼저 여섯 가지 색 조합 중 마음에 드는 것을 고른 뒤, 더 바꾸고 싶은 부분은 색 선택 버튼을 눌러 고르면 됩니다.

조명 강도의 기본 값은 25이며 0으로 내리면 조명이 꺼집니다.


잘못된 코드는 입력 칸에 설명하고 적용을 막도록 설계했습니다. 저장 실패 시 이전 설정과 화면을 복원하고 창을 유지합니다. 입력 색상은 보존하고 글자·선택 표시와 조명이 섞인 배경의 대비를 고려합니다. 발광은 움직이는 장식이 아닌 정적인 효과이며 화면 전체 블러나 새로운 애니메이션 타이머를 추가하지 않습니다.

날짜별 과일·꽃·기념일·도시 행사와 자연 색·픽셀 3D 회전은 유지 대상입니다.

자동 위치는 IP 기반의 대략적 추정이고 수동 위치는 선택한 지역을 사용하며, 정확한 실제 위치를 보장하지 않습니다.

사용 한도는 남은 토큰 수가 아니며 실제 비율과 원값을 보존합니다.

자원 설정은 초당 240장 달성을 보장하지 않습니다.

**35차는 정식 배포하며, 최소 실행의 관측 범위와 자동 검사 미완료를 아래에 구분합니다.** 앞의 34차 측정은 34차의 결과입니다.

**3.5.0 정식 배포본**입니다.

실제 EXE의 합성 UI 검사에서 라이트·한국어 100%, 다크·영어 100%, 라이트·한국어 150% 세 조합을 완료했습니다.

네 번째 다크·영어 150% 조합은 `AssertionError`로 완료하지 못했으며 정확한 원인은 미확정입니다.

이 자동 검사 미완료가 실제 150% 제품 고장을 확정하지 않습니다.

설정 검사는 다섯 항목 통과 뒤 첫 대화 상자 검사에서 180초 제한으로 중단됐습니다.

전체 UI·회귀·실제 설치의 통과를 뜻하지 않습니다.

## LEVEL 5 - Expert·35차

35차 준비 명세는 시스템·라이트·다크 모드와 기존 모드 보존, 여섯 프리 셋, 포인트·다크/라이트 배경의 6 자리 HEX, 색 선택기 및 0~100 정적 발광을 정의합니다.

잘못된 값은 필드별 오류와 적용 차단, 저장 실패는 이전 설정·팔레트 복원과 창 유지가 요구됩니다.

준비 코드에서 `appearance35.py`는 정규화·대비·팔레트를, `theme.py`는 팔레트 캐시와 조명 혼합을 담당합니다.

입력 원색을 유지하면서 읽기용 의미색과 조명이 섞인 배경의 대비를 평가합니다.

새 애니메이션 타이머·전체 블러는 추가하지 않습니다. `ui_appearance_smoke35.py`와 `test_appearance35.py`의 준비 검사는 실제 새 제품 및 독립 검증 결과와 구분해야 합니다.

설정 재읽기와 전체 프로세스 재시작 검사는 동의어가 아닙니다.

날짜별 과일·꽃·기념일·도시 행사와 자연 색·픽셀 3D 회전은 유지 대상입니다.

자동 위치는 IP 기반의 대략적 추정이고 수동 위치는 선택한 지역을 사용하며, 정확한 실제 위치를 보장하지 않습니다.

사용 한도는 남은 토큰 수가 아니며 실제 비율과 원값을 보존합니다.

자원 설정은 초당 240장 달성을 보장하지 않습니다.

**35차는 정식 배포하며, 최소 실행의 관측 범위와 자동 검사 미완료를 아래에 구분합니다.** 앞의 34차 측정은 34차의 결과입니다.

<!-- 35차-실제검증-시작 -->
**3.5.0 정식 배포본**입니다.

실제 EXE의 합성 UI 검사에서 라이트·한국어 100%, 다크·영어 100%, 라이트·한국어 150% 세 조합을 완료했습니다.

네 번째 다크·영어 150% 조합은 `AssertionError`로 완료하지 못했으며 정확한 원인은 미확정입니다.

이 자동 검사 미완료가 실제 150% 제품 고장을 확정하지 않습니다.

사용자는 150% 배율의 실 사용이 정상이라고 직접 확인했습니다.

이는 자동 검사 전체 통과와 구분합니다.

설정 검사는 다섯 항목 통과 뒤 첫 대화 상자 검사에서 180초 제한으로 중단됐습니다.

같은 EXE의 기본 실행 한 번은 종료 코드 0으로 끝났고 시작 준비·프레임 변화·투명 위젯을 확인했습니다.

전체 UI·회귀·실제 설치의 통과를 뜻하지 않습니다.
