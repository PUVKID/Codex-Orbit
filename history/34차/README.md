### LEVEL 1 · 배포 사용법의 수준 안내

**가이드 추가 후 재빌드와 새 배포 검사를 확인했습니다.** 전체 653개 검사에서 실패 0·건너뜀 1, 빌드 입력 843 파일 불변을 확인했습니다.

새 EXE의 한국어 가이드와 별도 한국어·영어 사용법에는 다섯 링크가 있으며, 영어 가이드까지 모두 EXE 안에 내장된 구조는 아닙니다.

새 실행 본의 네 합성 화면 조합·정적 227 검사·설치 본 47 파일 추출 대조를 확인했지만 실제 설치와 새 EXE의 행사 8 종 순회는 이 결과에 포함하지 않습니다.

[같은 수준의 34차 설명](README.md#user-content-reading-level-1) · [수리 범위와 원문 비교](../../docs/34차_배포사용법_수준안내.md)


**목적과 변화:** 날짜에 어울리는 과일·꽃·기념일이나 도시 행사 모양을 바탕화면에 보여 줍니다. 입체 모형을 작은 점처럼 표현하는 픽셀 방식으로 그리며, 모형이 세로축을 중심으로 한 바퀴 돕니다. 위치·날씨와 남은 사용 한도 글자는 알아보기 쉽게 따로 표시합니다.

**준비와 사용:** Windows 10 또는 11의 64비트 환경과 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다.

단일 실행 파일을 열거나 설치 본을 사용할 수 있습니다.

위젯을 누르면 기록과 한도 화면을 볼 수 있고, 지역 표시를 눌러 자동 추정이나 직접 검색한 지역을 선택할 수 있습니다.

자동 위치는 인터넷 주소에 따른 추정이어서 실제 건물 위치와 다를 수 있습니다.

**무엇을 확인하나요:** 강수량은 제공된 집계 간격을 함께 읽고 실제 0과 확인되지 않은 값을 구분합니다. 백분율은 소수 첫째 자리로 반올림해 보여 주며 원값은 툴팁에서 확인합니다. 도시 행사는 발표된 정확한 날짜에만 해당 모티프를 적용합니다.

**주의:** 모든 도시 행사나 발표되지 않은 미래 날짜가 수록된 것은 아닙니다. 33차는 별도 출시 없이 진행한 기록이고, 34차 검증 결과와 구분해 읽어야합니다. 한도 비율은 남은 토큰 개수가 아닙니다.


**검증 범위:** 검사에서는 총 653개 중 실패가 없었고 1개는 건너뛰었습니다.

실제 프로그램의 네 화면 조합에는 예시 날씨와 도시 자료를 사용했습니다.

설치 파일은 실행 설치가 아니라 내용만 꺼내 확인했습니다.

날씨 조회에는 8초 제한이 있으며 처음 조회가 시간 초과된 뒤 다시 한 번 성공했지만, 첫 실패 이유는 확인되지 않았습니다.

다른 방식의 보조 GPU 진단에서는 첫 화면을 제시간에 받지 못했고 종료 뒤 남은 작업이 없음을 확인했습니다.

#### LEVEL 1·34차·픽셀 입체 조형과 도시 행사

날짜별 과일·꽃·기념일과 도시 행사 주제를 실제 입체 삼각형 표면으로 만든 입체 모형의 픽셀 렌더로 표시하고 세로 축으로 한 바퀴 회전합니다.

글자·날씨·잔 량은 또렷하게 유지합니다.

자동·수동 위치와 강수량 집계 간격, 소수 첫째 자리 반올림·원값 확인을 이어받습니다.

도시 축제 목록 항목과 발표 일정, 근거 있는 시리즈·개최분·미분류를 구분합니다.

공식 날짜만 8 종 행사 모티프로 연결하고 출처·라이선스·갱신과 수록 한계를 표시합니다.

전 세계 모든 행사나 미발표 미래 날짜를 보장하지 않습니다. 33차는 별도 릴리스 없이 진행한 원문을 이번 공개에 보존하고 34차에 통합했으며, 당시 진행 상태와 34차의 실제 검증 결과를 구분합니다.

그래픽 장치(GPU) 작업은 별도 소유 프로세스에 격리하고 일반 앱과 내부 그래픽 장치(GPU) 진입을 분리합니다.

최대 5초 준비와 준비 뒤 표시 그림 한 장의 기존 2초 검사는 별개이며, 종료는 정상 회 수를 먼저 요청하고 필요한 경우 소유 앱이 소유한 작업 묶음(Job)만 한정해 강제 회수합니다.

OS의 모든 정지를 기한 안에 해결한다는 보장은 아닙니다.

실제 최종 결과는 검증 문서에서 구분해 확인합니다.

변경된 소스·검사·문서를 보존합니다. [자산 원문](자산_원문목록.json)은 크기·SHA와 내용이 고정된 v3.4.0 링크로 연결하며 큰 원본을 중복 저장하지 않습니다. 별도 릴리스 없이 진행한 33차 원문 보존과 34차 통합, 실제 공개 32차 기준을 구분하고 전체 이전 이력을 보존합니다.

**목적과 변화:** 날짜와 지역에 따른 주제를 입체 메시로 만들고 픽셀 표현과 회전을 적용합니다. 정보 글자는 조형과 분리해 가독성을 유지합니다. 자동 위치는 네트워크 기반 추정이며, 수동 지역은 검색 결과 선택으로 정합니다. 국가만 고를 때는 디자인 국가가 바뀌고 날씨 기준 지역은 유지됩니다.

**조건과 절차:** 행사 목록에는 행사 시리즈, 개최 회차, 미분류 항목이 함께 들어갑니다. 정확히 발표된 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열기구의 여덟 모티프를 연결합니다. 일정 새로고침이 실패하거나 검증되지 않으면 기존 자료와 상태를 확인합니다.

**확인과 주의:** 강수량은 수치와 집계 간격을 함께 표시하고 미확인·오래된 정보를 구분합니다. 33차 진행 원문은 34차에 통합됐지만 당시 진행 상태를 34차의 결과로 바꿔 해석하지 않습니다. 목록이 세계 모든 행사와 미래 일정을 포괄한다고 가정할 수 없습니다.


**검증 범위:** 검사 653개는 앞 325개와 뒤 328개로 나눴고 1개는 건너뛰었습니다.

화면과 행사 모티프 검사는 합성 자료이며, 설치 본은 읽기 전용 추출만 확인했습니다.

자동 날씨 조회의 제한은 8초이며 첫 기온 요청이 시간 초과됐고 다음 한 회에서 1.157초에 수신했으나 원인은 확정하지 않았습니다.

별도 혼합 실행 경로는 5초 응답에 실패했고 회수 후 잔존 0이었습니다.

날씨 코드의 8,000ms 제한, 기온 첫 요청 시간 초과와 새 클라이언트 한 회의 1.157초 수신을 함께 보존합니다.

픽셀 처리는 96×96 GPU 타깃과 최근접 확대이며 메모리 절감이나 고정 240fps를 입증하지 않습니다.

기존 전체 상세 원문은 실제 차수 문서에서 그대로 유지해야 합니다. 이 초안은 그 원문의 완전한 수준별 대조를 아직 끝내지 않았습니다.

OS의 모든 정지를 기한 안에 해결한다는 보장은 아닙니다.
