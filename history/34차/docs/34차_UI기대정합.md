# 34차 화면 검사 기대와 원값 보존

백분율 기본 요약은 소수 첫째 자리 반올림입니다.

원래 잔량 43.25%는 43.3%로 표시하고 원 비율 0.4325와 전체 백분율은 툴팁에서 확인합니다.

화면 표시를 맞추려고 저장 값이나 막대의 정밀도를 바꾸지 않습니다.

검사에서는 원래 행 전체가 그대로인지, 막대 값 432500이 유지되는지, 지연·미확인 상태와 새로 고침 상태가 유지되는지 함께 확인합니다.

작은 위젯의 저장 크기는 사용자의 선호 값입니다.

저장 값 230×270을 디스크에 쓴 뒤 새 설정 객체와 창을 만들고, 디스크와 메모리의 선호 값이 그대로인지 확인합니다.

실제 창은 선택한 글꼴과 날짜·시각·지역·기온·잔량을 읽을 수 있도록 필요한 최소 높이까지 커질 수 있습니다.

기존 저장 값을 새 기본 크기로 덮지 않습니다.

기본 100% 배율의 글자 크기14/16px와 조형 영역 최소 96px를 그대로 검사합니다.

실제 그려진 배치에서 모든 정보 영역이 화면 안에 있고, 조형·날짜·지역·기온·잔량이 겹치지 않으며 부가 날씨 줄도 해당 영역 안에 있는지 확인합니다.

폰트를 줄이거나 가로 잘림을 허용해서 작은 크기를 유지하는 방식은 사용하지 않습니다.

기존 시험의 43.25% 표시와 실제 높이 270px 고정 기대는 이 요구와 충돌했습니다. 해당 기대만 위 조건으로 정합화했고, 원래 날씨 시작·종료·늦은 신호 차단·시계 초 갱신 단언은 유지했습니다. 미저장 배율은 제품과 동일하게 기본 100%로 읽으며 물리 설정키가 항상 존재한다고 가정하지 않습니다.

좁은 관련 4개 검사는 통과했습니다. 이 결과는 전체 회귀·배포 파일·실제 설치·원격 반영의 완료 증명이 아닙니다. 전체 검사에서 발견한 이전 실패 원문은 별도 비공개 이력에 보존합니다.
