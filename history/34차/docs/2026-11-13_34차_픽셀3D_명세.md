# 34차·픽셀 입체 조형

날짜별 과일·꽃·기념일과 발표된 도시 행사의 주제를 유지하면서 실제 입체 메시를 저해상도 GPU 타깃에서 렌더해 픽셀 표현으로 표시합니다.

큐브 메시를 쌓은 복 셀 형상으로 구현했다고 주장하지 않습니다.

대상은 세로 축을 중심으로 12초에 한 바퀴 회전하며 처음·옆·뒤가 구분되고 한 바퀴 뒤 같은 모습으로 돌아옵니다.

글자·기온·강수량·잔량과 일반 화면은 픽셀 처리하지 않습니다.

다음 차수의 검정·초록 디자인 예약은 이번 작업에 적용하지 않습니다.

기본 화면은 날짜별 달력이며 모델 변경 알림이 달력 주제를 바꾸지 않습니다.

자동·수동 위치 기능, 국가만 선택할 때 날씨 지역을 별도로 유지하는 동작과 개인정보 경계를 보존합니다.

기본 지역 줄은 지명만 표시합니다.

백분율 요약은 소수 첫째 자리까지 ROUND_HALF_UP 반올림하며 원값·비율·표시 방법은 툴팁에서 확인합니다.

반올림된 ‘약 100.0%’와 실제 100.0%를 구분하고 막대 폭과 저장 원값은 반올림하지 않습니다.

도시 자료는 [오프라인 복구 범위](34차_도시자료복구.md)를 따릅니다.

전체 목록 항목과 근거 있는 시리즈·개최분·미분류를 구분하며, 목록 항목 수를 발표 일정 수로 바꾸어 쓰지 않습니다.

공식 날짜 근거가 확인된 날만 행사 모티프로 연결합니다.

이번 자료에 Paris 원문 데이터베이스는 포함하지 않습니다.

전 세계 모든 행사나 미발표 미래 일정을 보장하지 않습니다.

33차는 작업 원문과 당시 검사·실패를 보존하지만 별도 배포·원격 반영·최종 교체를 완료한 차수로 표시하지 않습니다. 34차는 해당 기능을 이어받아 실제 검사·빌드·독립 검토와 원격 확인을 따로 수행합니다. 현재 개발 단계의 파일 저장을 이 전체 절차의 완료로 간주하지 않습니다.

검사 범위는 실제 GPU의 투명 경계·픽셀 블록·회전 전후와 루프, 행사 8 종 형상과 날짜 연결, 한 영·라이트/다크·100/150%의 네 화면 조합, 작은 위젯의 긴 지명·강수 집계 간격·100.0%/약 100.0% 가 독성, 알림 원문 접근과 자동·수동 선택입니다.

모션 정지·자원 종료와 기존 종료 단언을 유지합니다. 33차의 국소 GPU 종료 지연 실패는 격리한 검사 통과만으로 해결됐다고 쓰지 않고 최종 실제 검사 결과와 구분합니다.

실제 배포 검사와 독립 검증의 실행 수·시간·건너뜀·해시는 결과가 나온 뒤 해당 검증 문서에 기록합니다. 이 문서는 검사 성공을 미리 보증하는 영수증이 아닙니다.


## 좁은 위젯의 읽기 높이

백분율은 소수 첫째 자리 반올림 요약과 원값 툴팁을 구분합니다.

실제 100%와 반올림으로 100.0%가 되는 값은 약 100.0% 표시로 구별하며 막대는 원래 비율을 사용합니다. 180px 폭과 150% 글자 크기에서는 날짜와 시각을 나누고 기온·잔량을 실제 글자 폭으로 줄 바꿈합니다.

글꼴 크기를 줄이지 않고 필요한 최소 높이와 조형 영역을 확보하므로 작은 저장 크기보다 현재 실제 높이가 커질 수 있습니다.

저장된 사용자 크기를 초기화하지 않습니다.
