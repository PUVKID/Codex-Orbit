-## LEVEL 5·35차 색상과 조명 준비
-
-현재 35차는 **3.5.0 정식 배포본**으로 안내합니다. 아래 준비 해설의 기능을 새 차수에 반영했으며 실제 EXE·설치본 메타와 최소 실행 결과는 [최소 검사 상태](../35차_최소검사.md)에 기록합니다. 전체 회귀와 독립 검증을 새로 통과한 것으로 표시하지 않습니다.
-
-35차 준비 명세는 시스템·라이트·다크 모드와 기존 모드 보존, 여섯 프리셋, 포인트·다크/라이트 배경의 6 자리 HEX, 색 선택기 및 0~100 정적 발광을 정의합니다.
-
-미리 보기는 전역 모드를 변경하지 않으며 기본값 복원은 적용해야 저장됩니다.
-
-잘못된 값은 필드별 오류와 적용 차단, 저장 실패는 이전 설정·팔레트 복원과 창 유지가 요구됩니다.
-
-준비 코드에서 `appearance35.py`는 정규화·대비·팔레트를, `theme.py`는 팔레트 캐시와 조명 혼합을 담당합니다.
-
-입력 원색을 유지하면서 읽기용 의미색과 조명이 섞인 배경의 대비를 평가합니다.
-
-새 애니메이션 타이머·전체 블러는 추가하지 않습니다. `ui_appearance_smoke35.py`와 `test_appearance35.py`의 준비 검사는 실제 새 제품 및 독립 검증 결과와 구분해야 합니다.
-
-설정 재읽기와 전체 프로세스 재시작 검사는 동의어가 아닙니다.
-
-날짜별 과일·꽃·기념일·도시 행사와 자연 색·픽셀 3D 회전은 유지 대상입니다.
-
-자동 위치는 IP 기반의 대략적 추정이고 수동 위치는 선택한 지역을 사용하며, 정확한 실제 위치를 보장하지 않습니다.
-
-사용 한도는 남은 토큰 수가 아니며 실제 비율과 원값을 보존합니다.
-
-자원 설정은 초당 240장 달성을 보장하지 않습니다.
-
-**35차는 정식 배포하며, 최소 실행의 관측 범위와 자동 검사 미완료를 아래에 구분합니다.** 앞의 34차 측정은 34차의 결과입니다.
-
-<!-- 35차-실제검증-시작 -->
-**3.5.0 정식 배포본**입니다.
-
-실제 EXE의 합성 UI 검사에서 라이트·한국어 100%, 다크·영어 100%, 라이트·한국어 150% 세 조합을 완료했습니다.
-
-네 번째 다크·영어 150% 조합은 `AssertionError`로 완료하지 못했으며 정확한 원인은 미확정입니다.
-
-이 자동 검사 미완료가 실제 150% 제품 고장을 확정하지 않습니다.
-
-사용자는 150% 배율의 실 사용이 정상이라고 직접 확인했습니다.
-
-이는 자동 검사 전체 통과와 구분합니다.
-
-설정 검사는 다섯 항목 통과 뒤 첫 대화 상자 검사에서 180초 제한으로 중단됐습니다.
-
-같은 EXE의 기본 실행 한 번은 종료 코드 0으로 끝났고 시작 준비·프레임 변화·투명 위젯을 확인했습니다.
-
-전체 UI·회귀·실제 설치의 통과를 뜻하지 않습니다.

-## LEVEL 5·36차 설치 선택 항목
-

+### LEVEL 5 · 실행·소스와 권리

+이 항목의 계약과 재현 조건을 아래 사실 및 연결 원문에 대조합니다. 관측값·기본값·조건 분기를 구분합니다.
+
+Windows 10/11 x64와 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. 단일 EXE는 Python 설치 없이 실행하고 설치 본은 현재 사용자용 바로 가기·제 거를 제공합니다. GPU 준비/실패는 정적 표식 또는 오류 설명으로 구분합니다.
+
+공개 소스는 GitHub 자동 Source code ZIP 또는 이 저장소에서 받습니다.
+

+

+
