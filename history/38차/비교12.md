+## 실행·소스와 권리
+

+## LEVEL 4·34차까지의 자세한 사용과 검토

+### LEVEL 4 추가 해설 · 구성 경계와 상태 전이
+
+로컬 기록 감시기는 JSONL을 읽어 기준선과 신규 변경을 구분하며, 앱은 명시적으로 기록된 모델·추론 강도·이유를 화면에 전달합니다.
+
+계정 한도는 `UsageClient`가 Codex app-server를 별도 파이프로 열어 읽기 요청합니다. 30초 갱신·12초 응답 제한·65초 이후 오래된 값 표시, 최대 세 번 3/6/9초 재연결은 30차 소스 설명의 범위입니다.
+
+실패를 0%로 바꾸지 않습니다.
+
+날짜 및 관측소의 GPU 그림은 실제 기록 관측과 분리됩니다. 34차는 GPU 소유 프로세스와 일반 앱 진입을 분리하며 최대 5초 준비와 준비 후 기존 2초 표시 프레임 검사를 구별합니다. 종료는 정상 회 수 우선 후 필요할 때 소유 Job에 한정해 강제 회수합니다. OS 전체 정지 해결에 대한 절대 보장은 아닙니다.

+
+설정의 테마·배율·모션, 프라이버시 표시, 진단 파일의 제외 규칙, 공식 릴리스 SHA 검증과 실패 시 복구는 별개 경계입니다. 실제 과거 차수의 함수·설정·전체 비교는 해당 차수의 같은 수준 설명과 원문을 함께 확인합니다.

+## LEVEL 4 · 배포 사용법의 수준 안내 추가
+
+**가이드 추가 후 재빌드와 새 배포 검사를 확인했습니다.** 전체 653개 검사에서 실패 0·건너뜀 1, 빌드 입력 843 파일 불변을 확인했습니다.
+
+새 EXE의 한국어 가이드와 별도 한국어·영어 사용법에는 다섯 링크가 있으며, 영어 가이드까지 모두 EXE 안에 내장된 구조는 아닙니다.
+
+새 실행 본의 네 합성 화면 조합·정적 227 검사·설치 본 47 파일 추출 대조를 확인했지만 실제 설치와 새 EXE의 행사 8 종 순회는 이 결과에 포함하지 않습니다.

+## LEVEL 4·35차 색상과 조명 준비
+
+현재 35차는 **3.5.0 정식 배포본**으로 안내합니다. 아래 준비 해설의 기능을 새 차수에 반영했으며 실제 EXE·설치본 메타와 최소 실행 결과는 [최소 검사 상태](../35차_최소검사.md)에 기록합니다. 전체 회귀와 독립 검증을 새로 통과한 것으로 표시하지 않습니다.
+
+구현 준비본은 색상 정규화·대비 계산과 팔레트 산출을 `appearance35.py`, 테마와 캐시 및 조명 배경을 `theme.py`, 설정 연결과 표시를 앱·관측소에서 담당합니다.
+
+사용자 입력색과 읽기용 의미색을 구분하고, 텍스트 및 선택 상태뿐 아니라 정적 조명이 섞인 최종 배경의 대비도 고려합니다.
+
+팔레트 변경은 정보창 캐시를 갱신합니다.
+
+설정 창은 여섯 프리셋, 각 6 자리 HEX, 조명 0~100과 미리 보기를 다룹니다.
+
+취소는 저장하지 않으며 기본값 복원도 적용이 필요합니다.
+
+검증 오류는 적용을 막고 저장 예외는 이전 설정·화면을 복구한 채 창을 유지하도록 준비했습니다.
+
+새 타이머나 전체 화면 블러는 도입하지 않습니다.
+
+실제 제품 검증에서 작은 창, 언어·배율, 조작 상태와 저장 실패 경로를 확인해야 합니다.
+
+날짜별 과일·꽃·기념일·도시 행사와 자연 색·픽셀 3D 회전은 유지 대상입니다.
+
+자동 위치는 IP 기반의 대략적 추정이고 수동 위치는 선택한 지역을 사용하며, 정확한 실제 위치를 보장하지 않습니다.
+
+사용 한도는 남은 토큰 수가 아니며 실제 비율과 원값을 보존합니다.
+
+자원 설정은 초당 240장 달성을 보장하지 않습니다.
+
+**35차는 정식 배포하며, 최소 실행의 관측 범위와 자동 검사 미완료를 아래에 구분합니다.** 앞의 34차 측정은 34차의 결과입니다.
+
+<!-- 35차-실제검증-시작 -->
+**3.5.0 정식 배포본**입니다.
+
+실제 EXE의 합성 UI 검사에서 라이트·한국어 100%, 다크·영어 100%, 라이트·한국어 150% 세 조합을 완료했습니다.
+
+네 번째 다크·영어 150% 조합은 `AssertionError`로 완료하지 못했으며 정확한 원인은 미확정입니다.
+
+이 자동 검사 미완료가 실제 150% 제품 고장을 확정하지 않습니다.
+
