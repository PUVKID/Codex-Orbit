+## 38차 · 알림 읽는 방법
+
+**제목 → 바뀐 항목 → 이전·현재 값 → 이유** 순서로 읽으시면 됩니다. 초록색 강조는 바뀐 현재 값이며 이전 값도 같은 행에서 비교할 수 있습니다. **설명 더 보기**를 누르면 전체 공개 설명이 나오고, 카드를 누르면 변경 기록이 열립니다. 고정·보관·닫기와 프라이버시 모드는 그대로 사용합니다.
+
+## 37차 · 알림 센터
+
+처음 실행할 때 재질 준비가 오래 걸리면 위젯에 **3D 준비 중**이 표시됩니다. 창 표시 전 대기는 최대 5초이며 이후 앱 조작을 계속할 수 있습니다. 실제 초기화 오류는 **3D 표시 오류**로 구분합니다. 첫 준비와 일반 프레임의 제한 시간은 다르며, 준비 상태를 실제 움직이는 3D로 표시하지 않습니다.
+
+위젯을 눌러 창을 연 뒤 왼쪽 **알림 센터**를 선택합니다. **기록 탐색**에서 채팅 제목·모델·이유·작업을 검색하고, 종류·기간·순서와 채팅별 묶음을 고를 수 있습니다. 기록을 선택하면 이전과 현재 모델·추론 강도, 이유와 맡은 작업을 확인합니다. 기록 재표시는 새 모델 변경이 아닙니다.
+
+**알림 설정**에서 표시 시간·동시 표시 개수·작업 알림·알림음을 조절합니다. 집중 시간이나 채팅별 음소거를 켜도 기록 수집은 계속합니다. **알림 다시 받기**로 집중을 끝내고, **모든 음소거 해제**로 채팅별 음소거를 풉니다. 가상 알림 미리보기는 실제 변경 기록에 남지 않습니다.
+
+위쪽 상태띠에서 감시 상태와 최근 진행을 확인합니다. 멈춤이나 지연이 보이면 **감시 다시 연결**을 누릅니다. **프라이버시 모드**는 채팅 제목과 작업 설명을 화면·복사·내보내기에서 가립니다. 저장된 원문을 삭제하지 않습니다.
+
+지역은 도시와 시도·국가를 함께 확인합니다. 수원시는 **경기도 · 대한민국**입니다. 자동 위치는 연결망의 위치 자료를 사용하므로 실제 기기 위치와 다를 수 있습니다. 다른 도시로 잡히면 **지역 변경 → 수동**에서 시도·국가까지 맞는 도시를 골라 주세요. 이번 버전은 서로 다른 동명 도시나 번역 후보를 섞지 않도록 확인을 강화했습니다.

+## 35차 · 색상과 조명
+
+화면 위쪽 **화면 테마**에서 시스템·라이트·다크를 선택합니다. 옆의 **색상 꾸미기**를 누르면 여섯 가지 색 조합을 고르거나 포인트색·다크 배경·라이트 배경의 색상 코드를 직접 입력할 수 있습니다. 색 선택 버튼도 제공합니다.
+
+조명 강도는 0부터 100까지 조절하며 **0은 조명 끄기**입니다. 미리보기의 다크·라이트 선택은 미리보기만 바꿉니다. **적용**해야 저장되며 **취소**하면 기존 설정을 유지합니다. 기본값 복원도 적용 전에는 저장하지 않습니다. 잘못된 색상 코드에는 설명을 표시하고 적용을 막으며, 저장 실패 시 이전 설정과 화면을 복원합니다.
+
+입력한 원색은 보존하고 글자색은 읽기 좋게 보정합니다. 날짜별 과일·꽃·기념일·도시 행사와 픽셀 입체 회전은 유지합니다. 잔량 막대의 실제 비율·원값, 자동·수동 위치, 모델·추론·작업 재개 알림도 그대로 사용합니다. 조명은 화면 전체 흐림이나 별도 애니메이션 타이머를 추가하지 않습니다.

+## 지역·날씨와 도시 행사
+
+위치는 자동 네트워크 추정이 기본입니다. 지역 선택 창에서 자동·수동을 명확히 고릅니다. 수동 검색이나 취소만으로 저장하지 않으며, 자동 모드로 돌아가면 이전 수동 위치를 해제하고 다시 조회합니다. 국가만 고르면 행사 기준만 바뀌고 날씨 지역은 유지됩니다. 네트워크 추정은 GPS나 건물 주소가 아닙니다.
+
+습도 옆에는 강수량(mm)과 제공 자료의 실제 직전 집계 간격을 표시합니다. 실제 0과 미확인(—)을 구분하고, 오래된 값은 이전 정보로 표시합니다. 일출·일몰은 제공 지역의 시간대를 유지합니다.
+
+화면 위의 선택 영역에서 언어·화면 테마(시스템/라이트/다크)·글자 크기를 바꿀 수 있습니다. 테마는 즉시 적용되고 저장되며, 시스템은 운영체제의 테마 변화를 따릅니다. 왼쪽 작업 현황에서 기록된 작업과 선택 설정·최근 실행에서 확인한 값을 구분해 봅니다. 화면 설정에는 움직임 줄이기·화면 가장자리에 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인이 있습니다. 프라이버시 모드는 화면에서 채팅 제목과 작업 설명을 가리며 저장된 기록은 그대로 유지합니다. 기존 월별 주제와 날짜별 대상은 유지하고, 날짜 위젯의 고리와 좌우 보조 장식은 제거했습니다. 당일 대상 하나를 입체로 표시합니다.
+
+투명한 바탕화면에서 당일의 3D 대상 하나가 움직이며, 로컬 Codex의 모델·추론 강도 변경과 작업 배정·재개를 알려 줍니다. 개인 기록은 이 컴퓨터에 저장합니다.
+
+## 시작
+
+1. 단일 `CodexOrbit.exe`를 실행하거나 `CodexOrbit-Setup.exe`로 현재 사용자에게 설치합니다. 둘을 동시에 같은 데이터 폴더에서 실행하지 않습니다.
+2. 위젯을 클릭하면 기록과 실제 계정 사용 한도가 열립니다. 드래그로 이동하고 오른쪽·아래 가장자리로 크기를 조절합니다.
+3. 첫 감시는 이전 기록을 기준선으로 읽습니다. 이후 새 변경을 알립니다. 선택 설정과 실행 관측은 서로 구분합니다.
+
+## 알림 읽기
+
+채팅 제목에는 장식 이모지를 붙이지 않습니다. 표시만 정리하며 Codex의 원래 제목을 바꾸지 않습니다.
+
+- 채팅 제목
+- ⬅️ 이전 모델 / 이전 추론 강도
+- ➡️ 현재 모델 / 현재 추론 강도
+- 💡 쉬운 이유
+
+☀️ Sol · ✨ Astra · 🌍 Terra · 🌙 Luna를 정확한 모델 ID와 함께 표시합니다. 추론 강도는 ⚪ 없음 · 💧 최소 · 🌱 낮음 · ⚖️ 보통 · 🔥 높음 · 🚀 매우 높음 · ⚡ 최고로 구분합니다. 기록되지 않은 이전 값이나 이유는 만들어 쓰지 않습니다. 공개된 배정 설명은 설명으로 표시하며 비공개 사고 과정을 보여 준다고 주장하지 않습니다.
+
+새 변경은 독립 알림으로 바로 표시합니다. 마우스를 올리면 자동 닫힘이 멈추고, 📌 고정하면 계속 남습니다. ☆ 기록 보관으로 북마크할 수 있습니다. 닫아도 이력은 남습니다. 화면에 표시할 수 있는 새 알림 상한을 넘긴 이력은 기록에서 확인합니다.

+## 입체 관측소
+
+- Sol은 태양, Astra는 결정, Terra는 구체, Luna는 초승달 코어입니다. 모델이 미확인이면 중립 코어를 사용합니다.
+- 실제 로컬 기록에서 확인한 작업자는 위성으로 표시합니다. 위성이나 작업 목록을 누르면 해당 채팅 기록을 엽니다. ★ 관심 채팅은 우선 궤도에 표시합니다. 위성은 최대 24개이며 나머지도 목록에서 확인합니다.
+- 진행·완료·응답 대기·오류·중단은 명시된 기록이 있을 때만 표시합니다. 확인되지 않은 작업을 진행 중이나 완료로 추정하지 않습니다.
+- 이전/현재 값은 같은 비중으로 표시하고 실제 바뀐 값만 강조합니다. 선택한 설정과 실행 중 관측한 설정은 구분합니다.
+- 슬라이더는 저장된 기록을 재생합니다. 실제 Codex 모델이나 추론 강도를 되돌리는 기능이 아닙니다.
+- 자리비움 이후 기록 수와 보관한 기록을 확인할 수 있습니다. 채팅 직접 이동은 지원이 확인되지 않아 ID 복사를 제공합니다.
