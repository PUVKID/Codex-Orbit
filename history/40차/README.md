# 40차 · 이모지와 알림 가독성

**3.10.0**은 종류별 이모지와 모델·추론 강도의 이모지를 다시 표시합니다. 이전·현재 값을 나란히 비교하고, 변경 이유를 별도 영역에서 읽습니다.

[전체 비교](직전차수.diff) · [웹 비교](비교.md) · [사용 방법](../../docs/40차_이모지와알림.md)

## LEVEL 1 - Beginner

### 기능과 표시

| 항목 | 동작·의미 |
| --- | --- |
| 읽는 순서 | 채팅 제목을 보고 이전·현재 모델과 추론 강도를 같은 줄에서 비교합니다. |
| 이모지 | 🔄는 실행 기록의 변경, ⚙️는 선택 설정, 📋는 작업 배정, ▶️는 작업 재개입니다. |
| 이유 | 별도 상자에서 짧은 설명을 읽습니다. 설명 더 보기로 전체 공개 원문을 엽니다. |
| 버튼 | 기록 열기로 해당 기록을 열며 고정·보관·닫기도 계속 사용할 수 있습니다. |

### 설정과 보존

| 조건 | 처리 |
| --- | --- |
| 이전 기록 없음 | 이전 값을 추측하지 않고 기록 부재를 표시합니다. |
| 테마·언어 | 한영·라이트/다크·사용자 색상·글자 배율을 유지합니다. |
| 공개 이유 | 기록된 설명만 표시하며 비공개 추론이나 원인을 만들지 않습니다. |
| 기존 기능 | 날짜별 과일·꽃 픽셀 모션, 감시·날씨·한도 기능은 유지합니다. |

### 확인과 한계

| 근거 | 범위·주의 |
| --- | --- |
| 화면 | 실제 Qt 알림을 합성 이벤트로 촬영해 전후 값과 이유 영역을 확인합니다. |
| 독립 확인 | 앱에 사용된 이모지와 작은 화면·명시적 버튼 동작을 별도로 확인합니다. |
| 기존 근거 | 변경하지 않은 기능은 기존 유효한 검사 결과를 재사용합니다. |
| 지원 한계 | 운영체제에 없는 미래 이모지나 모든 환경의 무결함을 보장하지 않습니다. |
| 모델 정보 | 로컬 관측이며 서버 모델 신원·비공개 추론의 증명이 아닙니다. |
