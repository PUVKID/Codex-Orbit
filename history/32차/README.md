## LEVEL 1 - Beginner

### LEVEL 1 · 처음 읽는 분을 위한 동작과 결과

날짜 위젯은 고리와 좌우 장식 없이 그날의 대상 하나를 보여 줍니다. 기존 888개 월별 주제와 일반일 대상을 유지하고 250개 국가·지역의 공휴일·지원 기념일에 행사명과 특별 모형을 표시합니다. 모형은 규칙으로 생성하므로 날짜마다 별도 수작업 파일이 있는 것은 아닙니다. 지역 표시를 눌러 도시·주소·장소·국가를 검색하면 선택 지점 날씨를 읽습니다. IP 자동 위치는 추정이며 미래 법 개정이나 모든 도시 축제의 확정 목록도 아닙니다.

날짜 위젯은 고리와 좌우 장식 없이 당일 대상 하나를 표시합니다. 기존 888개 월별 주제와 일반일 대상을 보존하고, 250개 국가·지역의 공휴일·지원 기념일에는 실제 행사명과 특집 조형을 적용합니다. 미래 법 개정과 모든 도시 축제까지 확정한 자료는 아닙니다.

지역 표시를 눌러 도시·주소·장소·국가를 직접 검색합니다. 선택 지점의 기온·날씨·습도·일출·일몰을 받아오며, 자동 IP 위치는 추정임을 표시합니다.

알림은 이전·현재 모델과 추론 강도를 나란히 비교하고 짧은 설명과 접을 수 있는 원문으로 정리했습니다. 화면은 흰색·슬레이트 블루와 다크 테마를 제공합니다.


이 폴더에는 직전 차수와 달라진 코드를 보존합니다. [새 자산 원문 목록](자산_원문목록.json)은 파일 크기·SHA-256과 불변 v3.2.0 자료를 연결합니다. 동일한 큰 자료를 두 번 쌓지 않으며 변하지 않은 자료와 전체 소스도 해당 태그에서 확인할 수 있습니다. 날짜별 조형은 절차적으로 생성하며 모든 날짜에 별도 수작업 모델 파일이 있다는 뜻이 아닙니다.

## LEVEL 2 - Explorer

### LEVEL 2 · 구성과 조건의 관계

날짜별 대상 선택과 지역별 행사 규칙, 위치 검색과 날씨 조회, 기록 변화 알림을 별도 흐름으로 읽습니다. 888개 월별 주제·250개 국가/지역의 지원 범위와 자동 IP 위치의 추정 수준을 구분합니다. 날씨는 선택 지점의 기온·습도·일출·일몰에 연결되고 알림은 이전/현재 모델·추론 강도를 비교합니다. 바뀐 코드와 자산 크기/SHA는 이 폴더와 불변 v3.2.0 태그로 연결됩니다.

## LEVEL 3 - Practitioner

### LEVEL 3 · 사용·실험 조건을 대조하는 순서
