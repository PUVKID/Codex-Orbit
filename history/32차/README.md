날짜 위젯은 고리와 좌우 장식 없이 그 날의 대상 하나를 보여 줍니다.

기존 888개 월별 주제와 일반 일 대상을 유지하고 250개 국가·지역의 공휴일·지원 기념일에 행사 명과 특별 모형을 표시합니다.
