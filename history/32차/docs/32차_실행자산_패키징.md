# 실행 자산 패키징

실행 파일에는 기존 달력·날씨·글꼴·라이선스 자산을 유지하며, 내부 생성 기록인 `assets/atom3d/creation_report.json`과 `assets/icons3d/direct_validation.json`만 포함하지 않습니다. 두 원본은 차수 자료에 보존합니다. 같은 이름의 다른 파일은 제외하지 않습니다.

기존 `elements3d` 실행본 제외 정책과 비공개 소스·재빌드 ZIP의 원본 보존 정책은 유지합니다. 통제된 임시 자산 검사로 정확한 제외 경로, 필수 자산과 라이선스의 바이트 보존, 원본 불변을 확인하고, 재빌드 실행 파일의 실제 내장 목록에서도 두 기록의 부재를 확인합니다.
