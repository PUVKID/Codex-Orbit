# 32차 알림과 화면 표시 변경 근거

사용자 요청에 따라 알림을 제목, 변경 종류, 이전·현재 모델과 추론 강도, 짧은 설명으로 정리합니다. 원본 이벤트와 정확한 모델 ID·추론 값은 변경하지 않습니다.

- 이전에는 값마다 ‘이전 모델’, ‘현재 모델’, ‘이전 추론 강도’, ‘현재 추론 강도’를 반복했습니다. 이제 두 열의 이전·현재 머리글과 네 값으로 비교하고, 각 값의 접근성 이름에는 네 필드 이름을 유지합니다.
- 채팅 제목 앞의 자동 이모지는 제거합니다. 원래 제목과 상세 원문은 보존합니다. 모델 계열·추론 단계의 값 아이콘은 유지합니다.
- 긴 공개 설명은 명시 목적이나 확인된 문제를 먼저 보여 줍니다. 검사 개수·게시 계획 등 보조 내용은 원문에서 읽을 수 있습니다. 제공되지 않은 모델 선택 동기를 만들지 않습니다. 선택 이유와 단순 작업 설명을 구분합니다.
- 명시적인 미기록 표식은 기존처럼 이유 미기록으로 안내합니다. 보호된 내용은 요약·툴팁·원문 펼치기에서 노출하지 않습니다. 긴 정상 설명을 미기록이라고 바꾸지 않습니다.
- 알림 안에서 전체 설명을 펼치거나 접을 수 있습니다. 고정·보관은 같은 행에 배치하며 타이머·알림 순서·기록 원문은 유지합니다.
- 기존 XML 이스케이프·UTF-16 길이·서로게이트 검사와 네 원문 값·이전 기록 없음의 구분은 유지합니다. 옛 이모지 접두사나 반복 라벨만 강제하던 UI 기대를 새 요청에 맞춰 갱신합니다.
- 콤보는 목록형 팝업을 사용합니다. 단일 항목에는 불필요한 메뉴 스크롤 장식을 표시하지 않고, 실제 항목이 많을 때 목록 스크롤을 유지합니다.
- 화면은 흰색·슬레이트 블루 라이트와 회청색 다크를 사용합니다. 날짜별 조형의 색·재질은 화면 팔레트 변환 대상이 아닙니다.
- 날씨의 직접 도시 지정과 네트워크 추정은 구분합니다. 검색 버튼을 누를 때만 도시 검색을 요청하며 선택된 검증 좌표로 기온을 조회합니다. 개인 검색·좌표는 공개 운영 기록에 넣지 않습니다.

- 지역 선택 창에서 도시·지역, 주소·장소, 국가를 검색합니다. 도시·장소 선택은 해당 좌표의 날씨와 행사 국가를 함께 저장합니다. 국가만 선택하면 기존 날씨 지역은 유지하며 두 기준을 따로 표시합니다. 장소 검색 출처는 Photon / OpenStreetMap이며 자동 검색은 하지 않습니다.
- 행사 기준이 자동일 때만 검증된 네트워크 국가 추정을 반영합니다. 직접 고른 행사 국가를 뒤늦은 자동 응답으로 바꾸지 않습니다. 국가 단위 행사 자료의 미지원 항목과 규칙 변경 가능성을 안내합니다.
- 공통 렌더의 국가·날짜와 위젯의 제목·시각을 맞춥니다. 날씨 지역과 행사 국가가 일치하고 지역 시차가 검증된 경우 현지 날짜를 사용하며, 그 밖에는 기본 한국 시각임을 안내합니다.
- 기온 옆에 날씨 상태를 표시하고 습도·일출·일몰은 별도 행으로 읽을 수 있게 합니다. 없는 값은 0으로 만들지 않고 ‘—’로 표시합니다. 일출·일몰은 제공 지역의 시차를 사용합니다. 기존 저장 크기는 초기화하지 않으며 아주 낮은 창은 읽을 수 있는 최소 높이를 확보합니다.

이 문서는 표시 요구의 변경 근거입니다. 실제 검사·화면 확인·독립 검토·배포 결과는 각 최종 검증 기록에 따로 기록합니다.

## 합성 화면 검사와 표시 준비

- 장소 검색 창에는 고정된 OpenStreetMap 저작권 링크와 기여자 표시를 제공합니다.
- 알림은 저장된 글자 크기를 적용하며 100→150→100%에서 기준 글꼴을 중첩하지 않습니다.
- `--ui-smoke-test --data-dir <새 폴더>`는 새 격리 폴더에 합성 자료만 만들고 감시·계정 조회·날씨 네트워크를 시작하지 않습니다. 기존 폴더와 다른 실행 옵션은 거부합니다. 일반 실행과 구분하여 PNG와 결과 JSON을 남깁니다.
- Windows 콤보는 펼침 애니메이션이 끝나기 전에 즉시 검사하면 숨김으로 관측될 수 있습니다. 실제 표시 상태를 최대 750ms 기다린 뒤 기존 활성·항목 포함·스크롤러·키보드 닫힘 단언을 검사합니다. 운영체제의 애니메이션 설정은 바꾸지 않습니다.
- 날씨 상태가 없는 예시는 맑음으로 만들지 않고 ‘날씨 미확인’으로 표시합니다. 기본 위젯 높이는 추가 날씨 정보에 맞춰 432px이며 저장된 크기는 유지합니다.
- 현재 검사는 소스 모드의 합성 자료로 수행했습니다. 실제 배포 실행 파일 검사와 독립 검토는 별도입니다. 그래픽의 사실감 완성 여부를 UI 조작 통과로 대신하지 않습니다.

수리25에서는 기존 한영 전환 시험의 표시 기대 두 곳을 새 계약에 맞춥니다. 알림 값에 반복하던 필드 라벨은 접근성 이름으로 정확히 검사하고, 값의 원문 모델 ID도 함께 확인합니다. 오래된 기온과 날씨 상태 미확인은 전체 표시 문자열로 검사합니다. 제목·작업·이유·추론 값·알림 시간·이벤트 및 백엔드 원문·출처·원지명·상태 중복 방지의 기존 단언은 유지합니다.

수리27·30은 기존 검사에서 반복 라벨·장식·기본 높이를 고정하던 기대를 새 표시 계약으로 정정합니다. 알림 네 필드의 접근성 이름, 실제 전후 원문 값, 한영, 모두 가시성, 원문 끝 접근, 타이머, 독립 크기 조절과 저장 단언은 유지합니다. 상세창의 글자 최소 기준은 그대로 두고 압축된 알림의 모델·추론 값은 16px 기준을 검사합니다.
수리28은 실제 닫기 버튼이 폴리시 뒤 20px로 낮아지던 결함을 수정합니다. 닫기 전용 내용 높이와 테두리를 명시하여 100%에서 30px, 150%에서 45px 클릭 영역과 글꼴 내용 영역을 보존합니다.
