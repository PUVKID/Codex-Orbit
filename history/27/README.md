# 27차 · GitHub 전달 문서 정리

26차 앱 2.10.0을 그대로 보존하고, 저장소 방문자가 앱의 목적·실행 방법·검증 결과·차수별 차이를 찾도록 공개 문서를 정리합니다. 별도 앱 `src/` 스냅샷과 새 실행 파일은 만들지 않습니다.

[26차 설명](../26/README.md) · [27차 실제 변경 기록](../../변경기록_27차.md) · [전체 차수](../../README.md) · [재검증 범위](../../docs/GitHub재검증_27차.md)

- README 상단에 앱 설명과 한영 안내·사용법·라이선스·검증·변경 기록 링크를 배치했습니다. 기존 모든 차수 행과 전체 diff·파일 명세 링크는 보존합니다.
- 26차의 속도 조절·설정 복원·모션 위상 보존을 사용자 관점에서 설명하고 공개 검증 요약을 연결했습니다.
- 공개 87개 검사와 개발 전체 365개 구성, 소스 정확성 127개 검사를 구분하고 출력이 일부만 보존된 한계를 명시했습니다.
- 앱 기능·설정·화면·자산·의존성·기존 바이너리는 이번 차수에서 변경하지 않습니다. 코드 주석·공백도 수정 대상이 아닙니다.

직전 기준은 26차 공개본 커밋 `7e2821ad78c85f46a131fda6f32bf82a1beee950`입니다. 27차 공개 묶음의 공백·개행까지 포함한 [전체 변경 diff](../../docs/27차_전체변경.diff)를 제공합니다. 기준 커밋과 v2.10.0의 원격 전체 차이는 [GitHub 비교](https://github.com/PUVKID/Codex-Orbit/compare/7e2821ad78c85f46a131fda6f32bf82a1beee950...v2.10.0)로 연결하며 실제 게시 여부는 별도 확인합니다. 기존 [26차 전체 소스 diff](../26/직전차수.diff)와 [파일 명세](../26/공개파일_비교.json)는 25→26 비교이고 26→27 문서 비교와는 다릅니다.

기존 2.10.0 배포본은 [Release](https://github.com/PUVKID/Codex-Orbit/releases/tag/v2.10.0)로 연결하며 게시·해시의 원격 일치는 별도로 확인합니다. 원격 저장소·Release의 게시 여부와 로컬 검증을 구분하며 로컬 저장만으로 GitHub 반영 완료를 의미하지 않습니다. 이 차수는 소프트웨어 공개 문서 작업으로 논문·원고 PDF를 새로 만들지 않습니다.
