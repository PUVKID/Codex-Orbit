# 37차 · 50개 개선 항목

선택 근거는 기록 탐색, 업데이트 신뢰성, 감시 상태 확인과 알림 제어를 쉽게 하기 위함입니다. **구현·연결했으며 관련 합성 검사 21개가 통과했습니다.** 알림 센터의 검색·빈 결과·초기화·프라이버시 복사·이력 없는 미리보기와 라이트·다크 화면을 격리한 Qt 화면에서 확인했습니다. 처음 통합 검사에서는 업데이트 창 닫기 오류와 별개의 기존 3D 초기 응답 시간 초과로 실패했습니다. 닫기 오류 수정 후 닫기·취소·처리 중 닫기 차단만 별도로 통과했으며, 전체 회귀나 전체 3D 실행을 통과했다고 뜻하지 않습니다. 기존 기능의 유지·보완을 포함하며, 메인 화면과 백엔드가 공유하는 기능은 한 번만 셉니다.

| 번호 | 영역 | 기능 | 실제 구현·유용한 점·한계 |
|---:|---|---|---|
| 1 | 알림 센터 | **검색** | `filter_events`: 제목·이유·작업과 전후 모델·강도를 대소문자 구분 없이 검색해 탐색을 돕습니다. 본문 전체 검색은 아닙니다. |
| 2 | 알림 센터 | **검색 초기화** | `WorkspacePanel._reset`: 검색어·종류·기간·순서·보관·관심 필터를 초기화해 다시 탐색합니다. 묶음 선택은 유지합니다. |
| 3 | 알림 센터 | **모델 필터** | `filter_events`와 `changed_fields`: 모델이 바뀐 기록만 모아 변경 이력을 찾습니다. 특정 모델명 선택 필터는 아닙니다. |
| 4 | 알림 센터 | **추론 필터** | `filter_events`와 `changed_fields`: 추론 강도가 바뀐 기록만 모읍니다. 특정 강도값 선택 필터는 아닙니다. |
| 5 | 알림 센터 | **작업 재개 필터** | `filter_events`: 활동 유형이 `resumed`인 기록을 골라 재개 이력을 찾습니다. 다른 활동은 제외합니다. |
| 6 | 알림 센터 | **오늘** | `event_time`과 `filter_events`: 현지 날짜가 오늘인 기록을 고릅니다. 시각 미확인 기록은 제외합니다. |
| 7 | 알림 센터 | **최근 7일** | `filter_events`: 현재부터 이전 7일의 기록을 골라 최근 흐름을 살핍니다. 미래와 시각 미확인은 제외합니다. |
| 8 | 알림 센터 | **보관 필터** | `filter_events`: 기존 보관 기록 ID와 대조해 저장한 기록만 보여 줍니다. 보관 목록 자체를 바꾸지 않습니다. |
| 9 | 알림 센터 | **관심 채팅 필터** | `filter_events`: 기존 관심 채팅 대상과 비교해 관련 기록을 좁힙니다. 대상이 일치해야 합니다. |
| 10 | 알림 센터 | **최신/오래된 순** | `filter_events`: 원본 시각을 기준으로 최신순 또는 오래된순 정렬합니다. 시각 미확인은 별도 기준으로 배치합니다. |
| 11 | 알림 센터 | **채팅 묶음** | `group_events`: 대상별로 기록과 건수를 묶어 연속 변경을 살핍니다. 전후 값을 합성하지 않습니다. |
| 12 | 알림 센터 | **검색 건수** | `WorkspacePanel.refresh`: 표시된 결과 수를 알려 조건의 효과를 확인합니다. 결과는 최대 500건입니다. |
| 13 | 알림 센터 | **빈 결과** | `WorkspacePanel.refresh`: 결과가 없으면 필터 변경을 안내합니다. 빈 결과를 오류로 단정하지 않습니다. |
| 14 | 알림 센터 | **선택 전체 요약** | `summary_text`: 선택한 한 기록의 시각·종류·전후값·이유·작업을 보여 줍니다. 미확인 값은 확인 불가로 표시합니다. |
| 15 | 알림 센터 | **요약 복사** | `WorkspacePanel._copy`: 선택한 기록 요약을 클립보드에 복사합니다. 선택이 없으면 실행하지 않습니다. |
| 16 | 알림 센터 | **재표시** | `WorkspacePanel._event_action`: 선택 ID를 `replay_event`에 전달해 알림을 다시 봅니다. 실제 새 관측을 뜻하지 않습니다. |
| 17 | 알림 센터 | **원 상세 열기** | `WorkspacePanel._event_action`: 선택 ID로 기존 상세를 열어 원문 맥락을 살핍니다. 선택된 기록이 필요합니다. |
| 18 | 알림 센터 | **CSV 내보내기와 수식 방어** | `csv_text`: 현재 필터 결과를 저장하며 수식 시작 문자·앞 공백·탭·줄바꿈을 방어합니다. 허용된 필드만 내보냅니다. |
| 19 | 알림 센터 | **JSON 내보내기** | `export_rows`와 `_export`: 현재 필터 결과를 JSON으로 저장해 재활용합니다. 대화 본문·위치·경로·식별자는 제외합니다. |
| 20 | 알림 센터 | **프라이버시 복사·내보내기 가림** | `export_rows`와 `summary_text`: 프라이버시 모드에서 제목·이유·작업을 가려 복사와 저장에 적용합니다. 저장된 원본은 바꾸지 않습니다. |
| 21 | 업데이트 | **정확 버전 표시** | `UpdateDialog`의 `VERSION`: 현재 3.7.0과 확인된 새 버전을 표시해 대상을 구분합니다. 공개 최신 여부는 확인 요청 후 판단합니다. |
| 22 | 업데이트 | **공식 페이지** | `UpdateDialog.open_release`: 고정된 공식 릴리스 주소를 엽니다. 오류 원문에 담긴 임의 주소는 열지 않습니다. |
| 23 | 업데이트 | **예상 MB** | `UpdateDialog.retranslate`: 릴리스 크기를 MB로 표시해 다운로드 규모를 가늠합니다. 1 MB는 1,048,576바이트로 안내합니다. |
| 24 | 업데이트 | **디스크 여유 사전 검사** | `SafeUpdater.stage` 연결: 다운로드 전 준비 경로의 여유 공간을 확인합니다. 실제 공간 부족이면 진행할 수 없습니다. |
| 25 | 업데이트 | **검증 SHA 복사** | `UpdateDialog.copy_sha`: 검증된 파일의 SHA-256을 복사해 대조를 돕습니다. 검증 준비 전에는 표시하지 않습니다. |
| 26 | 업데이트 | **설정 유지 안내** | `UpdateDialog.retranslate`: 설치 전 개인 설정과 MD 유지 및 실행 파일 백업을 안내합니다. 적용 결과가 곧 보존 성공의 증거는 아닙니다. |
| 27 | 업데이트 | **단계 구분** | `UpdateBridge.phase`와 `UpdateDialog`: 확인·다운로드·검증·설치 준비를 구분합니다. 작업 중 대화상자를 닫을 수 없습니다. |
| 28 | 업데이트 | **쉬운 오류와 원문** | `UpdateDialog.done`: 쉬운 실패 안내와 펼칠 수 있는 오류 원문을 함께 제공해 원인 파악을 돕습니다. 오류를 성공으로 바꾸지 않습니다. |
| 29 | 업데이트 | **최근 결과 기록** | `read_update_result`: 최근 업데이트·복구·실패 결과와 시각을 표시합니다. 저장된 결과가 없으면 보이지 않습니다. |
| 30 | 업데이트 | **결과 보기와 설정 보존** | `UpdateDialog`: 최근 결과를 다시 보여 주고 기존 설정·MD 보존을 안내합니다. 실패 시 이전 실행 파일 복구와 시작을 시도합니다. |
| 31 | 메인·알림 | **상태 띠** | `health_snapshot`과 `refresh_workspace`: 창 상태 띠와 툴팁, 위젯 9px 상태 점으로 감시 상태를 보여 줍니다. 색만으로 판단하지 않습니다. |
| 32 | 메인·알림 | **마지막 진행 시간** | `health_snapshot`: 마지막 진행 이후 경과 초를 상태 띠에 표시해 멈춤 확인을 돕습니다. 실제 진행 신호를 기준으로 합니다. |
| 33 | 메인·알림 | **복구 횟수** | `health_snapshot`: 감시 복구 횟수를 상태 띠에 표시합니다. 횟수만으로 복구 성공을 뜻하지 않습니다. |
| 34 | 메인·알림 | **지연 구분** | `health_snapshot`: 진행 신호가 20초를 넘으면 지연으로 구분합니다. 지연이 곧 종료를 뜻하지 않습니다. |
| 35 | 메인·알림 | **수동 재연결** | `install_workspace`: 다시 연결 버튼을 `retry_monitor37`에 연결합니다. 재연결 대기 중에는 버튼이 비활성화됩니다. |
| 36 | 메인·알림 | **감시 대상 경로 프라이버시 보호** | `refresh_workspace`: 프라이버시 모드에서는 툴팁의 감시 경로를 가립니다. 원래 설정 경로는 유지합니다. |
| 37 | 메인·알림 | **관측 채팅 수** | `health_snapshot`: `status.chats`의 확인된 값을 상태 띠 툴팁에 표시합니다. `len(watcher.state.models)`이며 관측 파일 수와 구분하고 없으면 —입니다. |
| 38 | 메인·알림 | **잔량 갱신 시간** | `freshness`: 잔량의 최종 조회 시각을 상태 띠 툴팁에서 확인합니다. 미확인·이전 정보도 구분합니다. |
| 39 | 메인·알림 | **날씨 갱신 시간** | `freshness`: 날씨의 최종 조회 시각을 같은 툴팁에서 확인합니다. 값이 없거나 유효하지 않으면 미확인입니다. |
| 40 | 메인·알림 | **실제 기록이 남지 않는 미리보기** | `WorkspacePanel`의 `preview_notice37`: 모델·추론·작업 알림을 미리 봅니다. 실제 관측 기록을 만들지 않는 용도입니다. |
| 41 | 메인·알림 | **집중 15/30/60분** | `NotificationPolicy.focus`: 15·30·60분 동안 알림 표시를 억제해 집중을 돕습니다. 원래 기록 수집은 계속합니다. |
| 42 | 메인·알림 | **즉시 재개** | `NotificationPolicy.resume`: 집중 종료 시각을 초기화해 즉시 알림을 다시 받습니다. 개별 채팅 음소거는 별도입니다. |
| 43 | 메인·알림 | **선택 채팅 30분 음소거** | `NotificationPolicy.mute_target`: 선택 채팅을 30분 음소거합니다. 유효한 대상이 필요하며 최대 64개입니다. |
| 44 | 메인·알림 | **음소거 초기화** | `NotificationPolicy.clear_mutes`: 모든 채팅 음소거를 해제합니다. 집중 모드는 별도로 유지됩니다. |
| 45 | 메인·알림 | **작업 재개 알림 켜기/끄기** | `NotificationPolicy.allows`: 작업 알림 표시 설정을 적용합니다. 활동 기록 자체는 계속 수집합니다. |
| 46 | 메인·알림 | **알림 시간 5~120초** | `NotificationPolicy._validated`: 표시 시간을 5~120초 정수로 제한합니다. 저장 실패 시 이전 설정을 복원합니다. |
| 47 | 메인·알림 | **동시 알림 1~8개** | `NotificationPolicy._validated`: 동시 표시 수를 1~8개로 제한합니다. 설정은 기존 알림 표시와 연결됩니다. |
| 48 | 메인·알림 | **재개 카드 간결 모드** | `NotificationPolicy.set_options`: 작업 알림의 간결 표시를 선택합니다. 작업 원문 기록을 삭제하지 않습니다. |
| 49 | 메인·알림 | **선택 알림음** | `NotificationPolicy.set_options`: 기존 알림음 켜기·끄기를 연결합니다. 별도의 음원 선택 목록은 확인되지 않았습니다. |
| 50 | 메인·알림 | **고정 제외 알림 모두 닫기** | `dismiss_unpinned37`: 고정하지 않은 알림을 닫아 화면을 정리합니다. 고정된 알림은 남깁니다. |

자동 복구와 업데이트 복구는 기존 기능을 유지·보완하며 새로 발명한 기능으로 세지 않습니다. 조형과 정보의 분리는 기존 동작을 유지합니다. 시간·크기·한도는 실제 확인된 값만 표시하며 IP 기반 위치는 GPS나 확정 주소가 아닙니다.

순수 기능 검사 7개와 6개, 변경된 사례 1개 재검사 및 메인 관련 4개는 부모가 통과 결과를 확인했습니다. GUI 연결과 시스템·라이트·다크의 모든 팝업 화면 확인은 대기 중이며 전체 테스트 통과를 뜻하지 않습니다.
