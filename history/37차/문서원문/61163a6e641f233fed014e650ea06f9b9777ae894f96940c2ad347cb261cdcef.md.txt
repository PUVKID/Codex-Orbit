# 37차 지역 표시 정합성 수정

**자동 위치의 도시·시도·국가가 다른 검색 후보와 섞이지 않도록 확인 절차를 강화했습니다.**
사용자 위치를 수원으로 강제 지정하거나 저장된 위치 설정을 바꾸지 않습니다.

| 확인한 항목 | 관측 근거 | 구분과 조치 |
| --- | --- | --- |
| 수원시의 소속 | 공개 Open-Meteo 검색에서 도시 ID `1835553`, 행정구역 ID `1841610`, 국가 `KR`의 같은 행은 한국어로 `수원시 · 경기도 · 대한민국`, 영어로 `Suwon · Gyeonggi-do · South Korea`입니다. | 한국어·영어 응답의 도시 ID와 행정구역 ID가 일치합니다. |
| 다른 지역의 동명 지명 | 같은 공개 검색에 `수원` ID `11906993`은 `전라북도`, `수원` ID `12010348`은 `충청남도`로 반환됐습니다. | 서로 다른 지명입니다. 이름만으로 경기도 수원시와 합치거나 목록에서 임의로 숨기지 않습니다. 제공자의 행정구역 원문을 유지합니다. |
| 기존 자동 위치 후보 선택 | 같은 국가이면서 IP 응답 좌표에서 30km 이내이면 가장 가까운 후보를 선택했습니다. | 확인된 IP 시도와 다른 후보도 통과하는 조건을 합성 응답으로 재현했습니다. 시도 정합성과 같은 영문 이름 조건을 추가했습니다. |
| 번역 표시 시점 | 기존 코드는 번역 후보를 먼저 표시한 뒤 별도 영어 응답으로 도시 ID만 확인했습니다. 확인 실패 후에도 먼저 표시한 지명은 남았습니다. | **도시 ID·행정구역 ID·국가·이름이 확인된 뒤 번역 표시와 캐시를 함께 반영**합니다. 확인 실패 시 기존 IP 지명을 보존합니다. |
| 수동 검색 결과 | 기존 결과 목록은 같은 응답 행의 도시·시도·국가 전체를 표시하고 선택한 행 자체를 전달합니다. | 기존 목록 표시와 사용자 선택을 유지합니다. 도시 검색 결과의 행정구역 ID도 정규화 사본에 보존합니다. |
| IP 추정 정확도 | 이번 수정은 실제 사용자 IP 응답을 수집하거나 검증하지 않았습니다. | **사용자가 본 충청도·전라도 표시의 직접 원인이 IP 응답 자체였는지는 미확정**입니다. IP가 다른 도시를 추정하는 문제와 앱의 후보 검증 누락을 구분합니다. |

행정구역 이름은 기존에 확인된 국내 영문·한글 대응표와 비교합니다.
다른 언어의 행정구역이 확실하게 대응하지 않으면 번역 지명을 임의로 확정하지 않고 IP 원문을 유지합니다.
이 때문에 일부 지역에서 번역보다 원문 표시가 우선될 수 있습니다.
위치 서비스나 GPS를 새로 켜지 않으며 자동 IP 모드가 실제 기기 위치를 보장하지는 않습니다.

## 최소 검사 결과

합성 응답 검사 4개로 다른 시도 후보 거부, 멀리 떨어진 동명 수원 구분, 같은 도시·행정구역 ID 확인 후 표시, 불일치 시 IP 원문 보존을 확인했습니다.
수정 전에는 4개 검사에서 5개 단언 실패를 관측했고 수정 후에는 **4개 모두 통과**했습니다.
사용자 IP·상세 주소·대화·인증정보는 검사 입력이나 문서에 포함하지 않았습니다.
기존 전체 회귀 검사는 반복하지 않았고 실제 사용자 위치 정확도를 검증했다고 주장하지 않습니다.
