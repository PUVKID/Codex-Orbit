# 37차 알림센터

**실제로 관측한 기록**을 검색하고 알림 표시 정책을 조정하는 독립 화면입니다.
기존 이벤트·모델 설정·대화 원문은 변경하지 않습니다.

| 영역 | 조작 | 동작과 기준 |
| --- | --- | --- |
| 기록 탐색 | 제목·모델·이유·작업 통합 검색, 초기화 | 원문 사본에서 대소문자를 구분하지 않고 검색합니다. |
| 기록 필터 | 모델 변경, 추론 강도 변경, 작업 재개 | 실제 전후값과 명시된 `activity_type=resumed`를 사용합니다. |
| 기간·관심 | 오늘, 최근 7일, 보관, 관심 채팅 | 시각 미확인 기록은 기간 필터에서 제외합니다. 오늘은 기기의 현지 날짜 기준입니다. |
| 정렬·묶음 | 최신순, 오래된순, 채팅별 묶음 | 기록별 전후값을 유지하며 채팅별 건수를 표시합니다. |
| 선택 기록 | 전체 요약, 복사, 알림 다시 보기, 원래 상세 열기 | 다시 보기는 기존 컨트롤러의 이벤트 ID 연결을 사용합니다. |
| 결과 저장 | UTF-8 CSV, JSON | 현재 필터·정렬의 최대 500건을 저장합니다. 대화 본문·위치·경로·식별자 필드는 제외합니다. |
| 개인정보 보호 | 프라이버시 모드 | 화면·클립보드·CSV·JSON의 제목·이유·작업을 가립니다. 모델과 추론 강도는 유지합니다. |
| 알림 설정 | 표시 시간 5~120초, 동시 표시 1~8개 | 정책 객체에 저장하고 실패하면 현재 저장값으로 조작 화면을 복원합니다. |
| 알림 조절 | 작업 알림, 간결 표시, 소리, 집중 15·30·60분, 재개 | 기존 정책 API로 적용합니다. 선택 채팅은 30분 무음으로 설정할 수 있습니다. |
| 알림 확인 | 모델·추론·작업 미리보기, 고정하지 않은 알림 닫기 | 부모 컨트롤러가 제공하는 미리보기·닫기 API를 호출합니다. |

**CSV 수식 실행 방어**를 위해 `=`, `+`, `-`, `@`로 시작하는 값과 탭·개행으로 시작하는 값 앞에 작은따옴표를 붙입니다.
원본 이벤트는 바꾸지 않습니다.
내보내기는 요약 필드 허용 목록을 사용하며, 허용된 이유·작업 문장에 사용자가 직접 기재한 민감정보까지 자동 판별하는 기능은 아닙니다.

화면 전체는 스크롤되며 `기록 탐색`과 `알림 설정` 두 탭으로 구성합니다.
한국어·영어 문구는 현재 앱 언어를 따르고 테마·글꼴은 부모 화면에서 상속합니다.
저장창은 앱 테마를 적용하는 Qt 파일 선택창을 사용합니다.
패널 자체의 갱신 타이머는 없습니다.

## 연결 API

`WorkspacePanel(controller, parent=None)`을 생성하고 기록 변경 시 `refresh()`, 언어 변경 시 `retranslate()`를 호출합니다.
`features.snapshot()['events']`, `features.pins`, `features.bookmarks`를 읽습니다.
프라이버시는 `settings.values['broadcast_mode']`를 따릅니다.
`replay_event(id)`, `show(id)`, `preview_notice37(kind)`, `dismiss_unpinned37()`와 `workspace_policy`를 컨트롤러에서 제공합니다.

## 확인 범위

`tests/test_workspace37.py`는 합성 이벤트만 사용합니다.
통합 검색, 변경 종류, 기간·관심 필터, 정렬·묶음의 원본 보존, 허용 필드·개인정보 가림, CSV 수식 방어를 검사합니다.
실제 화면 조작과 부모 컨트롤러의 저장·미리보기 동작은 통합 담당 범위입니다.
