# 37차 · 알림 센터와 감시 상태·업데이트 안내

**3.7.0**은 관측 기록을 찾아보는 알림 센터, 감시 상태와 알림 표시 조절, 공식 업데이트 안내를 연결한 차수입니다. 시스템·라이트·다크와 날짜별 과일·꽃 픽셀 입체 조형은 유지합니다. 실제 기록과 미리보기, 구현된 기능과 아직 확인하지 않은 실행 범위를 구분합니다.

## LEVEL 1 - Beginner · 37차

| 영역 | 기능·조건 |
| --- | --- |
| 기록 찾기 | 통합 검색·초기화, 모델 변경·추론 변경·작업 재개, 오늘·최근 7일·보관·관심 채팅, 정렬·묶음과 건수·빈 결과 |
| 선택·저장 | 전체 요약·복사·재표시·원 상세, CSV 수식 방어·JSON·프라이버시 가림 |
| 알림 조절 | 집중 15·30·60분과 즉시 재개, 선택 채팅 30분 음소거와 초기화, 작업 알림·간결 표시·알림음, 시간 5~120초·동시 1~8개, 고정 제외 모두 닫기 |
| 감시 확인 | 상태·마지막 진행·복구 횟수·20초 초과 지연·수동 재연결, 경로 가림·관측 채팅 수·잔량과 날씨 조회 시각 |
| 업데이트 | 버전·공식 페이지·예상 MB·디스크 여유·검증값 복사·설정 보존 안내·단계·쉬운 오류와 원문·최근 결과·복구 구분 |

알림 센터는 **이미 관측한 변경 기록을 찾아보는 화면**입니다. 모델은 작업에 선택한 모델의 이름이고 추론 강도는 해당 작업의 설정값입니다. 검색 결과가 실제로 모델을 바꾸거나 과거 대화를 수정하지는 않습니다. 검색은 제목·이유·작업과 전후 모델·강도를 대상으로 하며 대화 본문 전체 검색은 아닙니다.

먼저 검색어를 넣거나 변경 종류·기간·보관·관심 채팅을 고르고 결과를 선택합니다. 오늘은 기기의 현지 날짜이고 최근 7일은 현재 시각을 기준으로 합니다. 시각이 확인되지 않은 기록은 기간 조건에서 빠집니다. 초기화는 검색·필터·순서를 되돌리지만 채팅 묶음 선택은 유지합니다. 결과는 최대 500건이며 원래 전후 값을 합치지 않고 최신순·오래된순 또는 채팅별로 살필 수 있습니다.

선택한 기록은 시각·종류·전후 값·이유·작업을 요약해 복사하거나 기존 알림과 원 상세를 다시 열 수 있습니다. 다시 보기는 새로운 관측을 뜻하지 않습니다. CSV와 JSON은 현재 결과의 허용된 요약 필드만 저장합니다. 프라이버시 모드를 켜면 제목·이유·작업을 화면과 복사·내보내기에서 가리지만 저장된 원본은 유지합니다. 직접 적은 문장 속 민감정보를 모두 자동 판별하는 기능은 아닙니다.

집중과 음소거는 **표시를 줄이고 기록 수집은 계속**합니다. 실제 기록을 남기지 않는 모델·추론·작업 알림 미리보기도 구분합니다. 상태 띠의 지연과 복구 횟수는 확인을 돕는 정보이며, 곧 앱 종료나 복구 성공을 뜻하지 않습니다. 잔량·날씨의 조회 시각과 이전 정보·미확인 표시를 함께 확인합니다.

업데이트 창에서는 현재 버전과 확인한 새 버전, 예상 크기, 진행 단계를 확인합니다. 공식 페이지 버튼은 고정된 공식 릴리스 목록을 엽니다. 검증된 SHA-256은 내려받은 파일을 대조하는 값이며 다운로드 전 메타만으로 검증 성공을 표시하지 않습니다. 실패 안내와 오류 원문, 최근 결과를 구분해 읽고 미확인 결과를 성공으로 해석하지 않습니다.

지역 표시는 국가·시도·도시명과 식별자 정합성을 강화했습니다. 자동 위치는 연결망의 추정값이며 실제 기기 위치의 정확도를 보장하지 않습니다.

## LEVEL 2 - Explorer · 37차

| 영역 | 기능·조건 |
| --- | --- |
| 이벤트 사본 | 검색·종류·기간·보관·관심 조건 → 정렬·채팅 묶음·건수 → 선택 요약·재표시·원 상세 |
| 결과 사본 | 허용 필드 → 프라이버시 가림 → CSV 수식 방어 또는 JSON 저장 |
| 표시 정책 | 집중·음소거·작업 알림·간결 표시·알림음·시간·동시 수 → 실제 알림 표시 제어 |
| 관측 신호 | 진행 시각·작업자 수명·조회 시각 → 상태 띠·재연결·이전 정보·미확인 |
| 공식 업데이트 | 공식 주소·공간 확인 → 다운로드·검증 → 설치 준비·최근 결과·복구 구분 |

37차는 **관측 원본과 화면에서 쓰는 사본을 구분**합니다. 알림 센터는 이벤트 사본을 검색·필터·정렬하고 선택한 기록의 기존 ID를 재표시·상세 열기에 전달합니다. 채팅 묶음은 건수를 모을 뿐 각 기록의 전후 값을 합성하지 않습니다. 모델·추론 필터는 해당 값이 바뀐 기록을 고르는 조건이며 특정 모델명이나 강도값 선택 목록은 아닙니다.

기간은 유효한 원본 시각으로 계산하고 시각 미확인 기록은 오늘·최근 7일에서 제외합니다. 보관과 관심 조건은 기존 ID·대상과 비교하며 해당 목록 자체는 수정하지 않습니다. 초기화와 빈 결과 안내, 최대 500건·검색 건수·정렬·묶음이 같은 탐색 흐름을 구성합니다. 선택 요약과 복사, CSV·JSON은 대화 본문·위치·경로·식별자를 제외하는 허용 목록을 사용합니다. 프라이버시 가림과 CSV 수식 방어는 원본 이벤트를 바꾸지 않습니다.

알림 정책은 기록 수집과 분리됩니다. 집중 15·30·60분, 즉시 재개, 채팅별 30분 음소거와 전체 음소거 초기화를 조합하며 집중과 개별 음소거는 별도입니다. 유효한 음소거 대상은 최대 64개입니다. 작업 알림, 간결 표시, 알림음, 표시 시간 5~120초와 동시 1~8개를 기존 설정에 연결하고 저장 실패 때 이전 설정을 복원합니다. 미리보기는 실제 기록을 만들지 않고 모두 닫기는 고정한 알림을 남깁니다.

감시 상태는 마지막 진행과 작업자의 실제 수명을 기준으로 정합니다. 20초를 넘은 지연, 재연결 중·중단·첫 확인 대기를 구분하며 재연결 대기 중 버튼을 막습니다. 프라이버시 모드에서는 감시 경로를 가립니다. 관측 채팅 수는 파일 수와 다르고 미확인 값은 추정하지 않습니다. 잔량과 날씨의 조회 시각·이전 정보 표시도 상태 판단의 근거입니다.

업데이트는 공식 릴리스 확인→다운로드→검증→설치 준비를 구분합니다. 준비 볼륨의 여유 공간이 자산 크기 × 3 + 64 MB보다 작으면 다운로드를 시작하지 않습니다. 1 MB는 1,048,576바이트이며 크기 표시는 실제 메타에 근거합니다. 크기·SHA-256·EXE 형식 확인 뒤에만 검증값 복사를 제공합니다. 최근 결과는 업데이트·복구·실패와 시각을 구분하며 파일만 복원한 상태와 이전 EXE 재시작까지 확인한 복구 성공을 혼동하지 않습니다.

지역 표시는 국가·시도·도시명과 식별자 정합성을 강화했습니다. 자동 위치는 연결망의 추정값이며 실제 기기 위치의 정확도를 보장하지 않습니다.

## LEVEL 3 - Practitioner · 37차

| 영역 | 기능·조건 |
| --- | --- |
| 탐색 준비 | 검색·변경 종류·기간·보관·관심·순서·묶음·건수와 빈 결과 확인 |
| 선택과 내보내기 | 요약·복사·다시 보기·원 상세, 가림 상태와 CSV·JSON 저장 범위 확인 |
| 표시 설정 | 시간·동시 수·재개 알림·간결 표시·소리, 집중·재개·음소거·초기화 |
| 연결 확인 | 상태·진행·복구·지연·재연결, 경로 가림·채팅 수·조회 시각 |
| 업데이트 확인 | 버전·공식 출처·크기·공간·검증값·설정 안내·단계·오류·최근 결과 |

알림 센터의 기록 탐색 탭에서 검색어와 변경 종류, 오늘·최근 7일·보관·관심 조건, 최신·오래된 순과 채팅 묶음을 고릅니다. 원본 시각이 없는 기록은 기간 검색에 나타나지 않습니다. 초기화는 묶음 선택을 유지하고 결과는 최대 500건입니다. 결과가 비면 조건을 풀어 확인하며 빈 결과 자체를 앱 오류로 단정하지 않습니다.

기록을 선택한 뒤 요약 복사, 알림 다시 보기, 원래 상세를 사용합니다. CSV·JSON 저장은 **현재 필터 결과**에 적용됩니다. 대화 본문·위치·경로·식별자 필드는 포함하지 않지만 허용된 문장 속 민감정보까지 자동 탐지하지는 않습니다. 필요하면 프라이버시 모드를 켜 제목·이유·작업 가림을 적용한 뒤 저장합니다. CSV는 수식 시작 문자와 앞 공백·탭·개행을 방어합니다.

알림 설정 탭에서 표시 시간 5~120초와 동시 1~8개, 작업 재개 알림, 간결 표시와 알림음을 설정합니다. 집중 15·30·60분은 표시만 억제하며 즉시 재개로 해제합니다. 선택 채팅은 30분 동안 음소거할 수 있고 최대 64개이며 음소거 초기화와 집중 해제는 별도입니다. 모델·추론·작업 미리보기는 실제 기록을 생성하지 않습니다. 고정 제외 모두 닫기는 고정한 알림을 유지합니다.

상태 띠와 툴팁에서 마지막 진행·복구 횟수·관측 파일과 채팅 수, 잔량·날씨 갱신 시각을 확인합니다. 20초 초과 지연은 곧 종료를 뜻하지 않으며 수동 재연결 대기 중에는 버튼이 비활성화됩니다. 프라이버시 모드의 경로 가림, 미확인·이전 정보 표시를 함께 읽습니다.

업데이트 창에서 현재 3.7.0과 확인된 새 버전, 실제 메타의 예상 MB, 공간 부족 안내와 단계를 확인합니다. 고정 공식 페이지 버튼만 사용하고 검증 준비 전 SHA 복사 성공을 기대하지 않습니다. 실패 때 쉬운 안내와 일반 텍스트 오류 원문을 구분합니다. 작업 중 닫기·Esc는 제한되며 최근 결과와 복구 상태를 다시 볼 수 있습니다. 개인 설정·MD 유지 안내는 해당 업데이트가 실제 보존에 성공했다는 별도 실행 증거를 대신하지 않습니다.

지역 표시는 국가·시도·도시명과 식별자 정합성을 강화했습니다. 자동 위치는 연결망의 추정값이며 실제 기기 위치의 정확도를 보장하지 않습니다.

| update_widgets | 버전·공식 페이지·크기·검증값·설정 안내·단계·오류·최근 결과·작업 중 닫기 제한 |

workspace37은 이벤트 시각·검색·필터·정렬·묶음·요약·내보내기와 Qt 패널을, operations37은 표시 정책·감시 상태·메인 연결을 담당합니다. 앱 컨트롤러는 기존 이벤트 ID의 재표시·상세, 기록을 만들지 않는 미리보기, 고정 제외 닫기와 수동 재연결을 연결합니다. 알림 센터 패널 자체에는 갱신 타이머가 없고 부모 연결의 갱신 경로를 사용합니다. 같은 이력의 재렌더를 피하는 처리와 선택된 탐색 항목 표시도 연결 범위입니다.

탐색은 제목·이유·작업·전후 모델과 강도에 한정되며 본문 전체 검색이 아닙니다. 모델·추론 변경과 명시적인 작업 재개, 유효한 현지 시각의 오늘·최근 7일, 기존 보관·관심 대상 조건을 원본 사본에 적용합니다. 초기화는 묶음 선택을 유지하고 결과는 최대 500건입니다. 선택 ID를 기존 API에 전달하며 그룹 집계가 전후 값을 바꾸지 않게 합니다.

내보내기는 허용 필드만 구성하고 프라이버시 모드의 제목·이유·작업 가림을 화면·요약·CSV·JSON에 적용합니다. CSV 수식 방어는 수식 시작 문자·앞 공백·탭·개행을 다룹니다. 허용 문장에 사용자가 넣은 민감정보를 전부 자동 판별하지는 않습니다. 알림 정책의 시간 5~120초·동시 1~8개·불리언 설정은 검증하고 저장 예외 때 이전 설정을 복원합니다. 집중 15·30·60분과 최대 64개의 30분 음소거는 표시만 억제합니다.

감시 상태는 작업자 수명과 마지막 진행의 20초 경계를 사용하고 재연결·오류·대기·지연을 구분합니다. 경로는 프라이버시 모드에서 가리며 관측 파일 수·채팅 수·조회 시각·이전 정보를 혼합하지 않습니다. 작업 재개 알림·간결 표시·알림음·미리보기·고정 제외 닫기는 기존 기록 수집과 분리합니다.

safe_update는 준비 볼륨의 공간과 검증·결과 기록을 보완하고 update_widgets는 현재 버전·고정 공식 URL·MB·단계·검증 SHA·설정 유지·쉬운 오류와 읽기 전용 원문을 연결합니다. 결과 JSON은 16 KiB와 허용 필드·상태·버전·UTC 시각·오류 코드로 제한하며 링크·재분석 지점을 거부합니다. 같은 권한의 악의적인 동시 경로 교체까지 막는 서버 보안 경계는 아닙니다. 결과 기록 실패가 EXE 복구나 원래 예외를 덮지 않게 하고 복원 뒤 재시작 실패를 복구 성공과 구분합니다.

지역 표시는 국가·시도·도시명과 식별자 정합성을 강화했습니다. 자동 위치는 연결망의 추정값이며 실제 기기 위치의 정확도를 보장하지 않습니다.

## LEVEL 5 - Expert · 37차

| 영역 | 기능·조건 |

| 탐색1~20 | 기록 사본·필터 의미·시각·500건·ID·내보내기 허용 목록·프라이버시·CSV 방어 |

37차는 기존 이벤트 원본·모델 설정·대화를 수정하지 않는 알림 센터와 감시/표시 정책, 공식 업데이트 안내를 연결합니다. 50개 항목은 기존 기능의 유지·보완을 포함하고 공유하는 기능을 중복 집계하지 않습니다. 각 번호의 실제 함수·조건·제약은 50개 개선 원문에 대응합니다. 자동 복구나 조형·정보 분리처럼 이전부터 있던 기능을 새 발명으로 세지 않습니다.

이벤트 사본에 통합 검색·초기화, 모델/추론 변경·명시적 resumed, 유효 시각의 오늘·최근 7일, 보관·관심, 최신/오래된 순·채팅 묶음을 적용합니다. 초기화의 묶음 유지, 최대 500건·건수·빈 결과, 선택 요약·복사·재표시·원 상세의 ID 경계를 보존합니다. 허용 필드 CSV·JSON과 프라이버시 가림은 원본을 바꾸지 않습니다. CSV 수식 방어와 허용 문장 내부의 민감정보 자동 판별 한계를 구분합니다.

정책은 표시 시간 5~120초·동시 1~8개·작업 알림·간결 표시·알림음과 집중 15/30/60분·즉시 재개, 유효 대상 최대 64개의 30분 음소거·초기화를 다룹니다. 집중과 음소거가 수집을 멈추지는 않습니다. 기록 없는 미리보기와 고정 제외 닫기도 기존 기록과 분리합니다. 상태는 실제 진행·작업자 수명·20초 초과 지연을 사용하고 복구 횟수만으로 성공을 주장하지 않습니다. 감시 경로 가림·관측 채팅 수와 파일 수·잔량/날씨 조회 시각·미확인/이전 정보를 구분합니다.

업데이트의 공식 출처·SHA·형식·시작 실패 복구는 기존 경계를 유지합니다. 준비 볼륨의 자산 크기 × 3 + 64 MB 검사, 1 MB = 1,048,576바이트 표시, 검증 후 SHA 복사, 설정·MD 유지 안내, 단계·쉬운 오류/일반 텍스트 원문·최근 결과·닫기 제한을 추가 연결합니다.16 KiB 결과 JSON의 필드·버전·UTC·오류 코드·재분석 지점 검사와 원자 기록은 로컬 범위이며 악의적인 동시 경로 교체에 대한 서버 보증이 아닙니다. 파일 복원과 이전 EXE 재시작 성공을 분리합니다.
