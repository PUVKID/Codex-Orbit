# 🍎 30차 · 날짜별 바탕화면 테마 기본 복원

3.0.1은 표시 모드 기본값 네 곳을 calendar로 복원합니다. 새 설정과 표시 모드가 없는 기존 설정은 원래 날짜별 조형을 표시하고 모델 이벤트 이후에도 날짜 제목과 조형을 유지합니다. 명시 선택한 관측소 기능은 보존합니다. 기존 월·일 테마 코드와 자산을 바꾸지 않습니다.

[직전 소스 전체 비교](직전차수.diff) · [파일별 크기와 SHA](공개파일_비교.json) · [공개 전체 비교](../../docs/30차_전체변경.diff) · [변경 기록](../../변경기록_30차.md) · [검증](../../docs/공개검증_30차.md) · [29차](../29차/README.md)

주석·공백·개행까지 실제 바이트로 비교합니다. 바이너리는 파일 크기와 SHA-256을 기록합니다. 관측소 통합 검사에는 선택 상태를 명시하고, 기본값과 모델 이벤트 이후 날짜 조형 보존을 검사하는 합성 회귀 네 개를 추가했습니다.
