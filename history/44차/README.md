# 44차 · 알림과 내부 화면 통일

3.13.0은 내부 변경 기록을 위젯 알림과 같은 비교표로 정리합니다. 날짜별 과일·꽃·기념일의 픽셀 모션과 기존 날씨 보정은 유지합니다.

[전체 비교](직전차수.diff) · [웹 비교](비교.md) · [사용 안내](../../docs/44차_내부화면과날짜별위젯.md)

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner

### 기능과 사용 흐름

| 항목 | 동작·의미 |
| --- | --- |
| 비교표 | 이전·현재를 나란히 표시하며 모델 그림과 강도 막대는 글꼴과 별개로 그립니다. 정확한 ID와 강도 원문을 함께 읽습니다. |
| 이유 | 짧은 공개 설명을 먼저 표시하고 긴 작업 내용·원문·ID·근거는 펼쳐 읽습니다. 기록에 없는 이유나 이전 값을 만들지 않습니다. |
| 모양과 설정 | 공통 버튼·입력·메뉴·목록의 간격과 조작 상태를 다듬고 작은 창에서는 탐색을 스크롤하고 설정을 한곳에서 펼칩니다. 비교표의 폭이 부족하면 이전·현재 묶음을 위아래로 배치합니다. 언어·라이트·다크·배율·사용자 색은 유지합니다. |
| 날짜별 위젯 | 기존 월·일별 과일·꽃·기념일·지원 지역 행사를 보존합니다. 날짜 선택의 누락 검사와 실제 고유 모형의 움직임 검사는 구분합니다. |
| 예시 | 모델이 Sol에서 Astra로 바뀌면 왼쪽에는 Sol, 오른쪽에는 Astra가 보입니다. 강도가 같으면 그 값은 그대로 보이며 바뀐 현재 칸만 강조합니다. |
| 사용 순서 | 변경 기록에서 원하는 채팅을 선택한 뒤 두 행과 이유를 읽습니다. 더 알고 싶으면 원문·ID·근거를 펼칩니다. 모르는 값은 이전 기록 없음으로 안내합니다. |

### 조건과 한계

| 조건 | 처리·주의 |
| --- | --- |
| 날짜 범위 | 2026년부터 2099년 말까지 선택 결과와 연결을 검사합니다. 컴퓨터가 꺼진 날에도 실행된다는 뜻은 아닙니다. |
| 지역 행사 | 확인된 자료 범위를 따릅니다. 모든 도시의 미래 축제 일정이 확정되어 있다는 뜻은 아닙니다. |
| 위치·날씨 | 기존 연결 한정 확인 도시 보정과 60초 조회를 유지합니다. IP 위치의 건물 단위 정확도나 매분 새 관측을 보장하지 않습니다. |
| 개인정보 | 실제 채팅·위치·연결 식별값·사용자 설정·비공개 그래프와 운영 기록은 게시하지 않습니다. |

### 검사와 구현 근거

| 구분 | 확인 범위 |
| --- | --- |
| 화면 | 실제 Qt 구성요소에서 비교 값·변경 강조·펼치기·테마·작은 창과 배율을 검사합니다. 합성 자료와 실제 계정 기록을 구분합니다. |
| 날짜·그림 | 27,028일·888개월·윤일 18개 선택과 141종·282개 실제 GPU 프레임 생성을 구분해 확인했습니다. 미래 외부 서비스 정상 작동의 보증은 아닙니다. |
| 배포 | 같은 동결 소스에서 단일 실행·설치형을 만들고 내장 코드·테마 엔진·사용법 연결을 대조합니다. |
| 기존 근거 | 변경 없는 감시·날씨·한도·모션의 유효한 기존 37·41·43차 검사를 재사용하며 변경 영향만 확인합니다. |
| 성능 | 전후 성능을 측정하지 않았으므로 속도 향상을 주장하지 않습니다. 모든 환경·미래 입력의 절대 무결함을 보장하지 않습니다. |

**이전 값과 이유는 공개 기록에 근거합니다.** 긴 설명을 접어도 원문은 보존하며 비공개 내부 추론을 재구성하지 않습니다. 날짜별 디자인을 모델 아이콘으로 바꾸는 차수가 아닙니다.


### 알림 위치와 부드러운 움직임

| 설정 | 동작 |
| --- | --- |
| 기본 위치 | 위젯이 있는 모니터의 오른쪽 아래 모서리 |
| 위치 변경 | 화면 설정 → 알림 위치에서 네 모서리 선택·저장 |
| 등장·닫기 | 아래에서 부드럽게 올라오고 닫힐 때 내려감. 움직임 줄이기에서는 즉시 표시 |
| 이전 진단 | 짧은 안내부터 읽고 필요할 때 원문 펼치기. 같은 손상 기록은 반복 누적을 줄임 |

알림 여러 개가 나타나도 하나씩 지울 필요가 없습니다. 채팅 제목과 이전·현재 값을 비교한 뒤 이유를 읽습니다. 이전에 읽지 못한 기록이 있다는 안내는 현재 감시가 중단됐다는 뜻과 구분합니다.
