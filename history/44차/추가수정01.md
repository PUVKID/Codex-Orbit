-## 37차 · 알림 센터
-
-처음 실행할 때 재질 준비가 오래 걸리면 위젯에 **3D 준비 중**이 표시됩니다.  
-창 표시 전 대기는 최대 5초이며 이후 앱 조작을 계속할 수 있습니다.  
-실제 초기화 오류는 **3D 표시 오류**로 구분합니다.  
-첫 준비와 일반 프레임의 제한 시간은 다르며, 준비 상태를 실제 움직이는 3D로 표시하지 않습니다.
-
-위젯을 눌러 창을 연 뒤 왼쪽 **알림 센터**를 선택합니다.  
-**기록 탐색**에서 채팅 제목·모델·이유·작업을 검색하고, 종류·기간·순서와 채팅별 묶음을 고를 수 있습니다.  
-기록을 선택하면 이전과 현재 모델·추론 강도, 이유와 맡은 작업을 확인합니다.  
-기록 재표시는 새 모델 변경이 아닙니다.
-
-**알림 설정**에서 표시 시간·동시 표시 개수·작업 알림·알림음을 조절합니다.  
-집중 시간이나 채팅별 음소거를 켜도 기록 수집은 계속합니다.  
-**알림 다시 받기**로 집중을 끝내고, **모든 음소거 해제**로 채팅별 음소거를 풉니다.  
-가상 알림 미리보기는 실제 변경 기록에 남지 않습니다.
-
-위쪽 상태띠에서 감시 상태와 최근 진행을 확인합니다.  
-멈춤이나 지연이 보이면 **감시 다시 연결**을 누릅니다.  
-**프라이버시 모드**는 채팅 제목과 작업 설명을 화면·복사·내보내기에서 가립니다.  
-저장된 원문을 삭제하지 않습니다.
-
-지역은 도시와 시도·국가를 함께 확인합니다.  
-수원시는 **경기도 · 대한민국**입니다.  
-자동 위치는 연결망의 위치 자료를 사용하므로 실제 기기 위치와 다를 수 있습니다.  
-다른 도시로 잡히면 **지역 변경 → 수동**에서 시도·국가까지 맞는 도시를 골라 주세요.  
-이번 버전은 서로 다른 동명 도시나 번역 후보를 섞지 않도록 확인을 강화했습니다.

-## 35차 · 색상과 조명
-
-화면 위쪽 **화면 테마**에서 시스템·라이트·다크를 선택합니다.  
-옆의 **색상 꾸미기**를 누르면 여섯 가지 색 조합을 고르거나 포인트색·다크 배경·라이트 배경의 색상 코드를 직접 입력할 수 있습니다.  
-색 선택 버튼도 제공합니다.
-
-조명 강도는 0부터 100까지 조절하며 **0은 조명 끄기**입니다.  
-미리보기의 다크·라이트 선택은 미리보기만 바꿉니다.  
-**적용**해야 저장되며 **취소**하면 기존 설정을 유지합니다.  
-기본값 복원도 적용 전에는 저장하지 않습니다.  
-잘못된 색상 코드에는 설명을 표시하고 적용을 막으며, 저장 실패 시 이전 설정과 화면을 복원합니다.
-
-입력한 원색은 보존하고 글자색은 읽기 좋게 보정합니다.  
-날짜별 과일·꽃·기념일·도시 행사와 픽셀 입체 회전은 유지합니다.  
-잔량 막대의 실제 비율·원값, 자동·수동 위치, 모델·추론·작업 재개 알림도 그대로 사용합니다.  
-조명은 화면 전체 흐림이나 별도 애니메이션 타이머를 추가하지 않습니다.

+## 37차 · 알림 센터
+
+처음 실행할 때 재질 준비가 오래 걸리면 위젯에 **3D 준비 중**이 표시됩니다. 창 표시 전 대기는 최대 5초이며 이후 앱 조작을 계속할 수 있습니다. 실제 초기화 오류는 **3D 표시 오류**로 구분합니다. 첫 준비와 일반 프레임의 제한 시간은 다르며, 준비 상태를 실제 움직이는 3D로 표시하지 않습니다.

+위젯을 눌러 창을 연 뒤 왼쪽 **알림 센터**를 선택합니다. **기록 탐색**에서 채팅 제목·모델·이유·작업을 검색하고, 종류·기간·순서와 채팅별 묶음을 고를 수 있습니다. 기록을 선택하면 이전과 현재 모델·추론 강도, 이유와 맡은 작업을 확인합니다. 기록 재표시는 새 모델 변경이 아닙니다.
+
+**알림 설정**에서 표시 시간·동시 표시 개수·작업 알림·알림음을 조절합니다. 집중 시간이나 채팅별 음소거를 켜도 기록 수집은 계속합니다. **알림 다시 받기**로 집중을 끝내고, **모든 음소거 해제**로 채팅별 음소거를 풉니다. 가상 알림 미리보기는 실제 변경 기록에 남지 않습니다.

+

+## 35차 · 색상과 조명
