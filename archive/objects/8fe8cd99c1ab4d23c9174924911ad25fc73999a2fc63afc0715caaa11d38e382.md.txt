# 변경마다 독립 알림

사용자가 8차 즉시 알림 수신을 확인했고 앞 알림을 닫아야 뒤 알림이 뜨는 동작을 변경하도록 요청했습니다. 8차를 보존하고 9차로 분리합니다.

원인은 단일 Notice 및 enqueue_notice의 isVisible 조건입니다. 각 이벤트에 독립 Notice를 만들고 화면 안에서 여러 장을 즉시 쌓습니다. 공간을 넘으면 서로 어긋나게 겹치도록 하며, 새 알림을 기다리게 하지 않습니다. 같은 ID 중복은 갱신하고 각 카드 클릭은 해당 정확 ID로 상세를 엽니다. 만료와 닫기는 다른 알림을 지우지 않습니다. 기존 투명 모션·잔량·MD·선택 순간 감지는 보존합니다.

구현자는 먼저 현재 직렬 동작을 실패 검사로 재현하고 동시 3건·각 ID 클릭·가장자리·독립 닫기·만료·종료·중복 ID·제목 보강을 검증합니다. 기존 직렬 기대 검사는 새 사용자 요구와 대조해 변경 근거를 남깁니다. 전체 검사와 별도 verifier 후 EXE·설치본을 재빌드하고 기존 실행본을 교체합니다.

## 알림 가독성 후속 요구

사용자는 진행 중 알림과 글자 디자인도 더 직관적으로 바꾸도록 요청했습니다. 카드 안 정확한 채팅 제목을 크게, 변경 종류를 명확한 한글로, 이전 값→새 값을 계층적으로 배치합니다. 추론 강도는 보통(medium) 등 한글 풀이와 정확한 원문 값을 함께 표시합니다. 폰트는 내장 나눔고딕 Bold700을 유지하며 크기·간격·대비를 개선합니다. 확인된 짧은 이유만 사용하고 확인되지 않은 이유를 생성하지 않습니다. 각 알림이 자기 이벤트 상세로 연결되는 기준을 유지합니다. 이번 범위는 알림 카드이며 기존 MD/잔량/전체 UI를 무관하게 재작성하지 않습니다.
