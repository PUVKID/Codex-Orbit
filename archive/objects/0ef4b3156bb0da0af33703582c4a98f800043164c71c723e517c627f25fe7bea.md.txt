# Codex Orbit 배포 안내

13차 / 버전 2.0.2: 로컬 Codex 채팅에 선택한 모델·추론 강도 설정이 기록되면 다음 메시지 실행을 기다리지 않고 변경 알림을 표시합니다. 변경마다 독립 알림을 즉시 표시하며 무채색 입체 궤도·잔량·MD 기능은 유지합니다. 이전12차를 보존합니다.

투명한 회전 궤도 위젯으로 Codex 계정 잔량과 로컬 모델·추론 강도 변경을 확인하는 Windows 10/11 x64 앱입니다.

중심에는 확인된 기간 중 가장 적게 남은 사용 한도 비율을 표시합니다. 남은 토큰 개수가 아닙니다. 사용 한도 탭에는 버킷·기간별 잔량 막대, 초기화 한국 시각, 최종 조회 시각과 수동 새로고침이 있습니다. 공식 `account/rateLimits/read`를 설치된 `codex app-server`에서 읽기 전용으로 30초마다 조회하며 서버의 갱신 알림도 반영합니다. 없는 기간·null 수치는 만들어 표시하지 않습니다.

설치된 Codex의 ChatGPT 로그인이 필요합니다. EXE를 자동 탐색하고 실패하면 설정에서 설치된 `codex.exe`를 선택할 수 있습니다. 앱은 인증 파일을 직접 읽거나 복사하지 않고 로그인·리셋·구매·모델 실행·Codex 설정 변경을 하지 않습니다. 연결 실패·지연이면 이전 값임을 명시하며 재실행할 때 잔량을 디스크에서 복원하지 않습니다. 서버 반영과 연결 상황에 따라 조회가 늦어질 수 있습니다.

연속 변경은 앞 알림을 닫지 않아도 각각 즉시 표시합니다. 화면 안에 세로로 쌓고 공간이 부족하면 어긋나게 겹칩니다. 창은 최대 8장이며 초과 시 가장 오래된 창을 숨기고 새 알림을 바로 표시합니다. 숨긴 누적 건수는 화면에 안내하고 기존 이력에서 다시 볼 수 있습니다. 각 창의 닫기·클릭·자동 만료는 다른 창을 닫거나 표시 시간을 초기화하지 않습니다. 감시 진행이 20초 이상 없으면 지연을 표시하고, 종료된 작업자만 세 차례까지 재시작합니다. 실행 중인 정체 작업자를 강제 종료하지 않으며 이전 정체의 최초 원인은 확인되지 않았습니다.

같은 감지 묶음에서 유효한 원본 기록 시각을 안정 정렬하며, 시각이 없거나 잘못된 항목의 감지 위치는 유지합니다. 파일이 늦게 읽힌 경우 이미 표시한 알림까지 전체 시간순으로 바꾸지는 않습니다. 감지 시각과 원본 기록 시각을 구분합니다.

Windows 상태 교체의 짧은 공유 오류는 호출별 임시 파일과 최대 다섯 번의 제한된 교체 시도로 처리합니다. 지속 실패 시 기존 파일을 보존하고 다음 감시 주기에 재시도합니다. 진단 기록도 실패하면 원래 오류와 기록 오류를 화면에 함께 남깁니다. 필수 시작 준비 실패는 회전 위젯을 남기지 않습니다. 실제 운영의 WinError5 세 건과 별도 제어 재현을 근거로 수리했으며 과거17:32 중단의 최초 원인을 확정한 것은 아닙니다.

사용자 앱 데이터의 `startup.jsonl`은 PID·단계·경로·오류, `notice-presentations.jsonl`은 ID·대상·모델·강도·원본 시각·표시 요청 시각·동시 표시 수를 기록합니다. 표시 기록에는 대화 본문·제목·공개 이유를 넣지 않으며 사용자 확인 여부는 false입니다. 기록 저장 실패도 진단에 표시합니다. 파일은 2 MiB 순환 상한이 있고 영구 보관이나 실제 사용자 열람 인증은 아닙니다.

## 받는 사람에게 전달할 파일

- `CodexOrbit.exe`: Python 설치 없이 실행하는 단일 파일입니다. 기본 지침, 사용법, 글꼴이 내장되어 있습니다.
- `CodexOrbit-Setup.exe`: 현재 사용자용 설치본입니다. 설치 위치를 선택하고 시작 메뉴 바로가기와 제거 기능을 사용할 수 있습니다.
- `기본_지침.md`: 개인 정보가 빠진 배포 기본 지침입니다. 자신의 MD를 대신 가져와도 됩니다.
- `사용법.md`, `배포안내.md`: 한국어 사용 문서입니다.
- `라이선스/`, `소스와_재빌드.zip`: 포함 구성 요소의 라이선스와 소스·재빌드 자료입니다. 재배포할 때도 함께 전달하십시오.

## 시작과 MD 적용

앱을 켜면 작은 회전 위젯이 나타납니다. 끌어서 옮기고 클릭해서 상세 창을 여십시오. 처음에는 기존 기록을 기준선으로 읽으며 과거 알림을 쏟아내지 않습니다. 이전 버전의 감시 상태는 원본을 백업하고 이미 읽은 위치까지만 선택 설정 기준선을 복원합니다. 기존 이력을 지우지 않으며 복원 중 추가된 변경은 이후 새 알림으로 처리합니다. 큰 기록은 ‘기준선 준비 중’으로 표시하며 처리 시간이 걸릴 수 있습니다.

MD 탭에서 지침을 가져오거나 편집하고 적용 대상 AGENTS.md를 선택합니다. 미리보기를 확인하고 적용 버튼을 누릅니다. 기존 내용은 백업하고 관리구역만 갱신합니다. 다른 프로그램이 파일을 변경하면 적용·원복을 거부하여 그 변경을 보호합니다. 다른 사람에게 윤석님의 원본 MD를 줄 때는 개인 이름·절대 경로·프로젝트·민감 정보부터 확인하십시오.

MD 파일 적용은 Codex의 설정·권한·인증을 바꾸거나 이미 열린 모든 채팅에 지침을 재주입하는 기능이 아닙니다. 새 채팅이나 해당 프로젝트를 다시 여는 시점의 지침 읽기를 통해 적용 여부를 확인하십시오. 앱은 모델 자체를 변경하지 않습니다.

## 기록과 한계

감시 대상은 현재 사용자의 CODEX_HOME 또는 기본 .codex/sessions입니다. 설정에서 경로를 바꿀 수 있습니다. 로컬 기록이 생성되어야 변경을 관측할 수 있으므로 설정 화면을 누르는 순간과 감지 시각은 다를 수 있습니다. 변경 이유가 명시적으로 연결되지 않으면 확인 불가로 표시합니다. 서버 실행 모델 인증과 비공개 내부 사고과정은 제공하지 않습니다. 표시되는 추론 정보는 기록된 추론 강도와 공개 변경 이유입니다. 네트워크로 대화나 MD를 보내지 않습니다.

‘채팅 선택 설정 변경’은 Codex가 해당 채팅 ID와 함께 남긴 설정 기록을 뜻합니다. 다음 실행의 로컬 모델 관측과 구분하며 변경 주체나 이유를 추정하지 않습니다. 같은 설정의 반복 기록과 뒤따르는 동일 실행은 중복 알림을 만들지 않습니다. 실행 관측이 선택값과 다르면 별도 관측으로 남깁니다. 감시 주기 대기는 200ms이며, 초기 기준선·대용량 파일·파일 읽기 예산과 화면 처리 시간 때문에 전체 지연이 200ms 이내라고 보장하지 않습니다.

사용자별 앱 데이터와 이력은 사용자 데이터 폴더에 보존됩니다. 설치본 제거는 프로그램 파일과 바로가기를 제거하며 앱이 적용한 지침·백업·이력을 자동 삭제하지 않습니다.

## 라이선스와 재빌드

Python, PySide6/Qt, PyInstaller와 나눔고딕을 사용합니다. 나눔고딕은 SIL OFL, PySide6/사용 Qt 라이브러리는 LGPLv3 등 각 구성 요소 라이선스를 따릅니다. Qt 수정본 분석과 교체를 막는 제한을 추가하지 않습니다. 함께 제공한 소스에서 `python -m venv work/venv`, 가상환경의 `python -m pip install -r requirements.txt`로 환경을 준비하고 `python -m PyInstaller --onefile --windowed --name CodexOrbit --add-data "assets;assets" --paths src src/app.py`로 재빌드할 수 있습니다. 다른 호환 PySide6/Qt를 설치한 뒤 같은 소스로 재빌드해 교체할 수 있습니다. 설치본 재빌드는 Inno Setup 6.7.3의 ISCC로 `tools/installer.iss`를 컴파일합니다. 자세한 구성과 고정 버전은 소스 압축 안 requirements.txt와 tools/build_distribution.py에 있습니다.

프로그램은 코드 서명 인증서 없이 제작한 배포본입니다. 사용자 PC의 보안 검사 결과나 실행 허용을 보장하지 않으며 보안 기능을 끄지 않습니다.

알림 카드에는 정확한 채팅 제목과 변경 종류를 먼저 표시하고 이전 값 → 새 설정을 크기·대비로 구분합니다. 추론 강도는 보통 (medium)처럼 한글과 기록된 원문을 함께 표시합니다. 한글 명칭은 앱의 표시 편의이며 공식 품질 보증이 아닙니다. 모델 ID와 공개 이유 원문은 상세에 보존하며, 이유가 없으면 확인되지 않음으로 표시합니다. 나눔고딕 Bold(700)를 유지합니다.


긴 알림 제목은 화면 안에서 가능한 높이까지 표시합니다. 화면을 넘는 제목은 말줄임표로 구분하며 마우스를 올리거나 정확한 변경 상세를 열면 전체 제목을 확인할 수 있습니다. 원본 제목·이력은 축약하지 않습니다. 내 지침 탭은 전체 본문을 세로로 스크롤하며 작은 창에서도 편집 영역140px·미리보기100px 이상의 높이를 유지합니다.

설정을 저장하면 이전 감시 작업자에 정상 종료를 요청하고, 실제 종료 신호 뒤 최종 저장한 설정으로 한 번 재시작합니다. 연속 저장은 마지막 설정을 사용하며 의도적인 재시작은 오류 재시도 횟수를 소모하지 않습니다. 안내는 재시작 대기 또는 감시 준비로 구분하며, 첫 정상 진행 상태를 받은 뒤에만 감시 중으로 표시합니다. 앱 종료 중에는 예약된 재시작을 취소하고 실제 오류에 대한 기존 자동 재시도 상한3회는 유지합니다.


13차는 사용자 최초 참고에 맞춘 세 교차 타원선과 검은 중심원, 12초 주기 연속 모션을 적용합니다. 11차에서 정리한 상단 탭과 좌측 변경 목록·우측 큰 상세 구조는 유지합니다. 큰 모델 별칭 아래에 정확한 모델 ID·추론 원문을 유지합니다. 근거는 펼쳐 읽으며 작은 창에서도 전체 내용을 세로로 스크롤할 수 있습니다. 화면의 수치는 실제 조회값이고, 모션은 중간 수치를 만들어 표시하지 않습니다.


12차는 정적 아이콘을 굵은 O자 궤도와 오른쪽 위 위성 표식으로 통일했습니다. 창·헤더·알림·설치 그림이 같은 브랜드 렌더를 사용합니다. 148×148 움직이는 캐릭터의 하단은 읽지 않은 알림이 있으면 ‘새 변경’, 그 외에는 실제 감시 상태에 따라 ‘감시 중’ 또는 ‘확인 필요’를 표시합니다. 수치는 실제 조회값을 유지하며 정적 아이콘에는 작은 숫자를 넣지 않습니다.

13차 외부 캐릭터는 최초 참고의 선형 타원 구도를 기준으로 합니다. 이전의 넓은 은색 리본·금속 면은 사용하지 않습니다. 원본의 파일 형식 라벨은 제품 기능이 아니므로 표시하지 않습니다. 정적 O자 궤도·위성 브랜드와 실제 잔량·하단 상태는 그대로 유지합니다.
