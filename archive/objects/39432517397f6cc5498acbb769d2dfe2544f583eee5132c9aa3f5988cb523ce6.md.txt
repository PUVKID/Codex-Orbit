# 📨 28차 변경 기록 · 2.11.0

알림에서 채팅 제목, 이전 모델·추론 강도, 현재 모델·추론 강도, 쉬운 이유를 바로 비교하도록 정리했습니다. ☀️ 솔·✨ 아스트라·🌍 테라·🌙 루나·🤖 기타 모델을 정확한 모델 ID와 함께 표시합니다. 날짜별 바탕화면 모션·감지·실제 사용 한도·위치·시계는 유지합니다.

## 실제 변경

- `src/app.py`: 알림의 중복 설정·작업·근거 행을 정리하고 여섯 정보를 중심으로 표시합니다. 긴 큐 안내문에서도 고정 폭에 맞춰 카드 높이를 계산해 모델·추론 글자가 잘리는 문제를 고쳤습니다.
- `src/notice_format.py`: 공개 이유와 기록된 작업만 요약하고 없는 이유를 만들지 않는 공통 표시 함수를 분리했습니다. 화면·검사용 예시·검사 조건처럼 뜻이 명확한 용어를 풀어 쓰고 원문은 툴팁·상세에서 보존합니다.
- `src/i18n.py`: 이모지 라벨과 쉬운 미기록 안내, 열린 창의 이전 헤더까지 한국어·영어 전환을 지원합니다.
- `src/notifier.py`: 기존 감지 부분을 유지하고 별도 NativeToast의 표시 XML만 같은 여섯 정보로 맞췄습니다. 이 레거시 경로의 실제 Windows 전달은 검증하지 않았으며 EXE의 Notice 표시와 구분합니다.
- `assets/사용법.md`, 한영 README·배포 안내를 갱신하고 설치 버전을 2.11.0으로 올렸습니다.
- `docs/연도별_월별_테마_전체.md`와 CSV: 실제 카탈로그의 2026~2099년 888개 월 테마를 간결한 표로 제공합니다. 설치본에도 표를 넣습니다.
- 공개용 표시 검사와 기존 큐 배치 검사를 포함합니다. 개인 대화 fixture가 들어 있는 전체 개발 검사는 공개 범위에서 제외하며 로컬에 보존합니다.

## 비교와 검증 범위

직전 공개 기준은 27차 `85d0bfb823085da22ffa5d53477cb300b27eb3d0`입니다. 27차는 배포 문서 수정이므로 앱 소스 비교는 26차와 같습니다. 공개 전체 diff는 공백·주석을 포함하며 파일 크기·SHA-256도 기록합니다. diff 자체의 해시는 별도 반영 영수증으로 확인합니다.

TDD 미구현 실패, 고정 80ms 비동기 대기 실패, 큐 높이 실패와 새 영어 기대문구 대소문자 작성 오류는 각각 보존했습니다. 고정 대기 검사에서는 기존 최소 프레임·도착·전달 단언을 유지하고 준비 조건을 최대 1초 동안 기다리도록 했습니다. 큐 높이·제목 보존·측정 캐시의 기존 검사 단언은 유지했습니다. 제품 렌더나 240fps 추가 달성 작업은 하지 않았습니다.

최종 전체·독립·배포 검사 결과와 실행 파일 크기·해시는 배포 검증 후 별도 공개 검증 요약에 연결합니다. 이 문서 저장만으로 원격 게시 완료를 의미하지 않습니다. 논문·원고가 없는 앱 변경이므로 새 PDF는 만들지 않습니다.

개인 대화·지침·메모리·인증·실제 위치·계정 수치·원본 운영 로그·비공개 전체 소스 ZIP은 공개하지 않습니다.

## 최종 공개 문서 대조 수정

독립 검토에서 남아 있던 한국어·영어 공개 검사 수87개를 실제104개로 고쳤습니다. 현재 파일 해시와 검사 안내 링크를28차로 연결하고 assets사용법이 현재 가이드라는 설명을 맞췄습니다. 안내문을 포함하는 단일EXE와설치본도 다시 빌드했습니다. 실행소스24개의 동작 변경은 없습니다. 이전 문서 불일치와 수정 중 동결 차이 및 문자열 입력 실패는 로컬 기록에 보존합니다.

## 추론 강도별 이모지 추가

진행 중 사용자의 추가 요청으로 none⚪/minimal💧/low🌱/medium⚖️/high🔥/xhigh🚀/ultra⚡를 이전·현재 값에 함께 표시합니다. 미확인 값은❔로 구분하며 원래 강도와 미기록 설명을 유지합니다. 표시 검사4개를 추가해 새 표시 검사16개, 공개108개·개발381개 구성입니다. 영문 NativeToast에서 잘리던 이모지를 위해 두 강도 필드의 예산만52로 조정하고 전체255 UTF-16 상한은 유지합니다. 합성 미구현 TDD 실패와 실제 영문 예산 실패를 구분해 보존합니다.
