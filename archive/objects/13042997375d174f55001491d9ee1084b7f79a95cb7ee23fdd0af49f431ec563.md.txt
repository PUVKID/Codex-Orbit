# Codex Orbit 사용 설명

실행하면 투명 배경의 작은 원자 궤도가 화면 위에 나타납니다. 나눔고딕 Bold 글꼴을 내장하며 인터넷으로 대화 내용을 전송하지 않습니다.

## 궤도 조작

- 마우스로 드래그하면 위치를 옮깁니다. 다음 실행에서도 위치를 기억하고, 모니터가 바뀌어 화면 밖에 놓이면 보이는 화면으로 복구합니다.
- 궤도를 클릭하면 변경 이력이 열립니다. 우클릭하면 설정과 종료 메뉴가 나옵니다.
- 중심의 작은 점은 정상 감시일 때 초록, 새 변경이 있을 때 분홍, 감시 오류일 때 주황입니다.
- 새 변경의 말풍선을 클릭하면 가장 최근 변경의 상세를 봅니다. 설정에서 말풍선을 끌 수 있습니다.
- 밝은 화면에서는 ‘밝은 배경’, 어두운 화면에서는 ‘어두운 배경’ 대비를 선택할 수 있습니다.

## 감시와 근거

기본은 CODEX_HOME 환경변수 또는 사용자 홈의 .codex/sessions 폴더입니다. 설정에서 실제 sessions 폴더를 선택할 수 있습니다. 최초 실행은 기존 기록을 기준선으로 읽으므로 과거 알림을 쏟아내지 않습니다. 폴더별 상태가 별도로 보존됩니다.

실제 turn_context의 모델과 추론 강도 변화, 새 세션의 첫 배정을 로컬 기록에서 감지합니다. 로그에 남기 전의 화면 설정 변경과 서버 내부 변경을 즉시 알 수는 없습니다. 부모에서 상속한 기록은 자식의 실제 턴으로 중복 처리하지 않습니다.

채팅 제목은 sessions와 같은 상위 폴더의 session_index.jsonl에서 확인한 값만 씁니다. 없으면 채팅 ID를 표시합니다. 기록에 공개 이유가 없거나 연결 근거가 부족하면 ‘확인 불가’입니다. 로컬 기록이나 명시 배정 요청은 서버 모델 신원 인증이 아닙니다. 비공개 추론을 추출하지 않습니다.

상세에는 채팅 ID, 역할·부모 ID, 전후 모델·추론 강도, 감지 시각, 공개 이유와 근거가 나옵니다. 앱 표시 요청과 사용자가 실제 화면을 읽었다는 확인은 다릅니다. 모바일 ChatGPT 푸시나 Windows 알림 센터 보관을 제공하지 않습니다.

이력은 화면에 최근 500개를 표시하며 파일 읽기도 최대 2 MiB로 제한합니다. 감시기는 파일당 읽기 예산과 전체 읽기 예산을 두고 큰 파일을 나누어 읽으므로 새 변경 감지가 지연될 수 있습니다. 이력·진단은 2 MiB 초과 시 이전 파일 하나를 보존하며 순환합니다. 전체 영구 보관이 아닙니다. 설정·진단 탭에서 최근 오류를 확인할 수 있습니다.

## Markdown 지침

‘MD 지침’ 탭에서 기본 지침을 읽거나 임의의 UTF-8 Markdown 파일을 가져와 편집할 수 있습니다. 잘못된 UTF-8과 2 MiB 초과 파일은 오류로 표시합니다. 내보내기는 UTF-8로 저장합니다.

프로젝트 폴더 또는 사용자 지침을 선택하면 대상 AGENTS.md 경로를 확인할 수 있습니다. 적용 미리보기에서 적용 후 전체 문서를 확인하고 ‘미리본 대상에 명시 적용’을 눌러야 파일이 바뀝니다. 기존 원문 바이트는 앱 데이터의 backups에 보존합니다. 기존 내용은 유지하고 CODEX-ORBIT 관리구역만 추가·교체합니다. 심볼릭 링크·정션·재분석 경로에는 적용하지 않습니다.

미리보기 뒤 대상이 바뀌면 적용을 거부합니다. 새 미리보기를 확인해 주세요. ‘백업 선택 · 원복’은 적용 후 현재 해시가 그대로일 때만 원문 바이트를 복원합니다. 그 뒤 직접 바꾼 파일은 덮어쓰지 않습니다. 새로 만든 AGENTS.md를 원복하면 해당 새 파일을 제거합니다. 백업 파일은 남습니다.

지침 파일 저장은 열린 대화의 재주입, 계정·기기 동기화, 권한 증가, 자동 모델 전환을 보장하지 않습니다. auth, config, hooks와 신뢰 설정은 수정하지 않습니다.

## 데이터와 배포

앱 설정·위치·감시 상태·이력·백업은 기본적으로 현재 사용자의 LocalAppData/CodexOrbit에 저장합니다. 배포 EXE에 개인 대화·원본 개인 지침을 포함하지 않습니다. 제거 프로그램은 사용자 지침과 이력을 삭제하지 않습니다.

시험 실행에는 --data-dir, --sessions를 지정할 수 있습니다. --smoke-test --smoke-report 경로 옵션은 약 1초 동안 두 프레임의 변화·투명 모서리·내장 글꼴을 검사하고 JSON을 저장한 뒤 종료합니다. 실제 사용자 알림 수신의 증거는 아닙니다.
