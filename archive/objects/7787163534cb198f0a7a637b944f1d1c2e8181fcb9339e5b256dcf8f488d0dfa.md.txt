# 모델 변경 알림 요구 사항과 설계

확인일: 2026-10-21. 사용자 요청: 모델 또는 추론 강도 변경마다 이전/이후 값과 이유를 Windows 알림으로 표시하고 아이폰 ChatGPT 앱에서도 수신 가능성을 확인하여 연결한다.

이 프로젝트는 기존 Codex 모델 라우팅 3차와 별개다. 이전 결과, 모델 설정, 인증, 권한, 신뢰 저장소, Stop 훅을 변경하지 않는다. 기존 채팅을 재개하지 않는다.

## Windows

- 현재 사용자 `.codex/sessions` 로컬 JSONL의 실제 `turn_context`를 읽기 전용으로 감시한다. 서버 실행 모델 인증으로 표현하지 않는다.
- 최초 실행은 기존 기록을 기준선으로 삼고 과거 변경을 알림으로 쏟아내지 않는다. 새 채팅의 첫 모델은 최초 배정으로 구분한다. 같은 모델/강도 유지에는 알림을 만들지 않는다.
- `payload.model`, 실제로 확인된 추론 강도 필드와 세션 ID를 사용한다. 상속된 부모 기록은 자식의 별도 실행으로 중복 처리하지 않는다.
- 변경 사유는 명시적 알림 기록 또는 해당 변경과 확실하게 연결된 공개 배정 설명만 쓴다. 미기록·앱 수동 변경·서버 변경 사유는 확인 불가다. 비공개 추론을 추출하지 않는다.
- Windows 알림에는 작업/채팅, 이전/이후 모델·강도, 이유와 근거 수준을 표시한다. 긴 설명은 완전한 로컬 이력으로 보존한다.
- 감시 상태와 이력은 `work/` 아래 UTF-8로 원자 저장하며 재시작 중복을 방지한다. 물리적 LF만 분리하고 미완성 마지막 레코드는 기다린다. 잘못된 중간 JSON/UTF-8은 진단 기록으로 남긴다.
- 제한된 읽기·출력과 재시도, 단일 인스턴스, 숨김 시작, 사용자 로그인 자동 시작과 명시 중지/제거 수단이 필요하다. 외부 서버로 대화 내용을 보내지 않는다.
- 알림 전송 API 성공과 실제 사용자 화면 수신을 구분한다. Windows 집중 모드와 시스템 알림 차단을 우회하거나 전역 설정을 바꾸지 않는다.

## 아이폰 ChatGPT 앱

공식 notifications/mobile/hooks 문서에서 작업 완료·질문·권한 알림 및 연결된 PC 접근은 확인했다. 모델/추론 강도 변경용 임의 푸시 발송 API는 확인되지 않았다. 지원 API 없이 인증 토큰 추출이나 내부 비공개 API 호출로 만들지 않는다. 다른 앱 알림을 ChatGPT 수신이라고 하지 않는다. 모바일 실제 수신은 사용자의 기기 확인 없이는 검증 완료로 기록하지 않는다. 대안 서비스는 별도 사용자 선택이 필요하다.

## 검증

실제 JSONL 형태의 모델만 변경·강도만 변경·변경 없음·최초 상태·부모 상속·LF/U+0085·분할 UTF-8·잘못된 레코드·재시작·알림 실패 경로를 검사한다. Windows 실제 테스트 알림을 별도로 보내고 OS 이력/사용자 수신을 구분한다. 구현자와 다른 verifier가 최종 소스를 검토하고 중앙 검증 도구로 영수증을 발행한다.
