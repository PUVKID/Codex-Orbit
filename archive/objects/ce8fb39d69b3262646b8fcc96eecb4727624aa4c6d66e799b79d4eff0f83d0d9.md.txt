# 위젯 현재 기온·시계 추가 명세

2026-10-28 윤석님이 기존 수정 도중 현재 위치의 현재 기온과 현재 시각을 추가로 요청했습니다. 기존 운영 멈춤·크기 조절·888테마 요구를 대체하지 않습니다.

- 사용자 후속 정정에 따라 Windows 위치 서비스를 사용하지 않고 연결된 인터넷의 공개 IP에 대응하는 대략적인 지역을 자동 조회합니다. HTTPS ipwho.is 무료 엔드포인트에서 현재 접속 지역을 읽습니다. Windows 위치 서비스가 꺼진 환경도 지원해야 하며 권한·서비스·신뢰 설정을 변경하지 않습니다. 위치 조회 실패나 시간 초과를 실제 상태로 표시하고 다른 도시의 기온으로 대체하지 않습니다. 네트워크 기반 추정 위치임을 툴팁과 사용법에 명시합니다.
- 좌표는 기온 조회에만 사용하며 경로 이력이나 좌표 로그를 새로 저장하지 않습니다. HTTPS의 무료 Open-Meteo current.temperature_2m 값을 섭씨로 표시합니다. 해당 값은 제공처의 최신 현재 기온 자료이며 초 단위 현장 온도 센서 측정으로 표현하지 않습니다. 네트워크 기온은 기본5분마다, 위치도 각 갱신 시 새로 확인합니다.
- 사용자에게 필요한 값은 현재 기온 하나입니다. 바탕화면에는 기온과 조회 상태만 간결하게 표시하며 상세 예보·추가 탭·설정 기능을 임의 추가하지 않습니다. 마지막 성공 시각·출처·위치 오류는 필요한 툴팁으로 확인할 수 있게 합니다. 오래된 값은 최신 값으로 표시하지 않습니다.
- 현재 시각은 Windows의 현지 시각으로 초 단위 표시합니다. 날짜·실제 조형 이름·현재 시각·현재 기온·실제 계정 잔량을 서로 겹치지 않게 배치합니다. 이름16픽셀, 나머지 주요 글자14픽셀 이상을 유지하고 긴 이름은 줄바꿈합니다. 최소 크기와 기본 크기는 정보 영역을 모두 담도록 조정할 수 있으며 폭·높이 독립 조절과 저장을 보존합니다.
- 위치·네트워크 조회는 GUI 스레드를 막지 않고 유한 시간 안에 종료되는 작업자로 수행합니다. 종료 뒤 UI 접근·미종료 프로세스·무제한 재시도·무제한 캐시를 남기지 않습니다. 기존30초 기능/15초 소스/45초 합산 기준은 유지합니다.
- 성공·권한 거부·위치 없음·위치/네트워크 시간 초과·잘못된 온도/좌표·오래된 값·종료 경계를 검증합니다. 반복 네트워크 호출을 전체 회귀에 넣지 않으며 실제 한 번의 위치·기온 조회는 별도 증거로 보존하되 좌표는 출력하지 않습니다. 서로 다른 크기에서 모든 표시 영역과 폰트·막대 실제 비율을 확인합니다.

공식 근거: Microsoft Learn 위치 권한 문서를 확인한 뒤 사용자 정정으로 Windows 의존을 제외했습니다. ipwhois.io/documentation의 HTTPS·자기 IP 생략 조회·무료 일일1000회 제한과 Open-Meteo Forecast API를 확인했습니다. 전용 날씨·위치 플러그인 기능은 현재 노출 도구에서 확인되지 않아 공개 HTTPS API를 사용합니다.
