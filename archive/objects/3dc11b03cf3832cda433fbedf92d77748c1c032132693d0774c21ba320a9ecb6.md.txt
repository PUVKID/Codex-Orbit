# 17차 실제 3D 모델과 모션 브랜드 통일

2026-10-26 직접 요청: 바탕화면 위젯과 앱 안의 아이콘 등 전체를 실제 3D 모델링과 모션 그래픽으로 디자인합니다. 기존 자율 실행 지시를 적용해 추가 시안 승인 질문 없이 진행합니다. 부모의 디자인 선택이며 사용자께서 개별 새 시안을 승인했다고 표현하지 않습니다.

## 기준과 선택

사용자가 처음 제시한 세 교차 궤도와 어두운 핵, 이후 확정한 무채색 금속·원자/화학·투명 정사각형을 유지합니다. 16차는 링 회전축이 대부분 Z방향이고 앱 로고는 frame0 정지 QPixmap입니다. 실제 메시와 곡면 법선·깊이·표면 반사로 입체감을 강화하고 앱에서도 같은 모델이 움직이게 합니다. 핵의 실제 잔량 숫자는 고정하며 모션으로 가짜 중간값을 만들지 않습니다.

설치된 Game Studio의 web-3d-asset-pipeline 지침과 Khronos glTF2 공식 명세를 확인했습니다. 기존 OpenGL 오프스크린 제작과 제한 캐시 PNG 재생을 유지하고 원본 GLB를 제공합니다. 네이티브 앱을 WebView로 전환하거나 다른 게임 엔진을 붙이지 않습니다. 실행 중 실시간 3D 렌더와 제작된 3D 모션 프레임 재생을 구분합니다. Windows .ico/바탕화면 바로가기/트레이는 정적 대표 렌더이고 실행 위젯·앱 로고·알림은 애니메이션입니다.

## 요구와 성공 조건

- 148×148 투명 위젯 안에서 금속 세 링이 서로 다른 축/방향/속도로 움직입니다. 같은 평면 판 전체의 회전처럼 보이지 않아야 합니다. 서로 독립적이되 지나친 속도나 복잡한 장식은 피합니다.
- 실제 굵기/옆면/곡면 반사와 앞뒤 깊이 가림이 보이고 어두운 핵·절제된 전자 3개가 원자 모형을 연상시킵니다. 색깔 공·가짜 원소 기호·가짜 원자번호를 추가하지 않습니다.
- 앱 상단과 알림의 브랜드를 같은 모델의 모션으로 통일합니다. 모델/추론/시간/이유/잔량/갱신 같은 기존 기능 표식은 읽기 쉬운 무채색 입체 기호로 통일하되 버튼의 텍스트와 접근성 이름을 유지합니다. 작은 아이콘은 주기 변화가 식별되는 32~48px를 사용하고 텍스트 영역을 침범하지 않습니다.
- 나눔고딕 Bold700, 두 탭, 이전/새 모델과 이전/새 강도, 첫 관측 구분, 정확 ID/제목/공개 이유, 독립 동시 알림, 선택 순간 감지, 실제 잔량/지연/미확인과 MD 보존을 유지합니다.
- 숨김 창은 애니메이션 갱신을 멈추고 종료 시 타이머가 남지 않아야 합니다. 공유 프레임 캐시는 기존24장 상한을 유지합니다. 원래 전체30초/소스15초/총45초 및 종료25ticks/550ms/8초 기준을 약화하지 않습니다.

## 책임과 인터페이스

Astra/medium은 tools/render_atom3d.py, tools/atom3d_glb.py 및 assets/atom3d만 소유합니다. 296×296 RGBA, 540장,30fps,18초와 manifest 필드를 유지하고 새 자산은 별도 work 출력에서 만든 뒤 검증해17차로 반영합니다. 위젯 논리 외곽 반경60px와 여백을 지킵니다. 형상을 바꾸면 metadata와 GLB도 같은 값으로 맞춥니다. 실제 미리보기를 부모에게 제시한 뒤 전체 제작합니다.

기능 아이콘도 실제3D모델링 요청을 적용합니다. 자산 담당자의 소유를 tools/render_symbols3d.py와 assets/icons3d로 넓혀 모델 큐브·추론 계층·시계·이유 문서·한도 게이지·갱신 화살표·기록 카드의7종을 실제 메시와 금속 조명으로 제작합니다. 각96px RGBA 렌더와 GLB·형상/조명/해시 명세를 포함하고 앱의20~24px에서 직접 판독합니다. 이 기능 표식은 정지 입체 기호이며 주의 분산을 피합니다. 모션은 원자 로고/위젯/알림에서 공유합니다. build는 이 PNG를 사용하며 평면 그라데이션 그림으로 최종3D모델링을 대신하지 않습니다.

build Sol/medium은 src/brand.py·visuals.py·app.py의 시각 연결, 최소 theme, 관련 tests, tools/generate_visual_assets.py 및 assets/Orbit.ico·설치 브랜드 이미지를 소유합니다. 기존 core/notifier/usage/MD/감시 수명주기와 이전값 논리를 바꾸지 않습니다. 자산 변경과 metadata가 충돌하지 않도록 서로 맞춥니다. 다른 작업자의 변경을 되돌리지 않으며 추가 작업자를 만들지 않습니다.

부모는 docs/상태/증거/실행 의존성/버전2.3.0/배포/실제 실행 교체를 소유합니다. 과거2차venv가 삭제돼 이번17차 work/venv로 동일 Python3.12·기존 정확 패키지 버전을 복구합니다. 중앙 검사 argv의 Python 경로만 실제 새 경로로 갱신하고 검사·시간·수락 기준은 유지합니다. verifier Sol/high는 제품 수정 없이 원본 기능과 최종 화면을 독립 검증합니다.

## 최종 선택 모션과 과거 표본 검사의 대조

부모가 실제148px·확대·밝고어두운 배경의 v1/v2를 열어 동심원 구간을 줄인 v2를 채택했습니다. 최종 자산의 정확 값은 axis42/46/49도,cone10/12/13도,초기 기울기52/58/62도이며 동일 행렬로 GLB·PNG·motion 데이터를 제작했습니다. 이 선택은 사용자 직접 시안 승인으로 표현하지 않습니다.

원본 전체175검사에서 14차의 첫링2초 법선 제곱차>.05 검사가 실제.014109로 실패했습니다. 선택한 새 모션의 해당 최대 변화량은18초 전체에서.120615이고 상대 투영각 폭24.073도·법선 내적 폭.530144·모든제작정합은 충족했습니다. 수리49에서 기존.05하한을 낮추지 않고 링별 반주기(9/4.5/3초)에 대조하며18초540개 전체 표본의 단위 법선과 제작motion정합을 추가합니다. 이전2초기대와FAIL은 원문으로 보존하고 정확2초도 제작정합 비교에서 제외하지 않습니다. 공통회전불가·상대각20도·법선내적.15·loop와 모든 기능·시간·종료 기준은 유지합니다. 별도 verifier가 이 디자인/검사 대상 변경의 타당성을 판단합니다.
