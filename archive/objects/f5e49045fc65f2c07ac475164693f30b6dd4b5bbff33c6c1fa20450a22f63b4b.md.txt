# 26차 2.10.0 공개 검증 요약

이 문서는 2026-10-30의 로컬 개발·배포 검증 자료를 공개 가능한 범위로 요약한 것입니다. 원본 운영 로그·개인 대화·실제 계정 수치·실행 PC 식별 자료는 포함하지 않습니다. 27차 문서 정리를 제품 재검증이나 새 배포 실행으로 중복 집계하지 않습니다.

## 검사 범위와 결과

| 범위 | 확인한 결과 | 해석과 한계 |
| --- | --- | --- |
| 개발 전체 회귀 | 구성 365개 검사 ID, 개발 실행 오류 0·건너뜀 1 | 비공개 fixture를 포함한 원본 범위입니다. 건너뜀은 Windows 심볼릭 링크 생성 권한 부족입니다. 공개 저장소의 tests만으로 365개를 재현할 수 있다는 뜻이 아닙니다. |
| 공개본 회귀 | 기존 87개 오류 0; 2026-11-02 재실행 87개, 7.982초, OK, 종료 코드 0 | 공개 허용된 선별 검사 범위입니다. 27차 재실행의 외부 프로세스 시간은 10.547초이며 기존 QImage.mirrored 폐기 예정 경고는 오류와 구분합니다. 개발 전체 회귀의 대체가 아닙니다. |
| 독립 중앙 기능 회귀 | 27.125초, 종료 코드 0 | 전체 discover 실행의 통과 상태를 확인했습니다. 출력 57,481바이트 중 4,096바이트만 보존되어 이 중앙 실행의 최종 검사 개수·skip 줄을 직접 확인했다고 말할 수 없습니다. 구성 365개는 별도 ID 목록과 개발 실행 근거입니다. |
| 독립 중앙 소스 정확성 | 127개 파일, 0.860초, 종료 코드 0 | 엄격 UTF-8과 Python 구문 검사입니다. 23개 앱 소스 파일 수와 다르며 의미상 완전 무오류 보장이 아닙니다. |
| 배포 실행 | 단일 모션·한국어 한도 조회·영어 설치·설치본 모션·제거·영어 한도 조회 6단계, 각각 종료 코드 0 | 기존 실행·설치·제거와 사용자 자료 보존 근거입니다. 임의의 모든 PC·그래픽 장치에서 같은 결과를 보장하지 않습니다. |

독립 중앙 검증은 기능 30초·소스 15초·총 45초 기준을 유지했습니다. 앞선 30.157초 및 30.875초 기능 시간 초과와 수집 오류 이력은 보존하며, 최종 통과로 과거 실패를 삭제하거나 수집기 원인이 해결됐다고 주장하지 않습니다. 검증 시 소스가 바뀌지 않았음을 확인한 로컬 운영 기록은 서버 모델 신원 인증이나 자동 Stop 실행 증거가 아닙니다.

공개 루트 `src/`는 Python 23개입니다. 역사 스냅샷과 전체 개발 도구·문서가 포함된 수를 현재 앱 모듈 수로 세지 않습니다. 27차에서도 앱 소스·검사·자산·기존 바이너리는 보존합니다.

## 기능 검토와 한계

회전 배율 0.25~3배·저장/복원·무효 입력 거부·저장 실패 안내·한영 전환과 위상 연속성, 기존 알림·시계·날씨·사용 한도의 경계를 검토했습니다. 실제 한도는 계정 사용 한도의 남은 퍼센트이며 남은 토큰 개수가 아닙니다.

4K는 GPU 원본 3840×2160을 뜻합니다. 240fps는 페이싱 목표이며 고정 달성은 하지 못했습니다. 최근 생성 약 227~230fps, 고유 Qt 그리기 약 214~229fps이고 물리 모니터 표시율을 측정한 수치가 아닙니다. 고정 240fps 추가 달성 작업은 제외됐습니다. 날짜 27,028일·888연월은 카탈로그와 형상 생성 규칙의 검증이며 모든 날짜 실렌더·888개 수작업 모델을 의미하지 않습니다.

## 기존 배포본 식별

아래 값은 26차 로컬 `SHA256.json`과 독립 검토 자료에서 대조한 값입니다. 배포본은 [2.10.0 Release](https://github.com/PUVKID/Codex-Orbit/releases/tag/v2.10.0)로 연결합니다. 원격 게시와 해시 일치 여부는 배포 완료 단계에서 별도로 확인합니다. 기존 EXE를 다시 빌드했다는 뜻은 아닙니다.

| 파일 | 바이트 | SHA-256 |
| --- | ---: | --- |
| `CodexOrbit.exe` | 81711197 | `320ffe22db22fbdcf4b6a0af266557e82e89a1cc940c2aeec4feba27487fedcb` |
| `CodexOrbit-Setup.exe` | 84266777 | `e7a81104b30b74b0b2a37e93e8a14b3c05578fb2659ee76087f620f5280c2be5` |

원본 약 604 MB 전체 소스 ZIP에는 공개 범위 밖의 자료가 포함되어 공개하지 않습니다. 개인 대화 fixture·운영 지침·메모리·인증·실제 위치·계정 사용량·원본 로그도 제외합니다. 공개본의 소스와 라이선스는 [공개 범위](../공개범위.md), [현재 공개 사용법](사용법.md), [26차 실제 변경](../변경기록_26차.md)에서 확인합니다. 기존 권리 고지는 보존하며 새 소스 라이선스를 부여하지 않습니다.

근거는 보존된 26차 최종 독립 검증 결과·중앙 영수증·현재 영수증 대조, 배포 최신 경로 명세가 가리키는 6단계 실행 결과 및 배포 SHA-256 명세입니다. 이 요약은 비공개 원문 로그의 공개본이 아닙니다.
