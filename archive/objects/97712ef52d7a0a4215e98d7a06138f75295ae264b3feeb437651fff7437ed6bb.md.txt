# 26차 공개용 변경 기록

기준: 보존된25차 소스. 파일의 실제 바이트 차이를 비교했습니다. 배포 검증 결과는 아래와 같으며, 독립 검증과 원격 일치는 별도 로컬 영수증으로 관리합니다.

## 동작과 화면

- 회전 속도0.25~3배 슬라이더·우클릭 선택·기본1배 복원 및 저장·재시작 적용을 추가했습니다.
- 한국어·영어 표시, 저장 실패 시 이전 배율 복원과 화면 안내를 추가했습니다.
- 속도 변경 시 재생 위상을 이어가며 실제 날짜·시계·한도·날씨 주기는 유지합니다.
- 정적 정보 레이어는 입력이 바뀔 때 교체하며 모션 원본은 계속 새로 그립니다.
- 히어로의 같은 크기 이미지 교체는 부모 배치 재요청을 피하며 기본 Qt 라벨과 픽셀·표시 계약을 대조했습니다.

## 검증과 현재 한계

- 전체365검사에서 오류0·건너뜀1, 공개 소스87검사에서 오류0을 확인했습니다. 원본 픽셀90조건 대조와 실제 배포6단계(단일 실행·잔량·설치·설치본 실행·제거·영문 잔량)를 통과했습니다.
- 최근 실창 측정은 생성 약227~230fps, 고유 Qt 그리기 약214~229fps로 고정240fps에 미달합니다. 물리 모니터 표시율과는 별개입니다.
- GPU 초기 준비를 재생 측정에 포함한 기존 검사 실패를 보존하고, 첫 준비 성공 검사를 추가한 뒤 기존180ms·70ms 재생 조건을 유지했습니다.
- 차수별 공개 보존 소스의 전체 차이·설명·파일 목록은 첫 화면 README에서 연결합니다. 고정240fps 달성을 위한 추가 시도는 사용자 요청으로 제외했습니다.

실제 클래스 fixture에서 두 독립 종료 프로세스를 시작하고 기존 결과 검사 두 개만 마지막으로 배치해 대기를 겹쳤습니다. 전체365개 검사 ID와 나머지 검사 순서는 유지했습니다. 기존 코드 원문·단언·개별 제한은 유지하며 제품 코드는 이 조정으로 바뀌지 않습니다.
배포 안내의 차수 링크100개와 변경 기록은 GitHub 웹 주소로 연결해 설치 폴더에서도 열 수 있습니다.
