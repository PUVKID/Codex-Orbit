# Codex Orbit 사용 설명 · 16차 / 2.2.1

금속 곡면의 세 링과 흑연 원자핵, 전자 입자가 움직이는 투명한 무채색 위젯입니다. 실제 3D로 제작한 18초 모션을 재생하며 링은 각기 다른 축·방향·속도로 회전합니다. 중심의 숫자는 고정하며 실제 조회한 Codex 계정의 남은 사용 한도 비율만 표시합니다. 글꼴은 내장 나눔고딕 Bold700입니다.

## 화면과 조작

- 위젯을 끌면 위치가 바뀌고 다음 실행에서도 기억합니다. 화면 밖으로 이동한 위치는 보이는 모니터 안으로 복구합니다.
- 위젯을 누르면 변경 기록이 열립니다. 우클릭 메뉴에는 기록 열기와 종료처럼 필요한 조작만 둡니다.
- 화면은 ‘변경 기록’과 ‘사용 한도’ 두 탭만 사용합니다. 설정·내 지침·도움말 화면은 제거했습니다.
- 변경 기록에서 정확한 채팅 제목, 이전/새 모델 ID, 이전/새 추론 강도, 공개 이유를 확인합니다. 원문·ID·근거는 펼쳐 읽을 수 있습니다. 공개 이유가 없으면 임의로 만들지 않습니다.
- 긴 제목은 가능한 영역에 표시하고 화면을 넘으면 명시적으로 줄입니다. 상세와 원문은 보존합니다.
- ‘감시 중’, ‘새 변경’, ‘확인 필요’는 실제 감시/읽지 않은 기록 상태에 따른 문구입니다. 연결·기준선 준비·지연·실패를 정상으로 표시하지 않습니다. 오류 진단은 변경 기록 화면에서 확인합니다.

## 모델·추론 변경 알림

현재 사용자의 로컬 Codex 기록에서 선택 설정의 변경이 기록되면 다음 메시지 실행을 기다리지 않고 알립니다. 200ms 감시 주기와 실제 파일 쓰기·부하·UI 표시 지연이 있으므로 0ms 즉시 전달을 보장하지는 않습니다. 일반 채팅과 자식 작업의 모델만·강도만·동시 변경을 구분하며 후속 실행에서 같은 선택을 중복 알리지 않습니다. 앱은 모델을 바꾸는 도구가 아닙니다.

처음에는 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 기존 감시 상태·이력과 읽은 위치를 보존하며 큰 기록의 준비에는 시간이 걸릴 수 있습니다. 같은 감지 묶음은 유효한 원본 기록 시각 순으로 안정 정렬하고, 시각이 없거나 잘못되면 감지 위치를 유지합니다. 늦게 읽은 파일 때문에 이미 표시한 알림을 재정렬하지 않습니다.

변경마다 별도 알림이 나타나 앞 알림을 닫을 필요가 없습니다. 공간 안에 쌓고 부족하면 어긋나게 겹칩니다. 동시 최대8장, 초과 시 오래된 창을 숨기고 최신 알림을 바로 표시합니다. 숨긴 건수와 이력을 유지합니다. 각 알림의 닫기·클릭·만료는 다른 알림에 영향을 주지 않습니다. 기본 표시 시간은30초이며 기존 사용자 설정은 보존합니다. 알림을 누르면 그 항목의 정확한 기록이 열립니다.

감시 진행이20초 이상 없으면 지연을 표시하며 실제 종료된 작업자만 최대3차례 재시도합니다. 정체된 실행 작업자를 임의 강제 종료하지 않습니다. 이전 정체의 역사적 최초 원인은 확정되지 않았으며 진단과 실제 관측을 구분합니다.

## 실제 잔량

현재 로그인된 Codex 계정의 사용 한도 비율입니다. 남은 토큰 개수가 아닙니다. 여러 버킷·기간이 있으면 확인된 값 중 가장 낮은 남은 비율을 중심에 표시합니다. ‘사용 한도’에서 기간·버킷별 막대, 초기화 한국 시각, 최종 조회 시각과 수동 새로고침을 확인합니다. 서버가 주간만 주면 주간만 표시합니다.

설치된 Codex의 공식 App Server에 숨김 연결해 읽기 전용 account/rateLimits/read만 조회합니다. 최초 실행 후30초마다 자동 조회하고 서버 갱신 알림도 반영합니다. 설치된 Codex의 ChatGPT 로그인이 필요합니다. 앱은 인증 파일을 직접 읽거나 복사하지 않으며 로그인·리셋·구매·모델 실행·Codex 설정 변경을 하지 않습니다.

미확인은 ‘—’, 지연된 이전 수치는 ‘?’와 이전 조회 표시를 사용합니다. 초기화 시각이 지나도 임의로100%를 만들지 않습니다. 잔량을 디스크에서 복원하는 캐시는 사용하지 않습니다. 모션 장식의 중간값을 실제 잔량으로 표시하지 않습니다. 미리보기의53%·81% 등은 예시라고 표시한 경우 시연 숫자입니다.

## 지침·설정과 데이터

설정·MD·도움말 UI를 노출하지 않습니다. 기존 설정과 사용자 MD·백업은 삭제하거나 초기화하지 않습니다. 지침을 몰래 적용하지 않습니다. 앱 밖 운영 기록은 프로젝트 docs/운영_기억.md에 보존하며 계정 전역 메모리 저장이나 모든 대화의 지침 재주입을 뜻하지 않습니다.

기본 앱 데이터는 현재 사용자의 LocalAppData/CodexOrbit입니다. 감시 경로와 Codex 실행 파일은 기존 설정 및 자동 탐색을 사용합니다. 별도 감시 경로가 필요한 실행에는 --sessions 경로, 독립 데이터에는 --data-dir 경로를 지정할 수 있습니다. 공유할 때 개인 대화·계정·원본 사용자 데이터는 배포 파일에 포함하지 않습니다.

감시는 현재 설정된 sessions 디렉터리와 대응 session_index.jsonl의 로컬 기록 범위입니다. 다른 PC·원격·클라우드, 로컬에 기록되기 전 UI 선택, 서버 내부 모델 신원과 비공개 추론은 보장하지 않습니다. 파일 수4096개·레코드2MiB·주기별 읽기 예산이 있으며 상한/잘못된 기록은 진단에 남깁니다. 화면 이력은 최근500건입니다. startup.jsonl과 notice-presentations.jsonl은2MiB 순환 상한의 운영 기록이며 표시 요청은 사용자 실제 열람 인증이 아닙니다.

## 배포와 진단

CodexOrbit.exe는 Python 설치 없이 실행합니다. CodexOrbit-Setup.exe는 현재 사용자용 설치·시작 메뉴·선택 바탕화면 바로가기를 제공합니다. 제거 프로그램은 사용자 MD·백업·이력을 삭제하지 않습니다. 소스ZIP과 라이선스도 함께 제공합니다. 이 사용법은 배포 문서이며 앱 내부 도움말 탭은 없습니다.

--smoke-test --smoke-report 경로는 실제 EXE의 프레임 변화·투명 모서리·내장 글꼴을 검사하고 종료합니다. --usage-smoke-test는 실제 계정 조회·화면 표시를 저장하는 별도 진단이며 실제 사용자 알림 수신 증거는 아닙니다. --show-event 이벤트ID 또는 대상ID는 기존 이력을 다시 표시하며 새 관측이나 실행 중 앱에 명령 전달을 만들지 않습니다.

16차 수정: 모델·추론 변경의 이전값과 새값을 각각 구분해 표시합니다. 이전 기록이 없는 첫 관측은 실제 변경과 구분하며 과거값을 임의로 채우지 않습니다. 금속 원자 모션과 감시·계정 조회 및 보존 자료는 유지합니다.

17차 디자인: 실제3D 금속 원자 모델의 세 링이 서로 다른 축으로 움직이며 앱 상단과 알림도 같은 모션을 공유합니다. 기능 아이콘은 무채색 입체 표식으로 통일했습니다. 실행 위젯과 앱 안 로고는 움직이고 Windows 바로가기·실행파일·트레이 아이콘은 같은 모델의 정적 렌더입니다. 이전/새 모델과 추론 강도 및 실제 조회 수치의 의미는 유지합니다.
