# Codex Orbit 제작 계획

확인일: 2026-10-24. 사용자가 설계 방향을 승인하고 설명에 그치지 말고 실제 단일 EXE와 설치형 제작을 요청했습니다. 저장 위치는 최신 요청에 따라 D 드라이브입니다.

## 요구 사항과 성공 조건

- 배경·테두리가 투명한 약 140px 상시 표시 창에 굵은 궤도 3개와 중심 심볼을 그립니다. 시간에 따라 모양이 변하는 연속 회전이며 첨부 그림 자체를 편집하거나 정지 이미지로 대체하지 않습니다.
- 드래그 위치 기억, 클릭 상세 이력, 우클릭 종료·설정, 다중 모니터 화면 밖 위치 복구를 제공합니다.
- 기존 1차 감시기를 복사하여 관측/명시 요청 기준선 분리, 최초 기준선, LF와 UTF-8 경계, 상속 중복 제외를 유지합니다. 과거 폴더·실행 상태는 수정하지 않습니다.
- 로컬 모델·추론 강도·채팅·역할·이유·출처를 표시합니다. 미기록 이유는 확인 불가이며 서버 신원 인증이나 비공개 추론을 제공한다고 주장하지 않습니다.
- MD UTF-8 가져오기·편집·내보내기와 실제 AGENTS.md 적용을 제공합니다. 고유 관리구역을 사용하고 기존 원문을 바이트 백업합니다. 미리보기 뒤 동시변경 시 거부하며 심볼릭 링크·정션 경로는 거부합니다. 원복도 적용 후 해시 확인을 거칩니다.
- 배포 기본 지침은 개인 이름·경로를 제외한 범용 내용입니다. 사용자 원본 개인 MD를 자동 유출하지 않습니다. auth/config/hooks/신뢰를 수정하지 않습니다.
- 기본 프롬프트와 사용설명은 EXE 안에 포함하고 외부 MD로도 제공합니다. 나눔고딕 Bold 700과 라이선스를 포함합니다.
- 단일 EXE는 Python 설치 없이 실행되어야 합니다. 설치형은 현재 사용자 설치/바로가기/제거를 지원하며 사용자 이력과 지침을 제거하지 않습니다.

## 구조와 선택 이유

기존 Python 감시기를 유지하기 위해 PySide6를 사용합니다. QPainter와 타이머가 투명 궤도를 그리고 QThread가 디스크 감시를 맡아 애니메이션을 막지 않습니다. PyInstaller 단일 파일로 런타임·Qt·글꼴·MD를 묶고 Inno Setup으로 설치형을 만듭니다. 실행 데이터는 사용자별 디렉터리에 저장하며 다른 사용자의 기록을 포함하지 않습니다.

## 작업 순서

1. build 작업자는 src/notifier.py, src/core.py, src/app.py, assets/, tests/, tools/check_sources.py를 담당합니다. MD 백업·충돌·원복과 이벤트 연결의 실패 경로를 먼저 검사하고 구현합니다.
2. 부모는 D 드라이브 전용 빌드 환경, docs/, 설치 스크립트와 배포 문서, 중앙 라우팅 상태를 담당합니다. 기존 1차를 보존합니다.
3. 구현자 직접 전체 검사 후 소스를 동결합니다. 부모는 단일 EXE를 빌드하고 실제 GUI/애니메이션과 모의 세션 변경, 설치·실행·제거를 점검합니다.
4. 다른 verifier 작업자가 요구별 검토와 실제 검사를 수행합니다. 실패는 기록하고 원인을 조사·수리한 후 새로 동결·검증합니다.

## 검증 초점

잘못된 UTF-8, 손상/미완성 JSONL, 상속된 부모 기록, 기존 지침의 동시 수정, reparse 경로, 사용자별 데이터 분리, 새 시작 알림 폭탄, 설치 해제 후 사용자 지침·이력 보존을 확인합니다. 실제 사용자가 알림을 읽었는지는 자동 검사 성공과 구분합니다.
