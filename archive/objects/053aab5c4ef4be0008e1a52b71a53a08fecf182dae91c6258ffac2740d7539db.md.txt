# Codex Orbit 배포 안내

19차 / 버전2.4.1. 투명한 정사각형 위젯에 금속 곡면의 세 링·흑연 원자핵·전자 입자가 움직입니다. 실제 3D 메시·법선·깊이·반사 조명으로 제작한 18초 모션을 재생하며 각 링의 축·방향·속도는 독립적입니다. 화면은 변경 기록과 사용 한도만 남겼으며 설정·내 지침·도움말 UI는 제거했습니다. 이전17차는 보존합니다.

## 전달 파일

- CodexOrbit.exe: Windows10/11 x64 단일 실행 파일.
- CodexOrbit-Setup.exe: 현재 사용자 설치형. 설치 위치·시작 메뉴·선택 바탕화면 바로가기·제거 기능.
- 사용법.md/배포안내.md: 앱 밖 한국어 문서.
- 라이선스 및 소스와_재빌드.zip: 포함 구성 요소 라이선스와 재빌드 자료.
- 기본_지침.md: 개인 정보 없는 참고 지침. 앱 안 MD 적용 화면은 없으며 자동으로 적용하지 않습니다.

위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 로컬 Codex의 모델·추론 강도 선택 변경 기록을200ms 주기로 감지하며 각 알림을 독립 표시합니다. 최대8장 초과 시 오래된 창을 숨기고 최신을 즉시 표시하며 기록은 보존합니다. 정확한 제목·원문 모델ID·강도·공개 이유를 확인할 수 있습니다.

계정 잔량은 설치된 Codex App Server의 읽기 전용 account/rateLimits/read를30초마다 조회한 사용 한도 비율입니다. 토큰 개수가 아니며 없는 수치·이유를 만들지 않습니다. 실제 로그인은 설치된 Codex가 관리하고 이 앱은 인증 파일 직접 읽기·로그인·리셋·구매·모델 실행을 하지 않습니다.

기존 사용자 설정·MD·백업은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 감지 파일 수4096·레코드2MiB·주기별 읽기 예산, 화면 이력500건과 로그 순환 상한이 있습니다. 원격PC·클라우드·서버 모델 신원·비공개 추론·모든 부하에서의 무지연을 보장하지 않습니다. 상세한 동작과 진단 옵션은 사용법.md를 참고하십시오.

프로젝트 docs/운영_기억.md에 최신 운영 원칙을 보존합니다. 문서 저장이 계정 전역 AI 메모리 저장 또는 이미 열린 모든 대화의 지침 재주입을 뜻하지 않습니다. 앱은 사용자 설정·Codex 권한·인증·신뢰를 바꾸지 않습니다.

## 재빌드

requirements.txt의 의존성을 준비한 Python 환경에서 tools/build_distribution.py를 실행합니다. Inno Setup 컴파일러 경로는 CODEX_ORBIT_ISCC로 지정합니다. 배포 라이선스를 유지하고 SHA256.json을 확인하십시오. Python·PySide6·PyInstaller·Inno Setup이 필요하며 배포 EXE 실행에는 Python 설치가 필요하지 않습니다.

3D 원본과 제작 도구는 assets/atom3d 및 tools/render_atom3d.py에 포함합니다. 제작에만 필요한 의존성은 tools/requirements-3d.txt를 참고하십시오. 앱 실행에는 ModernGL·NumPy·Pillow 설치가 필요하지 않습니다. 중앙의 번호·기호·이름은 한국 날짜에 대응하는 원소이며, 실제 조회한 사용 한도 잔량은 아래 별도 표지에 표시합니다.

16차 수정: 모델·추론 변경의 이전값과 새값을 각각 구분해 표시합니다. 이전 기록이 없는 첫 관측은 실제 변경과 구분하며 과거값을 임의로 채우지 않습니다. 금속 원자 모션과 감시·계정 조회 및 보존 자료는 유지합니다.

17차 디자인: 실제3D 금속 원자 모델의 세 링이 서로 다른 축으로 움직이며 앱 상단과 알림도 같은 모션을 공유합니다. 기능 아이콘은 무채색 입체 표식으로 통일했습니다. 실행 위젯과 앱 안 로고는 움직이고 Windows 바로가기·실행파일·트레이 아이콘은 같은 모델의 정적 렌더입니다. 이전/새 모델과 추론 강도 및 실제 조회 수치의 의미는 유지합니다.

18차: 모델/추론 변경과 별도로 새 작업 배정·기존 작업 재개를 알립니다. 정확한 채팅·맡긴 일·확인된 공개 이유를 표시하고 없는 이유는 만들지 않습니다. 부드러운 색상과 카드로 내부 화면을 개선했습니다. 바탕화면은 기존3D형상을 유지하면서 한국 날짜1~31일에 맞춘 원소번호·기호·이름·디자인색을 표시하고 자정에 바뀝니다. 실제 잔량은 별도표시하며 원자번호와 혼동하지 않습니다. 26일은Fe철,27일은Co코발트,31일은Ga갈륨입니다. 색은 디자인 팔레트이며 실제 불꽃색/전자배치 시뮬레이션이 아닙니다.

19차(2026-10-26):원소와잔량을비겹침영역으로분리하고중앙원소가독성을높였습니다.기존투명정사각형/3D금속모션을유지하면서차가운은색·청색계열과SUIT글꼴로정돈합니다.실제사용한도와날짜별원소의의미및알림감지는유지합니다.사용자가글꼴변경을요청해이프로젝트19차는SUIT를사용하며실제글꼴파일과SUNN의SIL Open Font License1.1을함께포함합니다.공식출처:https://github.com/sun-typeface/SUIT/blob/main/LICENSE .이전18차는보존합니다.
