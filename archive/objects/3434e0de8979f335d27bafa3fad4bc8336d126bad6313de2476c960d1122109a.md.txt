# Codex Orbit 사용 설명 · 23차 / 2.7.0

크기를 조절할 수 있는 투명 바탕화면 위젯에서 날짜별 3D 조형이 움직이고, 클릭하면 모델·추론 강도 변경과 작업 배정·재개 기록을 확인합니다. SUIT 글꼴과 잉크 네이비 화면을 사용합니다. 이전 차수는 보존했습니다.

## 전달 파일

- `CodexOrbit.exe`: Windows 10/11 x64용 단일 실행 파일.
- `CodexOrbit-Setup.exe`: 현재 사용자 설치·시작 메뉴·선택 바탕화면 바로가기·제거 프로그램.
- `사용법.md`, `기본_지침.md`, 라이선스, `소스와_재빌드.zip`.

Python을 별도로 설치하지 않아도 실행합니다. 날짜별 실제 3D 모션에는 OpenGL 3.3을 지원하는 그래픽 드라이버가 필요합니다. GPU 준비 중에는 해당 월의 정적 표식을 보여 주며, 실패하면 사유를 표시합니다. 이때 정적 표식을 3D 성공으로 기록하지 않습니다. 감시·계정 조회는 3D 렌더와 분리됩니다.

## 매일 바뀌는 조형

한국 날짜 기준 2026-01-01부터 2099-12-31까지 27,028일을 지원합니다. 37개 주제 모티프와24개 동반 모티프의 서로 다른 쌍으로888개 연월 컬렉션을 구성하며 두 모티프와 날짜별 주연 대상을 실제 형상 규칙에 연결합니다. 같은12개 월 테마를 매년 반복하지 않습니다. 위젯에는 실제 대상 이름을 표시하며 월 테마는 카탈로그에 별도로 기록합니다. 공통 형상 생성기를 재사용하는 장식용 조형이며888개 수작업 모델이나 과학 도감 수준의 정확한 복제품이라는 뜻은 아닙니다. 전체 연월 목록은 함께 제공하는 `연도별_월_테마.md`와CSV, 원본은 `assets/calendar-art/themes.md` 및 `themes.csv`에서 확인합니다.

자정 이후 다음 프레임에 한국 날짜를 다시 확인하고 조형과 도크를 바꿉니다. 절전에서 복귀하거나 시계를 되돌려도 날짜를 재확인합니다. 수만 개 영상을 넣지 않고 그날의 실제 삼각형 메시만 렌더합니다. 두 궤도는 서로 다른 축과 속도로 움직입니다. 바탕화면과 내부 모션은 한 GPU 작업자·한 컨텍스트·최신 이미지와 정적 준비 이미지 두 장을 공유하며 초당 최대 30프레임입니다. 표시 대상이 없으면 렌더를 쉽니다. 날짜 카탈로그는 소스 ZIP의 `assets/calendar-art/catalog.json`에 있습니다.

## 변경 기록과 실제 한도

위젯에는 PC의 현지 시각을 초 단위로 표시하며, 인터넷 접속 IP의 대략적인 지역에서 현재 기온을 조회합니다. Windows 위치 서비스는 필요하지 않습니다. 지역 조회는 ipwho.is, 기온은 Open-Meteo의 최신 현재 기온 자료를 사용하며5분마다 자동 갱신합니다. 정확한 GPS 위치나 초 단위 현장 온도 센서 측정은 아니며 VPN·통신사망에서는 실제 지역과 다를 수 있습니다. 출처·조회 시각·네트워크 기반 지역은 툴팁에 표시하고, 조회 실패나 오래된 값은 정상 최신 기온으로 표시하지 않습니다. 앱은 IP·좌표·이동 이력을 저장하지 않습니다.

알림과 상세에서 모델 및 추론 강도를 각각 **이전 → 변경 후** 두 칸으로 표시합니다. 실제로 달라진 행만 강조합니다. 작업 배정·재개는 별도 종류이며 현재 설정을 표시합니다. 이전 기록이 없거나 필드가 미기록이면 사실대로 표시하고 과거 값을 추정하지 않습니다. 정확한 채팅 제목·맡긴 일·공개된 이유를 보존하며, 비공개 추론이나 확인되지 않은 선택 이유를 만들어 쓰지 않습니다.

잔량은 Codex App Server의 읽기 전용 `account/rateLimits/read`에서 조회한 계정 사용 한도 비율입니다. 남은 토큰 개수는 아닙니다. 30초마다 갱신하고 숫자·막대는 같은 실제 비율을 사용합니다. 0%는 빈 막대, 100%는 가득 찬 막대이며 최소 채움을 임의로 보태지 않습니다. 지연·미확인은 정상 잔량으로 채우지 않습니다. 사용 한도 화면은 큰 숫자, 비례 막대, 초기화·최종 조회 시각과 날짜별 입체 모션을 분리합니다.

## 사용 및 보존

위젯은 드래그로 이동하고 클릭하면 상세 기록을 엽니다. 오른쪽 가장자리를 끌면 폭, 아래쪽을 끌면 높이, 우하단 모서리를 끌면 두 크기를 함께 조절합니다. 크기와 위치는 저장되며 화면 밖에 있으면 복구합니다. 기본220×300·최소180×210이고, 조형과 이름·날짜·현재 시각·기온·실제 잔량은 독립 영역입니다. 기존에 저장한 크기는 보존합니다. 이름은 최소16픽셀로 유지하고 긴 이름은 줄을 바꿉니다. 로컬 선택 설정을 200ms 주기로 관측하며 알림은 각각 표시됩니다. 최대 8장 이후에는 오래된 창을 숨기고 기록은 보존합니다. 최초 실행은 기존 기록을 기준선으로 읽고 과거 알림을 쏟아내지 않습니다. 파일 수 4096개, 레코드 2MiB, 주기별 읽기 예산과 화면 이력 500건의 상한을 유지합니다. 원격·클라우드·서버 모델 신원·비공개 추론 또는 모든 부하에서 무지연을 보장하지 않습니다.

기본 데이터는 현재 사용자의 `%LOCALAPPDATA%/CodexOrbit`입니다. 기존 설정·사용자 MD·백업과 이력을 보존합니다. 설정·내 지침·도움말 탭은 사용자 요청에 따라 노출하지 않으며, 내장 MD를 몰래 적용하지 않습니다. 문서 저장은 계정 전역 메모리나 다른 채팅의 지침 재주입을 의미하지 않습니다. 인증·신뢰·보안 설정을 바꾸지 않습니다. 개인 대화·인증 파일은 배포본에 포함하지 않습니다.

## 재빌드

`requirements.txt`의 고정 의존성을 준비하고 `tools/build_distribution.py`를 실행합니다. `CODEX_ORBIT_ISCC`에 Inno Setup 컴파일러 경로를 지정합니다. 배포 파일의 SHA256.json과 라이선스를 보존하십시오. ModernGL·glcontext·NumPy·Pillow·PySide6는 EXE에 포함되며 별도 사용자 설치가 필요하지 않습니다. 제작 및 검증 도구는 소스 ZIP에 있습니다. Windows 바로가기·트레이·실행파일 아이콘은 운영체제 형식상 정적이며, 실행 위젯과 내부 조형은 움직입니다.

## 데이터와 진단 상세


설정·MD·도움말 UI를 노출하지 않습니다. 기존 설정과 사용자 MD·백업은 삭제하거나 초기화하지 않습니다. 지침을 몰래 적용하지 않습니다. 앱 밖 운영 기록은 프로젝트 docs/운영_기억.md에 보존하며 계정 전역 메모리 저장이나 모든 대화의 지침 재주입을 뜻하지 않습니다.

기본 앱 데이터는 현재 사용자의 LocalAppData/CodexOrbit입니다. 감시 경로와 Codex 실행 파일은 기존 설정 및 자동 탐색을 사용합니다. 별도 감시 경로가 필요한 실행에는 --sessions 경로, 독립 데이터에는 --data-dir 경로를 지정할 수 있습니다. 공유할 때 개인 대화·계정·원본 사용자 데이터는 배포 파일에 포함하지 않습니다.

감시는 현재 설정된 sessions 디렉터리와 대응 session_index.jsonl의 로컬 기록 범위입니다. 다른 PC·원격·클라우드, 로컬에 기록되기 전 UI 선택, 서버 내부 모델 신원과 비공개 추론은 보장하지 않습니다. 파일 수4096개·레코드2MiB·주기별 읽기 예산이 있으며 상한/잘못된 기록은 진단에 남깁니다. 화면 이력은 최근500건입니다. startup.jsonl과 notice-presentations.jsonl은2MiB 순환 상한의 운영 기록이며 표시 요청은 사용자 실제 열람 인증이 아닙니다.

## 배포와 진단

CodexOrbit.exe는 Python 설치 없이 실행합니다. CodexOrbit-Setup.exe는 현재 사용자용 설치·시작 메뉴·선택 바탕화면 바로가기를 제공합니다. 제거 프로그램은 사용자 MD·백업·이력을 삭제하지 않습니다. 소스ZIP과 라이선스도 함께 제공합니다. 이 사용법은 배포 문서이며 앱 내부 도움말 탭은 없습니다.

--smoke-test --smoke-report 경로는 실제 EXE의 프레임 변화·투명 모서리·내장 글꼴을 검사하고 종료합니다. --usage-smoke-test는 실제 계정 조회·화면 표시를 저장하는 별도 진단이며 실제 사용자 알림 수신 증거는 아닙니다. --show-event 이벤트ID 또는 대상ID는 기존 이력을 다시 표시하며 새 관측이나 실행 중 앱에 명령 전달을 만들지 않습니다.



22차 실행 자산 정리: 예전 원소 영상팩31개는 이전 차수와 소스 ZIP에 보존하며, 현재 달력 GUI에서 쓰지 않아 새 EXE에는 포함하지 않습니다. 소스 ZIP은 설치 파일과 별도로 제공합니다. 설치본은 실행 파일·사용법·라이선스·연도별 월 테마표를 설치합니다. 현재 달력과 원본 브랜드·기능 아이콘에 필요한 자산 검사는 유지합니다.
