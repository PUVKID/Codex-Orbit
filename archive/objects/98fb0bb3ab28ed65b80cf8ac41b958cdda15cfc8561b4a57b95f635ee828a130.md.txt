# Codex Orbit 배포 안내

투명한 회전 궤도 위젯으로 로컬 Codex의 모델·추론 강도 변경을 확인하는 Windows 10/11 x64 앱입니다.

## 받는 사람에게 전달할 파일

- `CodexOrbit.exe`: Python 설치 없이 실행하는 단일 파일입니다. 기본 지침, 사용법, 글꼴이 내장되어 있습니다.
- `CodexOrbit-Setup.exe`: 현재 사용자용 설치본입니다. 설치 위치를 선택하고 시작 메뉴 바로가기와 제거 기능을 사용할 수 있습니다.
- `기본_지침.md`: 개인 정보가 빠진 배포 기본 지침입니다. 자신의 MD를 대신 가져와도 됩니다.
- `사용법.md`, `배포안내.md`: 한국어 사용 문서입니다.
- `라이선스/`, `소스와_재빌드.zip`: 포함 구성 요소의 라이선스와 소스·재빌드 자료입니다. 재배포할 때도 함께 전달하십시오.

## 시작과 MD 적용

앱을 켜면 작은 회전 위젯이 나타납니다. 끌어서 옮기고 클릭해서 상세 창을 여십시오. 처음에는 기존 기록을 기준선으로 읽으며 과거 알림을 쏟아내지 않습니다. 새 기록을 처리하기까지 파일 크기에 따라 시간이 걸릴 수 있습니다.

MD 탭에서 지침을 가져오거나 편집하고 적용 대상 AGENTS.md를 선택합니다. 미리보기를 확인하고 적용 버튼을 누릅니다. 기존 내용은 백업하고 관리구역만 갱신합니다. 다른 프로그램이 파일을 변경하면 적용·원복을 거부하여 그 변경을 보호합니다. 다른 사람에게 윤석님의 원본 MD를 줄 때는 개인 이름·절대 경로·프로젝트·민감 정보부터 확인하십시오.

MD 파일 적용은 Codex의 설정·권한·인증을 바꾸거나 이미 열린 모든 채팅에 지침을 재주입하는 기능이 아닙니다. 새 채팅이나 해당 프로젝트를 다시 여는 시점의 지침 읽기를 통해 적용 여부를 확인하십시오. 앱은 모델 자체를 변경하지 않습니다.

## 기록과 한계

감시 대상은 현재 사용자의 CODEX_HOME 또는 기본 .codex/sessions입니다. 설정에서 경로를 바꿀 수 있습니다. 로컬 기록이 생성되어야 변경을 관측할 수 있으므로 설정 화면을 누르는 순간과 감지 시각은 다를 수 있습니다. 변경 이유가 명시적으로 연결되지 않으면 확인 불가로 표시합니다. 서버 실행 모델 인증과 비공개 내부 사고과정은 제공하지 않습니다. 표시되는 추론 정보는 기록된 추론 강도와 공개 변경 이유입니다. 네트워크로 대화나 MD를 보내지 않습니다.

사용자별 앱 데이터와 이력은 사용자 데이터 폴더에 보존됩니다. 설치본 제거는 프로그램 파일과 바로가기를 제거하며 앱이 적용한 지침·백업·이력을 자동 삭제하지 않습니다.

## 라이선스와 재빌드

Python, PySide6/Qt, PyInstaller와 나눔고딕을 사용합니다. 나눔고딕은 SIL OFL, PySide6/사용 Qt 라이브러리는 LGPLv3 등 각 구성 요소 라이선스를 따릅니다. Qt 수정본 분석과 교체를 막는 제한을 추가하지 않습니다. 함께 제공한 소스에서 `python -m venv work/venv`, 가상환경의 `python -m pip install -r requirements.txt`로 환경을 준비하고 `python -m PyInstaller --onefile --windowed --name CodexOrbit --add-data "assets;assets" --paths src src/app.py`로 재빌드할 수 있습니다. 다른 호환 PySide6/Qt를 설치한 뒤 같은 소스로 재빌드해 교체할 수 있습니다. 설치본 재빌드는 Inno Setup 6.7.3의 ISCC로 `tools/installer.iss`를 컴파일합니다. 자세한 구성과 고정 버전은 소스 압축 안 requirements.txt와 tools/build_distribution.py에 있습니다.

프로그램은 코드 서명 인증서 없이 제작한 배포본입니다. 사용자 PC의 보안 검사 결과나 실행 허용을 보장하지 않으며 보안 기능을 끄지 않습니다.
