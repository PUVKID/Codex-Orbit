# 무채색 입체 모션과 전체 화면 개선 계획

목표: 현재 궤도 모양을 유지하면서 무채색·1:1·입체 회전·모션 잔량으로 바꾸고 내부 모든 화면과 대화상자를 일관되게 정리합니다.

사용자는 설명 승인 단계를 반복하지 말고 실제 수정·배포하라고 이미 지시했습니다. 이번 상세 요구에 따라 기존 Python/PySide6/QPainter 구조로 직접 구현합니다. ‘ㄷㅌㄷ’은 한글 입력 상태의 EXE로 해석했습니다. 새 이미지 생성보다 코드로 움직이는 벡터가 적합하며, 이전 5차는 보존합니다.

## 선택한 구성

- 색상은 검정·회색·흰색만 사용합니다. 기본 나눔고딕 Bold700과 내장 글꼴·라이선스를 유지합니다. 운영체제·Codex 자체 글꼴과 설정은 바꾸지 않습니다.
- 떠 있는 캐릭터는 148×148 투명 캔버스 안에서 외곽이 매 프레임 1:1입니다. 현재 세 궤도 구조를 보존하고 실제 3차원 좌표 회전·원근 투영·깊이 정렬·금속 명암으로 평면 회전과 구분합니다. 굵은 링의 앞뒤 가림과 하이라이트가 움직여야 합니다.
- 가운데 잔량 허브도 원형 1:1로 하고, 검증된 숫자는 즉시 정확하게 표시합니다. 장식적 눈금·진행 링·빛 이동과 전환을 애니메이션으로 표현하되 중간 애니메이션 값을 실제 계정 수치로 가장하지 않습니다. 미확인·지연은 별도 모양과 문구로 구분합니다.
- 정적 EXE 아이콘은 같은 무채색 캐릭터를 정사각형 ICO 여러 해상도로 렌더합니다. 바탕화면 바로가기의 이름·경로는 실제 현재 경로를 조사한 뒤 이 앱에 해당하는 항목만 갱신합니다.
- 상세·이력·원문 펼침·잔량·설정·MD 편집/미리보기/백업/원복·도움말·말풍선·우클릭 메뉴·파일 선택·성공/오류 창까지 검사합니다. 앱이 소유하는 창과 대화상자는 무채색 테마와 현대적 간격·스크롤·명확한 버튼으로 통일합니다. 운영체제 보안·인증 UI는 조작하거나 꾸미지 않습니다.
- 채팅 제목·공개 이유·추론 강도·모델의 정확성, 감시·FIFO·저장 복구·MD 안전장치와 계정 조회 경계는 유지합니다. 비공개 사고과정을 수집하지 않습니다.

## 파일과 책임

구현자는 `src/app.py`, 필요한 `src/visuals.py` 또는 `src/theme.py`, 관련 `tests/`, 무채색 아이콘 생성 도구와 `assets/Orbit.ico` 및 사용법을 소유합니다. 부모는 계획·상태·증거·빌드/설치 도구와 실제 배포를 소유합니다. 일반 UI 분리는 필요한 단위만 하고 무관한 구조를 정리하지 않습니다.

## 실행 순서와 검토 기준

- [ ] 기존 화면/대화상자와 색상·아이콘·위젯 경계를 조사하고 실제 기록 3건을 보존합니다.
- [ ] 1:1/무채색/시간별 3D 변화/잔량 수치 정확성·지연 구분과 대화상자 테마의 관련 실패 검사를 먼저 기록합니다.
- [ ] 입체 렌더·중앙 잔량 모션·아이콘과 전체 테마를 구현합니다.
- [ ] 버튼·체크·선택·스크롤·원문/작은 창·파일 선택/취소·성공/오류·MD 원복 흐름을 실제 위젯으로 검토합니다. 기본 및 작은 창에서 글자 잘림이나 가로 스크롤이 없어야 합니다.
- [ ] 전체 기존 검사와 추가 검사를 실행합니다. 중앙 기능30초/소스15초/총45초와 기존 시작5초·종료8초의 검증을 유지합니다. 단위 GUI는 offscreen, 실제 Windows 배포는 별도 범위로 검증합니다.
- [ ] 별도 verifier Sol/high가 최종 동결 소스·실제 기록 3건·화면·아이콘·배포와 MD를 직접 검증합니다.
- [ ] 단일 EXE·설치본·소스 ZIP을 6차에서 빌드하고 실제 실행·설치·제거와 잔량을 대조합니다. 이전 사용자 데이터·MD와 백업을 보존합니다.

## 화면 제어 도구의 현재 한계

공식 `computer-use` 초기화는 node_repl의 `failed to write kernel assets ... os error 3`로 실행 전에 실패했습니다. 공식 reset 후 재시도도 같은 오류였습니다. 이를 직접 클릭 성공으로 표현하지 않습니다. 복구 불가 시 실제 운영 화면 조작과 별도 앱/격리 Qt 검사의 증거를 명확히 구분합니다. 임의 OS 입력이나 보안·인증 우회로 대체하지 않습니다.
