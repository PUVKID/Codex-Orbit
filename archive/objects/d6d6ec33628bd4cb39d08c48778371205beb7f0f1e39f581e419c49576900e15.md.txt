# 27차 공개용 변경 기록

기준: 26차 공개본 커밋 `7e2821ad78c85f46a131fda6f32bf82a1beee950`. 27차는 공개 전달 문서 정리이며 앱 버전 2.10.0을 유지합니다.

## 실제 추가·수정 범위

| 구분 | 파일 | 변경 |
| --- | --- | --- |
| 수정 | `README.md` | 앱 설명·검증된 배포본의 다운로드 복구 안내·빠른 이동을 앞에 배치하고 차수 링크를 상대 경로로 연결했습니다. 27차 문서 행을 추가하고 공개하지 않는 전체 소스 ZIP 안내를 정정했습니다. |
| 수정 | `README.en.md` | 한국어 안내·사용법·검증·차수·라이선스 연결, 앱 목적과 검증된 배포본의 다운로드 복구 안내를 추가하고 속도 안내의 누락 공백을 보완했습니다. |
| 수정 | `CHANGELOG.md` | 새 기능으로 오인하지 않도록 27차 문서 변경과 검증 범위 설명을 추가했습니다. |
| 수정 | `VERSIONS.md` | 별도 앱 소스 없는 27차 설명과 직전 변경 기록을 연결하고 20차·최종 소스 부재를 명시했습니다. |
| 수정 | `history/26/README.md` | 속도 조절·저장 실패 복원·위상 연속성을 설명하고 실제 검증 요약을 연결했습니다. 기존 소스 전체 비교는 보존했습니다. |

| 수정 | `공개범위.md` | 비공개 전체 ZIP과 GitHub 자동 공개 소스 ZIP, Release 첨부 범위를 구분했습니다. |
| 추가 | `변경기록_27차.md` | 이번 로컬 공개용 변경 기록입니다. |

공개용 배포 안내 `docs/DOWNLOADS.md`, `docs/사용법.md`, `docs/Usage.en.md`와 전체 diff `docs/27차_전체변경.diff`도 이번 추가 범위입니다. Release 첨부용 라이선스 묶음·해시 목록은 동결 명세와 배포 영수증에서 확인합니다.

앱 `src/` 23개·기존 tests·assets·의존성·EXE·설치본은 이 문서 작업에서 수정하지 않습니다. 삭제 파일은 없습니다. 한 줄·공백·개행까지 포함한 [공개 묶음 전체 diff](docs/27차_전체변경.diff)는 동결 단계에서 저장하며 파일별 해시와 원격 일치는 별도 영수증으로 확인합니다. diff 파일 자체의 해시는 후속 영수증에 기록해 자기 참조를 피합니다. 26차 [소스 diff](history/26/직전차수.diff)와 [파일 명세](history/26/공개파일_비교.json)는 25→26 비교입니다.

## 검증·제외·반영 상태

26차 검사 근거와 현재 한계는 [공개 검증 요약](docs/공개검증_26차.md)에 있습니다. 27차는 문서 변경에 필요한 UTF-8·링크·전체 비교·공개 안전성 검토를 수행하고 공식 공개 완료 검사로 후속 원격 일치를 확인합니다. 이 변경 기록 작성 시점에 새 독립 검증·원격 게시 성공을 확정하지 않습니다.

개인 대화·지침·메모리·인증·위치·실제 계정 수치·원본 운영 로그·비공개 전체 소스 ZIP은 제외합니다. 논문·원고를 추가하는 작업이 아니므로 새 PDF는 만들지 않습니다. 공개 다운로드를 복구하며 이전 원격 접근 관측과 남은 절차는 [27차 재검증 기록](docs/GitHub재검증_27차.md)에 있습니다. 푸시와 원격 확인 후의 커밋·시각·일치 결과는 별도 로컬 영수증에 보존합니다.
