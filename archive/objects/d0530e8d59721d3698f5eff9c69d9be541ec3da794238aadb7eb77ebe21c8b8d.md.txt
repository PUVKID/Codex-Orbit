# 25차 한글 위치와 4K·240fps 구현 계획

작성: 2026-10-30. 사용자가 240프레임을 초당240으로 명확히 답변했습니다. 이전 자율 구현 승인 유지. 기존24차 완료본은 수정하지 않고25차에 구현합니다.

목표: 위치를 한글로 표시하고 실제3840×2160 GPU 렌더와 초당240프레임 목표를 적용합니다. 실제 측정이 미달하면 수치를 숨기거나 설정값을 실측으로 표현하지 않습니다. Windows 화면 합성·모니터 주사율은 별도입니다.

기존 원인: calendar_motion FPS30/SIZE384, OrbitWidget20ms 갱신, renderer는 정사각size 및 CPU전체readback. 이 값만240/3840으로 바꾸면 메모리전송·대기부하가 커집니다.

접근: 기존ModernGL GPU작업자1개·최신이미지1개·투명Qt창과 날짜3D자산을 유지합니다. 렌더러에3840×2160 실제타깃과 종횡비보정 및 GPU축소전달 경로를 추가합니다. 원본해상도와위젯전달해상도·실측렌더율을구분합니다. 전체4K원본반환도검증용으로지원하고작은위젯은정사각중앙영역을왜곡없이축소합니다. 사용자크기가커지면그에맞춰전달해상도가따라가야합니다. 240fps는monotonic시간기준1/240초페이싱과실제프레임도착연계화면갱신으로구현합니다. busy-spin·기록무한누적·전체화면자동변경금지.

한글위치: 무료서비스가한국어를지원하는지공식문서로확인하고유료기능에의존하지않습니다. native가한국어면사용할수있으나없는경우국내시도/도시의검증된한글매핑과국가정보를이용합니다. 알수없는지명은임의번역하지않으며정확도가불명확한추정과원문을툴팁에서구분합니다. 외국지역도한국지역으로거짓표시하지않습니다. IP·좌표저장금지/현재비동기타임아웃/오래된값처리유지.
