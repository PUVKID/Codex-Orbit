## 35차·색상과 조명

화면 위쪽 **화면 테마**에서 시스템·라이트·다크를 선택합니다.  
옆의 **색상 꾸미기**를 누르면 여섯 가지 색 조합을 고르거나 포인트색·다크 배경·라이트 배경의 색상 코드를 직접 입력할 수 있습니다.  
색 선택 버튼도 제공합니다.

조명 강도는 0부터 100까지 조절하며 **0은 조명 끄기**입니다.

미리보기의 다크·라이트 선택은 미리보기만 바꿉니다.

**적용**해야 저장되며 **취소**하면 기존 설정을 유지합니다.

기본값 복원도 적용 전에는 저장하지 않습니다.

잘못된 색상 코드에는 설명을 표시하고 적용을 막으며, 저장 실패 시 이전 설정과 화면을 복원합니다.

입력한 원색은 보존하고 글자색은 읽기 좋게 보정합니다.  
날짜별 과일·꽃·기념일·도시 행사와 픽셀 입체 회전은 유지합니다.  
잔량 막대의 실제 비율·원값, 자동·수동 위치, 모델·추론·작업 재개 알림도 그대로 사용합니다.  
조명은 화면 전체 흐림이나 별도 애니메이션 타이머를 추가하지 않습니다.

**3.5.0은 정식 배포 본**입니다.

EXE·Setup 생성과 기본 실행의 최소 확인, 합성 화면 세 조합 완료와 네 번째 자동 검사 미완료, 설정 검사 시간 초과를 [검사 범위와 배포 상태](../docs/35차_최소검사.md)에서 구분합니다.

사용자는 150% 배율의 실사용이 정상이라고 직접 확인했습니다.

이는 자동 검사 전체 통과와 구분합니다.


## 34차·픽셀 입체 조형

날짜별 과일·꽃·기념일과 도시 행사 주제를 유지하면서 실제 입체 모형의 픽셀 표현을 표시합니다.

모형은 세로축을 중심으로 한 바퀴 회전하며, 지명·기온·강수량·잔량과 알림 글자는 또렷하게 표시합니다.

위치는 자동·수동을 고르고 기본 화면에는 지명을 간결하게 표시합니다.

백분율 요약은 소수 첫째 자리 반올림이며 원값은 툴팁에서 확인합니다.

## 지역·날씨와 도시 행사

위치는 자동 네트워크 추정이 기본입니다.  
지역 선택 창에서 자동·수동을 명확히 고릅니다.  
수동 검색이나 취소만으로 저장하지 않으며, 자동 모드로 돌아가면 이전 수동 위치를 해제하고 다시 조회합니다.  
국가만 고르면 행사 기준만 바뀌고 날씨 지역은 유지됩니다.  
네트워크 추정은 GPS나 건물 주소가 아닙니다.

습도 옆에는 강수량(mm)과 제공 자료의 실제 직전 집계 간격을 표시합니다.  
실제 0 과 미확인(—)을 구분하고, 오래된 값은 이전 정보로 표시합니다.  
일출·일몰은 제공 지역의 시간대를 유지합니다.

화면 위의 선택 영역에서 언어·화면 테마(시스템/라이트/다크)·글자 크기를 바꿀 수 있습니다.

테마는 즉시 적용되고 저장되며, 시스템은 운영체제의 테마 변화를 따릅니다.

왼쪽 작업 현황에서 기록된 작업과 선택 설정·최근 실행에서 확인한 값을 구분해 봅니다.

화면 설정에는 움직임 줄이기·화면 가장자리에 붙이기·알림 소리·성능과 화질·문제 확인용 파일 저장·새 버전 확인이 있습니다.

프라이버시 모드는 화면에서 채팅 제목과 작업 설명을 가리며 저장된 기록은 그대로 유지합니다.

기존 월별 주제와 날짜별 대상은 유지하고, 날짜 위젯의 고리와 좌우 보조 장식은 제거했습니다.

당일 대상 하나를 입체로 표시합니다.

투명한 바탕 화면에서 당일의 3D 대상 하나가 움직이며, 로컬 Codex의 모델·추론 강도 변경과 작업 배정·재개를 알려 줍니다. 개인 기록은 이 컴퓨터에 저장합니다.

## 도시 축제와 발표 일정

지역 설정의 ‘축제 목록·출처’에서 선택 도시 또는 추정 도시의 수록 항목과 발표 일정을 구분해 봅니다.

전체 항목에는 검증된 행사 시리즈, 개최 회차, 아직 분류되지 않은 항목이 함께 있으며 시리즈 수로 부풀리지 않습니다.

이름이나 가까운 좌표만으로 도시를 만들어 연결하지 않습니다.

주소·장소에 검증된 도시 식별자가 없으면 목록 지원 범위가 미확인으로 표시될 수 있습니다.

실제 발표된 정확한 날짜에만 음악·영화·눈·빛·카니발·꽃·문화·열 기구의 8가지 입체 모티프를 적용합니다.

주요 고정 특집은 유지합니다.

모든 개별 축제의 독립 수작업 모델이나 미발표 미래 개최 일을 보장하지 않습니다.

발표 일정의 날짜·출처·라이선스를 확인할 수 있고 ‘일정 새로 고침’은 검증된 국가 자료를 받아 같은 도시·날짜에도 새 자료를 반영합니다.

연결·검증 실패 시 기존 자료를 유지하고 상태를 표시합니다.

목록은 전 세계 모든 도시 행사의 완전한 사전이 아닙니다.


화면 위의 선택 영역에서 언어·화면 테마(시스템/라이트/다크)·글자 크기를 바꿀 수 있습니다.

## 시작

1. 단일 `CodexOrbit.exe`를 실행하거나 `CodexOrbit-Setup.exe`로 현재 사용자에게 설치합니다. 둘을 동시에 같은 데이터 폴더에서 실행하지 않습니다.
2. 위젯을 클릭하면 기록과 실제 계정 사용 한도가 열립니다. 드래그로 이동하고 오른쪽·아래 가장자리로 크기를 조절합니다.
3. 첫 감시는 이전 기록을 기준선으로 읽습니다. 이후 새 변경을 알립니다. 선택 설정과 실행 관측은 서로 구분합니다.

## 알림 읽기

채팅 제목에는 장식 이모지를 붙이지 않습니다. 표시만 정리하며 Codex의 원래 제목을 바꾸지 않습니다.

- 채팅 제목
- ⬅️ 이전 모델 / 이전 추론 강도
- ➡️ 현재 모델 / 현재 추론 강도
- 💡 쉬운 이유

☀️ Sol·✨ Astra·🌍 Terra·🌙 Luna를 정확한 모델 ID와 함께 표시합니다.

추론 강도는 ⚪ 없음·💧 최소·🌱 낮음·⚖️ 보통·🔥 높음·🚀 매우 높음·⚡ 최고로 구분합니다.

기록되지 않은 이전 값이나 이유는 만들어 쓰지 않습니다.

공개된 배정 설명은 설명으로 표시하며 비공개 사고 과정을 보여 준다고 주장하지 않습니다.

새 변경은 독립 알림으로 바로 표시합니다.  
마우스를 올리면 자동 닫힘이 멈추고, 📌 고정하면 계속 남습니다.  
☆ 기록 보관으로 북마크할 수 있습니다.  
닫아도 이력은 남습니다.  
화면에 표시할 수 있는 새 알림 상한을 넘긴 이력은 기록에서 확인합니다.

## 입체 관측소

- Sol은 태양, Astra는 결정, Terra는 구체, Luna는 초승달 코어입니다. 모델이 미확인이면 중립 코어를 사용합니다.
- 실제 로컬 기록에서 확인한 작업자는 위성으로 표시합니다.  
  위성이나 작업 목록을 누르면 해당 채팅 기록을 엽니다.  
  ★ 관심 채팅은 우선 궤도에 표시합니다.  
  위성은 최대 24개이며 나머지 도 목록에서 확인합니다.
- 진행·완료·응답 대기·오류·중단은 명시된 기록이 있을 때만 표시합니다. 확인되지 않은 작업을 진행 중이나 완료로 추정하지 않습니다.
- 이전/현재 값은 같은 비중으로 표시하고 실제 바뀐 값만 강조합니다. 선택한 설정과 실행 중 관측한 설정은 구분합니다.
- 슬라이더는 저장된 기록을 재생합니다. 실제 Codex 모델이나 추론 강도를 되돌리는 기능이 아닙니다.
- 자리비움 이후 기록 수와 보관한 기록을 확인할 수 있습니다. 채팅 직접 이동은 지원이 확인되지 않아 ID 복사를 제공합니다.

## 화면 조작

기록창의 조작줄과 위젯 우클릭에서 언어·회전 속도·관측소/달력 모드·일시정지·모션 축소·자원 사용을 조절합니다.  
**글자 크기는 위젯 크기와 별도로** 바꿉니다.  
좌측에서 입체 관측소·변경 기록·사용 한도를 선택해 작은 창에서도 각 화면을 넓게 볼 수 있습니다.

절전·균형·고화질은 자원 사용 상한을 조절합니다.  
고품질 원본 렌더는 3840×2160이며 실제 표시 크기에 맞게 전달합니다.  
초당 240 프레임 달성을 보장하거나 새로 실험하지 않습니다.  
모션을 정지해도 감시·알림·시계는 계속 동작합니다.

가장자리 도킹을 켜고 화면 좌우 끝에 두면 작은 손잡이로 접히며, 마우스를 올리면 펼쳐집니다. 화면 연결이 달라지면 보이는 영역으로 위치를 보정합니다.

프라이버시 모드는 제목·작업 설명을 이미 열린 알림과 상세창까지 즉시 가립니다.  
저장 원문을 삭제하지 않습니다.  
알림음은 기본 꺼짐이며 종류별 운영체제의 짧은 소리를 선택적으로 사용합니다.

## 실제 사용 한도·날씨·시계

잔량은 설치된 Codex의 로그인 상태에서 조회한 **계정 사용 한도 비율**입니다.  
정확한 남은 토큰 개수가 아닙니다.  
숫자와 막대, 관측소의 입체 용기로 표시합니다.  
미확인은 0%와 다르며, 오래된 값은 조회 상태와 함께 구분합니다.

위젯의 지역 표시를 눌러 도시·지역, 주소·장소 또는 국가를 검색하고 결과에서 직접 선택합니다.

도시·장소를 고르면 해당 지점의 현재 기온·날씨·습도·일출·일몰을 네트워크로 받습니다.

국가만 고르면 디자인 국가만 바꾸고 날씨 기준 지역은 별도로 표시합니다.

자동 위치는 IP 기반 추정이므로 VPN·통신망에 따라 다른 도시가 나올 수 있습니다.

Windows 위치 서비스를 켤 필요가 없습니다.

상세 주소는 검색 결과에 있는 정보만 표시하며 실제 건물 위치를 자동으로 보장하지 않습니다.

날씨는 선택 좌표 주변의 기상 자료이며 건물마다 별도의 실측 기온을 제공하는 것은 아닙니다.

연결 실패와 오래된 값은 갱신 상태로 구분합니다.

## 날짜별 조형

달력 모드는 2026~2099년의 888개 연 월 주제와 날짜별 대상 조형을 사용합니다. [전체 월 테마](../docs/연도별_월별_테마_전체.md)와 CSV를 확인하십시오.

날짜별 조형은 규칙에 따라 생성되며 27,028개의 개별 수작업 모델 파일이 있다는 뜻이 아닙니다.

선택 도시와 디자인 국가가 일치하고 날씨 응답에서 시차가 확인되면 해당 현지 날짜를 사용합니다.

국가만 선택해 시간대가 정해지지 않으면 한국 날짜 기준을 안내합니다. 250개 국가·지역의 공휴일과 지원 기념일에는 실제 행사 명과 특집 조형을 우선 합니다.

미래 법 개정이나 모든 도시 축제까지 확정한 자료는 아닙니다.

## MD·진단·업데이트

배포 폴더의 `기본_지침.md`는 공유 가능한 시작 자료입니다.  
개인 MD를 다른 사람에게 줄 때 대화·연락처·인증 값을 먼저 제외하십시오. 위젯이 Codex의 모든 채팅에 MD를 강제로 주입하거나 비공개 추론을 읽는 것은 아닙니다.  
Codex에 적용하려면 해당 프로젝트가 지원하는 지침 파일로 사용해야 합니다.

‘문제 확인용 파일 저장’은 대화·이벤트 원문·인증값·개인 경로를 제외한 허용 항목만 **로컬 파일**로 저장합니다. 자동 전송하지 않습니다.

‘새 버전 확인’은 공식 `PUVKID/Codex-Orbit` HTTPS 릴리스만 확인합니다.  
새 버전을 내려받아 SHA-256을 검증한 뒤 직접 설치·재시작할 수 있습니다.  
재시작 검사 실패 시 이전 실행 파일을 복구하며 개인 설정과 MD는 보존합니다.  
소스 실행에서는 배포 EXE의 설치 동작을 대신 수행하지 않습니다.

## 한계와 문제 확인

Codex에서 로컬로 공개하는 기록·설정만 관측합니다.  
서버 모델 신원이나 비공개 추론을 증명하지 않습니다.  
기록이 없는 이유·이전 값·작업 상태는 확인 불가로 표시합니다.  
감시가 중단되거나 복구되면 상태가 바뀔 때 한 번 알립니다.

필요 환경: Windows 10/11 x64, OpenGL 3.3 지 원 그래픽 드라이버. 개인 데이터는 사용자 AppData의 CodexOrbit 폴더에 유지하며 제거 프로그램은 개인 기록을 임의로 지우지 않습니다.  
출처·라이선스는 배포의 라이선스 폴더를 확인하십시오.
