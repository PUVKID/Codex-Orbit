# 모델·추론 강도 변경 알림 지침

모델 또는 추론 강도를 배정하거나 바꿀 때 사용자가 볼 수 있는 한국어 설명을 남겨 주세요.

- 대상 채팅 또는 작업 ID와 main/자식 작업 구분, 역할을 적어 주세요.
- 이전과 이후의 정확한 모델 ID와 추론 강도를 알려 주세요. 첫 배정은 이전 상태를 미배정으로 표시해 주세요.
- 확인한 요구, 실제 오류 또는 검증 지점과 선택 이유를 공개 가능한 근거로 설명해 주세요.
- 간결한 핵심 문장은 ‘이유:’로 명시하고 상세한 관측 근거와 구분해 주세요. 부모 채팅 제목과 자식 작업명을 구분해 주세요.
- 다른 모델의 새 작업자로 교체했다면 새 자식의 첫 배정과 기존 자식 내부의 모델 변경을 구분해 주세요.
- 파일 설정값, 도구 요청값, 로컬 실행 기록 관측, 서버 런타임 증거를 구분해 주세요. 확인하지 못한 값과 이유는 확인 불가로 적어 주세요.
- 전환 없이 같은 상태를 유지할 때 가짜 변경을 만들지 마세요.
- 사전 설명을 할 수 없었다면 확인 즉시 사후 안내하고 그 한계를 밝혀 주세요.
- 비공개 내부 사고과정이나 인증 정보는 수집하거나 공개하지 마세요.

이 문서는 안내 지침입니다. 저장만으로 열린 대화에 지침을 재주입하거나 다른 기기와 동기화하거나 권한을 늘리거나 모델을 자동 전환하지 않습니다. 시스템·개발자 지침과 실제 도구 지원·사용자 권한을 따릅니다.
